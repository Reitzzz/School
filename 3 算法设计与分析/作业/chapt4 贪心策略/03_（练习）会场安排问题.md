**题目描述**
假设要在足够多的会场里安排一批活动，并希望使用尽可能少的会场。设计一个有效的贪心算法进行安排。<br>
给定 $n$ 个活动，每个活动有一个开始时间 $s_i$ 和结束时间 $f_i$。**如果两个活动的时间不相交，则它们是相容的。求最多能安排多少个相容的活动**。

**输入格式**
第一行包含一个整数 $n$（$1 \le n \le 1000$），表示活动的个数。
接下来的 $n$ 行，每行包含两个整数 $s_i$ 和 $f_i$（$0 \le s_i < f_i \le 10000$），分别表示活动的开始时间和结束时间。

**输出格式**
输出一个整数，表示最多能安排的活动数量。

**输入样例**
```text
11
3 5
1 4
12 14
8 12
0 6
8 11
6 10
5 7
3 8
5 9
2 13
```

**输出样例**
```text
4
```

---

# 解决思路

### 1. 核心需求：区间最多不相交子集
这道题是经典的区间贪心问题。我们需要在众多可能重叠的时间区间中，挑选出数量最多的互不重叠的区间。

### 2. 贪心策略
我们应该选择哪一个活动作为第一个活动呢？
- 如果选择开始最早的，它可能持续很长时间，把后续的活动全挤掉了。
- 如果选择最短的，它可能正好卡在两个较好的活动中间。
- 正确的贪心策略是：**每次选择结束时间最早的活动。** 因为只有活动早点结束，留给后面活动的时间才越多，能容纳的活动数量也就越多。

### 3. 代码执行流程
1. 读取活动的数量和时间，将它们存入一个结构体数组（包含 `start` 和 `end`）。
2. 根据活动的**结束时间**进行升序排序。
3. 遍历排序后的活动列表，维护一个 `last_end` 变量记录上一个被选中活动的结束时间（初始为 -1）。
4. 如果当前活动的开始时间 $\ge$ `last_end`，则说明它与前面选中的活动不冲突，选中它，并将 `last_end` 更新为它的结束时间。
5. 最终统计选中的活动总数。

# 最终代码

```cpp
#include <bits/stdc++.h>

using namespace std;

// 定义活动结构体
struct Activity {
    int start;
    int end;
};

// 贪心策略：按结束时间升序排序
bool cmp(const Activity& a, const Activity& b) {
    if (a.end != b.end) {
        return a.end < b.end;
    }
    // 结束时间相同的话，开始时间晚的优先（区间更短）
    return a.start > b.start;
}

int main() {
    int n;
    if (!(cin >> n)) return 0;

    vector<Activity> activities(n);
    for (int i = 0; i < n; i++) {
        cin >> activities[i].start >> activities[i].end;
    }

    // 按结束时间进行排序
    sort(activities.begin(), activities.end(), cmp);

    int count = 0;
    int last_end = -1;

    // 遍历每一个活动
    for (int i = 0; i < n; i++) {
        // 如果当前活动的开始时间在上一选中活动结束之后，说明不相交
        if (activities[i].start >= last_end) {
            count++;
            last_end = activities[i].end; // 更新最后结束时间
        }
    }

    cout << count << "\n";

    return 0;
}
```
