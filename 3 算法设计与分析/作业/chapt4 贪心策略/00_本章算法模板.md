# 第四章 贪心策略模板

## 1. 贪心题下手顺序

1. 先找“每一步选什么最划算”。
2. 再确认选了之后不需要反悔。
3. 通常需要排序、堆、并查集等结构辅助。
4. 如果局部最优不一定推出整体最优，就不要硬套贪心，可能是 DP 或回溯。

## 2. 统计 + 自定义排序模板

### 识别信号

- 题目要求统计字符、数字、频率、次数。
- 输出要按“主关键字 + 次关键字”排序。
- 背景可能提到哈夫曼，但输出只要求频率表。

### 代码模板

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    char ch;
    int cnt;
};

bool cmp(const Node& a, const Node& b) {
    if (a.cnt != b.cnt) return a.cnt > b.cnt;
    return a.ch < b.ch;
}

int main() {
    string s;
    cin >> s;

    int cnt[26] = {0};
    for (char c : s) cnt[c - 'a']++;

    vector<Node> arr;
    for (int i = 0; i < 26; i++) {
        if (cnt[i] > 0) arr.push_back({char('a' + i), cnt[i]});
    }

    sort(arr.begin(), arr.end(), cmp);

    for (auto x : arr) {
        cout << x.ch << " " << x.cnt << "\n";
    }
    return 0;
}
```

### 易错点

- 不要被“哈夫曼编码”背景带跑，先看输出到底要什么。
- 频率相等时要按题目要求处理次关键字。
- 只输出出现过的字符。

## 3. Kruskal 最小生成树模板

### 识别信号

- 无向连通图。
- 要把所有点连起来。
- 要求总边权最小。
- 输入通常是边列表：`u v w`。

### 思路

1. 所有边按权值从小到大排序。
2. 依次尝试加入最短边。
3. 如果两个端点已经连通，加入会成环，跳过。
4. 如果不连通，选这条边并合并集合。
5. 选够 `n - 1` 条边结束。

### 代码模板

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Edge {
    int u, v, w;
};

bool cmp(const Edge& a, const Edge& b) {
    return a.w < b.w;
}

vector<int> parent_node;

int find_set(int x) {
    if (parent_node[x] == x) return x;
    return parent_node[x] = find_set(parent_node[x]);
}

bool unite(int a, int b) {
    a = find_set(a);
    b = find_set(b);
    if (a == b) return false;
    parent_node[b] = a;
    return true;
}

int main() {
    int n, e;
    cin >> n >> e;

    vector<Edge> edges(e);
    for (int i = 0; i < e; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }

    sort(edges.begin(), edges.end(), cmp);

    parent_node.resize(n + 1);
    for (int i = 1; i <= n; i++) parent_node[i] = i;

    long long ans = 0;
    int chosen = 0;

    for (auto edge : edges) {
        if (unite(edge.u, edge.v)) {
            ans += edge.w;
            chosen++;
            if (chosen == n - 1) break;
        }
    }

    cout << ans << "\n";
    return 0;
}
```

### 易错点

- 并查集初始化的是点，不是边。
- `n` 个点的生成树选 `n - 1` 条边。
- 边权和建议用 `long long`。

# 第五章 回溯法模板

## 4. 回溯通用模板

### 识别信号

- 要输出所有方案。
- 每一步都有多个选择。
- 选了之后继续试，不行就退回。
- 常见关键词：所有子集、全排列、组合、路径、方案数。

### 通用骨架

```cpp
void dfs(int depth) {
    if (到达完整解) {
        输出或更新答案;
        return;
    }

    for (每一个可选 choice) {
        if (choice 合法) {
            做选择;
            dfs(depth + 1);
            撤销选择;
        }
    }
}
```

### 回溯三件事

- 当前层含义：这一层在决定哪个元素/哪个位置？
- 递归边界：什么时候算一个完整解？
- 恢复现场：递归回来后有没有撤销选择？

## 5. 子集树：幂集模板

### 识别信号

- 从 `n` 个元素中选一些。
- 每个元素只有两种状态：选 / 不选。
- 总方案数是 `2^n`。

### 代码模板

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int choose_item[15];

void print_subset() {
    cout << "{";
    bool first = true;
    for (int i = n; i >= 1; i--) {
        if (choose_item[i]) {
            if (!first) cout << ",";
            cout << i;
            first = false;
        }
    }
    cout << "}\n";
}

void dfs(int k) {
    if (k == 0) {
        print_subset();
        return;
    }

    choose_item[k] = 0;
    dfs(k - 1);

    choose_item[k] = 1;
    dfs(k - 1);
}

int main() {
    while (cin >> n) {
        dfs(n);
    }
    return 0;
}
```

### 易错点

- 如果样例要求 `{}`, `{1}`, `{2}`, `{2,1}` 这种顺序，可以从 `n` 到 `1` 决定，并先不选再选。
- 子集内部降序输出，就从 `n` 到 `1` 扫。
- 多组数据用 `while (cin >> n)`。

## 6. 排列树：无重复全排列模板

### 识别信号

- 要输出 `1 ~ n` 的所有排列。
- 每个数字只能用一次。
- 总方案数是 `n!`。

### 代码模板

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int path[55];
bool used[55];
long long total_count = 0;

void dfs(int depth) {
    if (depth == n) {
        for (int i = 0; i < n; i++) {
            if (i > 0) cout << " ";
            cout << path[i];
        }
        cout << "\n";
        total_count++;
        return;
    }

    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true;
            path[depth] = i;

            dfs(depth + 1);

            used[i] = false;
        }
    }
}

int main() {
    cin >> n;
    dfs(0);
    cout << "Total=" << total_count << "\n";
    return 0;
}
```

### 易错点

- `depth == n` 才说明已经填满所有位置。
- `used[i]` 是判重关键。
- 想按字典序输出，就从小到大枚举 `i`。

## 7. 贪心和回溯的区别

| 题目特征 | 更像什么 |
|---|---|
| 每一步选当前最优，选完不用反悔 | 贪心 |
| 要连通所有点且总边权最小 | 最小生成树 |
| 要输出所有子集 | 子集树回溯 |
| 要输出所有排列 | 排列树回溯 |
| 要统计次数并排序输出 | 计数 + 排序 |
