**题目描述**
给定 $n$ 个作业，每个作业 $i$ 都有一个截止时间 $d_i \ge 1$ 和一旦在截止时间之前完成便可获得的利润 $p_i > 0$。<br>
**每个作业需要消耗 1 个单位的时间来执行，并且在任何给定的时刻，机器只能执行一个作业。<br>**
**如果作业 $i$ 在其截止时间 $d_i$ 之前或之时完成，我们就能获得利润 $p_i$；否则，利润为 0。<br>**
请设计一个贪心算法来安排作业的执行顺序，使得能获得的最大总利润。

**输入格式**
第一行包含一个整数 $n$（$1 \le n \le 1000$），表示作业的数量。
接下来 $n$ 行，每行包含两个整数 $d_i$ 和 $p_i$（$1 \le d_i \le 1000$，$1 \le p_i \le 10000$），分别表示每个作业的截止时间和利润。

**输出格式**
输出一个整数，表示能获得的最大总利润。

**输入样例**
```text
5
2 20
2 15
1 10
3 5
3 1
```

**输出样例**
```text
40
```

*(提示：在时刻 1 执行利润为 15 的作业，时刻 2 执行利润为 20 的作业，时刻 3 执行利润为 5 的作业。总利润：15 + 20 + 5 = 40)*

# 解决思路

### 1. 核心需求：价值最大化与时间槽分配
与“最优装载”（只看重量贪心）相比，这道题不仅要考虑利润大小，还受到时间的严格约束。这是一个带有“槽位占用”特性的贪心问题。

### 2. 贪心策略设计

这道题非常奇妙，它恰好对应了两种看待贪心的角度，它们殊途同归，最终达到的全局最优解是完全一致的：

**视角一（站在作业的立场）：**
我们的目标是总利润最大化。因此，直觉上，**应该优先安排利润最高的作业**。
然而，安排这个作业时，应该把它放在哪一个时间点呢？
- 如果把它安排在最前面（时刻 1），它可能会占用其他截止时间很紧的作业的唯一生存空间。
- 正确的分配策略是：**尽量“往后拖”**。对于任意一个作业，只要能在截止时间前完成即可。因此，我们应该从它的截止时间 $d_i$ 开始往前找，找到第一个空闲的时间槽把它塞进去，这样可以把前面的时间槽尽可能留给截止时间更紧的作业。

**视角二（站在时间槽的立场，倒推法）：**
时间从后往前流逝，对于每一个时间槽（从最晚的 deadline 到 1），去执行那个**当下能做的、利益最高**的作业。
- 我们从最晚的时间点 `max_d` 开始，倒着往回走，直到时刻 1。
- 对于每一个时刻 $t$，我们把**所有截止时间 $\ge t$ 且还没被执行的作业**全部扔进一个候选池里。
- 从候选池里挑出**利益最高**的那一个，安排在时刻 $t$ 执行。
- 剩下没被选中的作业**不要丢弃**，它们会自动保留在池子里，参与时刻 $t-1$ 的竞争。
这种思路如果配合“大根堆（优先队列）”可以达到 $O(N \log N)$。不过如果作业数量不多（比如 $N \le 1000$），我们完全可以直接使用最朴素的循环比较来实现这个思想，时间复杂度为 $O(N \times \text{max\_d})$。

### 3. 代码执行流程（按照视角二的思路，不使用优先队列）
1. 将所有作业存储到结构体数组中。
2. 找出所有作业中的最大截止时间 `max_d`，作为我们需要考虑的最晚时间槽。
3. 给每个作业增加一个 `executed` 标记，初始为 `false`，表示尚未被安排。
4. **时间槽倒推遍历**：从 `t = max_d` 往下循环遍历到 `1`。
   - 在每一个时刻 `t`，我们遍历一遍所有的作业。
   - 找出**尚未执行**、**截止时间 $\ge t$**，且**利润最大**的作业。
   - 如果找到了这样的作业，就标记它为已执行，并将它的利润累加到总和。
5. 输出最终累加的利润和。

# 最终代码

```cpp
#include <bits/stdc++.h>

using namespace std;

// 定义作业结构体
struct Job {
    int deadline;
    int profit;
    bool executed; // 记录是否已经被执行
};

int main() {
    int n;
    if (!(cin >> n)) return 0;

    vector<Job> jobs(n);
    int max_d = 0;
    for (int i = 0; i < n; i++) {
        cin >> jobs[i].deadline >> jobs[i].profit;
        jobs[i].executed = false; // 初始时所有作业都未执行
        if (jobs[i].deadline > max_d) {
            max_d = jobs[i].deadline;
        }
    }

    int total_profit = 0;

    // 视角二：站在时间槽的角度，从最晚的 deadline 倒推到 1
    // 不使用优先队列，每次直接遍历寻找当前能做的、利润最高的作业
    for (int t = max_d; t >= 1; t--) {
        int best_job_idx = -1;
        int max_profit = -1;

        // 寻找满足 deadline >= t 且还未执行的利润最高的作业
        for (int i = 0; i < n; i++) {
            if (!jobs[i].executed && jobs[i].deadline >= t) {
                if (jobs[i].profit > max_profit) {
                    max_profit = jobs[i].profit;
                    best_job_idx = i;
                }
            }
        }

        // 如果找到了这样一个作业，就在时刻 t 执行它
        if (best_job_idx != -1) {
            jobs[best_job_idx].executed = true; // 标记为已执行
            total_profit += jobs[best_job_idx].profit;
        }
    }

    cout << total_profit << "\n";

    return 0;
}
```
