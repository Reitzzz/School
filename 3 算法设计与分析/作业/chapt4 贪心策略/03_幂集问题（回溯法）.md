**题目描述**
集合是数学中一个重要的知识点，一个集合有 $2^n$ 个子集，现在的任务是给定一个大小为 $n$ 的集合，集合为 $\{1, 2, ..., n\}$，求出该集合的所有子集合。
子集合中所有元素降序排列，并按字典序输出，不同元素使用“,”隔开。
多组测试数据

**输入格式**
集合元素个数 $n, n<10$。

**输出格式**
所有子集合

**输入样例**
```text
2
3
```

**输出样例**
```text
{}
{1}
{2}
{2,1}
{}
{1}
{2}
{2,1}
{3}
{3,1}
{3,2}
{3,2,1}
```

# 解决思路

### 1. 核心思想：回溯法（子集树）
这道题目要求输出一个集合的所有子集，也就是求“幂集”。对于大小为 $n$ 的集合，每个元素都有“选”或“不选”两种状态，总共有 $2^n$ 种子集，这正对应了回溯法中的**子集树**模型。

### 2. 输出顺序的玄机（从 $n$ 到 $1$ 递归）
本题的难点在于**输出顺序的要求**。观察样例输出的规律：
* 当 $n=2$ 时，输出为 `{}`, `{1}`, `{2}`, `{2,1}`。
* 当 $n=3$ 时，前4个输出就是 $n=2$ 的结果，接着是将 `3` 加入到前4个结果中的组合：`{3}`, `{3,1}`, `{3,2}`, `{3,2,1}`。
这种生成顺序实际上类似于二进制数的递增，优先决定较大元素是否出现。

为了完美契合这种输出顺序，我们在设计回溯函数时，应该**从大到小（从 $n$ 递减到 $1$）去决定每个元素选或不选**，并且在每一次分支时，**先走“不选”的分支，再走“选”的分支**。
* 比如判断元素 $k$ 时：
  1. 标记 $k$ 为不选，递归去判断 $k-1$。
  2. 标记 $k$ 为选中，递归去判断 $k-1$。
* 当递归深度到达 $0$ 时（所有元素都已做完决定），即可进行一次输出。

### 3. 降序排列与格式控制
* 题目要求子集内的元素按**降序排列**，这恰好符合我们定义集合 $\{1, 2, ..., n\}$ 的倒序。当到达叶子节点准备输出时，我们只需用一个从 $n$ 递减到 $1$ 的 `for` 循环遍历，遇到被标记为“选”的元素就打印出来，这样天然就是降序。
* 利用一个布尔变量 `first` 来控制逗号 `,` 的输出，确保只有在输出非首个元素时才打印逗号，从而满足 `{3,2,1}` 这样的格式。
* 因为有**多组测试数据**，主函数中需使用 `while (cin >> n)` 来循环接收输入。

# 最终代码

```cpp
#include <iostream>
#include <vector>

using namespace std;

// 使用全局数组记录每个数字的选中状态，arr[i]=1表示选中数字i，0表示不选
int arr[15]; 
int n;

// 回溯函数，k 表示当前正在做决定的数字 (从 n 递减到 1)
void backtrack(int k) {
    // 终止条件：当 k == 0 时，说明 1~n 所有数字都已经做完了决定
    if (k == 0) {
        cout << "{";
        bool first = true;
        // 按降序输出被选中的元素
        for (int i = n; i >= 1; i--) {
            if (arr[i]) {   //注意只有选中时才考虑输出 否则会输出无关{}
                if (!first) cout << ","; // 非首个元素前加逗号
                cout << i;
                first = false;
            }
        }
        cout << "}\n";
        return;
    }
    
    // 核心回溯逻辑：为了满足字典序和样例输出的顺序，
    // 必须先走“不选”的分支，再走“选”的分支。

    // 分支 1：不选当前数字 k，并进行递归，直到所有的数字都决定完，然后打印出一个子集
    arr[k] = 0;
    backtrack(k - 1);
    
    // 分支 2：选中当前数字 k，并进行递归，直到所有的数字都决定完，然后打印出一个子集
    arr[k] = 1;
    backtrack(k - 1);
}

int main() {
    // 应对多组测试数据
    while (cin >> n) {
        // 从最大的数字 n 开始倒序决定
        backtrack(n);
    }
    return 0;
}
```
