# 题干

**题目描述**
有一地图，图中的顶点为各个小区，无向边表示两个小区之间的连通关系，边上的权值为两个小区之间的距离。经研究发现，这张图上的任意两个小区之间都是连通的。

现在的问题是，要建造若干条马路把所有城市联系起来，如何设计使得马路的总长度最小。

**输入格式**
第一行为两个正整数 `n`、`e`，分别表示小区数和边数。

以下 `e` 行，每行三个非负整数 `i j k`，表示小区 `i`、`j` 之间的距离是 `k`，小区编号最小为 1。

**输出格式**
输出马路的最短总距离。

**输入样例**
```text
5 8
1 2 2
2 5 9
5 4 7
4 1 10
1 3 6
2 3 3
3 4 4
3 5 8
```

**输出样例**
```text
16
```

---

# 解决思路：Kruskal 贪心算法

这道题要求用若干条边连接所有顶点，并让总权值最小，是典型的最小生成树问题。

Kruskal 算法的贪心策略是：

1. 将所有边按权值从小到大排序。
2. 依次考察每条边。
3. 如果这条边连接的两个顶点当前不在同一个连通分量中，就选中这条边。
4. 如果这条边会形成回路，就跳过。
5. 当选中 `n - 1` 条边时，所有小区已经连通，得到最小生成树。

判断两个顶点是否已经连通，可以使用并查集维护。

# 参考代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Edge {
    int u;
    int v;
    int w;
};

vector<int> parentNode;

int findSet(int x) {
    if (parentNode[x] == x) return x;
    return parentNode[x] = findSet(parentNode[x]);
}

bool unionSet(int a, int b) {
    int rootA = findSet(a);
    int rootB = findSet(b);

    if (rootA == rootB) return false;

    parentNode[rootB] = rootA;
    return true;
}

int main() {
    int n, e;
    cin >> n >> e;

    vector<Edge> edges(e);
    for (int i = 0; i < e; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }

    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.w < b.w;
    });

    parentNode.resize(n + 1);
    for (int i = 1; i <= n; i++) {
        parentNode[i] = i;
    }

    long long answer = 0;
    int selected = 0;

    for (const Edge& edge : edges) {
        if (unionSet(edge.u, edge.v)) {
            answer += edge.w;
            selected++;

            if (selected == n - 1) break;
        }
    }

    cout << answer << '\n';
    return 0;
}
```
