**题目描述**
有一地图，图中的顶点为各个小区，**无向边**表示两个小区之间的连通关系，边上的权值为两个小区之间的距离。经过研究发现，这张图上的任意两个小区之间都是连通的。现在的问题是，要建造若干条马路把所有城市联系起来，如何设计使得马路的总长度最小。

**输入格式**
第一行为两个正整数n（小区数），e（边数）
以下e行，每行三个非负整数i，j，k，表示小区i，j之间的距离是k（小区i，j最小为1）

**输出格式**
马路的最短总距离

**输入样例**
```text
5 8
1 2 2
2 5 9
5 4 7
4 1 10
1 3 12
4 3 6
5 3 3
2 3 8
```

**输出样例**
```text
19
```

# 解决思路

### 1. 核心算法：最小生成树 (MST) 与贪心策略
这道题是图论中非常经典的“最小生成树（Minimum Spanning Tree, MST）”问题。
题目要求：
* 把所有小区（顶点）联系起来。
* 马路（边）的总长度（权值和）最小。
* 图本身是连通的。
针对这种需求，我们可以使用贪心算法来求解。最常用的两种算法是 **Kruskal 算法** 和 **Prim 算法**。鉴于题目给出的输入格式直接就是“边列表（顶点 $i$、顶点 $j$、权值 $k$）”，使用 **Kruskal 算法** 尤为方便和直观。

### 2. Kruskal 算法的核心贪心思想
Kruskal 算法的核心思想是 **“从权值最小的边开始，尽可能多地挑选不构成回路的边”**。
具体步骤如下：
1. **收集与排序**：将图中所有的边收集起来，并按照权值从小到大进行排序。这是贪心策略的体现，总是优先考虑最短的边。
2. **并查集辅助**：在图的顶点中初始化一个“并查集”，起初每个顶点各自属于一个独立的集合。
3. **遍历与合并**：按排好序的顺序依次考察每一条边：
   * 如果这条边连接的两个顶点当前属于**不同的集合**，说明把这条边修好后**不会产生回路**（即这条边是必须的连通桥梁）。我们就选中这条边，将其权值累加到总长度中，并在并查集中将这两个顶点所在的集合合并。
   * 如果这条边连接的两个顶点当前属于**同一个集合**，说明它们之间已经有其他更短的路径连通了，再修这条边就会形成环/回路，纯属浪费。因此直接抛弃这条边。
4. **结束条件**：当成功选出了 $n - 1$ 条边时（$n$ 个顶点构成的树恰好有 $n - 1$ 条边），所有的顶点必然已经全部连通，此时直接提前退出循环即可。

### 3. 代码执行流程
1. 读取顶点数 $n$ 和边数 $e$。
2. 读取 $e$ 条边的信息，存入自定义结构体 `Edge` 的数组或 `vector` 中。
3. 调用 `sort` 并传入自定义的比较函数 `cmp`，对边集合进行升序排序。
4. 初始化并查集数组 `parent_node`，使每个顶点的编号（通常从 1 到 n）父节点指向自己。
5. 遍历排序后的边，使用 `find_set` 函数判断连通性，用 `union_sets` 合并集合，同时累加最小总距离。
6. 输出累加的最小总距离。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 边的结构体定义  u和v为端点，w为距离
struct Edge {
    int u, v, w;
};

// 自定义排序规则，用于按边权值从小到大排序
bool cmp(const Edge& a, const Edge& b) {
    return a.w < b.w;
}

// 并查集数组
//检测两点是否已连通（避免形成环），并维护当前的连通分量用于 Kruskal 算法
  //若根相同（find_set(u)==find_set(v)），说明 u、v 已连通，添加此边会产生环，应跳过。
  //若根不同，则选择此边并用 union_sets(u,v) 合并两个集合（连接分量）。
vector<int> parent_node;

// 查找该节点属于哪个集合
int find_set(int v) {
    if (v == parent_node[v])
        return v;
    // 路径压缩，加速后续查找
    return parent_node[v] = find_set(parent_node[v]);
}

// 合并操作：将两个集合合并
void union_sets(int a, int b) {
    a = find_set(a);
    b = find_set(b);
    if (a != b) {
        parent_node[b] = a;
    }
}

int main() {
    int n, e;
    if (!(cin >> n >> e)) return 0;

    vector<Edge> edges(e);
    for (int i = 0; i < e; ++i) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }

    // 1. 贪心策略：将所有边按权值从小到大排序
    sort(edges.begin(), edges.end(), cmp);

    // 2. 初始化并查集，顶点编号从 1 开始
    //注意是初始化顶点 而不是边
    parent_node.resize(n + 1);
    for (int i = 1; i <= n; ++i) {
        parent_node[i] = i;
    }

    long long min_cost = 0;
    int edge_count = 0;

    // 3. 遍历所有边，执行 Kruskal 算法
    for (Edge edge : edges) {
        // 如果边的两个端点不在同一个集合中（不会形成回路）
        if (find_set(edge.u) != find_set(edge.v)) {
            min_cost += edge.w;           // 累加边权
            union_sets(edge.u, edge.v);   // 合并集合
            edge_count++;                 // 已选边数加1
            
            // 选够 n - 1 条边即可连通所有 n 个顶点，提前结束
            if (edge_count == n - 1) {
                break;
            }
        }
    }

    // 输出最短总距离
    cout << min_cost << "\n";

    return 0;
}
```
