# 题干

**题目描述**
有一地图，图中的顶点为各个小区，无向边表示两个小区之间的连通关系，边上的权值为两个小区之间的距离。经研究发现，这张图上的任意两个小区之间都是连通的。

现在的问题是，要建造若干条马路把所有城市联系起来，如何设计使得马路的总长度最小。

**输入格式**
第一行为两个正整数 `n`、`e`，分别表示小区数和边数。

以下 `e` 行，每行三个非负整数 `i j k`，表示小区 `i`、`j` 之间的距离是 `k`，小区编号最小为 1。

**输出格式**
输出马路的最短总距离。

**输入样例**
```text
5 8
1 2 2
2 5 9
5 4 7
4 1 10
1 3 6
2 3 3
3 4 4
3 5 8
```

**输出样例**
```text
16
```

---

# 解决思路：Kruskal 贪心算法

这道题要求用若干条边连接所有顶点，并让总权值最小，是典型的最小生成树问题。

Kruskal 算法的贪心策略是：

1. 将所有边按权值从小到大排序。
2. 依次考察每条边。
3. 如果这条边连接的两个顶点当前不在同一个连通分量中，就选中这条边。
4. 如果这条边会形成回路，就跳过。
5. 当选中 `n - 1` 条边时，所有小区已经连通，得到最小生成树。

判断两个顶点是否已经连通，可以使用并查集维护。

# 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 定义边的结构体
struct Edge {
    int point1; // 边的第一个端点
    int point2; // 边的第二个端点
    int value;  // 边的权值（距离）
};

// 并查集的父节点数组，用于判断两个节点是否在同一个连通分量中
vector<int> parentNode;

// 查找节点所在集合的代表元素（根节点），并进行路径压缩
int findSet(int x) {
    if (parentNode[x] == x) return x; // 如果自己是根节点，直接返回
    return parentNode[x] = findSet(parentNode[x]); // 否则递归查找并更新父节点（路径压缩）
}

// 如果成功合并（原本不在同一个集合），返回 true 可以加入队列
// 如果已经在同一个集合，返回 false（表示会形成环） 不能加入队列
bool unionSet(int a, int b) {
    int rootA = findSet(a);
    int rootB = findSet(b);

    if (rootA == rootB) {
        return false;} // 已经在同一个集合中，加入这条边会形成回路

    if (rootA != rootB) {
        parentNode[rootB] = rootA; // 将其中一个集合的根节点连接到另一个集合的根节点
        return true;
    }
    
}

bool cmp(Edge a, Edge b) {
    return a.value < b.value;
}

int main() {
    int n, e;
    cin >> n >> e; // 输入小区数（顶点数）和边数

    vector<Edge> edges(e);
    for (int i = 0; i < e; i++) {
        cin >> edges[i].point1 >> edges[i].point2 >> edges[i].value; // 读取每条边的信息
    }

    // 1. 将所有边按权值从小到大排序
    sort(edges.begin(), edges.end(), cmp);

    // 初始化并查集，初始时每个节点各自为一个独立的集合
    parentNode.resize(n + 1);
    for (int i = 1; i <= n; i++) {
        parentNode[i] = i;
    }

    long long answer = 0; // 记录最小生成树的总权值
    int selected = 0;     // 记录当前已经选中的边数

    // 2. 依次考察每条边
    for (int i = 0; i < e; i++) {
        // 3. 如果这条边连接的两个顶点当前不在同一个连通分量中（即不会形成回路），就选中这条边
        if (unionSet(edges[i].point1, edges[i].point2)) {
            answer += edges[i].value; // 累加权值
            selected++;               // 选中的边数加1

            // 当选中了 n - 1 条边时，所有小区已经连通，提前结束循环
            if (selected == n - 1) break;
        }
    }

    // 输出最短总距离
    cout << answer << '\n';
    return 0;
}
```
