**题目描述**
哈夫曼编码是一种编码方式，是可变字长编码的一种，由 Huffman 于 1952 年提出。该方法完全依据字符出现概率来构造异字头的平均长度最短的码字，有时称之为最佳编码，一般就叫 Huffman 编码。简单地来说，就是出现概率高的字符使用较短的编码，反之出现概率低的则使用较长的编码，这便使编码之后的字符串的平均期望长度降低，从而达到无损压缩数据的目的。
现在请你模拟这样的原则对给定的一个字符串进行字母统计。

**输入格式**
只有一行，是一个字符串，由小写英文字母组成，长度不超过255个字符。

**输出格式**
有若干行，每行有两部分组成：一个字母和该字母出现的频率，中间用一个空格分隔，并按频率高低排列，频率相同时则按字母的 ASC 码的先后顺序排列。

**输入样例**
```text
soon
```

**输出样例**
```text
o 2
n 1
s 1
```

# 解决思路

### 1. 核心需求：字母频率统计与排序
虽然题目背景是经典的“哈夫曼编码”，但细读题意和输入输出样例可以发现，**这道题实际上并不需要我们真正去构建哈夫曼树或输出具体的二进制编码。**题目的落脚点在最后一句：**“模拟这样的原则对给定的一个字符串进行字母统计”**。
结合输出格式要求，本题的核心需求只有两个：
1. **统计**：计算字符串中每个小写字母出现的次数。
2. **排序**：将统计结果按要求排序并输出。

### 2. 数据结构选择
* **统计阶段**：由于需要统计字符及其对应的出现次数，且题目明确指出字符串由小写英文字母组成，最简单高效的方法是使用一个普通数组来充当哈希表。因为小写字母只有 26 个，我们可以开辟一个大小为 26 的整型数组 `count`，利用 `字符 - 'a'` 算出其在字母表中的相对偏移量，作为数组下标来记录频率（例如 `'a' - 'a' == 0`，对应下标 0）。
* **排序阶段**：为了满足“先按频率降序，再按 ASCII 升序”的复合排序要求，可以定义一个结构体 `CharFreq` 包含字符和频率。由于小写字母最多只有 26 个，直接使用固定大小的结构体数组 `CharFreq arr[26]` 即可，不需要使用 `vector`。

### 3. 自定义排序规则 (Comparator)
将出现过的字符保存到结构体数组后，我们使用 `std::sort` 并传入自定义的比较函数 `cmp`：
* **首要条件**：如果两个字母的频率不同，则频率高的排在前面（降序，`a.count > b.count`）。
* **次要条件**：如果两个字母的频率相同，则按字母的 ASCII 码顺序排列（升序，`a.ch < b.ch`）。

### 4. 代码执行流程
1. 读取字符串。
2. 遍历字符串，利用普通数组 `count` 和 `字符 - 'a'` 的偏移量统计每个字母的出现频率。
3. 遍历 `count` 数组，将频率大于 0 的字符及其频率存入结构体数组，并用 `len` 记录有效元素个数。
4. 调用 `sort(arr, arr + len, cmp)` 和自定义的比较函数进行排序。
5. 按顺序遍历结构体数组中前 `len` 个元素输出结果。

# 最终代码

```cpp
#include <bits/stdc++.h>

using namespace std;

// 存储字符及其频率的结构体
struct CharFreq {
    char ch;
    int count;
};

// 自定义排序规则
bool cmp(const CharFreq& a, const CharFreq& b) {   //完全可以删除&和const，但加上能加快程序
    if (a.count != b.count) {
        return a.count > b.count; // 频率不相等时，按频率降序排列
    }
    return a.ch < b.ch;           // 频率相等时，按 ASCII 码升序排列
}

int main() {
    string s;
    // 读取字符串，若没有输入则直接结束
    if (!(cin >> s)) return 0;
    
    // 题目明确只有小写英文字母，使用大小为 26 的普通数组统计频率
    // 利用 c - 'a' 算出相对偏移量作为下标
    int count[26] = {0};
    for (char c : s) {
        count[c - 'a']++;
    }
    
    // 将数组中出现过的字符及频率转移到结构体数组中以便进行自定义排序
    CharFreq arr[26];
    int len = 0;
    for (int i = 0; i < 26; i++) {
        if (count[i] > 0) { //如果该字母出现过
            arr[len].ch = (char)(i + 'a');
            arr[len].count = count[i];
            len++;
            // 将下标还原为对应的实际字符
        }
    }
    
    // 调用 sort 进行排序
    sort(arr, arr + len, cmp);
    
    // 按格式输出
    for (int i = 0; i < len; i++) {
        cout << arr[i].ch << " " << arr[i].count << "\n";
    }
    
    return 0;
}
```
