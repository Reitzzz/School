**题目描述**
给定一个无向图 $G=(V, E)$。如果 $U \subseteq V$ 且对任意 $u, v \in U$ 有 $(u, v) \in E$，则称 $U$ 为 $G$ 的完全子图。$G$ 的最大完全子图称为 $G$ 的最大团。
请使用**队列式分支限界法**来求解无向图的最大团问题，求出最大团中顶点的个数。

**输入格式**
第一行包含两个整数 $n$ 和 $m$（$1 \le n \le 50$，$1 \le m \le 1200$），分别表示图的顶点数和边数。顶点编号从 1 到 $n$。
接下来 $m$ 行，每行两个整数 $u, v$，表示顶点 $u$ 和 $v$ 之间有一条无向边。

**输出格式**
输出一个整数，表示最大团的顶点个数。

**输入样例**
```text
5 7
1 2
1 4
1 5
2 3
2 5
3 5
4 5
```

**输出样例**
```text
3
```
*(提示：{1, 2, 5} 是一个大小为 3 的最大团)*

---

# 解决思路

### 1. 核心需求：子集树搜索与 FIFO 队列
最大团问题是一个典型的子集选取问题（每个顶点选或不选），其解空间树是一棵**子集树**。
在队列式分支限界法中，我们采用先进先出（FIFO）的策略，逐层展开这棵子集树。

### 2. 队列式分支限界与剪枝策略
1. **结点定义**：队列中存储结点的层数 `level`、当前团的大小 `cn`、以及当前团内已经选中的顶点集合（为了后续判断连通性）。
2. **限界函数（剪枝）**：
   - **左分支（选择当前顶点）**：必须满足可行性约束。即当前顶点必须与已选入团中的所有顶点都相邻。如果满足，则作为一个可行结点加入队列。
   - **右分支（不选择当前顶点）**：运用最优性限界。设当前团的大小为 `cn`，剩余还没有判断的顶点数为 `n - level`。如果把剩下的顶点全加进来（即 `cn + n - level`），总数依然**不大于**当前已知的最大团大小 `bestn`，那么沿着这条路走下去绝对不可能刷新记录，直接剪枝（不入队）。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

// 队列结点状态
struct Node {
    int level;           // 当前正在决定第几个顶点（1 到 n）
    int cn;              // 当前团内已经包含的顶点数
    vector<int> clique;  // 当前团内包含的顶点编号集合
};

int main() {
    int n, m;
    if (!(cin >> n >> m)) return 0;
    
    // 使用邻接矩阵存储无向图
    vector<vector<int>> g(n + 1, vector<int>(n + 1, 0));
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        g[u][v] = 1;
        g[v][u] = 1;
    }
    
    int bestn = 0; // 记录当前发现的最大团大小
    queue<Node> q;
    
    // 初始状态入队，从第1个顶点开始判断，当前团大小为0
    q.push({1, 0, {}}); 
    
    // 队列式分支限界法核心
    while (!q.empty()) {
        Node curr = q.front();
        q.pop();
        
        int i = curr.level; // 当前考虑是否将顶点 i 加入团
        
        // 到达叶子节点之外
        if (i > n) {
            continue;
        }
        
        // --- 左儿子分支：尝试将顶点 i 加入团 ---
        bool can_add = true;
        // 检查顶点 i 是否与当前团内的所有顶点都相邻
        for (int u : curr.clique) {
            if (g[u][i] == 0) {
                can_add = false;
                break;
            }
        }
        
        if (can_add) {
            Node left = curr;
            left.level = i + 1;
            left.cn = curr.cn + 1;
            left.clique.push_back(i);
            
            // 更新当前最优值
            if (left.cn > bestn) {
                bestn = left.cn;
            }
            q.push(left);
        }
        
        // --- 右儿子分支：不将顶点 i 加入团 ---
        // 限界函数：如果当前大小加上剩余所有可能顶点数大于 bestn，才有探索价值
        if (curr.cn + n - i > bestn) {
            Node right = curr;
            right.level = i + 1;
            q.push(right);
        }
    }
    
    cout << bestn << "\n";
    return 0;
}
```
