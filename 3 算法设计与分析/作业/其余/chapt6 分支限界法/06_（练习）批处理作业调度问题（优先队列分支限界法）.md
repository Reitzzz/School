**题目描述**
给定 $n$ 个作业，每个作业 $i$ 都要先在机器 $M_1$ 上处理，然后再在机器 $M_2$ 上处理。作业 $i$ 在 $M_1$ 和 $M_2$ 上的处理时间分别是 $t_{1i}$ 和 $t_{2i}$。
批处理作业调度问题要求确定这 $n$ 个作业的执行顺序，使得所有作业在机器 $M_2$ 上**完成的时间之和**最小。
请使用**优先队列式分支限界法**求解此问题。

**输入格式**
第一行包含一个整数 $n$（$1 \le n \le 12$），表示作业的数量。作业编号从 1 到 $n$。
接下来 $n$ 行，每行包含两个整数 $t_{1i}, t_{2i}$（$1 \le t_{1i}, t_{2i} \le 100$），分别表示作业 $i$ 在机器 $M_1$ 和机器 $M_2$ 上的处理时间。

**输出格式**
输出一个整数，表示所有作业在机器 $M_2$ 上的最小完成时间之和。

**输入样例**
```text
3
2 1
3 1
2 3
```

**输出样例**
```text
18
```
*(提示：最优排列是 1, 3, 2。在 M1 上的完成时间依次为 2, 4, 7；在 M2 上的完成时间依次为 3, 7, 8。完成时间之和为 3 + 7 + 8 = 18)*

---

# 解决思路

### 1. 核心需求：排列树搜索
要求确定 $n$ 个作业的执行顺序，这等价于对作业的全排列进行搜索，因此解空间树是一棵**排列树**。由于我们需要求完成时间之和的**最小值**，这又是一个最优化问题，采用**优先队列式分支限界法**非常合适。

### 2. 剪枝与限界函数
1. **结点定义**：由于是机器调度，我们需要在结点中记录：
   - 当前在 $M_1$ 上已经花费的时间 `f1`
   - 当前在 $M_2$ 上已经花费的时间 `f2`
   - 当前已经累积的完成时间之和 `cost`
2. **限界函数（估算下界）**：
   - 每次安排一个新的作业，都会使 `cost` 增加该作业在 $M_2$ 上的完成时间。因此，随着树的层数加深，`cost` 是**单调递增**的。
   - 为了代码简洁，我们可以直接把当前累积的真实代价 `cost` 作为该子树的**下界**（这其实退化成了类似于 Dijkstra 算法的代价值优先扩展）。虽然不如复杂的下界公式剪枝效率高，但对于小规模数据完全够用且逻辑清晰。
3. **优先队列设计**：使用小根堆，把 `cost` 最小的结点放在队列前面优先扩展。
4. **剪枝条件**：如果从优先队列中弹出的结点的 `cost` 已经大于或等于当前找到的最优解 `best_cost`，则直接终止搜索（因为堆顶是代价最小的，后面的只能比它更大）。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

// 优先队列中的结点状态
struct Node {
    int level;          // 已经安排好的作业数量（树的层数）
    int f1;             // 机器 M1 上安排完当前作业后的完成时间
    int f2;             // 机器 M2 上安排完当前作业后的完成时间
    int cost;           // 当前所有已安排作业在 M2 上的完成时间之和（作为下界）
    vector<int> x;      // 记录作业的排列顺序
    
    // 优先队列是小根堆，把累积代价最小（最有希望）的结点放在最前面优先扩展
    bool operator<(const Node& other) const {
        return cost > other.cost;
    }
};

int main() {
    int n;
    if (!(cin >> n)) return 0;
    
    vector<int> t1(n + 1), t2(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> t1[i] >> t2[i];
    }
    
    priority_queue<Node> pq;
    int best_cost = 1e9; // 记录历史搜索过程中发现的最优调度代价
    
    // 初始化作业顺序为 1, 2, ..., n
    vector<int> initial_x(n + 1);
    for (int i = 1; i <= n; i++) {
        initial_x[i] = i;
    }
    
    // 初始状态入队
    pq.push({0, 0, 0, 0, initial_x});
    
    // 优先队列式分支限界法核心
    while (!pq.empty()) {
        Node curr = pq.top();
        pq.pop();
        
        // 剪枝：如果当前结点的累积代价已经不小于已知最优解，直接终止搜索
        if (curr.cost >= best_cost) {
            break; 
        }
        
        int i = curr.level;
        
        // 如果已经安排了 n 个作业，说明找到了一个完整的调度方案
        if (i == n) {
            if (curr.cost < best_cost) {
                best_cost = curr.cost;
            }
            continue;
        }
        
        // 扩展产生子结点：从剩下的未安排作业（x[i+1] 到 x[n]）中挑选一个放在当前位置
        for (int j = i + 1; j <= n; j++) {
            Node child = curr;
            
            // 交换位置，代表选择了作业 x[j]
            swap(child.x[i + 1], child.x[j]);
            
            int job_id = child.x[i + 1];
            
            // 计算新的完成时间
            child.f1 += t1[job_id]; // M1 上的时间无缝衔接
            // M2 上的时间必须等 M1 上的作业完工，并且 M2 自己也有空闲时才能开始
            child.f2 = max(child.f1, child.f2) + t2[job_id]; 
            
            // 累加完成代价
            child.cost += child.f2;
            child.level = i + 1;
            
            // 只有当前代价小于最优解时，才加入队列（限界函数）
            if (child.cost < best_cost) {
                pq.push(child);
            }
        }
    }
    
    cout << best_cost << "\n";
    return 0;
}
```
