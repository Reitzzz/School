**题目描述**
给定一个带权有向图 $G=(V, E)$ 和源点 $s$。要求找出从源点 $s$ 到其他所有顶点的最短路径长度。
请使用**优先队列式分支限界法**（本质上对应 Dijkstra 算法思想）来求解。

**输入格式**
第一行包含三个整数 $n$、$m$ 和 $s$（$1 \le n \le 100$，$1 \le m \le 1000$），分别表示图的顶点数、边数和源点编号（顶点编号从 1 到 $n$）。
接下来 $m$ 行，每行三个整数 $u, v, w$，表示存在一条从 $u$ 到 $v$ 的有向边，权重为 $w$（$w \ge 0$）。

**输出格式**
输出一行，包含 $n$ 个整数，分别表示源点 $s$ 到顶点 1 到 $n$ 的最短距离。如果不可达，输出 -1。用空格隔开。

**输入样例**
```text
5 7 1
1 2 10
1 4 30
1 5 100
2 3 50
3 5 10
4 3 20
4 5 60
```

**输出样例**
```text
0 10 50 30 60
```

---

# 解决思路

### 1. 核心需求：代价下界优先搜索
最短路径问题中，我们希望每次扩展的都是“当前距离最短”的结点。这正好契合了**优先队列式分支限界法**：维护一个小根堆，每次弹出当前累积代价值（路径长度）最小的活结点，去扩展它的所有邻居。

### 2. 剪枝与限界函数
- **限界与更新**：在优先队列中，随着结点的不断扩展，路径会不断变长。一旦某个活结点弹出来时，它的路径长度 `dist` 已经大于了记录在案的全局最短距离 `best_dist[u]`，这个结点就是个过期的“死结点”，没有再往下扩展的意义。
- **入队条件**：只有当 `new_dist < best_dist[v]` 时，我们才认定找到了更优的路径，将其记录，并作为新的“活结点”压入优先队列。
- 这套基于代价的优先队列分支限界法逻辑，在所有边权均为非负数的情况下，**完全等价于经典的 Dijkstra 算法**。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

const int INF = 1e9;

// 边结构体
struct Edge {
    int to;
    int weight;
};

// 优先队列中的结点状态
struct Node {
    int id;   // 当前所在的顶点编号
    int dist; // 从源点到当前顶点的累积距离

    // 优先队列的大根堆默认把最大元素放前面
    // 对于求最小代价的分支限界，我们要重载小于号，改成“代价越小优先级越高”
    bool operator<(const Node& other) const {
        return dist > other.dist; 
    }
};

int main() {
    int n, m, s;
    if (!(cin >> n >> m >> s)) return 0;

    // 邻接表建图
    vector<vector<Edge>> graph(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        graph[u].push_back({v, w});
    }

    // 记录从源点到各个顶点的最优解
    vector<int> best_dist(n + 1, INF);
    priority_queue<Node> pq;

    // 初始状态压入活结点表
    pq.push({s, 0});
    best_dist[s] = 0;

    // 优先队列分支限界核心
    while (!pq.empty()) {
        Node curr = pq.top();
        pq.pop();

        int u = curr.id;

        // 剪枝判断：如果当前取出的路径长度比已知的最短路径还长，说明是个过期的死结点，直接丢弃
        if (curr.dist > best_dist[u]) {
            continue;
        }

        // 扩展所有的相邻儿子结点
        for (auto& edge : graph[u]) {
            int v = edge.to;
            int new_dist = curr.dist + edge.weight;

            // 限界函数：只有当找到了更短的路径时，才更新并加入活结点表
            if (new_dist < best_dist[v]) {
                best_dist[v] = new_dist;
                pq.push({v, new_dist});
            }
        }
    }

    // 打印结果
    for (int i = 1; i <= n; i++) {
        if (best_dist[i] == INF) cout << "-1 ";
        else cout << best_dist[i] << " ";
    }
    cout << "\n";

    return 0;
}
```
