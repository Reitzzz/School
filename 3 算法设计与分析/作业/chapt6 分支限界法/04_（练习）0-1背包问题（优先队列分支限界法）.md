**题目描述**
给定 $n$ 个物品，每个物品有一个重量 $w_i$ 和一个价值 $v_i$。还有一个容量为 $C$ 的背包。要求选择若干个物品放入背包，使得放入背包中的物品总重量不超过 $C$，且总价值最大。
请使用**优先队列式分支限界法**来求解 0-1 背包问题，求出最大总价值。

**输入格式**
第一行包含两个整数 $n$ 和 $C$（$1 \le n \le 50$，$1 \le C \le 10000$），分别表示物品的数量和背包的容量。
接下来 $n$ 行，每行包含两个整数 $w_i, v_i$，分别表示第 $i$ 个物品的重量和价值。

**输出格式**
输出一个整数，表示能够获得的最大价值。

**输入样例**
```text
4 10
2 4
3 5
4 6
5 7
```

**输出样例**
```text
16
```
*(提示：选第 1、2、4 个物品，总重量 2+3+5=10，总价值 4+5+7=16。)*

---

# 解决思路

### 1. 核心需求：效益上界优先搜索
0-1 背包问题要求我们找到最大的价值。如果我们能在一个结点的层面上，**预估出“沿着这条路走到底，最多能拿到多少价值”（上界）**，我们就可以用一个优先队列把那些**潜力最大**的结点放在最前面优先探索。

### 2. 剪枝与限界函数
1. **预处理**：为了让上界估算更准确、快速逼近最优解，我们首先将所有物品按照**单位重量价值**（$v_i / w_i$）从大到小排序。
2. **限界函数（估算上界）**：
   - 设当前已经装入的重量为 `in_w`，价值为 `in_v`。
   - 剩下的容量 `left_c = C - in_w`。
   - 我们贪心地把剩下的物品往里装，直到装不下为止；对于装不下的那个物品，我们将其**拆分开**（像倒水一样）填满剩余容量。这样计算出的连续分数背包的最优解，就是原 0-1 背包在该分支下的**价值上界** `up`。
3. **优先队列设计**：使用大根堆，按照结点的上界 `up` 降序排列。
4. **剪枝条件**：
   - 如果从优先队列弹出的结点的上界 `up` 已经不大于当前我们已经找到的最好结果 `best_v`，因为堆顶的上界是整个队列里最大的，说明后续所有结点都不可能超越 `best_v` 了，**直接结束搜索（break）**。
   - 对于右儿子（不选当前物品），需要重新计算其上界。只有当其新上界 `right_up > best_v` 时，才值得将其加入优先队列。

# 最终代码

```cpp
#include <bits/stdc++.h>

using namespace std;

// 物品结构体
struct item {
    double w, v;
    double unit; // 单位重量的价值
};

// 按照单位重量价值从大到小排序
bool cmp(const item& a, const item& b) {
    return a.unit > b.unit;
}

// 优先队列中的结点状态
struct Node {
    int level;  // 正在考虑第 level 个物品（0 到 n-1）
    int in_w;     // 当前已装入背包的总重量
    int in_v;     // 当前已装入背包的总价值
    double up;  // 该结点子树能够达到的价值上界    
};

// 优先队列是大根堆，把价值上界最大的结点放在最前面优先扩展
bool operator<(const Node& a, const Node& b) {
    return a.up < b.up; 
}

int n, c;
item items[55]; // 因为 1 <= n <= 50

// 计算当前结点的价值上界（采用分数背包的贪心思路）
double bound(int i, int in_w, int in_v) {
    int left_c = c - in_w;
    double bound_v = in_v;
    
    // 贪心：按单位价值从大到小依次将剩余物品装入背包
    while (i < n && items[i].w <= left_c) {
        left_c -= items[i].w;
        bound_v += items[i].v;
        i++;
    }
    
    // 如果当前物品无法完整装入，则将其“切碎”，取一部分刚好填满背包的剩余容量
    if (i < n) {
        bound_v += items[i].v / items[i].w * left_c;
    }
    return bound_v;
}

int main() {
    cin >> n >> c;
    
    for (int i = 0; i < n; i++) {
        cin >> items[i].w >> items[i].v;
        items[i].unit = items[i].v / items[i].w;
    }
    
    // 必须先按单位价值降序排列，以保证限界函数的正确性和紧凑性
    sort(items, items + n, cmp);
    
    priority_queue<Node> pq;
    int best_v = 0;
    
    // 初始化并加入根结点
    double initial_up = bound(0, 0, 0);
    pq.push({0, 0, 0, initial_up});
    
    // 优先队列式分支限界法核心
    while (!pq.empty()) {
        Node curr = pq.top();
        pq.pop();
        
        // 剪枝：如果当前最有潜力的结点上界都不如我们手头的最好结果，直接终止搜索
        if (curr.up <= best_v) {
            break; 
        }
        
        int i = curr.level;
        if (i == n) {
            continue;
        }
        
        // --- 左儿子分支：尝试装入第 i 个物品 ---
        if (curr.in_w + items[i].w <= c) {
            int new_in_w = curr.in_w + items[i].w;
            int new_in_v = curr.in_v + items[i].v;
            
            if (new_in_v > best_v) {
                best_v = new_in_v;
            }
            
            // 左儿子的上界与父结点相同（因为最优预测本身就包含了选入这件物品的情况）
            pq.push({i + 1, new_in_w, new_in_v, curr.up});
        }
        
        // --- 右儿子分支：不装入第 i 个物品 ---
        // 失去了一件高性价比物品，必须重新计算其子树的上界
        double right_up = bound(i + 1, curr.in_w, curr.in_v);
        
        // 只有当新的上界仍然有希望打破记录时，才将右儿子入队
        if (right_up > best_v) {
            pq.push({i + 1, curr.in_w, curr.in_v, right_up});
        }
    }
    
    cout << best_v << "\n";
    return 0;
}
```
