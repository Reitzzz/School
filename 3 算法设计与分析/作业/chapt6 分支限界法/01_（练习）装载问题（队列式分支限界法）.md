**题目描述**
有一批共 $n$ 个集装箱要装上一艘载重量为 $c$ 的轮船。其中集装箱 $i$ 的重量为 $w_i$。最优装载问题要求在不超过轮船载重量的前提下，将尽可能重的集装箱装上轮船。
请设计一个**队列式分支限界法**来求解该问题，求出最大装载重量。

**输入格式**
第一行包含两个整数 $n$ 和 $c$（$1 \le n \le 30$，$1 \le c \le 10000$），分别表示集装箱的数量和轮船的载重量。
第二行包含 $n$ 个整数，表示每个集装箱的重量 $w_i$。

**输出格式**
输出一个整数，表示最大装载重量。

**输入样例**
```text
3 50
10 40 40
```

**输出样例**
```text
50
```

---

# 解决思路

### 1. 核心需求：子集树搜索与 FIFO 队列
装载问题本质上是从 $n$ 个物品中挑选若干个（子集），使得总重量最接近但不超过 $c$。这棵解空间树是一棵**子集树**。
与回溯法（深度优先）不同，分支限界法采用广度优先（队列式），一层一层地横向扩展节点。

### 2. 队列式分支限界与剪枝策略
1. **结点定义**：队列中只需要存储到达某个结点时的**当前总重量** `ew` 和**当前处理到的层数** `level`。
2. **限界函数（剪枝）**：
   - **左剪枝（超重剪枝）**：如果当前重量加上即将装入的第 $i$ 个集装箱重量超出了载重 $c$（`ew + w[i] > c`），则左分支（装入）不可行，直接作为死结点丢弃。
   - **右剪枝（最优性剪枝）**：我们需要维护一个当前已知的最大装载量 `bestw`，以及剩余所有未处理集装箱的总重量 `r`（可以通过预处理后缀和数组得到）。如果当前重量加上后面所有的剩余重量都不可能超过 `bestw`（即 `ew + r <= bestw`），那么就算后面全装上也没有意义了，右分支（不装）可以直接剪掉。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

// 队列结点状态
struct Node {
    int weight; // 当前已经装载的重量
    int level;  // 当前正在决定第几个集装箱（0 到 n-1）
};

int main() {
    int n, c;
    if (!(cin >> n >> c)) return 0;

    vector<int> w(n);
    for (int i = 0; i < n; i++) {
        cin >> w[i];
    }

    // 预处理后缀和 r[i]，表示第 i 个集装箱及之后所有集装箱的总重量
    // 这对于在右分支时计算“未来还能拿多少”至关重要
    vector<int> r(n + 1, 0); 
    for (int i = n - 1; i >= 0; i--) {
        r[i] = r[i + 1] + w[i];
    }

    queue<Node> q;
    q.push({0, 0}); // 初始活结点：重量0，第0层
    
    int bestw = 0; // 记录历史搜索过程中发现的最优装载量

    // 队列式分支限界法核心
    while (!q.empty()) {
        Node curr = q.front();
        q.pop();

        int level = curr.level;

        // 到达叶子节点，虽然在这个过程中 bestw 已经被更新过了，但还是判断一下
        if (level == n) {
            continue;
        }

        // 尝试生成左儿子（装入第 level 个集装箱）
        if (curr.weight + w[level] <= c) {
            int new_weight = curr.weight + w[level];
            q.push({new_weight, level + 1});
            
            // 及时更新 bestw，让右儿子的剪枝标准更加苛刻
            if (new_weight > bestw) {
                bestw = new_weight;
            }
        }

        // 尝试生成右儿子（不装入第 level 个集装箱）
        // 限界函数：当前重量 + 剩下后面所有物品的总重量 > bestw 时才值得探索
        if (curr.weight + r[level + 1] > bestw) {
            q.push({curr.weight, level + 1});
        }
    }

    cout << bestw << "\n";
    return 0;
}
```
