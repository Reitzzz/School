# 题干

**题目描述**
已知矩阵的大小定义为矩阵中所有元素的和。给定一个矩阵，你的任务是找到最大的非空(大小至少是 $1 \times 1$)子矩阵。

**输入格式**
输入是一个 $N \times N$ 的矩阵。输入的第一行给出 $N (0 < N \le 100)$。再后面的若干行中，依次给出矩阵中的 $N^2$ 个整数，整数之间由空白字符分隔。已知矩阵中整数的范围都在 $[-127,127]$。

**输出格式**
输出最大子矩阵的大小。

---

# 解决思路：降维打击（二维转化为一维）

如果直接暴力枚举子矩阵的上下左右四个边界，时间复杂度高达 $O(N^4)$。我们可以利用加法结合律，将二维问题“压扁”成一维问题，套用一维数组的“最大连续子段和”算法（Kadane算法），将时间复杂度优化至 $O(N^3)$。

### 1. 核心数学转化：为什么“竖着加起来”等价于“求矩阵和”？
一个子矩阵由四个边界决定：上边界 $i$、下边界 $j$、左边界 $L$、右边界 $R$。
当我们用两层循环**固定死**上边界 $i$ 和下边界 $j$ 后，寻找最大子矩阵的问题，就变成了寻找最优的左右边界 $L$ 和 $R$。

根据加法结合律，我们可以换个顺序相加：
* 先把夹在第 $i$ 行和第 $j$ 行之间的每一列（假设为第 $k$ 列）的元素竖向相加，得到这一列的总和，记为 $S_k$。
* 原本需要逐个格子累加的子矩阵总和，在数学上就完全等价于：$$S_L + S_{L+1} + \dots + S_R$$

这就是为什么：**“寻找最优左右边界使得多列总和最大” 完美等价于 “在一个一维数组中寻找最大连续子段和”。**

### 2. 核心变量解析：`col_sum` 与 `current_sum`

这两个变量是算法的黄金搭档，分别负责“压扁矩阵”和“挑选最大值”：

* **`col_sum`（数组）：负责“压扁”矩阵的容器**
  * 当我们锁定某两行作为上下边界后，`col_sum` 用来存储夹在这两行之间的**每一列的总和**。
  * 它成功把选定的二维区块，压缩成了一个简单的一维数组。
* **`current_sum`（整数）：负责“扔掉累赘”的决策者**
  * 它是 Kadane 算法的核心指针，在这个一维数组 `col_sum` 里边走边算。
  * **核心决策逻辑（是累赘就扔）**：
    * 如果 `current_sum > 0`：说明之前的累加和是“资产”，对后续结果有增益，继续把当前列的值加进来。
    * 如果 `current_sum <= 0`：说明之前的累加和变成了“负债”，只会拖累后面的数字。果断清空，从当前列的数值重新开始计算。

### 3. 执行流程总结
1. 外层两层循环枚举所有可能的上下边界组合 $(i, j)$。
2. 每次固定好上下边界后，计算这两行之间每一列的总和，存入 `col_sum` 数组（使用滚动累加优化，无需每次从头算）。
3. 针对当前的 `col_sum` 数组，利用 `current_sum` 跑一遍一维最大连续和算法。
4. 随时使用 `max_sum` 记录并更新出现过的最大值，最终输出。

# 最终代码

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n;
    // 读取矩阵维度
    if (cin >> n) {
        vector<vector<int>> matrix(n, vector<int>(n));
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                cin >> matrix[i][j];
            }
        }

        // 初始化全局最大值。为了安全起见，初始化为一个足够小的负数
        int max_sum = -127 * 100 * 100; 

        // 1. 枚举子矩阵的上边界 i
        for (int i = 0; i < n; i++) {
            // col_sum 用于记录从第 i 行到第 j 行每一列的元素总和（压扁后的容器）
            vector<int> col_sum(n, 0);
            
            // 2. 枚举子矩阵的下边界 j
            for (int j = i; j < n; j++) {
                
                int current_sum = 0; // Kadane 算法的决策者：记录当前连续子段和
                
                // 3. 遍历每一列 k，进行降维处理和一维最大和求解
                for (int k = 0; k < n; k++) {
                    // 将第 j 行第 k 列的元素累加到对应的列和中 (向下扩展，滚动更新)
                    col_sum[k] += matrix[j][k];
                    
                    // 求解一维数组 col_sum 的最大子段和 (决策逻辑：是累赘就扔)
                    if (current_sum > 0) {
                        current_sum += col_sum[k]; // 前面的和为正，有增益，继续累加
                    } else {
                        current_sum = col_sum[k];  // 前面的和为负或零，无增益，从当前列重新开始
                    }
                    
                    // 随时更新全局最大子矩阵和
                    if (current_sum > max_sum) {
                        max_sum = current_sum;
                    }
                }
            }
        }

        // 输出最终结果
        cout << max_sum << "\n";
    }
    return 0;
}
```
