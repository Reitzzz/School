# 题干

**题目描述**
今天是阴历七月初五，acm队员zb的生日。zb正在和C小加、never在武汉集训。他想给这两位兄弟买点什么庆祝生日，经过调查，zb发现C小加和never都很喜欢吃西瓜，而且一吃就是一堆的那种，zb立刻下定决心买了一堆西瓜。当他准备把西瓜送给C小加和never的时候，遇到了一个难题，never和C小加不在一块住，只能把西瓜分成两堆给他们，**为了对每个人都公平，他想让两堆的重量之差最小**。每个西瓜的重量已知，你能帮帮他么？

**输入格式**
*多组测试数据*（$\le 1500$）。
第一行输入西瓜数量 $N$ ($1 \le N \le 20$)
第二行有 $N$ 个数，$W_1, \dots, W_n$ ($1 \le W_i \le 10000$) 分别代表每个西瓜的重量

**输出格式**
输出分成两堆后的质量差

**输入样例**
```text
5
5 8 13 27 14
6
3689 3090 6280 3464 3849 5282
```

**输出样例**
```text
3
14
```

# 解决思路

### 1. 核心算法：问题转化（0-1背包模型）
这道题的核心诉求是“将一堆物品分成两部分，使得两部分的重量和尽可能接近”。
如果想让两堆的重量差最小，最理想的情况就是把西瓜平分，即每堆的重量都正好等于西瓜总重量的一半。
因此，我们可以把问题转化成一个经典的 **0-1 背包问题**：
* 设所有西瓜的总重量为 $S$。
* 我们可以把其中一堆西瓜的目标重量设为 $S / 2$（向下取整）。
* 把 $S / 2$ 看作背包的最大容量，每个西瓜的重量既是它消耗的“体积”，也是它产生的“价值”。
* 问题就变成了：**在这个容量为 $S / 2$ 的背包里，我们最多能装多重的西瓜？** 只要我们找出了这堆能装下的最大重量，另一堆的重量自然就确定了，两者的差值即为最小质量差。

### 2. 状态定义与转移方程
* **状态定义**：设定一个一维数组 $dp[j]$，表示“当背包容量为 $j$ 时，最多能装下的西瓜总重量”。
* **状态转移方程**：面对第 $i$ 个西瓜（重量为 $W_i$），我们要么把它放进背包，要么不放。
  $$dp[j] = \max(dp[j], dp[j - W_i] + W_i)$$
  为了保证每个西瓜只被选用一次，在使用一维数组时，内层循环必须**从大到小逆序遍历**背包容量。

### 3. 结果计算
假设经过动态规划后，我们在容量为 $\lfloor S / 2 \rfloor$ 的背包里装入的最大重量为 $dp[\text{target}]$。
这意味着：
* 第一堆西瓜的重量是 $dp[\text{target}]$。
* 第二堆西瓜（剩下的西瓜）的重量是 $S - dp[\text{target}]$。
因为背包容量最多只有总重的一半，所以第一堆必定小于等于第二堆。
这两堆西瓜的质量差为：
$$(S - dp[\text{target}]) - dp[\text{target}] = S - 2 \times dp[\text{target}]$$

### 4. 复杂度与常数优化
题目中提到有多达 $1500$ 组测试数据，虽然 $N \le 20$ 较小，但总容量上限达到了 $100000$。为了防止多组数据导致超时（TLE），可以在内层循环加上一个小优化：不需要每次都遍历到背包的最大容量，而是动态维护一个 `current_sum`（当前所有已出现的西瓜重量之和）。在推导第 $i$ 个西瓜时，背包容量的最大有效枚举上界只需是 $\min(\text{target}, \text{current\_sum})$ 即可，这样能大幅缩减无效的循环运算。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void solve() {
    int n;
    // 处理多组测试数据，直到读入失败为止
    while (cin >> n) {
        vector<int> w(n);
        int sum = 0;
        
        for (int i = 0; i < n; i++) {
            cin >> w[i];
            sum += w[i]; // 累加所有西瓜的总重量
        }

        // 背包的容量上限设为总重量的一半
        int target = sum / 2;
        
        // dp[j] 表示容量为 j 的背包所能装下的最大西瓜重量
        vector<int> dp(target + 1, 0);

        int current_sum = 0; // 用于常数级优化，记录前 i 个物品的总重
        
        // 0-1背包一维数组推导
        for (int i = 0; i < n; i++) {
            current_sum += w[i];   //已解锁的西瓜总重
            // 优化：内层循环的起点只需从 target 和当前总重中取小者开始
            int max_cap = min(target, current_sum);
            
            // j表示容量，逆序遍历容量，确保每个西瓜在当前轮次只被选择一次
            for (int j = max_cap; j >= w[i]; j--) {
                dp[j] = max(dp[j], dp[j - w[i]] + w[i]);
            }
        }

        // 计算最终两堆的质量差
        // 一堆质量为 dp[target]，另一堆为 sum - dp[target]
        int diff = sum - 2 * dp[target];
        cout << diff << "\n";
    }
}

int main() {
    
    solve();
    
    return 0;
}
```
