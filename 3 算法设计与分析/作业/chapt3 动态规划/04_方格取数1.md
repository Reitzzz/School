# 题干

**题目描述**
设有 $N \times N$ 的方格图，我们在其中的某些方格中填入正整数，而其它的方格中则放入数字 0。<br>
![1234](https://bsyimg.luoca.net/imgtc/20260512/6dfdfdeebd4bd3c12a4fe1a5a0b64fba.webp)

某人从图中的左上角 A 出发，**可以向下行走，也可以向右行走，直到到达右下角的 B 点**。在走过的路上，他可以取走方格中的数（取走后的方格中将变为数字 0）。

此人从 A 点到 B 点共走了两次，试找出两条这样的路径，使得取得的数字和为最大。

**输入格式**
第一行为一个整数 $N$（$N \le 10$），表示 $N \times N$ 的方格图。
接下来的每行有三个整数，第一个为行号数，第二个为列号数，第三个为在该行、该列上所放的数。一行 `0 0 0` 表示结束。

**输出格式**
第一个整数，表示两条路径上取得的最大的和。

**输入样例**
```text
8
2 3 13
2 6 6
3 5 7
4 4 14
5 2 21
5 6 4
6 3 15
7 2 14
0 0 0
```

**输出样例**
```text
67
```

# 解决思路

1. **核心算法：多线程动态规划（同时走模型）**
   本题如果采用贪心策略（先找第一条最大路径，把走过的点置为 0，再找第二条）是无法保证得到全局最优解的，因为第一条路的最优选择可能会破坏第二条路的潜在更优解。
   正确的思路是**让两个人同时从起点出发**，每次两人都走一步。这样我们可以统一状态，方便处理两人走到同一个格子的特殊情况。

2. **状态定义**
   两个人同时走，由于每次只能向右或向下，所以他们走的步数（即横纵坐标之和）始终是相同的。
   我们设 $k$ 为横纵坐标之和（即 $k = x + y$），步数相同意味着两人所处的格子坐标和都是 $k$。
   设定一个三维数组 $dp[k][i_1][i_2]$：
   * $k$ 表示当前走到的步数阶段（坐标和）。
   * $i_1$ 表示第一个人当前所在的行号。
   * $i_2$ 表示第二个人当前所在的行号。
   * 对应的列号可以直接计算得出：$j_1 = k - i_1$，$j_2 = k - i_2$。
   * 数组的值表示在这一状态下两人取得的数字最大和。

3. **状态转移方程**
   每个人到达当前格子都有两种可能：从上方（向下走）过来，或从左方（向右走）过来。两个人组合起来就有 $2 \times 2 = 4$ 种前置状态：
   * 两人都向右走：对应前置状态 $dp[k-1][i_1][i_2]$
   * 两人都向下走：对应前置状态 $dp[k-1][i_1-1][i_2-1]$
   * 一向下，二向右：对应前置状态 $dp[k-1][i_1-1][i_2]$
   * 一向右，二向下：对应前置状态 $dp[k-1][i_1][i_2-1]$
   
   当前状态的最大值，就是这 4 种前置状态中的最大值，加上当前格子里的数字。

4. **处理重合与越界**
   * **重合问题**：如果在某一步，两人走到了同一个格子上（即 $i_1 == i_2$，因为 $k$ 相同，所以 $j_1$ 也必定等于 $j_2$），那么这个格子里的数字只能被取走一次。否则，两人分别取走各自格子里的数字（相加）。
   * **越界问题**：推导列号 $j_1$ 和 $j_2$ 后，需判断是否在 $1 \le j \le N$ 的合法范围内。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    // 优化输入输出流
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    // 构建网格，下标从 1 开始
    vector<vector<int>> grid(n + 1, vector<int>(n + 1, 0));
    int r, c, v;
    while (cin >> r >> c >> v) {
        if (r == 0 && c == 0 && v == 0) break;
        grid[r][c] = v;
    }

    // dp[k][i1][i2]：k 表示横纵坐标之和，范围是 2 到 2n
    // i1 和 i2 表示两人的行号，范围是 1 到 n
    vector<vector<vector<int>>> dp(n * 2 + 1, vector<vector<int>>(n + 1, vector<int>(n + 1, 0)));

    for (int k = 2; k <= n * 2; ++k) {
        for (int i1 = 1; i1 <= n; ++i1) {
            for (int i2 = 1; i2 <= n; ++i2) {
                int j1 = k - i1;
                int j2 = k - i2;

                // 判断当前行号推算出的列号是否在合法范围内
                if (j1 >= 1 && j1 <= n && j2 >= 1 && j2 <= n) {
                    
                    // 获取四个前置状态的最大值
                    int max_prev = dp[k - 1][i1][i2];
                    max_prev = max(max_prev, dp[k - 1][i1 - 1][i2 - 1]);
                    max_prev = max(max_prev, dp[k - 1][i1 - 1][i2]);
                    max_prev = max(max_prev, dp[k - 1][i1][i2 - 1]);

                    // 处理当前格子的价值
                    int value = grid[i1][j1];
                    if (i1 != i2) {
                        // 如果两人不在同一行（即没走到同一个格子），则分别加上两者的数字
                        value += grid[i2][j2];
                    }

                    // 状态转移
                    dp[k][i1][i2] = max_prev + value;
                }
            }
        }
    }

    // 输出最终状态：两人都走到右下角 (坐标和为 2n，行号都为 n)
    cout << dp[n * 2][n][n] << "\n";

    return 0;
}
```
