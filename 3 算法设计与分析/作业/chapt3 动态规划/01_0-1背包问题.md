**题目描述**
给定 $n$ 种物品和一个背包，物品 $i$ 的重量是 $W_i$，其价值为 $V_i$，问如何选择装入背包的物品，使得装入背包的物品的总价值最大？
在选择装入背包的物品时，对每种物品 $i$ 只能有两种选择，装入或者不装入，不能装入多次，也不能部分装入。

**输入格式**
第一行输入物品的个数 $n$。
第二行输入物品的重量序列 $w$。（中间有空格）
第三行输入物品的价值序列 $v$。（中间有空格）
第四行输入背包容量 $c$。

**输出格式**
第一行输出装入背包的物品。（用 $0$ 和 $1$ 表示，中间无空格）
第二行输出最大价值。

**输入样例**
```text
3
3 4 5
4 5 6
10
```

**输出样例**
```text
011
11
```

---

# 解决思路

### 1. 核心算法：为什么是动态规划？
本题是经典的“0-1背包问题”。“0-1”意味着面对每一件物品，你只有两个绝对的选择：要么完全不拿（0），要么整个拿走（1），不能拆分。
这类问题无法使用贪心算法（比如每次挑“单价最高”或“最轻”的），因为局部的贪心可能会盲目占据背包空间，导致后续体积稍大但总价值极高的物品无法装入。我们必须通过**动态规划**统筹全局，权衡“空间代价”与“价值收益”。

### 2. 状态定义：理解为“闯关解锁游戏”
动态规划的核心是构建一个二维表格 $dp$。我们可以把填表的过程想象成一个**“限制条件不断放宽的闯关游戏”**：
* **$i$（行）**：代表“当前被允许挑选的物品范围”（当前解锁了前 $i$ 个物品）。
* **$j$（列）**：代表“当前分配给背包的容量上限”。
* **$dp[i][j]$**：代表“在只允许从前 $i$ 件物品中挑选，且背包最大容量为 $j$ 的严格前提下，**能拿到的最大总价值”**。

计算机无法一眼看穿全局最优解，必须从“只解锁1个物品，配极小的背包”开始，一步步积攒局部最优解，推导出“看2个物品”、“看3个物品”，直到推导出右下角的终点 $dp[n][c]$，即“解锁所有 $n$ 个物品，配完整的容量 $c$”时的全局最优战绩。

### 3. 状态转移方程（核心逻辑）
当我们**面对刚解锁的第 $i$ 件物品**（重量 $W_i$，价值 $V_i$）时，如何填写 $dp[i][j]$？只有两种客观情况：

* **情况 1：背包根本装不下（$j < W_i$）**
  连选择的余地都没有，只能不拿。此时的最大价值等于没有这件物品时的价值。
  **推导：** $dp[i][j] = dp[i-1][j]$

* **情况 2：背包装得下（$j \ge W_i$）**
  装得下不一定要装，需要对比“装”与“不装”哪种方案收益更高：
  * **不装：** 空间省下来了，价值依然是 $dp[i-1][j]$。
  * **装：** 获得了 $V_i$ 的价值，但消耗了 $W_i$ 的容量。这就意味着装入它之前，**背包只能留下 $j - W_i$ 的空间**。所以总价值变成了：前 $i-1$ 件物品在容量为 $j - W_i$ 时的**最大价值**，加上当前物品价值 $V_i$。即 $dp[i-1][j - W_i] + V_i$。 <br>
  **推导：** 取两者最大值，即 $dp[i][j] = \max(dp[i-1][j]  ,   dp[i-1][j - W_i] + V_i)$

### 4. 路径回溯：如何找出选了哪些物品？
题目要求输出诸如 `011` 的具体选择序列。填表是从前向后正向推导的，而找具体方案则需要**从终点开始，沿着“脚印”倒推回起点**。核心法则在于找“价值增量”：

站在表格右下角 $dp[n][c]$ 开始，对比当前状态与上一层状态（即没有第 $n$ 个物品时的状态 $dp[n-1][c]$）：
* **如果没有增量（$dp[i][j] == dp[i-1][j]$）**：说明第 $i$ 个物品的加入并没有让总战绩变得更好，最优解中**没有选第i个物品**。记录 `0`，背包剩余容量 $j$ 不变，继续向上考察第 $i-1$ 个物品。
* **如果有增量（$dp[i][j] > dp[i-1][j]$）**：说明总价值实打实地增加了，这必然是因为我们把第 $i$ 个物品装进了背包。记录 `1`。既然选了它，就要把它的重量从当前容量中扣除，更新 $j = j - W_i$，带着缩水后的新容量，继续向上考察第 $i-1$ 个物品。

### 5. 代码细节实现
在代码中，回溯判断往往需要写成一个严谨的三重校验：<br>
`if (temp_c >= w[i] && dp[i][temp_c] == dp[i - 1][temp_c - w[i]] + v[i] && dp[i][temp_c] > dp[i-1][temp_c])`
1. **`temp_c >= w[i]`**：防越界，确保当前容量还够装。
2. **`dp[i][temp_c] == dp[i - 1][temp_c - w[i]] + v[i]`**：溯源，确认当前价值确实是按“装入”的转移方程算来的。
3. **`dp[i][temp_c] > dp[i-1][temp_c]`**：确认增益，确认装入它确实带来了**严格价值提升**(即＞ 而不是≤)。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>

using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;

    // 物品索引从 1 开始
    vector<int> w(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i];
    
    vector<int> v(n + 1);
    for (int i = 1; i <= n; i++) cin >> v[i];

    int c;
    cin >> c;

    // dp[i][j] 表示前 i 个物品在容量为 j 下的最大价值
    vector<vector<int>> dp(n + 1, vector<int>(c + 1, 0));

    // 动态规划填表（像闯关一样，逐个解锁物品，枚举容量）
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= c; j++) {
            if (j < w[i]) {
                dp[i][j] = dp[i - 1][j]; // 容量不足，无法装入
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i]); // 权衡装与不装
            }
        }
    }

    // 路径回溯（从终点倒推，找价值增量）
    string res = "";
    int temp_c = c; //当前背包剩余/当前可追溯的容量
    for (int i = n; i >= 1; i--) {
        // 三重校验：容量够装 && 来源是装入操作 && 带来了实际增益
        if (temp_c >= w[i] 
        && dp[i][temp_c] == dp[i - 1][temp_c - w[i]] + v[i] 
        && dp[i][temp_c] > dp[i-1][temp_c]) {
            res = '1' + res;     // 选中，前置拼接1
            temp_c -= w[i];      // 扣除占用的容量
        } else {
            res = '0' + res;     // 未选中，前置拼接0
        }
    }

    // 输出 01 序列
    cout << res << "\n";
    // 输出最大价值 (右下角终点)
    cout << dp[n][c] << "\n";

    return 0;
}
```
