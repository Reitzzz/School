# 题干

**题目描述**
给定长度为 `n` 的整数序列 `a[1...n]`，求某个连续子区间 `[i, j]`，使得 `a[i] + ... + a[j]` 最大，并输出这个最大和。

**输入格式**
第一行输入整数 `n`。
第二行输入 `n` 个整数。

**输出格式**
输出最大子段和。

**输入样例**
```text
8
-2 11 -4 13 -5 -2 7 -3
```

**输出样例**
```text
20
```

---

# 解决思路：线性动态规划

**设 `dp[i]` 表示“以第 `i` 个元素结尾的最大连续子段和”。**
对于第 `i` 个元素，有两种选择：

1. 接在前面的最大子段后面：`dp[i-1] + a[i]`。
   - **通俗解释**：看前面的老大哥 `dp[i-1]` 是正资产还是负资产。如果 `dp[i-1] > 0`，带着他能让当前的值变得更大，那我们就选择合并。
   - ❌ **易错点解析**：你之前想的是“看 `dp[i-1] + a[i]` 能不能大于 `dp[i-1]`”。这其实是在判断下一个数字 `a[i]` 是不是正数。哪怕下一个数是负数（加了之后总和变小了），只要老大哥 `dp[i-1]` 还是正的，我们就应该继续合并，因为后面可能还有更大的正数（例如 `11, -4, 13`，遇到 `-4` 时绝对不能断开）。
2. 从当前元素重新开始：`a[i]`。
   - **通俗解释**：如果前面的老大哥 `dp[i-1] <= 0`，是个负资产，带上他反而会拖累当前的数字 `a[i]`，那还不如甩掉他，自己单干、另起炉灶。
   - ❌ **易错点解析**：你之前想的是“如果不能（大于 `dp[i-1]`）就变为 `a[i]`”。这意味着只要加上当前的数导致总和变小，就立刻断开重新开始。真正的断开条件并不是“加上它之后有没有变小”，而是：**前面累积的老本 `dp[i-1]` 本身已经变成负数了**，带上它纯属累赘，这时候才需要果断断开，变为 `a[i]`。

因此状态转移方程为：

```text
dp[i] = max(dp[i-1] + a[i], a[i])
```

答案为所有 `dp[i]` 中的最大值。该算法也称为 Kadane 算法，时间复杂度为 `O(n)`。

# 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    long long current = a[0];
    long long answer = a[0];

    for (int i = 1; i < n; i++) {
        current = max(current + a[i], a[i]);
        answer = max(answer, current);
    }

    cout << answer << '\n';
    return 0;
}
```
