# 题干

**题目描述**
给定长度为 `n` 的整数序列 `a[1...n]`，求某个连续子区间 `[i, j]`，使得 `a[i] + ... + a[j]` 最大，并输出这个最大和。

**输入格式**
第一行输入整数 `n`。
第二行输入 `n` 个整数。

**输出格式**
输出最大子段和。

**输入样例**
```text
8
-2 11 -4 13 -5 -2 7 -3
```

**输出样例**
```text
20
```

---

# 解决思路：线性动态规划

设 `dp[i]` 表示“以第 `i` 个元素结尾的最大连续子段和”。

对于第 `i` 个元素，有两种选择：

1. 接在前面的最大子段后面：`dp[i-1] + a[i]`。
2. 从当前元素重新开始：`a[i]`。

因此状态转移方程为：

```text
dp[i] = max(dp[i-1] + a[i], a[i])
```

答案为所有 `dp[i]` 中的最大值。该算法也称为 Kadane 算法，时间复杂度为 `O(n)`。

---

# 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    long long current = a[0];
    long long answer = a[0];

    for (int i = 1; i < n; i++) {
        current = max(current + a[i], a[i]);
        answer = max(answer, current);
    }

    cout << answer << '\n';
    return 0;
}
```
