# 题干

**题目描述**
给定 `n` 个矩阵 `{A1,A2,...,An}`，其中 `Ai` 与 `Ai+1` 是可乘的，`i = 1, 2, ..., n-1`。请确定计算矩阵连乘积的计算次序，**使得依此次序计算矩阵连乘积需要的数乘次数最少**。

例如，给定三个连续矩阵 `{A1, A2, A3}` 的维数分别是 `10*100`、`100*5` 和 `5*50`：

- 采用 `(A1A2)A3`，乘法次数为 `10*100*5 + 10*5*50 = 7500` 次。
- 采用 `A1(A2A3)`，乘法次数为 `100*5*50 + 10*100*50 = 75000` 次。

显然，最好的次序是 `(A1A2)A3`，乘法次数为 `7500` 次。

**输入格式**
第一行输入矩阵个数 `n`，`n <= 100`。

第二行输入 `n + 1` 个数字 `p0, p1, ..., pn`。其中 `(p0, p1)` 表示第一个矩阵的行数和列数，`(p1, p2)` 表示第二个矩阵的行数和列数，以此类推。

题目可能包含多组输入，读到文件结束为止。

**输出格式**
对每组输入，输出需要的最少数乘次数。结果保证小于 `2^31 - 1`。

**输入样例**
```text
3
10 100 5 50
3
1 2 3 4
```

**输出样例**
```text
7500
18
```

---

# 解决思路：区间动态规划

设 `dp[i][j]` 表示计算矩阵 `Ai ... Aj` 的最少数乘次数。

当 `i == j` 时，只有一个矩阵，不需要乘法，所以：

```text
dp[i][i] = 0
```

下面的代码为了更符合矩阵编号习惯，会把输入的 `p0, p1, ..., pn` 存成 `p[1], p[2], ..., p[n+1]`。

对于区间 `[start, end]`，枚举最后一次断开的位置 `i`：

```text
dp[start][end] = min(dp[start][i] + dp[i+1][end] + p[start] * p[i+1] * p[end+1])
```

其中 `start <= i < end`。按照区间长度从小到大递推即可。

# 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long cal(const vector<long long>& p, int n) {
    // dp[i][j] 表示计算 Ai 到 Aj 这一段矩阵连乘的最少乘法次数
    vector<vector<long long>> dp(n + 1, vector<long long>(n + 1, 0));

    // len 表示当前计算的矩阵链长度：
    // len = 2 表示算两个矩阵相乘，len = 3 表示算三个矩阵连乘，以此类推
    for (int len = 2; len <= n; len++) {
        for (int start = 1; start<= n-len+1; start++) {  //start<= n-len+1 : 防止end出界
            int end = start + len - 1;
            dp[start][end] = LLONG_MAX;

            // 枚举最后一次乘法的分割点：
            // i 表示把 Astart...Aend 分成 Astart...Ai 和 A(i+1)...Aend
            for (int i = start; i < end; i++) {
                // p 使用 1 下标：
                // A1 是 p[1] * p[2]，A2 是 p[2] * p[3]，以此类推
                // Astart...Ai 的结果维度是 p[start] * p[i+1]
                // A(i+1)...Aend 的结果维度是 p[i+1] * p[end+1]
                // 所以最后一次相乘的代价是 p[start] * p[i+1] * p[end+1]
                long long cost = dp[start][i]                                    // 左半段 Astart...Ai 的最少代价
                               + dp[i + 1][end]                                  // 右半段 A(i+1)...Aend 的最少代价
                               + p[start] * p[i + 1] * p[end + 1];               // 最后左右两个结果矩阵相乘的代价
                if (cost < dp[start][end]) {
                    dp[start][end] = cost;
                }
            }
        }
    }

    return dp[1][n];
}

int main() {
    int n;

    // 题目可能有多组数据，一直读到文件结束
    while (cin >> n) {
        // p[1..n+1] 用来表示 n 个矩阵的维度：
        // A1 是 p[1] * p[2]，A2 是 p[2] * p[3]，以此类推
        vector<long long> p(n + 2);
        for (int i = 1; i <= n + 1; i++) {
            cin >> p[i];
        }

        cout << cal(p, n) << '\n';
    }

    return 0;
}
```
