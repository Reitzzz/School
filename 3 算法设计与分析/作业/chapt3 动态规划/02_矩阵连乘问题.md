# 题干

**题目描述**
给定 `n` 个矩阵 `{A1,A2,...,An}`，其中 `Ai` 与 `Ai+1` 是可乘的，`i = 1, 2, ..., n-1`。请确定计算矩阵连乘积的计算次序，使得依此次序计算矩阵连乘积需要的数乘次数最少。

例如，给定三个连续矩阵 `{A1, A2, A3}` 的维数分别是 `10*100`、`100*5` 和 `5*50`：

- 采用 `(A1A2)A3`，乘法次数为 `10*100*5 + 10*5*50 = 7500` 次。
- 采用 `A1(A2A3)`，乘法次数为 `100*5*50 + 10*100*50 = 75000` 次。

显然，最好的次序是 `(A1A2)A3`，乘法次数为 `7500` 次。

**输入格式**
第一行输入矩阵个数 `n`，`n <= 100`。

第二行输入 `n + 1` 个数字 `p0, p1, ..., pn`。其中 `(p0, p1)` 表示第一个矩阵的行数和列数，`(p1, p2)` 表示第二个矩阵的行数和列数，以此类推。

题目可能包含多组输入，读到文件结束为止。

**输出格式**
对每组输入，输出需要的最少数乘次数。结果保证小于 `2^31 - 1`。

**输入样例**
```text
3
10 100 5 50
3
1 2 3 4
```

**输出样例**
```text
7500
18
```

---

# 解决思路：区间动态规划

设 `dp[i][j]` 表示计算矩阵 `Ai ... Aj` 的最少数乘次数。

当 `i == j` 时，只有一个矩阵，不需要乘法，所以：

```text
dp[i][i] = 0
```

对于区间 `[i, j]`，枚举最后一次断开的位置 `k`：

```text
dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1] * p[k] * p[j])
```

其中 `i <= k < j`。按照区间长度从小到大递推即可。

# 参考代码

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

long long matrixChain(const vector<long long>& p, int n) {
    vector<vector<long long>> dp(n + 1, vector<long long>(n + 1, 0));

    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = LLONG_MAX;

            for (int k = i; k < j; k++) {
                long long cost = dp[i][k] + dp[k + 1][j] + p[i - 1] * p[k] * p[j];
                if (cost < dp[i][j]) {
                    dp[i][j] = cost;
                }
            }
        }
    }

    return dp[1][n];
}

int main() {
    int n;

    while (cin >> n) {
        vector<long long> p(n + 1);
        for (int i = 0; i <= n; i++) {
            cin >> p[i];
        }

        cout << matrixChain(p, n) << '\n';
    }

    return 0;
}
```
