## 1. DP 通用下手模板

### 四个问题

1. `dp` 表示什么？
   - 例如：`dp[i][j]` 表示前 `i` 个物品、容量 `j` 的最大价值。

2. 初始值是什么？
   - 空序列、容量为 0、单个区间、起点位置，通常是边界。

3. 当前状态从哪里来？
   - 选/不选。
   - 左/上/左上。
   - 分割点 `k`。
   - 最后一组有多少个。

4. 按什么顺序填表？
   - 依赖上一行：`i` 从小到大。
   - 一维 0-1 背包：容量倒序。
   - 区间 DP：区间长度从小到大。

## 2. 0-1 背包模板

### 识别信号

- 每个物品只能选一次。
- 有容量限制。
- 求最大价值、最大重量、是否能达到某重量。

### 二维模板

```cpp
vector<vector<int>> dp(n + 1, vector<int>(C + 1, 0));

for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= C; j++) {
        dp[i][j] = dp[i - 1][j];
        if (j >= w[i]) {
            dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i]] + v[i]);
        }
    }
}
```

### 一维优化模板

```cpp
vector<int> dp(C + 1, 0);

for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

### 路径回溯模板

```cpp
string choose;
int cap = C;
for (int i = n; i >= 1; i--) {
    if (cap >= w[i] && dp[i][cap] == dp[i - 1][cap - w[i]] + v[i]
        && dp[i][cap] > dp[i - 1][cap]) {
        choose = '1' + choose;
        cap -= w[i];
    } else {
        choose = '0' + choose;
    }
}
```

### 易错点

- 一维 0-1 背包容量必须倒序，否则同一物品会被重复使用。
- 第 `i` 个物品通常建议从 `1` 开始编号，公式更清楚。

## 3. 分两堆差最小：背包转化模板

### 识别信号

- 把一堆物品分成两组。
- 要让两组和尽量接近，差最小。

### 转化

总重量为 `sum`，只需要找一个不超过 `sum / 2` 的最大可达重量 `dp[target]`。

答案：

```cpp
sum - 2 * dp[target]
```

### 代码模板

```cpp
int target = sum / 2;
vector<int> dp(target + 1, 0);

for (int x : w) {
    for (int j = target; j >= x; j--) {
        dp[j] = max(dp[j], dp[j - x] + x);
    }
}

cout << sum - 2 * dp[target] << "\n";
```

## 4. 区间 DP：合并沙子模板

### 识别信号

- 每次只能合并相邻的东西。
- 求把一段区间合成一个整体的最小/最大代价。
- 常见关键词：石子合并、沙子合并、括号合并、区间最优。

### 状态

`dp[i][j]`：把区间 `[i, j]` 合并成一堆的最小代价。

### 转移

枚举最后一次合并前的分割点 `k`：

```cpp
dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + sum(i, j));
```

### 代码模板

```cpp
const int INF = 1e9;
vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));

for (int len = 2; len <= n; len++) {
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++) {
            int cost = prefix[j] - prefix[i - 1];
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + cost);
        }
    }
}
```

### 易错点

- 必须按区间长度 `len` 从小到大。
- `k < j`，不能写成 `k <= j`。
- 区间和用前缀和 `prefix[j] - prefix[i - 1]`。

## 5. LCS 最长公共子序列模板

### 识别信号

- 两个字符串/序列。
- 求保持相对顺序的最长公共部分。
- 允许不连续。

### 状态与转移

`dp[i][j]`：第一个串前 `i` 个字符和第二个串前 `j` 个字符的 LCS 长度。

```cpp
if (s1[i - 1] == s2[j - 1])
    dp[i][j] = dp[i - 1][j - 1] + 1;
else
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
```

### 代码模板

```cpp
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (s1[i - 1] == s2[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
        else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
    }
}
```

## 6. 双人同步 DP：方格取数模板

### 识别信号

- 同一张网格走两次。
- 只能向右/向下。
- 同一个格子的值只能取一次。

### 核心转化

把“两次走”看成“两个人同时走”。两个人走的步数相同，所以坐标和相同：

```cpp
k = i + j
```

用 `dp[k][i1][i2]` 表示当前步数为 `k`，两个人分别在第 `i1` 行、第 `i2` 行时的最大收益。列号由 `j1 = k - i1`、`j2 = k - i2` 算出。

### 转移模板

```cpp
for (int k = 2; k <= 2 * n; k++) {
    for (int i1 = 1; i1 <= n; i1++) {
        for (int i2 = 1; i2 <= n; i2++) {
            int j1 = k - i1, j2 = k - i2;
            if (j1 < 1 || j1 > n || j2 < 1 || j2 > n) continue;

            int best = max({
                dp[k - 1][i1][i2],
                dp[k - 1][i1 - 1][i2],
                dp[k - 1][i1][i2 - 1],
                dp[k - 1][i1 - 1][i2 - 1]
            });

            int val = grid[i1][j1];
            if (i1 != i2) val += grid[i2][j2];
            dp[k][i1][i2] = best + val;
        }
    }
}
```

## 7. 最大子矩阵和：二维压缩模板

### 识别信号

- 求矩阵中连续子矩阵的最大和。
- `N <= 100` 左右。

### 核心转化

枚举上下边界，把这几行每一列的和压成一维数组，然后对这一维数组求最大连续子段和。

### 代码模板

```cpp
int ans = -1e9;

for (int top = 0; top < n; top++) {
    vector<int> col(n, 0);
    for (int bottom = top; bottom < n; bottom++) {
        int cur = 0;
        for (int c = 0; c < n; c++) {
            col[c] += a[bottom][c];
            cur = max(col[c], cur + col[c]);
            ans = max(ans, cur);
        }
    }
}
```

### 易错点

- 矩阵可能全是负数，`ans` 不能初始化为 `0`。
- `col` 要在固定 `top` 后清零，然后随着 `bottom` 向下滚动累加。

## 8. 线性 DP：分批运输模板

### 识别信号

- 把前 `i` 个对象分成若干批。
- 每一批的代价只和批大小有关。
- 枚举最后一批有多少个。

### 模板

```cpp
vector<long long> dp(n + 1, INF);
dp[0] = 0;

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        dp[i] = min(dp[i], dp[i - j] + cost[j]);
    }
}
```

### 本题提醒

如果每批都把“返回”算进去了，最后答案要减去最后一次多算的回程。

## 9. LIS 最长递增子序列模板

### 识别信号

- 要从一个序列里选尽量多的数。
- 保持原顺序。
- 要求选出的数递增。
- 电路布线中“不相交”可转化为 `pi` 序列递增。

### O(n log n) 模板

```cpp
vector<int> tails;

for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x;
}

cout << tails.size() << "\n";
```

### 易错点

- 严格递增用 `lower_bound`。
- 非递减才用 `upper_bound`。
- `tails` 不一定是真实的 LIS，只保证长度正确。
