## 1. 线性 DP 模板

线性 DP 是最基础的 DP 模型，状态的设计往往与序列的前缀（前 $i$ 个元素）或两个序列的前缀组合有关，且转移呈现明显的单向线性关系（包括网格中的单向移动）。

### (1) 单序列/分批划分模型
**特征：** 对一个序列进行划分，第 $i$ 个状态可以由前面的某几个状态推导而来。
**示例（分批运输）：**
```cpp
vector<long long> dp(n + 1, INF);
dp[0] = 0;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) { // 枚举最后一批包含的元素个数
        dp[i] = min(dp[i], dp[i - j] + cost[j]);
    }
}
```

### (2) 最长递增子序列模型 (LIS)
**特征：** 要求在单序列中寻找保持原顺序的递增子序列。
**$O(n \log n)$ 模板（基于贪心 + 二分）：**
```cpp
vector<int> tails; // tails[i] 表示长度为 i+1 的递增子序列的最小结尾元素
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x; // 替换以维持潜力
}
// tails.size() 即为 LIS 长度
```

### (3) 双序列匹配模型 (LCS)
**特征：** 比较两个字符串或序列，寻找最大匹配。
**示例（最长公共子序列）：**
```cpp
vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (s1[i - 1] == s2[j - 1]) 
            dp[i][j] = dp[i - 1][j - 1] + 1; // 匹配成功
        else 
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]); // 错位匹配
    }
}
```

### (4) 坐标/多维网格模型
**特征：** 在矩阵中游走，每次只能向右或向下，有时涉及多路径同步进行。
**示例（最大子矩阵）：**
通过压缩行区间，转化为一维连续子段和：
```cpp
int ans = -1e9;
for (int top = 0; top < n; top++) {
    vector<int> col(n, 0); // 压缩成一维数组
    for (int bottom = top; bottom < n; bottom++) {
        int cur = 0;
        for (int c = 0; c < n; c++) {
            col[c] += a[bottom][c];
            cur = max(col[c], cur + col[c]);
            ans = max(ans, cur);
        }
    }
}
```
**示例（双线并行的网格取数）：**
用步数 $k$ 作为主序（$k = i + j$），消除维度的独立性。
```cpp
for (int k = 2; k <= 2 * n; k++) {
    for (int i1 = 1; i1 <= n; i1++) {
        for (int i2 = 1; i2 <= n; i2++) {
            int j1 = k - i1, j2 = k - i2;
            if (j1 < 1 || j1 > n || j2 < 1 || j2 > n) continue;
            // 从左左、左上、上左、上上四种状态转移
            int best = max({dp[k-1][i1][i2], dp[k-1][i1-1][i2], dp[k-1][i1][i2-1], dp[k-1][i1-1][i2-1]});
            int val = grid[i1][j1] + (i1 != i2 ? grid[i2][j2] : 0);
            dp[k][i1][i2] = best + val;
        }
    }
}
```

## 2. 背包 DP 模板

背包 DP 专门处理“在给定容量限制下，在若干个物品中选择，以使得某种价值最大（或重量最小）”的问题。本质是特殊的线性 DP。

### (1) 0-1 背包标准模板
**特征：** 每种物品只有一件，只能选择拿或不拿。
**二维形式推导：**
`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`

**一维滚动数组优化：**
注意：容量 `j` 必须**倒序**遍历，以保证每个物品只被使用一次！
```cpp
vector<int> dp(C + 1, 0); // 容量为 C
for (int i = 1; i <= n; i++) {
    for (int j = C; j >= w[i]; j--) { // 倒序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

### (2) 0-1 背包路径回溯模板
如果题目需要输出具体选择了哪些物品，必须保留二维数组（或者记录转移来源），然后从终点倒推。
```cpp
string choose = "";
int cap = C;
for (int i = n; i >= 1; i--) { // 从最后一个物品往前推
    // 如果容量足够 且 当前状态确实是从选第 i 个物品转移过来的
    if (cap >= w[i] && dp[i][cap] == dp[i - 1][cap - w[i]] + v[i] 
        && dp[i][cap] > dp[i - 1][cap]) {
        choose = "1" + choose;
        cap -= w[i];
    } else {
        choose = "0" + choose;
    }
}
```

### (3) 背包转化模型（两堆差最小）
**特征：** 将一个集合分成两堆，让它们和尽可能接近。
**思路：** 将问题转化为背包容量为 $sum / 2$ 的 0-1 背包问题，求在此容量下能装入的最大重量 $dp[target]$，最终差值即为 $sum - 2 \times dp[target]$。
```cpp
int target = sum / 2;
vector<int> dp(target + 1, 0);
for (int x : w) {
    for (int j = target; j >= x; j--) {
        dp[j] = max(dp[j], dp[j - x] + x); // 重量即价值
    }
}
cout << sum - 2 * dp[target] << "\n";
```

## 3. 区间 DP 模板

区间 DP 用于解决需要把一段区间进行合并、拆分或求解最优性质的问题。
**核心标志：** 每次操作涉及相邻元素的合并（如石子/沙子合并、矩阵连乘、多边形划分等）。

### 通用求解思路
1. **状态定义**：`dp[i][j]` 表示处理原序列中区间 `[i, j]` 的最优解。
2. **转移方程**：枚举区间内的分割点 $k$。
   `dp[i][j] = max/min(dp[i][k] + dp[k+1][j]) + cost(i, j)`
3. **遍历顺序**：因为大区间依赖小区间，所以**必须先从小到大枚举区间长度 `len`**。

### 区间合并模板
**示例（合并沙子）：**
每次只能合并相邻的两堆沙子，代价为两堆沙子的重量和。利用前缀和数组 `prefix` 快速计算区间重量和。
```cpp
const int INF = 1e9;
vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));

// 第一层：从小到大枚举区间长度 len
for (int len = 2; len <= n; len++) {
    // 第二层：枚举区间的起点 i
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1; // 确定区间终点 j
        dp[i][j] = INF;
        
        int cost = prefix[j] - prefix[i - 1]; // 合并该区间的固定代价
        
        // 第三层：枚举区间 [i, j] 之间的分割点 k
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + cost);
        }
    }
}
```
**易错点提醒：**
- $len = 1$ 的区间本身不需要合并，初始代价为 0，因此 $len$ 从 2 开始。
- $k$ 的范围是 $[i, j-1]$，绝不能写成 $k \le j$。
