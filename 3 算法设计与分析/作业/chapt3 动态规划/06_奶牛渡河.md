# 题干

**题目描述**
Farmer John 以及他的 $N (1 \le N \le 2500)$ 头奶牛打算过一条河，但他们所有的渡河工具仅仅是一个木筏。由于奶牛不会划船，在整个渡河过程中，FJ 必须始终在木筏上。

在这个基础上，木筏上的奶牛数目每增加 1，FJ 把木筏划到对岸就得花更多的时间。当 FJ 一个人坐在木筏上，他把木筏划到对岸需要 $M (1 \le M \le 1000)$ 分钟。当木筏搭载的奶牛数目从 $i-1$ 增加到 $i$ 时，FJ 得多花 $M_i (1 \le M_i \le 1000)$ 分钟才能把木筏划过河。也就是说，船上有 1 头奶牛时，FJ 得花 $M + M_1$ 分钟渡河；船上有 2 头奶牛时，时间就变成 $M + M_1 + M_2$ 分钟。

FJ 每次从对岸划回来接下一批奶牛的时间也需要包括在内（划回来时船上只有 FJ 一个人）。求把所有奶牛带到对岸所需的最少时间。

**输入格式**
第 1 行：2 个用空格隔开的整数 $N$ 和 $M$。
第 2..$N+1$ 行：第 $i+1$ 行为 1 个整数 $M_i$。

**输出格式**
输出 1 个整数，为 FJ 把所有奶牛都载过河所需的最少时间。

**输入样例**
```text
5 10
3
4
6
100
1
```

**输出样例**
```text
50
```

---

# 解决思路

1. **核心算法：动态规划**
   本题是一个典型的线性 DP 问题。我们需要决定如何将 $N$ 头奶牛分成若干批次运送，使得“运送时间 + 回程时间”的总和最小。

2. **预处理：单次运送成本**
   * 首先计算运送 $i$ 头奶牛**单程** *(即不考虑回程)* 所需的时间。令 $time[i]$ 表示运送 $i$ 头奶牛到对岸的时间。
   * 根据题意：$time[i] = M + \sum_{j=1}^{i} M_j$。
   * **回程代价**：除了最后一批奶牛，FJ 每运一批过去，都必须独自划回来。由于 FJ 独自划回来的时间也是 $M$，我们可以直接将回程的 $M$ 分钟合并到单次运送成本中。
   * 定义 $cost[i] = time[i] + M = 2M + \sum_{j=1}^{i} M_j$。**这意味着运送 $i$ 头奶牛到对岸并返回的总代价**。

3. **状态定义与转移**
   * 定义 $dp[i]$ 为运送 $i$ 头奶牛到对岸并**返回**所需的最少时间。
   * 状态转移方程：
     $$dp[i] = \min_{1 \le j \le i} \{ dp[i-j] + cost[j] \}$$
     **这里 $j$ 代表最后一批运送的奶牛数量。我们将 $i$ 头奶牛拆分为“前 $i-j$ 头已经运完并返回”和“最后一批运送 $j$ 头并返回”两部分。**


4. **细节处理：消除多余的回程时间**
   * 在我们的 $dp$ 定义中，每一批都包含了返回的时间。
   * 但事实上，**运送完最后一批奶牛后，FJ 已经完成了任务，不需要再划回来**。
   * 因此，最终答案应该是 $dp[N] - M$。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n, m;
    if (cin >> n >> m) {
        // cost[i] 表示一次性运送 i 头奶牛并划回来的总时间
        // 公式：M (去) + Mi累加 (增加时间) + M (回)
        vector<long long> cost(n + 1);
        long long sum_mi = 0; 
        for (int i = 1; i <= n; i++) {
            int mi;
            cin >> mi;
            sum_mi += mi;
            cost[i] = 2 * m + sum_mi;
        }

        // dp[i] 表示运送 i 头奶牛并划回来的最小总时间
        vector<long long> dp(n + 1, 1e18); // 初始化为一个很大的数
        dp[0] = 0; // 0 头奶牛不需要时间

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                // 尝试最后一次运送 j 头奶牛
                dp[i] = min(dp[i], dp[i - j] + cost[j]);
            }
        }

        // 减去最后一次多算的划回来的时间 M
        cout << dp[n] - m << endl;
    }
    return 0;
}
```
