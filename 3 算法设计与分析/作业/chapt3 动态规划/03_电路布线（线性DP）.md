# 题干

**题目描述**
在一块电路板的上下两端分别有 $n$ 个接线柱。根据电路设计，要求用导线 $(i, \pi(i))$ 将上端接线柱 $i$ 与下端接线柱 $\pi(i)$ 相连，如图。<br>
![1234](https://img2018.cnblogs.com/blog/1358881/201910/1358881-20191012114911767-483335384.png)<br>
其中 $\pi(i)$, $1 \le i \le n$，是 $(1, 2, \dots, n)$ 的一个排列。<br>
导线 $(i, \pi(i))$ 称为该电路板上的第 $i$ 条连线。**对于任何 $1 \le i < s \le n$，第 $i$ 条连线和第 $s$ 条连线相交的充分且必要条件是 $\pi(i) > \pi(s)$。**

在制作电路板时，要求将这 $n$ 条线分布到若干个绝缘层上，在同一层上的连线不能相交。电路布线问题要确定将哪些连线安排在第一层上，使得该层上有尽可能多的连线。
多组测试数据。

**输入格式**
第一行 $n$
第二行 $\pi(i)$

**输出格式**
最大不相交连线数目

**输入样例**
```text
10
8 7 4 2 5 1 9 3 10 6
```

**输出样例**
```text
4
```

# 解决思路

### 1. 题目大白话翻译：电线什么时候“不交叉”？
想象一块电路板，上面有一排接口编号为 $1, 2, 3, \dots, n$（从左到右排好），下面也有一排接口，但是编号是题目给定的打乱序列 $\pi(i)$。
我们要把上面的 $1$ 连到下面的 $\pi(1)$，上面的 $2$ 连到下面的 $\pi(2)$，以此类推。

如果挑出两根电线，既然左边那根的“上端”更靠左（即 $i < s$），那么为了让两根线不打架（不相交），它的“下端”也必须在另一根的左边，也就是 $\pi(i) < \pi(s)$。
也就是说，要在打乱的下端序列中挑出一串数字，满足**后一个数字必须比前一个数字大**。
所以，这道题的本质就是求下端序列的**最长递增子序列（Longest Increasing Subsequence, 简称 LIS）**。

### 2. 核心算法：如何高效排队？
求最长递增子序列，我们可以用一个非常巧妙的“排队”比喻。假设我们要选拔一个由矮到高的队伍，并且希望队伍越长越好。
**核心心法**：为了让后面能有更多的人排进队伍，我们必须保证目前队伍的队尾**尽可能地矮**！尾巴越矮，后面接人的空间就越大。

为了实现这个策略，我们维护一个 `tails` 数组，用来记录“各个长度的队伍，目前最矮的队尾是谁”。

### 3. 具体操作步骤与贪心逻辑
遍历给定的序列，每拿到一个新数字时，执行以下判断：
* **情况一：新数字比 `tails` 名单里所有人都大**
    直接把它排在队伍最后面。队伍成功变长了，也就是最长递增子序列的长度 $+1$（对应代码中的 `tails.push_back`）。
* **情况二：新数字不是最大的**
    它没法让队伍直接变长，但它具有“潜力”。我们在 `tails` 名单里找一个“刚好比它大，或者一样大”的倒霉蛋，用新数字把它**替换**掉。
    替换的绝妙之处在于：队伍长度虽然没变，但某个位置的队尾变矮了！这样就能为后续数字接上来创造极好的条件（对应代码中利用二分查找 `lower_bound` 寻找并替换）。

最终，这个 `tails` 数组的长度，就是整个序列的最长递增子序列的长度，也就是题目所求的**最大不相交连线数目**。

# 最终代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void solve() {
    int n;
    // 循环读取多组测试数据
    while (cin >> n) {
        vector<int> pi(n);
        for (int i = 0; i < n; i++) {
            cin >> pi[i];
        }

        // tails 数组用于记录各长度递增子序列的最小末尾元素
        vector<int> tails;

        for (int i = 0; i < n; i++) {
            // lower_bound 进行二分查找，返回 tails 中第一个 >= pi[i] 的迭代器
            auto it = lower_bound(tails.begin(), tails.end(), pi[i]);
            
            if (it == tails.end()) {
                // 如果找不到，说明 pi[i] 突破了当前上限，最长子序列长度 +1
                tails.push_back(pi[i]);
            } else {
                // 如果找到了，贪心地用更小的 pi[i] 替换原有的末尾元素
                // 这样能让后续元素更容易接在后面
                *it = pi[i];
            }
        }

        // tails 数组的长度即为 LIS 的长度（最大不相交连线数目）
        cout << tails.size() << "\n";
    }
}

int main() {
    // 关闭同步流，加速大量的输入输出操作
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    solve();
    
    return 0;
}
```
