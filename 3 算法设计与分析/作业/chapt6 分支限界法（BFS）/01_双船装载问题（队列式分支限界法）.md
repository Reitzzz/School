# 题干

**题目描述**
有一批共 `n` 个集装箱要装上 2 艘载重量分别为 `c1` 和 `c2` 的轮船，其中集装箱 `i` 的重量为 `w[i]`，且所有集装箱总重量不超过 `c1 + c2`。请判断是否存在一种合理装载方案，使这些集装箱全部装上两艘轮船；如果存在，输出一种方案。

**输入格式**
第一行输入三个整数 `n c1 c2`。
第二行输入 `n` 个整数，表示每个集装箱的重量。

**输出格式**
若可以装载，第一行输出 `YES`，第二行输出装入第一艘船的集装箱编号。
若不可以装载，输出 `NO`。

**输入样例**
```text
4 50 50
10 40 40 10
```

**输出样例**
```text
YES
1 2
```

---

# 解决思路：转化为第一艘船最优装载

双船装载问题可以先考虑第一艘船：

1. 设全部集装箱总重量为 `sum`。
2. 若能在第一艘船上装入重量 `best`，且 `sum - best <= c2`，则剩余集装箱可以装入第二艘船。
3. 因此目标是：在不超过 `c1` 的前提下，使第一艘船装得尽可能重。

使用队列式分支限界法搜索每个集装箱“装入第一艘船”或“不装入第一艘船”两种选择，并用剩余重量作为上界剪枝。

# 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int level;              // 当前准备决策第 level 个集装箱，已经决策完的数量是level-1
    int weight;             // 第一艘船当前已装重量
    vector<int> chosen;     // 已经选择装入第一艘船的集装箱编号
};

int main() {
    int n, c1, c2;
    cin >> n >> c1 >> c2;

    vector<int> w(n + 1);
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        cin >> w[i];
        sum += w[i];
    }

    // 总重量超过两艘船容量之和时，一定无法全部装载。
    if (sum > c1 + c2) {
        cout << "NO\n";
        return 0;
    }

    // remain[i] 表示从第 i 个到第 n 个集装箱的总重量。
    // 它用于估计当前分支未来最多还能增加多少重量，从而剪枝。
    vector<int> remain(n + 2, 0);
    for (int i = n; i >= 1; i--) {
        remain[i] = remain[i + 1] + w[i];
    }

    int bestWeight = 0;
    vector<int> bestChosen;

    queue<Node> q;
    // 从第 1 个集装箱开始搜索，此时第一艘船重量为 0。
    q.push({1, 0, {}});

    while (!q.empty()) {
        Node cur = q.front();
        q.pop();

        // 所有集装箱都已经决策完，更新第一艘船的最优装载重量。
        if (cur.level==n+1) {
            if (cur.weight > bestWeight) {
                bestWeight = cur.weight;
                bestChosen = cur.chosen;
            }
            continue;
        }

        int i = cur.level;

        // 左分支：尝试把第 i 个集装箱装入第一艘船。
        if (cur.weight + w[i] <= c1) {
            // 注意：不建议直接修改 cur。因为左右分支必须基于相同的父节点状态推导。
            // 如果左分支直接修改了 cur 的属性，会污染状态，导致后面的右分支逻辑错误。
            // 通过新建 left/right 变量克隆出干净的副本，可以保证各分支互不干扰。
            Node left = cur;
            left.level = i + 1;
            left.weight += w[i];
            left.chosen.push_back(i);
            q.push(left);
        }

        // 右分支：不把第 i 个集装箱装入第一艘船。
        // 如果当前重量加上后续所有剩余重量仍不可能超过 bestWeight，这个分支不可能产生更优解，可以直接剪掉
        // 所以只把有可能产生更优解的节点放回去
        if (cur.weight + remain[i + 1] > bestWeight) {
            Node right = cur;
            right.level = i + 1;
            q.push(right);
        }
    }

    // 第一艘船尽量装重后，只要剩余重量能放进第二艘船，就存在双船装载方案。
    if (sum - bestWeight <= c2) {
        cout << "YES\n";
        for (int i = 0; i < (int)bestChosen.size(); i++) {
            if (i) cout << ' ';
            cout << bestChosen[i];
        }
        cout << '\n';
    } else {
        cout << "NO\n";
    }

    return 0;
}
```
