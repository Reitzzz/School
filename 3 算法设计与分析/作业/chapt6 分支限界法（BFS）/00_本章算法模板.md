## 1. 分支限界法通用思想

### 识别信号

- 需要求解**最优化问题**（如最大价值、最短路径、最小成本）。
- 搜索空间是一棵解空间树（子集树或排列树）。
- 强调**广度优先**或**最佳优先**，而不是深度优先（回溯法）。
- 需要使用剪枝函数（限界函数）来尽早淘汰不可能产生最优解的节点。

### 核心要素

- **队列（Queue）/优先队列（Priority Queue）**：用于存放活结点（未展开的结点）。
- **限界函数（Bound Function）**：计算当前结点向下拓展可能达到的最优值，用于剪枝。
- **当前最优解（Best Value）**：记录搜索过程中遇到过的最好结果，结合限界函数判断是否剪枝。

## 2. 队列式（FIFO）分支限界法模板

队列式分支限界法按照广度优先（BFS）的顺序扩展节点。

void bfs() {

    q.push(root);

            }
            continue; 
        }

        for (/* 每一个可选分支 */) {
            Node child = /* 基于 curr 和当前分支生成的新节点 */;
            
            // 5. 约束条件与限界函数检查
            if (/* 满足约束条件(child) */ && check_bound(child)) {

## 3. 优先队列式分支限界法模板

优先队列式分支限界法按照**最佳优先**的顺序扩展节点。通常需要重载 `<` 运算符以维护一个最大堆或最小堆。

> **💡【避坑指南】C++ `priority_queue` 的排序反常识设定：**
> C++ 的 `priority_queue` 默认是一个**大根堆**，并且它的底层只认 `<` 运算符。每次比较时，它会把被判定为“大”的元素往上提（堆顶）。
> - **求最大值（大根堆）**：重载 `<` 时，老老实实写 `<`（如 `return a.up < b.up;`）。这会把最大值顶到堆首。
> - **求最小值（小根堆）**：重载 `<` 时，要“骗”它，反着写 `>`（如 `return a.cost > b.cost;`）。这会把最小值顶到堆首。
> 
> *注意：这和常规容器（如 `std::sort`）完全相反！在 `std::sort` 中，写 `<` 得到的是升序（最小的在前面）。只有优先队列在这点上表现相反。*

```cpp
#include <iostream>
#include <queue>
using namespace std;

// 定义状态节点
struct Node {
    int level;      // 当前层数
    int value;      // 当前实际获得的值
    int bound;      // 预测的限界值（用于决定出队优先级）
    
    // 重载小于号，定义优先队列的优先级（具体原理见上方避坑指南）
    // 注意：如果是最小堆（求最小代价），这里反着写 >
    //      如果是最大堆（求最大收益），这里正常写 <
    bool operator<(const Node& other) const {
        return this->bound > other.bound; // 这里以最小堆为例
    }
};

int best_value = 初始极差值;

// 计算限界值
int calc_bound(Node node) {

    return /* bound_value */;
}

void best_first_search() {
    priority_queue<Node> pq;
    
    // 1. 初始化根节点，计算限界值并入队
    Node root = {0, 0, 0};
    root.bound = calc_bound(root);
    pq.push(root);
    
    while (!pq.empty()) {
        // 2. 取出优先级最高的节点
        Node curr = pq.top();
        pq.pop();
        
        // 限界剪枝：出队时发现当前节点的限界值已经不如全局最优解了，直接丢弃
        // 对于优先队列，由于是按优先级出队，如果堆顶都不如 best_value，
        // 说明后面的节点更不可能好，可以直接 break 或者 continue。
        if (curr.bound /* 劣于 */ best_value) {
            continue; // 或者 break;
        }
        
        // 3. 判断是否到达叶子节点
        if (curr.level == n) {
            if (curr.value /* 优于 */ best_value) {
                best_value = curr.value;
                // 对于某些问题（如最小堆找最短路径），第一个到达叶子的可能就是最优解
            }
            continue;
        }
        
        // 4. 扩展当前节点的所有可能分支
        for (/* 每一个可选分支 */) {
            Node child = /* 基于 curr 生成的新节点 */;
            
            if (/* 满足约束条件(child) */) {
                child.bound = calc_bound(child);
                
                // 入队前进行限界剪枝
                if (child.bound /* 优于 */ best_value) {
                    pq.push(child);
                }
            }
        }
    }
}
```
