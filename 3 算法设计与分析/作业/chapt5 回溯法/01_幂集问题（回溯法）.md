**题目描述**
集合是数学中一个重要的知识点，一个集合有 $2^n$ 个子集，现在的任务是给定一个大小为 $n$ 的集合，集合为 $\{1, 2, ..., n\}$，求出该集合的所有子集合。
子集合中所有元素降序排列，并按字典序输出，不同元素使用“,”隔开。
多组测试数据

**输入格式**
集合元素个数 $n, n<10$。

**输出格式**
所有子集合

**输入样例**
```text
2
3
```

**输出样例**
```text
{}
{1}
{2}
{2,1}
{}
{1}
{2}
{2,1}
{3}
{3,1}
{3,2}
{3,2,1}
```

# 解决思路

### 1. 核心思想：回溯法（子集树）
这道题目要求输出一个集合的所有子集，也就是求“幂集”。对于大小为 $n$ 的集合，每个元素都有“选”或“不选”两种状态，总共有 $2^n$ 种子集，这正对应了回溯法中的**子集树**模型。

### 2. 输出顺序的玄机（从 $n$ 到 $1$ 递归）
本题的难点在于**输出顺序的要求**。观察样例输出的规律：
* 当 $n=2$ 时，输出为 `{}`, `{1}`, `{2}`, `{2,1}`。
* 当 $n=3$ 时，前4个输出就是 $n=2$ 的结果，接着是将 `3` 加入到前4个结果中的组合：`{3}`, `{3,1}`, `{3,2}`, `{3,2,1}`。

**为什么要“从大到小递归”且“先走不选，再走选”呢？**
仔细观察，这种生成顺序实际上就是**二进制数的递增过程**。
如果我们把集合 $\{3, 2, 1\}$ 中元素的“选”看作二进制的 `1`，“不选”看作二进制的 `0`：
* `{}` $\rightarrow$ 都不选 $\rightarrow$ `000`
* `{1}` $\rightarrow$ 只选1 $\rightarrow$ `001`
* `{2}` $\rightarrow$ 只选2 $\rightarrow$ `010`
* `{2, 1}` $\rightarrow$ 选2和1 $\rightarrow$ `011`
* `{3}` $\rightarrow$ 只选3 $\rightarrow$ `100`
...依此类推，刚好是十进制 $0$ 到 $7$ 的严格递增！

**结论推导：**
1. **最高位的决定**：在二进制中，最高位变化最慢。数字 `3` 的变化最慢（前一半都是不选它，后一半都是选它），这说明数字 `3` 对应的是最高位。<br>
   因此我们需要**优先去决定大数字（从 $n$ 递减到 $1$）**。
2. **0 和 1 的顺序**：由于二进制数是从小到大递增的（如 `000` 接着是 `001`），**每一位都必须先经历 `0`，再经历 `1`。<br>**
   这对应到代码中，就是每一次做决定时，必须**先走“不选（0）”的分支，再走“选（1）”的分支**。

这就是为什么我们的回溯函数代码被设计成这样（对于只有“选”和“不选”两种状态的子集问题，如果强行套用 `for` 循环反而显得多此一举，直接平铺写出两个分支是最清晰的做法）：
* 判断元素 $k$ 时：
  1. 标记 $k$ 为不选（对应二进制的 `0`），递归去判断 $k-1$。
  2. 标记 $k$ 为选中（对应二进制的 `1`），递归去判断 $k-1$。
* 当递归深度到达 $0$ 时（所有元素都已做完决定），即可进行一次输出。

### 3. 降序排列与格式控制
* 题目要求子集内的元素按**降序排列**，这恰好符合我们定义集合 $\{1, 2, ..., n\}$ 的倒序。当到达叶子节点准备输出时，我们只需用一个从 $n$ 递减到 $1$ 的 `for` 循环遍历，遇到被标记为“选”的元素就打印出来，这样天然就是降序。
* 利用一个布尔变量 `first` 来控制逗号 `,` 的输出，确保只有在输出非首个元素时才打印逗号，从而满足 `{3,2,1}` 这样的格式。
* 因为有**多组测试数据**，主函数中需使用 `while (cin >> n)` 来循环接收输入。

# 最终代码

```cpp
#include <iostream>
#include <vector>

using namespace std;

// 使用全局数组记录每个数字的选中状态，arr[i]=1表示选中数字i，0表示不选
int arr[15]; 
int n;

// 回溯函数，k 表示当前正在做决定的数字位数 (从 n 递减到 1)
void dfs(int k) {
    // 终止条件：当 k == 0 时，说明 1~n 所有数字都已经做完了决定
    if (k == 0) {
        cout << "{";
        bool first = true;
        // 按降序输出被选中的元素
        for (int i = n; i >= 1; i--) {
            if (arr[i]) {   //注意只有选中时才考虑输出 否则会输出无关{}
                if (!first) cout << ","; // 非首个元素前加逗号
                cout << i;
                first = false;
            }
        }
        cout << "}\n";
        return;
    }
    
    // 核心回溯逻辑：直接展开两个分支，比写 for 循环更清晰简洁
    // 为了满足字典序和样例输出的顺序，必须先走“不选（0）”的分支，再走“选（1）”的分支。

    // 分支 1：不选当前数字 k，对应二进制位 0
    arr[k] = 0;
    dfs(k - 1);
    
    // 分支 2：选中当前数字 k，对应二进制位 1
    // （这里给 arr[k] 赋新值，天然起到了“撤销上一步选择并做新选择”的作用）
    arr[k] = 1;
    dfs(k - 1);
}

int main() {
    // 应对多组测试数据
    while (cin >> n) {
        // 从最大的数字 n 开始倒序决定
        dfs(n);
    }
    return 0;
}
```
