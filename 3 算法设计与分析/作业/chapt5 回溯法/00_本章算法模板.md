## 1. 回溯通用模板

### 识别信号

- 要输出所有方案。
- 每一步都有多个选择。
- 选了之后继续试，不行就退回。
- 常见关键词：所有子集、全排列、组合、路径、方案数。

### 通用骨架

```cpp
void dfs(int depth) {
    if (到达完整解) {
        输出或更新答案;
        return;
    }

    for (每一个可选 choice) {
        if (choice 合法) {
            做选择;
            dfs(depth + 1);
            撤销选择;
        }
    }
}
```

### 回溯三件事

- 当前层含义：这一层在决定哪个元素/哪个位置？
- 递归边界：什么时候算一个完整解？
- 恢复现场：递归回来后有没有撤销选择？

## 2. 子集树（如：幂集、01背包）通用骨架

```cpp
// 数组记录每个元素的状态（选/不选）
int choose[MAXN];

void dfs(int depth) {
    // 1. 递归边界：所有元素都已经做过决定
    if (depth == n) {
        // 判断当前子集是否合法，如果合法则记录/输出
        process(choose);
        return;
    }

    // 分支 1：不选第 depth 个元素
    choose[depth] = 0; // 记录状态
    // (可选) 剪枝：如果当前状态已经不可能达到最优，就不要递归下去
    dfs(depth + 1);    // 深入下一层

    // 分支 2：选择第 depth 个元素
    choose[depth] = 1; // 记录状态
    // (可选) 剪枝：如果选择后超过容量限制，就不要递归下去
    if (选择合法) {
        dfs(depth + 1);    // 深入下一层
    }
    
    // 恢复现场：这里因为每次都会直接覆盖 choose[depth]，所以不需要显式撤销。
}
```

## 3. 排列树（如：全排列、N皇后）通用骨架

```cpp
// path 记录排列结果，used 记录某个元素是否已经被使用过
int path[MAXN];
bool used[MAXN];

void dfs(int depth) {
    // 1. 递归边界：填满了所有的位置
    if (depth == n) {
        // 找到一个完整的排列，处理或输出
        process(path);
        return;
    }

    // 2. 尝试在当前位置填入每一个可能的候选元素
    for (int i = 1; i <= n; i++) {
        // 如果元素 i 还没有被使用过，且填在这里合法（如 N皇后的对角线检查）
        if (!used[i] && check_valid(i)) {
            
            // 做选择：记录路径，标记为已使用
            path[depth] = i;
            used[i] = true;

            // 深入下一层，填下一个位置
            dfs(depth + 1);

            // 撤销选择：恢复现场，为尝试下一个元素做准备
            used[i] = false;
        }
    }
}
```
