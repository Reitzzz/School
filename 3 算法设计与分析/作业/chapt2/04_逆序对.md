# 题干

**题目描述**
给定一个序列a1,a2,...,an，如果存在i < j并且ai > aj，那么我们称之为逆序对，求逆序对的数目。

**输入格式**
第一行为n,表示序列长度，接下来的n行，第i+1行表示序列中的第i个数。

**输出格式**
输出：所有逆序对总数。
数据范围：N<=10^5。Ai<=10^5。时间限制为1s。

**输入样例**
```text
4
3 2 3 2
```

**输出样例**
```text
3
```

---

# 解决思路

1. **核心算法：归并排序（Merge Sort）**
   暴力破解两层循环的时间复杂度为 O(N²)，对于 10^5 的数据必定会超时。利用归并排序“分而治之”的思想，可以在合并两个有序子数组的过程中顺便统计逆序对，将时间复杂度大幅降低至 O(N log N)。

2. **核心逻辑：打包统计逆序对**
   在合并左半边 `[l, mid]` 和右半边 `[mid+1, r]` 时（前提是左右两边内部均已从小到大排好序）：
   * 设置双指针 `i` 和 `j` 分别指向左右两边的当前元素。
   * 若 `a[i] <= a[j]`，符合前小后大，无逆序，正常将 `a[i]` 放入临时数组。
   * 若 `a[i] > a[j]`，则**产生逆序对**。因为左半边是有序的，既然当前的 `a[i]` 大于 `a[j]`，那么 `a[i]` 后面的所有元素必然也都大于 `a[j]`。此时可以直接进行“打包计算”，这一批逆序对的数量刚好就是左边剩下的元素个数，即 `mid - i + 1`。将该数量累加到结果中。

3. **细节陷阱：数据类型防溢出**
   当原数组为完全倒序排列时，逆序对数量达到理论最大值 N(N-1)/2。对于 N = 10^5，最大逆序对数量约为 5×10^9，这已经超出了 32 位有符号整数 `int` 的最大上限（约 21.4 亿）。因此，存储和返回逆序对总数的变量必须使用 `long long` 类型，否则会引发溢出错误。

---

# 最终代码

```cpp
#include <iostream>
#include <vector>

using namespace std;

long long merge_sort(vector<int>& a, int l, int r, vector<int>& tmp) {
    if (l >= r) return 0;

    int mid = l + (r - l) / 2;
    long long res = merge_sort(a, l, mid, tmp) + merge_sort(a, mid + 1, r, tmp);

    int i = l, j = mid + 1, k = 0;

    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            res += mid - i + 1;
            tmp[k++] = a[j++];
        }
    }

    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];

    for (i = l, k = 0; i <= r; i++, k++) {
        a[i] = tmp[k];
    }

    return res;
}

int main() {
    int n;
    if (cin >> n) {
        vector<int> a(n);
        for (int i = 0; i < n; i++) {
            cin >> a[i];
        }
        
        vector<int> tmp(n);
        cout << merge_sort(a, 0, n - 1, tmp) << "\n";
    }
    return 0;
}
