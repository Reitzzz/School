# 题干

**题目描述**
输入两个元素个数都为n的有序数组，将其合并后有序输出。

**输入格式**
第一行输入一个m，表示有m组数据。（m <= 10000）
第二行输入一个n，表示两个数组的元素个数。（n <= 500000）
第三、第四行分别输入两个数组。

**输出格式**
合并后的有序数组。每组数据的输出结果占一行，元素之间以空格分隔。

**输入样例**
```text
2
3
1 3 5
2 4 6
4
1 2 7 8
3 4 5 6
```

**输出样例**
```text
1 2 3 4 5 6
1 2 3 4 5 6 7 8
```

---

# 解决思路

1. **核心算法：双指针（Two Pointers）**
   因为题目给定的两个数组已经是**有序**的，所以不需要将它们拼接后再进行整体排序。我们可以在单趟遍历中，直接利用双指针将两者按序合并，时间复杂度为 O(n)。

2. **指针初始化与循环比较**
   * 设定两个变量 `i` 和 `j` 作为指针，初始值均设为 `0`，分别指向数组 `a` 和数组 `b` 的起始位置。
   * 当 `i < n` 且 `j < n` 时，进入核心比对循环：比较 `a[i]` 和 `b[j]` 的大小，谁的值更小，就输出谁，并将对应的指针向后移动一位（`i++` 或 `j++`）。

3. **处理剩余元素（收尾）**
   当其中一个数组被完全遍历后（指针达到 `n`），核心循环结束。此时另一个数组中必定还有未输出的元素。由于原数组本身有序，且剩余元素必然大于已输出的所有元素，因此直接通过 `while` 循环将未走完的数组的剩余元素依次输出即可。

4. **细节：输出格式控制**
   * **空格问题**：为了避免末尾多出空格导致格式错误（Presentation Error），引入一个布尔变量 `first`（初始为 `true`）。在每次准备输出数字前检查，如果 `!first` 则先输出一个空格，随后将 `first` 置为 `false`。这个逻辑要贯穿核心循环和收尾循环。
   * **换行问题**：因为有多组测试数据，在每一组数据的合并操作全部完成后，必须输出一个换行符 `\n`。

# 最终代码

```cpp
#include <iostream>
#include <vector>

using namespace std;

void solve() {
    int n;
    cin >> n;
    
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    vector<int> b(n);
    for (int i = 0; i < n; i++) {
        cin >> b[i];
    }
    
    bool first = true;
    int i = 0, j = 0;

    while (i < n && j < n) {
        if (!first) cout << " ";

        if (a[i] < b[j]) {
            cout << a[i];
            i++;
        } else {
            cout << b[j];
            j++;
        }

        first = false;
    }

    while (i < n) {
        if (!first) cout << " ";
        cout << a[i];
        i++;
        first = false;
    }

    while (j < n) {
        if (!first) cout << " ";
        cout << b[j];
        j++;
        first = false;
    }

    cout << "\n";
}

int main() {
    int m;
    if (cin >> m) {
        while (m--) {
            solve();
        }
    }
    return 0;
}
```
