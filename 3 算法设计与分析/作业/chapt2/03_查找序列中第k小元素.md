# 题干

**题目描述**
对于给定的含有n（n<=1000000）元素的无序序列，求这个序列中第k（1≤k≤n）小的元素。

**输入格式**
第一行为n，第二行为n个数。第三行为k的值。

**输出格式**
第k小的元素。

**输入样例**
```text
10
243 3 4365 34 4365 21 234 1 234 3
5
```

**输出样例**
```text
34
```

---

# 解决思路

1. **核心算法：快速选择（Quick Select）**
   本题要求在一个无序数组中寻找“第 k 小”的元素。如果对整个数组进行完全排序，时间复杂度为 O(n log n)；而使用基于快速排序思想的“快速选择算法”，每次只需要处理目标元素所在的那一半区间，可将平均时间复杂度优化至 O(n)。

2. **挖坑法划分区间（Partition）**
   * 在当前区间 `[l, r]` 内，选定最左侧的元素 `a[l]` 作为基准值（Pivot）存入临时变量 `tmp` 中，此时 `a[l]` 形成一个“坑”。
   * 利用双指针 `i` 和 `j` 从两端向中间逼近：
     * `j` 从右向左扫描，找到比基准值小的元素就填入 `i` 的坑中，此时 `j` 变成新坑。
     * `i` 从左向右扫描，找到比基准值大的元素就填入 `j` 的坑中，此时 `i` 变成新坑。
   * 当 `i` 与 `j` 相遇时，将基准值 `tmp` 填入最后的坑中。此时，基准值左边的元素都比它小，右边的元素都比它大，基准值的绝对位置已确定。

3. **按需递归**
   * 判断基准值当前所处的绝对位置（假设为 `j`）与目标位置 `k` 的关系：
     * 如果 `k == j`，说明找到了第 k 小的元素，直接返回。
     * 如果 `k < j`，说明目标在基准值的左侧，舍弃右半侧，递归处理 `[l, i-1]`。
     * 如果 `k > j`，说明目标在基准值的右侧，舍弃左半侧，递归处理 `[i+1, r]`。
   * 当区间缩小至唯一元素且正好对应位置 `k` 时，触发递归出口直接返回。

# 最终代码

````cpp
#include <iostream>

using namespace std;

int n, k;
int a[1000001];

int Quick(int l, int r, int k) {
    int i = l, j = r, tmp;
    if (l < r) {
        tmp = a[l];
        while (i != j) {
            while (j > i && a[j] >= tmp) j--;
            a[i] = a[j];
            while (i < j && a[i] <= tmp) i++;
            a[j] = a[i];
        }
        a[i] = tmp;
        if (k == j) return a[i];
        else if (k < j) return Quick(l, i - 1, k);
        else return Quick(i + 1, r, k);
    }
    else if (l == r && l == k)
        return a[k];
    
    return 0;
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    cin >> k;
    cout << Quick(1, n, k);
    return 0;
}
