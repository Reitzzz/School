# 题干

**题目描述**
序列的子序列是指给定序列中遗漏了一些元素（也可能没有遗漏）的序列。给定序列 $X = \langle x_1, x_2, \dots, x_m \rangle$，另一序列 $Z = \langle z_1, z_2, \dots, z_k \rangle$ 是 $X$ 的子序列，如果存在严格递增序列 $\langle i_1, i_2, \dots, i_k \rangle$，使得对于所有 $j = 1, 2, \dots, k$，$x_{i_j} = z_j$。例如，$Z = \langle a, b, f, c \rangle$ 是索引序列 $\langle 1, 2, 4, 6 \rangle$ 的 $X = \langle a, b, c, f, b, c \rangle$ 的子序列。给定两个序列 $X$ 和 $Y$，问题是找到 $X$ 和 $Y$ 的最大长度公共子序列的长度。

**输入格式**
文件中的每个数据集包含表示给定序列的两个字符串。序列由任意数量的空格分隔。输入数据正确。

**输出格式**
对于每一组数据，程序在标准输出上打印从单独行开始的最大长度公共子序列的长度。

**输入样例**
```text
abcfbc abfcab
programming contest
abcd mnp
```

**输出样例**
```text
4
2
0
```

# 解决思路

1. **核心算法：动态规划**
   本题是**经典的“最长公共子序列”问题**。由于要求两个字符串中按原有相对顺序提取的最长公共部分，不能通过简单的排序或双指针单次遍历解决，可以通过动态规划构建状态表来求解。

2. **核心难点：状态定义与转移方程**
   动态规划的本质是“查表推导”，我们将计算整个长序列的最长公共子序列这一庞大问题，拆解为计算不断截断的短子串的局部小问题。

   * **状态定义（明确表格中每个格子的含义）：**
     设定一个二维数组 $dp[i][j]$ 来记录状态。
     * 变量 $i$ 表示当前仅截取字符串 $X$ 的前 $i$ 个字符。
     * 变量 $j$ 表示当前仅截取字符串 $Y$ 的前 $j$ 个字符。
     * $dp[i][j]$ 的数值，就代表在上述两个截断的子串中，最长公共子序列的长度。
     * 例如，$X$ 为 "abc"，$Y$ 为 "adc" 时，$dp[2][1]$ 代表用 $X$ 的前 2 个字符（"ab"）去匹配 $Y$ 的前 1 个字符（"a"），此时公共长度为 1，故 $dp[2][1] = 1$。

   * **转移方程（明确如何通过已知的小格子推导未知的大格子）：**
     在计算 $dp[i+1][j+1]$ 时，核心破局点在于观察这两个子串当前处理的字符（即对应原字符串中的 $X[i]$ 和 $Y[j]$）。根据它们是否相等，逻辑产生分歧：

     * **情况一：当前字符相同（匹配成功）**
       如果 $X[i] == Y[j]$，说明这个字符必定属于当前最长公共子序列的最末尾元素，它能为总长度稳稳贡献 1 长度。
       既然末尾已经匹配上了，那前面的公共部分有多长呢？只需将两个字符串的当前字符都“剥离”，直接去查阅它们前置部分的最长公共长度（即左上角的状态 $dp[i][j]$）。
       **推导公式：** $dp[i+1][j+1] = dp[i][j] + 1$

     * **情况二：当前字符不同（匹配失败）**
       如果 $X[i] \neq Y[j]$，说明这两个字符水火不容，绝对不可能同时出现在同一个公共子序列的末尾。为了寻找“最长”的公共子序列，我们需要兵分两路，分别尝试抛弃其中一个碍事的字符：
       1. **抛弃 $X$ 的当前字符**：保留 $Y$ 不变，用 $X$ 的前 $i$ 个字符去和 $Y$ 的前 $j+1$ 个字符匹配，其最大长度对应表格正上方的状态 $dp[i][j+1]$。
       2. **抛弃 $Y$ 的当前字符**：保留 $X$ 不变，用 $X$ 的前 $i+1$ 个字符去和 $Y$ 的前 $j$ 个字符匹配，其最大长度对应表格正左侧的状态 $dp[i+1][j]$。
       既然要的是最长公共部分，我们只需在这两条路径的结果中，取那个更大的值即可。
       **推导公式：** $dp[i+1][j+1] = \max(dp[i][j+1], dp[i+1][j])$

3. **初始化与边界条件**
   当其中任意一个字符串的长度为 0 时，它们不可能有公共部分，因此公共子序列长度必然为 0。即二维数组的第一行和第一列全部初始化为 0：$dp[i][0] = 0$ 和 $dp[0][j] = 0$。在代码中，可以直接将整个二维数组的初始值设为 0 来自然满足边界条件。

4. **细节处理：多组数据输入**
   题目要求处理“文件中的每个数据集”，并且“序列由任意数量的空格分隔”。在 C++ 中，利用 `while (cin >> s1 >> s2)` 可以在达到文件末尾（EOF）前持续读取字符串。这种方式能自动跳过任意数量的空格、制表符或换行符，完美契合题意。

# 最终代码

```cpp
#include <bits/stdc++.h>

using namespace std;

void solve(const string& s1, const string& s2) {
    int m = s1.length();
    int n = s2.length();
    
    // dp[i][j] 表示 s1 的前 i 个字符和 s2 的前 j 个字符的 LCS 长度
    // 默认初始化为 0，自然处理了 i=0 或 j=0 的边界情况
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (s1[i] == s2[j]) {
                // 当前字符匹配，在抛弃两者的前置状态上加一
                dp[i + 1][j + 1] = dp[i][j] + 1;
            } else {
                // 字符不匹配，取抛弃 s1 当前字符或抛弃 s2 当前字符状态的最大值
                dp[i + 1][j + 1] = max(dp[i][j + 1], dp[i + 1][j]);
            }
        }
    }
    
    // 输出两串整体的最大公共子序列长度，并换行
    cout << dp[m][n] << "\n";
}

int main() {
    string s1, s2;
    // 持续读取每一对字符串，处理任意数量的空格，直到文件结束 (EOF)
    while (cin >> s1 >> s2) {
        solve(s1, s2);
    }
    
    return 0;
}
```
