# 题干

题目描述
给定一个序列 a1, a2, ..., an，如果存在 i < j 并且 ai > aj，那么称 (i, j) 为一个逆序对，求逆序对的总数。

输入格式
第一行为 n，表示序列长度；接下来的 n 行，第 i+1 行表示序列中的第 i 个数。

输出格式
输出所有逆序对的总数。

数据范围
N <= 10^5，Ai <= 10^5，时间限制为 1s。

输入样例
4
3 2 3 2

输出样例
3

---

# 解决思路

1. 核心算法：归并排序（Merge Sort）
   暴力做法需要枚举所有 i, j，时间复杂度为 O(N^2)。当 N 达到 10^5 时，这种方法一定超时。归并排序利用分治思想，把序列拆成左右两半，先分别统计左右区间内部的逆序对，再在合并两个有序区间时统计跨区间逆序对，从而把时间复杂度降到 O(N log N)。

2. 合并时统计跨区间逆序对
   假设左半区间是 [l, mid]，右半区间是 [mid+1, r]，并且这两个区间内部已经排好序。
   当左指针 i 指向 a[i]，右指针 j 指向 a[j] 时：
   如果 a[i] <= a[j]，说明当前元素不构成逆序对，把 a[i] 放入临时数组，i 右移。
   如果 a[i] > a[j]，说明 a[j] 与左半区间中从 i 到 mid 的所有元素都构成逆序对，因为左半区间有序，所以 a[i], a[i+1], ..., a[mid] 都大于 a[j]。此时逆序对数量一次性增加 mid - i + 1。

3. 数据类型要用 long long
   当序列完全逆序时，逆序对数量最大为 n(n-1)/2。对于 n = 10^5，结果大约是 5 × 10^9，已经超过 32 位整数的范围，因此计数变量必须使用 long long。

---

# 最终代码

    #include <iostream>
    #include <vector>

    using namespace std;

    long long merge_sort(vector<int>& a, int l, int r, vector<int>& tmp) {
        if (l >= r) return 0;

        int mid = l + (r - l) / 2;
        long long res = merge_sort(a, l, mid, tmp) + merge_sort(a, mid + 1, r, tmp);

        int i = l, j = mid + 1, k = 0;

        while (i <= mid && j <= r) {
            if (a[i] <= a[j]) {
                tmp[k++] = a[i++];
            } else {
                res += mid - i + 1;
                tmp[k++] = a[j++];
            }
        }

        while (i <= mid) tmp[k++] = a[i++];
        while (j <= r) tmp[k++] = a[j++];

        for (i = l, k = 0; i <= r; i++, k++) {
            a[i] = tmp[k];
        }

        return res;
    }

    int main() {
        int n;
        if (cin >> n) {
            vector<int> a(n);
            for (int i = 0; i < n; i++) {
                cin >> a[i];
            }

            vector<int> tmp(n);
            cout << merge_sort(a, 0, n - 1, tmp) << "\n";
        }
        return 0;
    }
