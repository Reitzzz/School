# 题干

题目描述
给定一个序列 $a_1, a_2, \ldots, a_n$，如果存在 $i < j$ 并且 $a_i > a_j$，那么称 $(i, j)$ 为一个逆序对，求逆序对的总数。

输入格式
第一行为 n，表示序列长度；接下来的 n 行，第 i+1 行表示序列中的第 i 个数。

输出格式
输出所有逆序对的总数。

数据范围
$N \le 10^5$，$A_i \le 10^5$，时间限制为 1s。

输入样例
4
3 2 3 2

输出样例
3

---

# 解决思路

1. **核心算法：归并排序（Merge Sort）**
    暴力做法需要枚举所有 $i, j$，时间复杂度为 $O(N^2)$。当 $N$ 达到 $10^5$ 时，这种方法一定超时。归并排序利用分治思想，把序列拆成左右两半，先分别统计左右区间内部的逆序对，再在合并两个有序区间时统计跨区间逆序对，从而把时间复杂度降到 $O(N \log N)$。

2. **合并时统计跨区间逆序对**
    假设左半区间是 $[l, mid]$，右半区间是 $[mid+1, r]$，并且这两个区间内部已经排好序。
    当左指针 $i$ 指向 $a[i]$，右指针 $j$ 指向 $a[j]$ 时：
    如果 $a[i] \le a[j]$，说明当前元素不构成逆序对，把 $a[i]$ 放入临时数组，$i$ 右移。
    如果 $a[i] > a[j]$，说明 $a[j]$ 与左半区间中从 $i$ 到 $mid$ 的所有元素都构成逆序对，因为左半区间有序，所以 $a[i], a[i+1], \ldots, a[mid]$ 都大于 $a[j]$。此时逆序对数量一次性增加 $mid - i + 1$。

3. **数据类型要用 long long**
    当序列完全逆序时，逆序对数量最大为 $n(n-1)/2$。对于 $n = 10^5$，结果大约是 $5 \times 10^9$，已经超过 32 位整数的范围，因此计数变量必须使用 long long。

# 最终代码
```cpp
    #include <iostream>
    #include <vector>

    using namespace std;

    /**
     * a 待排序和统计的数组
     * l 当前处理区间的左端点
     * r 当前处理区间的右端点
     * tmp 辅助数组，用于归并时存储结果
     */
    long long merge_sort(vector<int>& a, int l, int r, vector<int>& tmp) {

        // 递归终止条件：当子数组长度为 0 或 1 时，不可能存在逆序对
        if (l >= r) return 0;

        // 计算中间位置，防止下标越界
        int mid = l + (r - l) / 2;
        
        // 1. 统计左半区间 [l, mid] 内部的逆序对
        // 2. 统计右半区间 [mid+1, r] 内部的逆序对
        // 3. 同时完成左右两部分的排序，为后续合并做准备
        long long res = merge_sort(a, l, mid, tmp) + merge_sort(a, mid + 1, r, tmp);

        // 经过上面的递归，此时 [l, mid] 和 [mid+1, r] 都已是递增有序的
        // 现在需要合并这两个有序区间，并统计跨越两个区间的逆序对
        
        int i = l;           // 左指针，指向左半区间的起始位置
        int j = mid + 1;     // 右指针，指向右半区间的起始位置
        int k = 0;           // 临时数组指针，指向 tmp 的起始位置

        while (i <= mid && j <= r) {
            if (a[i] <= a[j]) {
                // 【情况1】左元素 ≤ 右元素
                // 说明左边的元素较小（或相等），不构成逆序对
                // 按照归并排序的正常逻辑，将较小的元素放入临时数组
                tmp[k++] = a[i++];
            } else {
                // 【情况2】左元素 > 右元素（重点：批量统计逆序对）
                // 这是统计逆序对的关键！由于左半区间 [l, mid] 已经是递增有序的，
                // 如果 a[i] > a[j]，那么从 i 到 mid 的所有元素都满足：
                //    a[i], a[i+1], a[i+2], ..., a[mid] 都 > a[j]
                // 因此当前的 a[j] 与左半区间剩余的所有元素都构成逆序对
                // 左半区间剩余元素的个数是：mid - i + 1
                res += mid - i + 1;
                // 将较小的右元素放入临时数组，右指针向后移动
                tmp[k++] = a[j++];
            }
        }

        //善后工作：处理剩余元素
        // 将左半区间的剩余元素（如果有）直接追加到临时数组末尾
        while (i <= mid) tmp[k++] = a[i++];
        
        // 将右半区间的剩余元素（如果有）直接追加到临时数组末尾
        while (j <= r) tmp[k++] = a[j++];

        // 将排序好的临时数组 tmp 的内容，写回原数组 a 对应区间
        // 这一步是必需的！因为算法的正确性依赖于 [l, r] 最终是有序的，

        for (i = l, k = 0; i <= r; i++, k++) {
            a[i] = tmp[k];
        }

        return res;
    }

    int main() {
        int n;
        if (cin >> n) {
            vector<int> a(n);
        
            for (int i = 0; i < n; i++) {
                cin >> a[i];
            }

            // 创建辅助数组，用于归并排序中的临时存储
            // 使用 long long 而非 int 是因为当 N=10^5 时，
            // 逆序对最多有 n(n-1)/2 ≈ 5×10^9，超过了 int 的范围
            vector<int> tmp(n);
            
            cout << merge_sort(a, 0, n - 1, tmp) << "\n";
        }
        return 0;
    }
```
