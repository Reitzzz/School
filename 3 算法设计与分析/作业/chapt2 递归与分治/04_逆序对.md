# 题干

**题目描述**
给定一个序列 $a_1, a_2, \ldots, a_n$，如果存在 $i < j$ 并且 $a_i > a_j$ **（即违反了升序排序）**，那么称 $(i, j)$ 为一个逆序对，求逆序对的总数。

**输入格式**
第一行为 n，表示序列长度；接下来的 n 行，第 i+1 行表示序列中的第 i 个数。

**输出格式**
输出所有逆序对的总数。

**数据范围**
$N \le 10^5$，$A_i \le 10^5$，时间限制为 1s。

**输入样例**
```text
4
3 2 3 2
```

**输出样例**
```text
3
```

---

# 解决思路

通过将数组不断地“劈成两半”再“像拉链一样咬合合并”，我们能在 $O(N \log N)$ 的时间复杂度内统计出逆序对的数量，避免了暴力的 $O(N^2)$ 超时。
整个逻辑可以拆解为以下三个模块的伪代码：

### 1. 递归分治
首先将大数组不断劈开，直到只剩 1 个数字。然后分别算出左右两半各自内部的逆序对。

```text
    // 递归停止条件
    如果 左边界 >= 右边界: 返回 0

    中点 = (左边界 + 右边界) / 2
    
    // 1. 分治：分别算出左半边和右半边内部的逆序对
    左边逆序对 = 归并排序求逆序对(左边界, 中点)
    右边逆序对 = 归并排序求逆序对(中点 + 1, 右边界)
    总数 = 左边逆序对 + 右边逆序对
```

### 2. 双指针合并与批量统计（核心高光）
这是产生逆序对的关键步骤。既然左右两半已经**排好了升序**，我们就用双指针 `i` 和 `j` 将它们合并。

```text
    // 2. 合并：双指针合并两段有序数组
    i = 左边界    // i 指向左半边开头
    j = 中点 + 1  // j 指向右半边开头
    k = 0         // 临时数组的指针
    
    只要 (i <= 中点) 并且 (j <= 右边界):
        如果 a[i] <= a[j]:   
            // 正常情况，拿走左边的，没有逆序对
            tmp[k++] = a[i++]
        否则:
            // 【产生逆序对】此时 a[i] > a[j]
            // 由于左半区已排好升序，a[i...mid] 这 (mid - i + 1) 个元素必然全都大于 a[j]
            // 因此它们都会和 a[j] 构成逆序对，总数直接增加 (mid - i + 1)
            tmp[k++] = a[j++]
            总数 = 总数 + (中点 - i + 1)
```

### 3. 扫尾工作与物归原主
当拉链的一边走到头后，把另一边剩下的元素直接全盘放进临时数组。最后，必须将排好序的临时数组复制回原数组，只有这样才能为上一层的合并提供“已经排好序”的基础。

```text
    // 3. 扫尾工作
    只要 (i <= 中点): tmp[k++] = a[i++]
    只要 (j <= 右边界): tmp[k++] = a[j++]
    
    // 4. 物归原主：把排好序的临时数组贴回原数组
    将 tmp 中本次排好序的内容复制回 a[左边界 ... 右边界]
    
    返回 总数
```

> **注意：数据类型防溢出**
> 当序列完全逆序时，逆序对数量最大为 $n(n-1)/2$。对于 $n = 10^5$，结果大约是 $5 \times 10^9$，已经超过了 32 位 `int` 的最大值，因此统计逆序对的总数变量必须使用 `long long`。

# 最终代码
```cpp
    #include <iostream>
    #include <vector>

    using namespace std;

    const int MAXN = 100005; // 根据题目数据范围 N <= 10^5 设定最大长度
    vector<int> a(MAXN);    // 待排序和统计逆序对的原数组
    vector<int> tmp(MAXN);  // 辅助数组，用于归并排序合并阶段的临时存储

   
    // l 当前处理区间的左端点
    // r 当前处理区间的右端点
    long long merge_sort(int l, int r) {

        // 递归终止条件：当子数组长度为 0 或 1 时，不可能存在逆序对
        if (l >= r) return 0;

        // 计算中间位置，防止下标越界
        int mid = l + (r - l) / 2;
        
        // 1. 统计左半区间 [l, mid] 内部的逆序对
        // 2. 统计右半区间 [mid+1, r] 内部的逆序对
        // 3. 同时完成左右两部分的排序，为后续合并做准备
        
        long long res = merge_sort(l, mid) + merge_sort(mid + 1, r);

        // 经过上面的递归，此时 [l, mid] 和 [mid+1, r] 都已是递增有序的
        // 现在需要合并这两个有序区间，并统计跨越两个区间中的逆序对
        
        int i = l;           // 左指针，指向左半区间的起始位置
        int j = mid + 1;     // 右指针，指向右半区间的起始位置
        int k = 0;           // 临时数组指针，指向 tmp 的起始位置

        while (i <= mid && j <= r) {
            if (a[i] <= a[j]) {
                // 注意：只有a[i]>a[j]才是严格的逆序对
                tmp[k++] = a[i++];
            } else {
                // 右边较小，说明 a[i...mid] 均大于 a[j]，产生批量逆序对
                // 因为左半区已排好升序，a[i]>a[j] 则说明从当前 i 到末尾 mid 共有 (mid - i + 1) 个数都必然＞a[j]
                // 逆序对增加量 = 左侧剩余元素个数 (mid - i + 1)
                res += mid - i + 1;
                tmp[k++] = a[j++];
            }
        }

        //善后工作：处理剩余元素
        // 将左半区间的剩余元素（如果有）直接追加到临时数组末尾
        while (i <= mid) tmp[k++] = a[i++];
        
        // 将右半区间的剩余元素（如果有）直接追加到临时数组末尾
        while (j <= r) tmp[k++] = a[j++];

        // 将排序好的临时数组 tmp 的内容，写回原数组 a 对应区间
        // 这一步是必需的！因为算法的正确性依赖于 [l, r] 最终是有序的，

        for (i = l, k = 0; i <= r; i++, k++) {
            a[i] = tmp[k];
        }

        return res;
    }

    int main() {
        int n;
        if (cin >> n) {
            for (int i = 0; i < n; i++) {
                cin >> a[i];
            }
            
            // 调用时只需传递左右边界即可
            cout << merge_sort(0, n - 1) << "\n";
        }
        return 0;
    }
```

# 灵魂拷问：排序会不会打乱原本的逆序对？

在学习归并求逆序对时，最容易产生的一个疑问是：**既然我们要找的是原数组中的逆序对，可 `mergesort` 把数组的相对位置都打乱（排序）了，这难道不会影响最终结果吗？**

答案是：**绝对不会！** 它的精妙之处在于严格遵守了以下两步：

1. **内部的相对位置：算完之后才改变！**
   当程序对左半区执行 `mergesort` 时，它会先在这个小圈子内部找出所有的逆序对，并加到总成绩 `res` 里。**在彻底查清并记录完之后**，它才把小圈子内部排好序。案发现场虽然被破坏了，但“证据”已经安全入档了。

2. **跨越边界的相对位置：即使内部排序，也没有人跨界！**
   这是最核心的一点。当左半区排好序，右半区排好序，准备进行跨界合并时，**左半区的全体成员依然集体排在右半区的全体成员前面**。
   不管左半区内部怎么洗牌，它们去和右半区比对时，“左边的人依然在左边，右边的人依然在右边”，跨越鸿沟的宏观相对位置根本没有改变。所以跨界统计出来的逆序对，绝对是原汁原味的！
