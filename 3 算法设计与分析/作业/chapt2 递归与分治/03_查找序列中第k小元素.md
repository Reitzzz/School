# 题干

**题目描述**
对于给定的含有n（n<=1000000）元素的无序序列，求这个序列中第k（1≤k≤n）小的元素。

**输入格式**
第一行为n，第二行为n个数。第三行为k的值。

**输出格式**
第k小的元素。

**输入样例**
```text
10
243 3 4365 34 4365 21 234 1 234 3
5
```

**输出样例**
```text
34
```

---

# 解决思路

1. **核心算法：直接排序 + 下标访问**
    本题要求在一个无序数组中寻找“第 k 小”的元素。最直接的做法是先将整个数组排序，再输出对应位置的元素。使用 `sort` 的时间复杂度为 $O(n \log n)$，实现简单且不容易出错。

2. **排序后定位答案**
    * 先把所有输入读入数组或 `vector`。
    * 调用 `sort` 将序列从小到大排序。
    * 排序完成后，第 `k` 小的元素就是第 `k-1` 个下标位置的值。

3. **输出结果**
    * 直接输出排序后的 `a[k-1]` 即可。
    * 若题目使用从 1 开始的数组下标，则按实际存储方式转换后输出对应元素。

---

# 最终代码

````cpp
#include <bits/stdc++.h>

using namespace std;

int main() {

    int n, k;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    cin >> k;

    sort(a.begin(), a.end());
    cout << a[k - 1];
    return 0;
}
````
