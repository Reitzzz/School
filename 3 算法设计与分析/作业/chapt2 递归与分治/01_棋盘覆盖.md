# 题干

**题目描述**
在一个 `2^k * 2^k` 的棋盘中，恰有一个特殊方格。请使用 4 种不同形态的 L 型骨牌覆盖除特殊方格以外的所有方格，且任意两个骨牌不能重叠。

**输入格式**
第一行输入整数 `k`。
第二行输入特殊方格的位置 `x y`，表示第 `x` 行第 `y` 列，行列编号从 `0` 开始。

**输出格式**
输出覆盖后的棋盘。特殊方格记为 `0`，同一个 L 型骨牌覆盖的 3 个方格使用相同编号。

**输入样例**
```text
2
1 1
```

---

# 解决思路：分治

棋盘大小为 `2^k * 2^k`。每次把当前棋盘分成 4 个大小相同的子棋盘：

1. 判断特殊方格位于哪一个子棋盘。
2. 在棋盘中心放置一个 L 型骨牌，使它覆盖另外 3 个子棋盘靠近中心的方格。
3. 这样 4 个子棋盘都各自拥有一个“特殊方格”。
4. 对 4 个子棋盘递归执行同样的覆盖过程。

当子棋盘大小为 `1 * 1` 时递归结束。

# 参考代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<vector<int>> board;
int tileId = 1;

void cover(int top, int left, int specialX, int specialY, int size) {
    if (size == 1) return;

    int half = size / 2;
    int centerX = top + half;
    int centerY = left + half;
    int id = tileId++;

    int quadrant;
    if (specialX < centerX && specialY < centerY) quadrant = 0;
    else if (specialX < centerX && specialY >= centerY) quadrant = 1;
    else if (specialX >= centerX && specialY < centerY) quadrant = 2;
    else quadrant = 3;

    if (quadrant != 0) board[centerX - 1][centerY - 1] = id;
    if (quadrant != 1) board[centerX - 1][centerY] = id;
    if (quadrant != 2) board[centerX][centerY - 1] = id;
    if (quadrant != 3) board[centerX][centerY] = id;

    cover(top, left,
          quadrant == 0 ? specialX : centerX - 1,
          quadrant == 0 ? specialY : centerY - 1,
          half);

    cover(top, centerY,
          quadrant == 1 ? specialX : centerX - 1,
          quadrant == 1 ? specialY : centerY,
          half);

    cover(centerX, left,
          quadrant == 2 ? specialX : centerX,
          quadrant == 2 ? specialY : centerY - 1,
          half);

    cover(centerX, centerY,
          quadrant == 3 ? specialX : centerX,
          quadrant == 3 ? specialY : centerY,
          half);
}

int main() {
    int k, x, y;
    cin >> k >> x >> y;

    int n = 1 << k;
    board.assign(n, vector<int>(n, 0));

    cover(0, 0, x, y, n);

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j) cout << ' ';
            cout << board[i][j];
        }
        cout << '\n';
    }

    return 0;
}
```
