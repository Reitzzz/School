# 题干

**题目描述**
在一个 `2^k * 2^k` 的棋盘中，恰有一个特殊方格。请使用 4 种不同形态的 L 型骨牌覆盖除特殊方格以外的所有方格，且任意两个骨牌不能重叠。

**输入格式**
第一行输入整数 `k`。
第二行输入特殊方格的位置 `x y`，表示第 `x` 行第 `y` 列，行列编号从 `0` 开始。

**输出格式**
输出覆盖后的棋盘。特殊方格记为 `0`，同一个 L 型骨牌覆盖的 3 个方格使用相同编号。

**输入样例**
```text
2
1 1
```

**输出样例**
```text
2 2 3 3
2 0 1 3
4 1 1 5
4 4 5 5
```

---

# 解决思路：分治

棋盘大小为 `2^k * 2^k`。每次把当前棋盘分成 4 个大小相同的子棋盘：

1. 判断特殊方格位于哪一个子棋盘。
2. 在棋盘中心放置一个 L 型骨牌，使它覆盖另外 3 个子棋盘靠近中心的方格。
3. 这样 4 个子棋盘都各自拥有一个“特殊方格”。
4. 对 4 个子棋盘递归执行同样的覆盖过程。

当子棋盘大小为 `1 * 1` 时递归结束。

# 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> board;
int current_id = 1;

void solve(int row, int col, int specialrow, int specialcol, int size){
    // 递归边界
    if(size == 1) return;

    int halfsize = size / 2;
    int centralrow = row + halfsize;
    int centralcol = col + halfsize;
    
    //在循环前先固定当前 L 型骨牌的 ID，确保 3 个格子编号相同
    int my_id = current_id++; 

    for(int i = 0; i < 2; i++){
        for(int j = 0; j < 2; j++){
            int subrow = row + i * halfsize;
            int subcol = col + j * halfsize;

            int subspecialrow = specialrow;
            int subspecialcol = specialcol;

            // 范围判断
            bool flag = (specialrow >= subrow && specialrow < subrow + halfsize
                         && specialcol >= subcol && specialcol < subcol + halfsize);
            
            if(!flag){
                subspecialrow = centralrow - 1 + i;
                subspecialcol = centralcol - 1 + j;
            
                board[subspecialrow][subspecialcol] = my_id; 
            }

            //加上必不可少的递归调用，继续向下切分处理子棋盘
            solve(subrow, subcol, subspecialrow, subspecialcol, halfsize);
        }
    }
}

int main() {
    int k, x, y;
    cin >> k >> x >> y;
    
    // 也可以写成 int n = 1 << k; 效率更高
    int n = pow(2, k); 

    // 初始化二维 vector
    board.assign(n, vector<int>(n, 0));

    solve(0, 0, x, y, n);

    // 打印输出
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j) cout << ' ';
            cout << board[i][j];
        }
        cout << '\n';
    }

    return 0;
}
```
