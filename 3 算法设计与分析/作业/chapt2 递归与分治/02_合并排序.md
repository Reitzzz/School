# 题干

**题目描述**
给定 `n` 个整数，使用分治递归策略完成从小到大的排序，并输出结果。

**输入格式**
第一行输入一个整数 `n`。
第二行输入 `n` 个整数。

**输出格式**
输出排序后的整数序列，整数之间用一个空格分隔。

**输入样例**
```text
6
9 3 1 8 2 5
```

**输出样例**
```text
1 2 3 5 8 9
```

---

# 解决思路：合并排序

合并排序采用分治思想：

1. 将数组从中间分成左右两半。
2. 递归地分别排序左右两半。
3. 将两个已经有序的子数组合并成一个有序数组。

时间复杂度稳定为 `O(n log n)`，需要额外数组辅助合并，空间复杂度为 `O(n)`。

---

# 参考代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void mergeArray(vector<int>& a, vector<int>& temp, int left, int mid, int right) {
    int i = left, j = mid + 1, k = left;

    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) temp[k++] = a[i++];
        else temp[k++] = a[j++];
    }

    while (i <= mid) temp[k++] = a[i++];
    while (j <= right) temp[k++] = a[j++];

    for (int p = left; p <= right; p++) {
        a[p] = temp[p];
    }
}

void mergeSort(vector<int>& a, vector<int>& temp, int left, int right) {
    if (left >= right) return;

    int mid = left + (right - left) / 2;
    mergeSort(a, temp, left, mid);
    mergeSort(a, temp, mid + 1, right);
    mergeArray(a, temp, left, mid, right);
}

int main() {
    int n;
    cin >> n;

    vector<int> a(n), temp(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    mergeSort(a, temp, 0, n - 1);

    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    return 0;
}
```
