## 1. 有序数组合并：双指针模板

### 识别信号

- 题目给了两个已经排好序的数组。
- 要把它们合并后仍然有序。
- 不需要重新整体排序。

### 思路

两个指针 `i`、`j` 分别指向两个数组开头，每次取较小的元素输出/放入结果数组。一个数组走完后，把另一个数组剩余部分直接接上。

### 代码模板

```cpp
vector<int> merge_sorted(const vector<int>& a, const vector<int>& b) {
    int i = 0, j = 0;
    vector<int> res;

    while (i < (int)a.size() && j < (int)b.size()) {
        if (a[i] <= b[j]) res.push_back(a[i++]);
        else res.push_back(b[j++]);
    }

    while (i < (int)a.size()) res.push_back(a[i++]);
    while (j < (int)b.size()) res.push_back(b[j++]);

    return res;
}
```

### 易错点

- 两个数组已经有序，整体 `sort` 虽然能过小数据，但没有体现题目考点。
- 输出格式用 `first` 或先存结果再统一输出，避免末尾多空格。

## 2. 二分查找模板

### 识别信号

- 数据已经从小到大排好。
- 问某个值是否存在，或问第一个/最后一个满足条件的位置。

### 标准查找模板

```cpp
bool binary_search_exist(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size() - 1;

    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == x) return true;
        else if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }

    return false;
}
```

### 思考口诀

- `a[mid] < x`：答案在右边，`l = mid + 1`。
- `a[mid] > x`：答案在左边，`r = mid - 1`。
- `while (l <= r)`：适合判断是否存在。

### 易错点

- `mid` 推荐写成 `l + (r - l) / 2`。
- 不要把 `l < r` 和 `l <= r` 混用；存在性查找用 `l <= r` 最直观。

## 3. 第 k 小元素：排序定位模板

### 识别信号

- 给一个无序序列。
- 求第 `k` 小。
- 数据范围允许 `O(n log n)`。

### 代码模板

```cpp
int kth_smallest(vector<int>& a, int k) {
    sort(a.begin(), a.end());
    return a[k - 1]; // k 从 1 开始，数组下标从 0 开始
}
```

### 易错点

- 第 `k` 小对应下标 `k - 1`。
- 如果题目卡时间，可以考虑快速选择 `nth_element`，但本章作业用排序即可。

## 4. 逆序对：归并排序统计模板

### 识别信号

- 求满足 `i < j` 且 `a[i] > a[j]` 的对数。
- 暴力两层循环会超时。
- 题目数据规模常到 `1e5` 或更大。

### 核心思想

分治统计三部分：

1. 左半边内部逆序对。
2. 右半边内部逆序对。
3. 左右之间的跨区间逆序对。

跨区间统计发生在归并时：如果 `a[i] > a[j]`，因为左半边已经有序，所以 `a[i...mid]` 都大于 `a[j]`，一次增加 `mid - i + 1`。

### 代码模板

```cpp
vector<int> a, tmp;

long long merge_sort_count(int l, int r) {
    if (l >= r) return 0;

    int mid = l + (r - l) / 2;
    long long ans = merge_sort_count(l, mid) + merge_sort_count(mid + 1, r);

    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            ans += mid - i + 1;
            tmp[k++] = a[j++];
        }
    }

    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];

    for (int p = l, q = 0; p <= r; p++, q++) {
        a[p] = tmp[q];
    }

    return ans;
}
```

### 易错点

- 逆序对是严格 `>`，所以合并时 `a[i] <= a[j]` 应该先拿左边，避免把相等元素算成逆序对。
- 答案最大可到 `n * (n - 1) / 2`，必须用 `long long`。
- 合并后必须把 `tmp` 写回 `a[l...r]`，否则上一层无法利用有序性。

## 5. 本章做题自查

- 题目有没有给“有序”这个条件？
- 能不能用两个指针从左右/两数组推进？
- 如果是递归分治，递归边界是不是 `l >= r`？
- 合并阶段除了排序，还能不能顺手统计答案？
- 计数类答案是否会超过 `int`？
