**题目描述**
给定 $n$ 个物品和一个容量为 $C$ 的背包。第 $i$ 个物品的重量为 $w_i$，价值为 $v_i$。
要求在不超过背包容量的前提下，选择若干物品装入背包，使得装入的物品总价值最大。
请使用**回溯法**（而不是动态规划）解决此问题。

**输入格式**
第一行包含两个整数 $n$ 和 $C$（$1 \le n \le 20$，$1 \le C \le 10^5$），分别表示物品个数和背包容量。
接下来 $n$ 行，每行包含两个整数 $w_i$ 和 $v_i$（$1 \le w_i, v_i \le 10^4$），分别表示每个物品的重量和价值。

**输出格式**
输出一个整数，表示能获得的最大总价值。

**输入样例**
```text
4 10
2 3
3 4
4 5
5 6
```

**输出样例**
```text
13
```

---

# 解决思路

### 1. 核心需求：子集树搜索
01背包问题的核心是对于每一个物品，都有“选”或“不选”两种状态。这构成了一棵深度为 $n$ 的子集树。通过回溯法遍历整棵树，我们就可以找到总价值最大的组合。

### 2. 回溯法设计
1. **当前层含义 `depth`**：当前在决定第 `depth` 个物品（从 0 开始）选还是不选。
2. **维护状态**：递归函数中携带当前状态 `curr_weight` 和 `curr_value`，其中 `curr_weight` 表示当前已装入的总重量，`curr_value` 表示已获得的总价值。全局维护一个 `max_value` 记录遇到的最大价值。
3. **递归边界**：当 `depth == n` 时，说明所有物品都决策完毕。此时比较 `curr_value` 和 `max_value`，若更大则更新答案，然后返回。
4. **剪枝（可选但推荐）**：
   - 可以在中途判断，如果当前重量加上接下来要选的物品超过了容量 $C$，则不再进入“选”的递归分支。

# 最终代码

```cpp
#include <bits/stdc++.h>

using namespace std;

int n, C;
vector<int> weight;
vector<int> value;
int max_value = 0;

// dfs(depth, curr_weight, curr_value)
// depth 表示当前决策第 depth 个物品
void dfs(int depth, int curr_weight, int curr_value) {
    // 达到叶子节点，更新最大价值
    if (depth == n) {
        if (curr_value > max_value) {
            max_value = curr_value;
        }
        return;
    }

    // 分支1：不选第 depth 个物品
    dfs(depth + 1, curr_weight, curr_value);

    // 分支2：选第 depth 个物品
    // 前提是装下该物品后不会超重
    if (curr_weight + weight[depth] <= C) {
        dfs(depth + 1, curr_weight + weight[depth], curr_value + value[depth]);
    }
}

int main() {
    if (cin >> n >> C) {
        weight.resize(n);
        value.resize(n);
        for (int i = 0; i < n; i++) {
            cin >> weight[i] >> value[i];
        }

        dfs(0, 0, 0);

        cout << max_value << "\n";
    }
    return 0;
}
```
