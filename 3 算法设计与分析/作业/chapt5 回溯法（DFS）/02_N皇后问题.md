**题目描述**
N 皇后问题是指在 $N \times N$ 的棋盘上摆放 $N$ 个皇后，使得任意两个皇后都不能处于同一行、同一列或同一斜线上。
给定整数 $N$，求出共有多少种摆法。

**输入格式**
包含一个整数 $N$（$1 \le N \le 13$）。

**输出格式**
输出一个整数，表示合法的摆法总数。

**输入样例**
```text
8
```

**输出样例**
```text
92
```

---

# 解决思路

### 1. 降维打击（为什么不需要行检查？）
如果让第 $k$ 个皇后在全图随便找位置，我们需要写两层 `for` 循环（遍历行和列），且需要检查行冲突。
但根据规则，同一行绝对不能有多个皇后。既然如此，我们可以直接强制规定：**第 $k$ 个皇后，你就老老实实待在第 $k$ 行，自己挑个列就行了。**
这样不仅直接省掉了一层巨大的 `for(row)` 循环，而且因为**强行一人分了一行**，行冲突在物理层面上就不可能发生了。因此，本题只需要关心**列冲突**和**斜线冲突**。

### 2. 回溯法设计（坐标差值法）
我们使用一个一维数组 `MapArr[i] = col`，它的含义是：**“第 `i` 行的皇后，被安放在了第 `col` 列”**。
1. **当前层含义 `k`**：当前正在决定第 `k` 行的皇后应该放在哪一列。
2. **递归边界**：当 `k == n` 时，说明前 $n$ 个皇后都已合法放置完毕，方案数 `total++`，然后 `return`。
3. **合法性检查 (`check` 函数)**：当尝试在第 `k` 行第 `col` 列放皇后时，回头查阅 `0` 到 `k-1` 行的历史记录：
   - **列检查**：看看之前的行 `i` 是不是也用了 `col` 列（`MapArr[i] == col`）。
   - **斜线检查**：两点如果在同一直斜线上，则它们横坐标差值的绝对值 `abs(k - i)` 等于纵坐标差值的绝对值 `abs(col - MapArr[i])`。
4. **恢复现场**：放入皇后后，记录位置并向下递归 `dfs(k+1)`。递归回来后，将 `MapArr[k]` 设回 `0`（虽然会被下一次循环覆盖，但写上是个良好的回溯习惯）。

# 最终代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int MapArr[15] = {}; // 记录第 i 行的皇后放在了第 col 列
int n;
int total = 0;

//检查当前想放的坐标 (k, col) 是否安全
bool check(int k, int col) {
    for (int i = 0; i < k; i++) {
        // 1. 列冲突：检查col 列是否已经被占用
        if (MapArr[i] == col) return false;

        // 2. 斜线冲突：检查横坐标差值的绝对值 == 纵坐标差值的绝对值
        int r1 = abs(k - i);
        int r2 = abs(col - MapArr[i]);
        if (r1 == r2) return false;
    }
    return true; 
}

void dfs(int k) {
    // 终止条件：走完第 n 行，说明找齐了一种方案
    if (k == n) {
        total++;
        return;
    }

    // 尝试把当前第 k 行的皇后，放到第 0 到第 n-1 列
    for (int i = 0; i < n; i++) {
        if (check(k, i)) {
            // 做记录（做选择）：宣告第 k 行的皇后占用了 i 列
            MapArr[k] = i;
            
            // 深入下一行
            dfs(k + 1);
            
            // 撤销记录（恢复现场）
            MapArr[k] = 0;
        }
    }
}

int main() {
    if (cin >> n) {
        dfs(0); // 从第 0 行开始往下推
        cout << total << "\n";
    }
    return 0;
}
```
