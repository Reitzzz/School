# 算法设计与分析 - 第三章 动态规划

## 一、 动态规划算法的总体思想与基本要素
* **总体思想**：动态规划算法与分治法类似，其基本思想也是将待求解问题分解成若干个子问题。**但是经分解得到的子问题往往不是互相独立的，不同子问题的数目常常只有多项式量级**。如果能够保存已解决的子问题的答案，在需要时简单查看一下结果，就可以避免大量重复计算，从而得到多项式时间的算法。
* **基本步骤**：
    1. 找出最优解的性质，并刻划其结构特征。
    2. 递归地定义最优值。
    3. 以自底向上的方式计算出最优值。
    4. 根据计算最优值时得到的信息，构造最优解。
* **两大基本要素**：
    * **最优子结构**：问题的最优解包含着其子问题的最优解。这是问题能用动态规划算法求解的前提。
    * **重叠子问题**：递归算法求解问题时，每次产生的子问题并不总是新问题，有些子问题被反复计算多次。
* **备忘录方法**：动态规划算法的变形，利用表格保存已解决子问题的结果，但其采用的是自顶向下的递归方式。

## 二、 经典应用：矩阵连乘问题
* **问题描述**：给定 $n$ 个矩阵 $\{A_1, A_2, ..., A_n\}$，求数乘次数最少的完全加括号计算次序。
* **最优子结构性质**：计算 $A[i:j]$ 的最优次序所包含的计算矩阵子链 $A[i:k]$ 和 $A[k+1:j]$ 的次序也是最优的。
* **建立递归关系**：设计算 $A[i:j]$ 所需要的最少数乘次数为 $m[i,j]$。当 $i=j$ 时 $m[i,i]=0$；当 $i<j$ 时：
    $$m[i,j] = \min_{i \le k < j}\{m[i,k] + m[k+1,j] + p_{i-1}p_k p_j\}$$
* **复杂度**：算法通过三重循环自底向上计算，时间复杂度为 $O(n^3)$，空间复杂度为 $O(n^2)$。

## 三、 经典应用：最长公共子序列 (LCS)
* **问题描述**：给定两个序列 $X=\{x_1, x_2, ..., x_m\}$ 和 $Y=\{y_1, y_2, ..., y_n\}$，找出它们的最长公共子序列。
* **子问题的递归结构**：用 $c[i][j]$ 记录序列 $X_i$ 和 $Y_j$ 的最长公共子序列的长度。
    $$c[i][j] = \begin{cases} 0 & i=0 \text{ 或 } j=0 \\ c[i-1][j-1]+1 & i,j>0 \text{ 且 } x_i=y_j \\ \max\{c[i][j-1], c[i-1][j]\} & i,j>0 \text{ 且 } x_i \ne y_j \end{cases}$$
* **算法改进**：如果只需要计算长度，可以不使用构造最优解的辅助数组，并且只利用两行数组空间即可，空间需求减至 $O(\min(m,n))$。

## 四、 经典应用：最大子段和
* **问题描述**：给定长度为 $n$ 的整数序列，求某个连续子区间使得其内元素之和最大。
* **不同策略分析**：
    * 穷举法：三层循环，时间复杂度 $O(n^3)$。
    * 穷举优化法：两层循环，时间复杂度 $O(n^2)$。
    * 分治法：分为左右两段及跨越中间边界的段，时间复杂度 $O(n \log n)$。
    * **动态规划法**：时间复杂度 $O(n)$。设 $b[j]$ 表示以位置 $j$ 为终点的最大子区间和。如果前一个子区间和为负，则抛弃它，直接从当前数字开始；如果为正，则累加当前数字。
```cpp
// 动态规划求解最大子段和
int maxSum(int a[], int num) {
    int localSum = 0;
    int b = 0;
    for (int i = 0; i < num; i++){
        if (b > 0)
            b += a[i];
        else
            b = a[i];
        if (b > localSum)
            localSum = b;
    }
    return localSum;
}
```

## 五、 经典应用：凸多边形最优三角剖分
* **问题描述**：将凸多边形分割成互不相交的三角形的弦的集合，使得三角形上权之和最小。
* **递归求解**：设 $t[i][j]$ 为子多边形 $\{v_{i-1}, v_i, ..., v_j\}$ 的最优权值。
    $$t[i][j] = \begin{cases} 0 & i=j \\ \min_{i \le k < j}\{t[i][k] + t[k+1][j] + w(v_{i-1}v_k v_j)\} & i<j \end{cases}$$
* **算法复杂度**：与矩阵连乘结构相似，所需计算时间为 $O(n^3)$。

## 六、 其他应用：多边形游戏、图像压缩与电路布线
* **多边形游戏**：涉及加法和乘法。由于两个负数相乘可能变成最大的正数，因此状态不仅要保存当前链合并的最大值 $maxf$，还需保存最小值 $minf$。时间复杂度为 $O(n^3)$。
* **图像压缩**：将像素分段存储，寻找占据存储空间最小的分段方式。设 $s[i]$ 为前 $i$ 个像素的最优分段存储位数，每次转移需要考虑附加的 $11$ 位段头信息。
* **电路布线**：求连线集的最大不相交子集。若不包含第 $i$ 条线，最大集合规模即为 $Size(i-1, j)$；若包含，规模转移为 $Size(i-1, \pi(i)-1)+1$。
* **流水作业调度**：运用 Johnson 不等式，使得两台机器 $M_1$ 和 $M_2$ 的执行重叠部分最大，有效缩短整体加工时间。
