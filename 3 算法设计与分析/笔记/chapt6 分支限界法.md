# 算法设计与分析 - 第六章 分支限界法

> **💡 通俗理解：什么是分支限界法？**
> 你可以把“分支限界法”想象成 **“在一个巨大的迷宫里寻宝，并且带了一个聪明的探测仪”** 的过程。<br>
> 假设你在寻宝，面临很多条岔路（**分支**）。<br>
> 你每到一个路口，不仅列出所有可能的岔路，还会用你手里的“探测仪”（**限界函数**）扫一下：<br>
> 如果探测仪显示“这条路走到尽头，找到的宝藏也不如我现在手里已经有的多”，那这条路就直接被封死，不走了（**剪枝 / 限界**）。<br>
> 这能帮你省去大量做无用功的时间，非常适合用来找“最好”、“最便宜”、“最大”的解。

## 一、 分支限界法的思想与基本概念
* **核心思想**：分支限界法也是在问题的**解空间树**中搜索最优解的方法。它一边按照某种规则生成分支，一边利用**限界函数**估计当前结点所在子树可能达到的最优值；如果该子树已经不可能产生比当前最优解更好的解，就把它剪去。
* **与回溯法的联系**：二者都属于系统搜索，都需要构造解空间树，也都会用剪枝减少搜索量。不同的是，回溯法通常采用**深度优先搜索**（像个铁憨憨一条路走到黑），而分支限界法常采用**广度优先**或**最小耗费 / 最大效益优先**的方式选择扩展结点。
* **适用问题**：分支限界法主要用于求解**优化问题**，例如最短路径、0-1 背包、装载、最大团、旅行售货员问题和批处理作业调度问题。
* **常用概念（通俗翻译）**：
    * **扩展结点**：当前正在展开并生成儿子结点的结点。（你现在正站在上面，准备看它有哪些岔路的那个路口）
    * **活结点**：已经生成但尚未扩展的结点。（刚发现但还没进去探索的路口）
    * **死结点**：已经被扩展完，或由于限界函数判断不可能产生最优解而被剪去的结点。（死胡同，或者被探测仪否决的烂路）
    * **限界函数**：估计某个结点所在子树的最好可能结果，用来决定是否保留该结点。（你的智能探测仪）

## 二、 分支限界法的搜索策略
当你面前有一堆“活结点”（还没探索的路口）时，你该先走哪个？
* **队列式分支限界法（老实人排队法 / 广度优先）**：使用先进先出队列（**FIFO**）保存活结点，每次取出队首结点作为扩展结点。在 C++ 中对应普通的 `std::queue`。
    * *通俗理解*：按照发现路口的先后顺序，挨个探索。也就是先把第一层的所有路口看完，再看第二层的所有路口。它本质上接近广度优先搜索，会按层次逐步展开解空间树。
* **优先队列式分支限界法（势利眼VIP法）**：使用优先队列保存活结点，每次选择优先级最高的结点扩展。在 C++ 中对应会根据估价自动插队的 `std::priority_queue`。对于最小化问题，常选择**代价下界最小**的结点；对于最大化问题，常选择**效益上界最大**的结点。
    * *通俗理解*：打破先来后到的规矩！探测仪不仅能排除烂路，还能给剩下的路打分。你永远优先选择“看起来最有可能拿到大奖”的那条路去探索。
* **剪枝依据**：
    * 对最小化问题，若当前结点的下界已经不小于当前最优值，则不可能改进答案。
    * 对最大化问题，若当前结点的上界已经不大于当前最优值，则不可能改进答案。
* **效率特点**：好的限界函数能让搜索更集中地朝最可能产生最优解的分支前进，通常比盲目遍历整个解空间更高效。

## 三、 分支限界法的一般算法框架
* **基本流程**：
    1. 定义问题的解空间树和结点状态。
    2. 设计限界函数，计算每个结点的上界或下界。
    3. 用队列或优先队列维护活结点表。
    4. 每次从活结点表中取出一个结点作为扩展结点。
    5. 生成其儿子结点，并用约束条件和限界函数判断是否加入活结点表。
    6. 当找到更优可行解时更新当前最优值，并继续剪去不可能改进的分支。

```cpp
// 分支限界法简单 C++ 模板 (以队列式为例)
#include <queue>
using namespace std;

// 1. 定义状态结点
struct State {
    int level;        // 当前所在的层数
    int currentValue; // 当前累积的价值/代价
};

// 2. 限界函数：估算该节点未来能达到的最好情况
bool canImprove(State child, int bestValue) {
    int expectedValue = child.currentValue + /* 估算的剩余最大可能价值 */;
    return expectedValue > bestValue; // 还有超越最优解的希望，才返回true
}

void branchAndBound() {
    queue<State> q;       // 活结点表 (如果用优先队列则是 priority_queue)
    int bestValue = 0;    // 记录目前找到的最优解
    
    // 初始化起点并入队
    State root = {0, 0};
    q.push(root);

    while (!q.empty()) {
        State curr = q.front(); 
        q.pop(); // 拿出一个结点准备探索

        // 情况A：已经走到底了，找到了一个完整解
        if (curr.level == 目标层数) {
            if (curr.currentValue > bestValue) {
                bestValue = curr.currentValue; // 更新最优解
            }
            continue; // 这条路走到底了，回头看其他路
        }

        // 情况B：还没走到底，继续生成下一步的岔路（子结点）
        for (int i = 0; i < 所有可能的选择; ++i) {
            State child = /* 生成子结点 */;
            
            // 剪枝判断：必须没违规，并且探测仪(限界函数)觉得它有希望
            if (满足约束条件 && canImprove(child, bestValue)) {
                q.push(child); // 有希望，加入队列以后慢慢看
            }
        }
    }
}
```

* **关键点**：分支限界法的核心不是简单地“多搜索”，而是通过限界函数判断“哪些分支值得搜索”。限界函数越紧，剪枝越有效；限界函数计算越复杂，单个结点处理时间也越高。

## 四、 队列式与优先队列式的比较
* **队列式分支限界法**：
    * 优点是实现简单，活结点按生成顺序扩展，适合理解解空间树的层次结构。
    * 缺点是没有主动选择更有希望的结点，可能会扩展较多无效分支。（有时候明明有一条路看起来很有希望，但因为它是后发现的，非得等前面的看完才轮到它）
* **优先队列式分支限界法**：
    * 优点是能利用限界函数指导搜索，优先扩展最可能产生最优解的结点。（非常聪明，往往能最快找到最优解）
    * 缺点是需要维护优先队列，并且限界函数的设计对效果影响很大。
* **常见优先级设计**：
    * 8 数码问题可用“已经移动步数 + 还未到位的数字块数”作为估价函数。
    * 0-1 背包可用剩余物品能达到的最大价值上界作为优先级。
    * 旅行售货员问题可用当前路径长度加剩余边的估计下界作为优先级。

## 五、 典型应用：单源最短路径问题
> **💡 通俗理解：手机导航**，找从起点到所有其他点最短的路。谁现在离我最近，我就先从谁继续往下探路。如果发现走到某个地方的距离，比我之前记录的最短记录还要长，直接放弃这条路（剪枝）。

* **问题描述**：给定带权有向图和源点，求从源点到所有其他顶点的最短路径。
* **分支限界思路**：把从源点出发的路径看成搜索树中的结点，当前路径长度作为代价。每次优先扩展当前距离最小的活结点，并用已有最短距离剪去更差的路径。
* **与 Dijkstra 算法的关系**：当所有边权非负时，Dijkstra 算法可以看作一种特殊的优先队列式分支限界法。
* **剪枝方式**：如果一条到顶点 $v$ 的候选路径长度已经不小于当前记录的最短距离 `dist[v]`，则该路径不再进入活结点表。

## 六、 典型应用：装载问题 / 0-1 背包问题
> **💡 通俗理解：搬家打包**，船/背包的容量有限，怎么装最重/最值钱？面对每一个物品，都有两个选择：装或不装。如果发现“就算把剩下的好东西全装进去，总价值也比不上刚才试出来的某种装法”，那就说明当前这条选择路线废了，直接剪枝。

### 装载问题
* **问题描述**：有一批集装箱需要装上船，船的载重量为 $c$，要求在不超过载重量的前提下，使装载重量尽可能大。
* **解空间树**：使用**子集树**。第 $i$ 层决定第 $i$ 个集装箱是否装上船，左儿子表示装入，右儿子表示不装入。
* **剪枝函数**：
    * 若 `ew + w[i] <= c`，则左儿子是可行结点。
    * 若 `ew + r > bestw`，说明即使当前不装第 $i$ 个集装箱，后续仍可能超过当前最优重量，右儿子才值得保留。

### 0-1 背包问题
* **问题描述**：给定 $n$ 个物品，每个物品重量为 $w_i$、价值为 $v_i$，背包容量为 $C$，要求选择若干物品，使总重量不超过 $C$ 且总价值最大。
* **限界函数**：通常先按单位重量价值 $v_i / w_i$ 从大到小排序，再用部分背包思想估计当前结点的价值上界。若上界 `up` 小于当前最优价值 `bestp`，则该结点不可能产生更优解。

## 七、 典型应用：最大团问题
* **问题描述**：给定无向图 $G=(V,E)$，若顶点子集 $U$ 中任意两个顶点之间都有边，则称 $U$ 是一个团；最大团问题要求找顶点数最多的团。
* **解空间树**：使用**子集树**。第 $i$ 层判断第 $i$ 个顶点是否加入当前团。
* **限界函数**：设当前团顶点数为 `cn`，剩余可选顶点数为 `n - i + 1`。若 `cn + n - i + 1 <= bestn`，即使把剩余顶点全加入也不能超过当前最优值，则可以剪枝。

## 八、 典型应用：旅行售货员问题 (TSP)
> **💡 通俗理解：送快递规划路线**，去好几个城市送货，最后回起点，怎么走最省油？每走到一半估算一下：“就算剩下的城市我都抄最近的近道走，总路程是不是已经比我现在已知的最好路线还要长了？”如果是，立刻回头。

* **问题描述**：给定带权图，从某城市出发，每个城市恰好访问一次，最后回到出发城市，要求总路程最短。
* **解空间树**：使用**排列树**。每一层确定访问序列中的下一个城市。
* **限界函数**：对每个结点估计完成剩余旅行所需的最小可能代价。若“当前路径长度 + 剩余路径下界”已经不小于当前最优回路长度，则剪去该分支。

## 九、 典型应用：批处理作业调度问题
* **问题描述**：有 $n$ 个作业需要依次在两台机器 $M_1$、$M_2$ 上加工，要求确定作业排列，使第二台机器完成时间之和最小。
* **解空间树**：使用**排列树**。
* **限界函数**：对未安排作业估计未来完成时间的下界。若当前已产生的代价加上剩余作业的下界不可能优于当前最优调度，则剪枝。

## 十、 小结
* 分支限界法适合求解最优化问题，核心是“分支生成候选解，限界排除无希望分支”。
* 回溯法通常偏向深度优先，分支限界法通常使用 FIFO 队列或优先队列维护活结点。
* 队列式分支限界法实现简单，优先队列式分支限界法更依赖估价函数，也更能体现“向最有希望的子树扩展”的思想。
* 对最大化问题常设计上界函数，对最小化问题常设计下界函数。
* 典型应用包括单源最短路径、装载、0-1 背包、最大团、TSP 和批处理作业调度。设计时应先明确解空间树，再确定结点状态、限界函数和活结点表的组织方式。
