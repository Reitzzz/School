# 算法设计与分析 - 第六章 分支限界法

## 一、 分支限界法的思想与基本概念
* **核心思想**：分支限界法也是在问题的**解空间树**中搜索最优解的方法。它一边按照某种规则生成分支，一边利用**限界函数**估计当前结点所在子树可能达到的最优值；如果该子树已经不可能产生比当前最优解更好的解，就把它剪去。
* **与回溯法的联系**：二者都属于系统搜索，都需要构造解空间树，也都会用剪枝减少搜索量。不同的是，回溯法通常采用**深度优先搜索**，而分支限界法常采用**广度优先**或**最小耗费 / 最大效益优先**的方式选择扩展结点。
* **适用问题**：分支限界法主要用于求解**优化问题**，例如最短路径、0-1 背包、装载、最大团、旅行售货员问题和批处理作业调度问题。
* **常用概念**：
    * **扩展结点**：当前正在展开并生成儿子结点的结点。
    * **活结点**：已经生成但尚未扩展的结点。
    * **死结点**：已经被扩展完，或由于限界函数判断不可能产生最优解而被剪去的结点。
    * **限界函数**：估计某个结点所在子树的最好可能结果，用来决定是否保留该结点。

## 二、 分支限界法的搜索策略
* **队列式分支限界法**：使用先进先出队列保存活结点，每次取出队首结点作为扩展结点。因此它本质上接近广度优先搜索，会按层次逐步展开解空间树。
* **优先队列式分支限界法**：使用优先队列保存活结点，每次选择优先级最高的结点扩展。对于最小化问题，常选择**代价下界最小**的结点；对于最大化问题，常选择**效益上界最大**的结点。
* **剪枝依据**：
    * 对最小化问题，若当前结点的下界已经不小于当前最优值，则该结点不可能改进答案。
    * 对最大化问题，若当前结点的上界已经不大于当前最优值，则该结点不可能改进答案。
* **效率特点**：分支限界法不保证最坏情况下一定是多项式时间，但好的限界函数能让搜索更集中地朝最可能产生最优解的分支前进，通常比盲目遍历整个解空间更高效。

## 三、 分支限界法的一般算法框架
* **基本流程**：
    1. 定义问题的解空间树和结点状态。
    2. 设计限界函数，计算每个结点的上界或下界。
    3. 用队列或优先队列维护活结点表。
    4. 每次从活结点表中取出一个结点作为扩展结点。
    5. 生成其儿子结点，并用约束条件和限界函数判断是否加入活结点表。
    6. 当找到更优可行解时更新当前最优值，并继续剪去不可能改进的分支。

```cpp
while (!liveNodes.empty()) {
    Node u = selectNode(liveNodes);   // FIFO 或按优先级取结点

    if (u 是一个完整可行解) {
        updateBest(u);
        continue;
    }

    for (每一个儿子结点 v) {
        if (v 满足约束 && bound(v) 可能优于当前最优解) {
            liveNodes.push(v);
        }
    }
}
```

* **关键点**：分支限界法的核心不是简单地“多搜索”，而是通过限界函数判断“哪些分支值得搜索”。限界函数越紧，剪枝越有效；限界函数计算越复杂，单个结点处理时间也越高。

## 四、 队列式与优先队列式的比较
* **队列式分支限界法**：
    * 优点是实现简单，活结点按生成顺序扩展，适合理解解空间树的层次结构。
    * 缺点是没有主动选择更有希望的结点，可能会扩展较多无效分支。
* **优先队列式分支限界法**：
    * 优点是能利用限界函数指导搜索，优先扩展最可能产生最优解的结点。
    * 缺点是需要维护优先队列，并且限界函数的设计对效果影响很大。
* **常见优先级设计**：
    * 8 数码问题可用“已经移动步数 + 还未到位的数字块数”作为估价函数。
    * 0-1 背包可用剩余物品能达到的最大价值上界作为优先级。
    * 旅行售货员问题可用当前路径长度加剩余边的估计下界作为优先级。

## 五、 典型应用：单源最短路径问题
* **问题描述**：给定带权有向图和源点，求从源点到所有其他顶点的最短路径。
* **分支限界思路**：把从源点出发的路径看成搜索树中的结点，当前路径长度作为代价。每次优先扩展当前距离最小的活结点，并用已有最短距离剪去更差的路径。
* **与 Dijkstra 算法的关系**：当所有边权非负时，Dijkstra 算法可以看作一种特殊的优先队列式分支限界法。它每次选择当前最短距离最小的顶点扩展，并用松弛操作更新到其他顶点的最短距离。
* **剪枝方式**：如果一条到顶点 $v$ 的候选路径长度已经不小于当前记录的最短距离 `dist[v]`，则该路径不再进入活结点表。

## 六、 典型应用：装载问题
* **问题描述**：有一批集装箱需要装上船，船的载重量为 $c$，要求在不超过载重量的前提下，使装载重量尽可能大。
* **解空间树**：使用**子集树**。第 $i$ 层决定第 $i$ 个集装箱是否装上船，左儿子表示装入，右儿子表示不装入。
* **队列式做法**：按层次扩展结点，记录当前装载重量 `ew` 和剩余集装箱重量 `r`。
* **剪枝函数**：
    * 若 `ew + w[i] <= c`，则左儿子是可行结点，可以进入活结点表。
    * 若 `ew + r > bestw`，说明即使当前不装第 $i$ 个集装箱，后续仍可能超过当前最优重量，右儿子才值得保留。
* **改进要点**：为了让右子树剪枝有效，进入左子树时应及时更新 `bestw`。这样后续判断 `ew + r > bestw` 时，能更早剪去不可能改进答案的分支。

## 七、 典型应用：0-1 背包问题
* **问题描述**：给定 $n$ 个物品，每个物品重量为 $w_i$、价值为 $v_i$，背包容量为 $C$，要求选择若干物品，使总重量不超过 $C$ 且总价值最大。
* **解空间树**：使用**子集树**。第 $i$ 层决定是否选择第 $i$ 个物品，左儿子表示选取，右儿子表示不选。
* **限界函数**：通常先按单位重量价值 $v_i / w_i$ 从大到小排序，再用部分背包思想估计当前结点的价值上界。若上界 `up` 小于当前最优价值 `bestp`，则该结点不可能产生更优解。
* **搜索过程**：
    * 若 `cw + w[i] <= C`，说明选择第 $i$ 个物品后仍可行，可以生成左儿子。
    * 对右儿子，需要计算不选第 $i$ 个物品后的价值上界；只有当 `up >= bestp` 时，才把右儿子加入活结点表。
* **特点**：分支限界法和回溯法都能解决 0-1 背包问题，但分支限界法常用优先队列按价值上界选择更有希望的结点，从而更快接近最优解。

## 八、 典型应用：最大团问题
* **问题描述**：给定无向图 $G=(V,E)$，若顶点子集 $U$ 中任意两个顶点之间都有边，则称 $U$ 是一个团；最大团问题要求找顶点数最多的团。
* **解空间树**：使用**子集树**。第 $i$ 层判断第 $i$ 个顶点是否加入当前团。
* **约束条件**：若顶点 $i$ 加入当前团，它必须与当前团中所有顶点相邻。
* **限界函数**：设当前团顶点数为 `cn`，剩余可选顶点数为 `n - i + 1`。若 `cn + n - i + 1 <= bestn`，即使把剩余顶点全加入也不能超过当前最优值，则可以剪枝。
* **算法特点**：最大团问题的分支限界法重点在于同时利用“加入后仍是团”的约束和“剩余顶点数能否超过最优值”的上界判断。

## 九、 典型应用：旅行售货员问题 (TSP)
* **问题描述**：给定带权图，从某城市出发，每个城市恰好访问一次，最后回到出发城市，要求总路程最短。
* **解空间树**：使用**排列树**。每一层确定访问序列中的下一个城市。
* **限界函数**：对每个结点估计完成剩余旅行所需的最小可能代价。若“当前路径长度 + 剩余路径下界”已经不小于当前最优回路长度，则剪去该分支。
* **FIFO 示例思路**：队列式方法按层扩展路径结点，直到形成完整回路；在扩展过程中用当前最优路径长度排除明显更差的分支。
* **优先队列思路**：把路径代价下界作为优先级，优先扩展下界较小的路径。这样通常能更早找到较好的完整回路，并利用它加强后续剪枝。

## 十、 典型应用：批处理作业调度问题
* **问题描述**：有 $n$ 个作业需要依次在两台机器 $M_1$、$M_2$ 上加工，每个作业先在 $M_1$ 加工，再在 $M_2$ 加工，要求确定作业排列，使第二台机器完成时间之和最小。
* **解空间树**：使用**排列树**。第 $r$ 层表示已经安排了前 $r$ 个作业，活结点对应一个部分作业序列。
* **目标函数**：常用 $\sum F_{2i}$ 表示所有作业在第二台机器上的完成时间之和，目标是使该值最小。
* **限界函数**：对未安排作业估计未来完成时间的下界。若当前已产生的代价加上剩余作业的下界不可能优于当前最优调度，则剪枝。
* **特点**：该问题的关键在于对未排作业给出尽量紧的下界。下界越准确，优先队列式分支限界法越能避免扩展低质量排列。

## 十一、 小结
* 分支限界法适合求解最优化问题，核心是“分支生成候选解，限界排除无希望分支”。
* 回溯法通常偏向深度优先，分支限界法通常使用 FIFO 队列或优先队列维护活结点。
* 队列式分支限界法实现简单，优先队列式分支限界法更依赖估价函数，也更能体现“向最有希望的子树扩展”的思想。
* 对最大化问题常设计上界函数，对最小化问题常设计下界函数。
* 典型应用包括单源最短路径、装载、0-1 背包、最大团、TSP 和批处理作业调度。设计时应先明确解空间树，再确定结点状态、限界函数和活结点表的组织方式。
