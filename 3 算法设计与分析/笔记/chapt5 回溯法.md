## 一、 回溯法的思想与基本概念
* **核心思想**：回溯法是一种系统地搜索问题解的方法，常被称为“通用解题法”。它在包含问题所有可能解的**解空间树**中，按照**深度优先搜索 (DFS)** 的策略从根节点向下探索；如果当前结点不可能产生可行解或最优解，就立即停止向下搜索，返回上一层尝试其他分支。
> **闭卷重点：回溯法本质** 解空间树 + 深度优先搜索 + 剪枝；它不是广度优先，也不是每次都直接得到最优。
* **适用问题**：
    * **存在性问题**：判断是否存在满足约束条件的解。
    * **优化问题**：在所有可行解中寻找目标函数最优的解。
* **常用概念**：
    > **闭卷重点：结点概念辨析** 扩展结点是“当前正在展开”的结点；活结点是“已生成但尚未扩展”的结点；死结点是不再扩展的结点。模拟卷已考“活结点一定是扩展结点”这类判断，答案是否定。
    * **扩展结点**：当前正在展开、准备产生子结点的结点。
    * **活结点**：已经生成但尚未扩展的结点。
    * **死结点**：不满足约束条件，或不可能得到更优解，因而不再继续扩展的结点。
* **搜索过程**：回溯法的本质是“生成结点 + 判断剪枝 + 深度优先遍历”。若不剪枝，往往需要遍历整个解空间；剪枝函数的质量直接影响算法效率。

## 二、 解空间树与剪枝函数
* **解空间**：问题的所有可能解组成解空间，回溯法通常把解空间组织成树形结构。每一层对应一个决策变量，每条从根到叶子的路径对应一个可能解。
* **子集树**：当问题要求从 $n$ 个元素中选择一个满足条件的子集时使用。每个元素通常有“选”与“不选”两个分支，叶子结点数为 $2^n$，典型问题包括 0-1 背包、最优装载、幂集、最大团。
* **排列树**：当问题要求确定 $n$ 个元素的排列时使用。第 $i$ 层选择排列中的第 $i$ 个元素，叶子结点数通常为 $n!$，典型问题包括旅行售货员问题。
* **m 叉树模型**：当每一步有 $m$ 种固定选择时使用，如图的 $m$ 着色问题、N 皇后问题中的列选择。
> **闭卷重点：解空间树规模** 子集树 `2^n`，排列树 `n!`，m 叉树 `m^n`；题目常让匹配问题类型和树类型。
* **剪枝函数**：
    > **闭卷重点：剪枝函数分类** 约束函数判断可行性，限界函数判断是否可能更优；不要把二者作用混淆。
    1. **约束函数**：判断当前部分解是否满足问题约束。不满足则剪去该分支。
    2. **限界函数**：估计当前分支能达到的最好结果。若不可能优于当前最优解，则剪去该分支。

## 三、 回溯法的一般算法框架
* **基本流程**：
    1. 定义解空间和解向量，例如 $(x_1,x_2,\dots,x_n)$。
    2. 确定搜索树类型：子集树、排列树或 m 叉树。
    3. 深度优先生成候选结点。
    4. 用约束函数判断可行性，用限界函数判断是否值得继续。
    5. 到达叶子结点或得到完整可行解时更新答案。

```cpp
void backtrack(int t) {
    if (t > n) {
        // 处理一个完整解，或更新当前最优解
        return;
    }

    for (每一个可选分支 choice) {
        做出选择;
        if (constraint(t) && bound(t)) {
            backtrack(t + 1);
        }
        撤销选择;
    }
}
```

* **效率分析**：回溯法最坏情况下仍可能遍历整个解空间，因此时间复杂度常为指数级或阶乘级。剪枝的作用是减少实际访问的结点数，但不能从根本上改变很多问题的最坏复杂度。
> **闭卷重点：回溯效率** 剪枝改善实际运行，但很多问题最坏复杂度仍是指数级/阶乘级。

## 四、 典型应用：0-1 背包问题
* **问题描述**：给定 $n$ 个物品，每个物品重量为 $w_i$、价值为 $v_i$，背包容量为 $C$，要求选择若干物品，使得总重量不超过 $C$ 且总价值最大。
* **解空间树**：使用**子集树**。第 $i$ 层决定是否选择第 $i$ 个物品，左分支通常表示选取，右分支表示不选。
* **约束函数**：若当前重量 $cw + w_i \le C$，则可以进入选择第 $i$ 个物品的分支。
* **限界函数**：用剩余物品可能产生的最大价值作为上界。常先按单位重量价值从高到低排序，再用类似部分背包的方式估计当前分支的最优可能值。若上界不超过当前最优值 `bestp`，则剪枝。
> **闭卷重点：0-1 背包回溯** 子集树；约束看容量，限界看价值上界；最坏 `O(2^n)`。
* **特点**：排序需要 $O(n \log n)$，回溯搜索最坏仍为 $O(2^n)$，但限界函数能显著减少实际搜索量。

## 五、 典型应用：最优装载问题
* **问题描述**：有一批集装箱需要装上两艘轮船，第一艘载重量为 $c_1$，第二艘载重量为 $c_2$。若存在合理方案使所有集装箱都装上船，求一种装载方案。
* **基本思路**：先尽可能把第一艘船装满，再判断剩余重量能否装入第二艘船。该问题可转化为在不超过 $c_1$ 的前提下，使第一艘船装载重量最大。
* **解空间树**：使用**子集树**。第 $i$ 层决定第 $i$ 个集装箱是否装入第一艘船。
* **剪枝函数**：
    > **闭卷重点：最优装载回溯** 目标是先让第一艘船装得尽量重；右子树是否保留常看 `cw + rest > bestw`。
    * **约束函数**：若 $cw + w_i \le c_1$，则可以进入“装入第一艘船”的分支。
    * **限界函数**：若 $cw + rest > bestw$，说明当前分支仍可能超过当前最优装载重量，才继续搜索。
* **复杂度**：最坏时间复杂度为 $O(2^n)$，剪枝依赖剩余重量 `rest` 与当前最优重量 `bestw` 的比较。

## 六、 典型应用：幂集问题
* **问题描述**：求集合 $A=\{1,2,\dots,n\}$ 的所有子集。
* **解空间树**：每个元素都有“属于子集”或“不属于子集”两种状态，因此是典型的**子集树**。
> **闭卷重点：幂集规模** `n` 个元素共有 `2^n` 个子集；这和模拟卷 LCS 题干中的“序列有 `2^n` 个子序列”同类。
* **算法思路**：从第一个元素开始递归，对每个元素分别进入“不选”和“选”两个分支；当所有元素都完成决策时，输出当前子集。
* **复杂度**：共有 $2^n$ 个子集，输出所有子集本身就需要 $O(2^n)$ 级别的时间。

## 七、 典型应用：旅行售货员问题 (TSP)
* **问题描述**：给定带权图，从某城市出发，每个城市恰好访问一次，最后回到出发城市，要求路径总长度最短。
* **解空间树**：使用**排列树**。第 $i$ 层确定访问序列中的第 $i$ 个城市。
* **约束函数**：当前选择的城市必须与前一个城市有边相连；形成完整路径时，还必须能回到起点。
* **限界函数**：若当前路径长度已经不小于当前最优路径长度 `bestDist`，则该分支不可能产生更优解，可以剪枝。
* **实现要点**：常用交换法维护排列数组，在递归层中把候选城市交换到当前位置，搜索结束后再交换回来。

## 八、 典型应用：最大团问题
* **问题描述**：给定无向图 $G=(V,E)$，若顶点子集 $U \subseteq V$ 中任意两个顶点之间都有边，则称 $U$ 是图的一个团；最大团是顶点数最多的团。
* **解空间树**：可使用**子集树**。第 $i$ 层判断第 $i$ 个顶点是否加入当前团。
* **约束函数**：若顶点 $i$ 要加入当前团，它必须与当前团中所有顶点相邻。
* **限界函数**：若当前团顶点数 $cn$ 加上剩余可选顶点数仍不超过当前最优值 `bestn`，则继续搜索没有意义，可以剪枝。
* **特点**：剪枝的关键在于尽早发现“加入后不再是团”的分支，并利用剩余顶点数量估计是否还可能改进最优解。

## 九、 典型应用：图的 m 着色问题
* **问题描述**：给定无向图 $G$ 和 $m$ 种颜色，判断能否用这 $m$ 种颜色给图中每个顶点着色，使任意相邻顶点颜色不同。
* **解空间树**：每个顶点有 $m$ 种颜色可选，因此解空间是一棵 $m$ 叉树，共有 $m^n$ 个潜在着色方案。
> **闭卷重点：m 着色** m 叉树，潜在方案数 `m^n`，约束是相邻顶点颜色不同。
* **约束函数**：给第 $k$ 个顶点着色时，检查它与所有已着色相邻顶点是否颜色不同。
* **算法特点**：若只要求一个可行方案，找到后即可停止；若要求方案数，则需要遍历所有满足约束的叶子结点。

## 十、 典型应用：N 皇后问题
* **问题描述**：在 $n \times n$ 棋盘上放置 $n$ 个皇后，使任意两个皇后不在同一行、同一列或同一条斜线上。
* **解向量**：通常用 $x_i$ 表示第 $i$ 行皇后所在的列号。因为每行只放一个皇后，所以只需要判断列冲突和斜线冲突。
> **闭卷重点：N 皇后表示** 常用 n 维向量 `x_i` 表示第 `i` 行皇后的列号；解可有多种 n 维向量表示方式。模拟卷已考。
* **约束函数**：
    * 不同列：$x_i \ne x_j$。
    * 不同斜线：$|i-j| \ne |x_i-x_j|$。
* **搜索方式**：逐行放置皇后。若当前行所有列都不合法，则回溯到上一行更换位置；若成功放置到第 $n$ 行，则得到一个可行解。

## 十一、 典型应用：迷宫问题
* **问题描述**：从迷宫入口出发，寻找一条到达出口的路径。若当前方向可走则继续前进，否则换方向；若所有方向都不可走，则回退到上一个位置。
* **解空间树**：每个位置的候选分支是上、下、左、右等可行方向。
* **剪枝函数**：
    * 不能进入墙或障碍。
    * 不能走出迷宫范围。
    * 不能重复访问已经在当前路径中的位置。
* **特点**：迷宫问题体现了回溯法的“试探-失败-退回-再试探”过程，也常用于理解递归搜索路径的维护。

## 十二、 小结
* 回溯法适合解空间明确、需要系统搜索的问题。
* 设计回溯算法时，应先确定解空间树，再设计约束函数和限界函数。
* 子集树常对应 $O(2^n)$ 的搜索规模，排列树常对应 $O(n!)$ 的搜索规模，m 叉树常对应 $O(m^n)$ 的搜索规模。
* 回溯法的效率主要取决于剪枝策略：约束函数负责保证可行性，限界函数负责排除不可能更优的分支。
* 回溯法一般不能避免最坏情况下的指数级复杂度，但在很多实际问题中，合理剪枝可以大幅减少搜索结点数。
