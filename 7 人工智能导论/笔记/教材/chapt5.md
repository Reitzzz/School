# 第5章 搜索求解策略（导论5）

## 1. 搜索求解的基本概念
- **状态空间表示法**：将实际问题抽象为图论模型的一种方法。
  - **状态 (State)**：描述问题在特定时刻的具体情况，通常用向量或数据结构表示。
  - **算符 (Operator)**：将问题从一个状态转移到另一个状态的操作或规则。
  - **状态空间图**：以状态为节点、算符为边的有向图。搜索问题的本质就是在状态空间图中寻找从初始节点到目标节点的路径。

## 2. 盲目搜索 (无信息搜索)
盲目搜索在搜索过程中不利用任何与问题相关的领域启发信息，仅按固定策略展开。
- **广度优先搜索 (BFS)**：逐层展开节点，保证能找到步骤最少的最优解，但空间复杂度呈指数级增长。
- **深度优先搜索 (DFS)**：一直向深处搜索直到无法继续或找到目标，空间复杂度较小，但容易陷入死循环且不能保证最优解。
- **代价一致搜索 (UCS)**：总是扩展当前路径累计代价 $g(n)$ 最小的节点。
- **迭代加深搜索 (IDS)**：结合了DFS的空间优势与BFS的完备性，通过不断增加深度限制来进行多次深度优先搜索。

## 3. 启发式搜索 (有信息搜索)
利用领域经验知识引导搜索方向，从而减少搜索空间。
- **估价函数**：用于评估节点的好坏，公式为：
  $$f(n) = g(n) + h(n)$$
  其中 $g(n)$ 是从初始节点到当前节点 $n$ 的实际代价，$h(n)$ 是从节点 $n$ 到目标节点的启发式估计代价。
- **A* 算法**：最著名的启发式搜索算法。当且仅当启发函数 $h(n)$ 满足**可采纳性**（即 $h(n) \le h^*(n)$，$h(n)$ 从不超估实际到达目标的代价）时，A*算法保证能找到最优解。

# A* 算法伪代码逻辑
def a_star_search(start_node, goal_node):
    open_list = [start_node]  # 存放已发现但尚未扩展的节点
    closed_list = []          # 存放已经扩展完毕的节点
    
    while open_list:
        # 选取估价函数 f(n) = g(n) + h(n) 值最小的节点优先扩展
        current = get_node_with_min_f(open_list)
        
        if current == goal_node:
            return construct_path(current) # 追溯并返回最优路径
            
        open_list.remove(current)
        closed_list.append(current)
        
        # 遍历当前节点的所有可达后继节点

            if neighbor in closed_list:

## 4. 博弈树搜索
主要应用于双人零和博弈（如象棋、围棋）。
- **极大极小算法 (Minimax)**：假设对手总是采取对其最有利（即对我方最不利）的策略。我方在 MAX 层选择评估值最大的分支，对手在 MIN 层选择评估值最小的分支。
- **$\alpha-\beta$ 剪枝**：在Minimax算法基础上优化的剪枝策略：
  - **$\alpha$ 剪枝**：当 MIN 节点的当前值小于等于其祖先 MAX 节点的 $\alpha$ 值时，停止搜索该 MIN 节点的其他分支。
  - **$\beta$ 剪枝**：当 MAX 节点的当前值大于等于其祖先 MIN 节点的 $\beta$ 值时，停止搜索该 MAX 节点的其他分支。
