# 第2章 知识表示与知识图谱

## 1. 知识与知识表示的概念
* **知识的定义**：知识是人们在长期的生活和社会实践中总结出来的认识客观世界成果的结晶。
* **知识表示（Knowledge Representation）**：将人类的知识形式化或模型化，转化为计算机可以接受、存储、处理和运用的数据结构及其控制策略的过程。

## 2. 经典知识表示方法
### 2.1 一阶谓词逻辑表示法
* **核心思想**：利用数理逻辑中的命题和谓词来形式化地描述事物及其关系。
* **基本元素**：
    * **谓词**：通常表示为 $P(x_1, x_2, ..., x_n)$，描述事物的状态、属性或关系。
    * **逻辑连接词**：否定 $\neg$、合取（与） $\wedge$、析取（或） $\vee$、蕴含 $\rightarrow$、等价 $\leftrightarrow$。
    * **量词**：全称量词 $\forall$（表示“对于所有”）、存在量词 $\exists$（表示“至少存在一个”）。
* **特点**：严密、精确、推理过程规范，但难以表示不确定性和启发式知识，存在组合爆炸的风险。

### 2.2 产生式表示法
* **基本形式**：使用“条件-动作”规则来表示知识，通常形式为 `IF P THEN Q` 或 $P \rightarrow Q$。
* **系统结构**：一个产生式系统通常由规则库（知识库）、综合数据库（工作记忆）和控制系统（推理机）三部分组成。
* **特点**：格式直观自然、模块化好、易于增删和修改；但系统执行效率较低，各规则间缺乏结构性联系。

### 2.3 框架表示法
* **核心思想**：一种基于面向对象思想的表示形式。用“框架（Frame）”来描述一类事物，框架由若干“槽（Slot）”组成，每个槽又可以包含若干“侧面（Facet）”。
* **特点**：结构性强，善于表示复杂事物的层次关系，支持默认值和继承机制。

### 2.4 语义网络表示法
* **概念**：一种用有向图来表示知识的方法。图中的节点代表概念、事物、事件，带有方向的边代表节点之间的语义联系（如 ISA, HASA 关系）。
* **特点**：直观、易于理解，能够清晰表示知识间的网状关联，具有激活扩散的推理机制。

## 3. 知识图谱初步
* **基本概念**：知识图谱（Knowledge Graph）本质上是一种大规模的语义网络，以图结构（节点和边）的形式描述真实世界中客观事物的实体及其之间的关联关系。
* **体系架构**：
    * **数据层**：以事实（三元组 `<实体, 关系, 实体>` 或 `<实体, 属性, 属性值>`）为基本单位进行存储。
    * **模式层（本体层）**：定义知识图谱的数据模式，是数据层实体概念的提炼，包含概念的层级与逻辑关系。
* **核心技术**：知识抽取（实体抽取、关系抽取、属性抽取）、知识融合（实体对齐）、知识加工与推理、知识存储（图数据库，如 Neo4j）。
