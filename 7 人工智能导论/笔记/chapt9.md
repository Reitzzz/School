# 第9章 智能体与多智能体系统（导论5）

## 1. 智能体 (Agent) 的基本概念
智能体是驻留在特定环境中，能够感知环境并自主采取行动以实现设计目标的计算实体或物理实体。
- **四个核心特性 (弱定义)**：
  1. **自治性 (Autonomy)**：能够在没有外部直接干预的情况下自我控制其行为和内部状态。
  2. **反应性 (Reactivity)**：能够感知所处环境的变化，并及时对这些变化做出响应。
  3. **主动性 (Pro-activeness)**：不仅对环境做出反应，还能主动采取行动以达成既定目标。
  4. **社会性 (Social Ability)**：能够与其他智能体（或人类）通过某种通信语言进行信息交互。

## 2. 智能体的结构分类
- **逻辑型智能体**：行为基于形式化逻辑和符号演绎推理。
- **反应型智能体 (Reactive Agent)**：不维持复杂的内部状态模型，仅通过“感知-行动”规则直接映射环境（如包容体系结构 Subsumption Architecture）。
- **BDI 智能体模型**：基于人类心理学概念设计，内部状态由三个核心结构组成：
  - **信念 (Beliefs)**：智能体对环境及其自身状态的认知。
  - **愿望 (Desires)**：智能体想要达到的目标。
  - **意图 (Intentions)**：智能体为了实现愿望而决定采取的行动计划。

## 3. 多智能体系统 (Multi-Agent System, MAS)
多个智能体为了共同完成一个庞大或复杂的任务而组成的系统。
- **核心特点**：系统是去中心化的，不存在拥有全局知识的控制节点；数据和控制是分布式的。
- **交互方式**：包括通信、协作、协调和协商。

## 4. 智能体通信与协作
- **通信语言**：智能体之间进行知识和意图传递的标准，如 KQML (Knowledge Query and Manipulation Language) 和 FIPA ACL 规范。
- **多智能体协作机制**：
  - **黑板架构 (Blackboard System)**：所有智能体通过一个共享的公共数据区（黑板）读写信息来协同解决问题。
  - **合同网协议 (Contract Net Protocol)**：一种基于市场机制的分布式任务分配协议，核心流程包含四个阶段：
    1. **招标 (Call for Proposals)**：管理者广播任务需求。
    2. **投标 (Bidding)**：承包者评估自身能力后给出报价。
    3. **中标 (Awarding)**：管理者评估所有报价，选择最优的承包者。
    4. **签约/执行**：双方确认后，承包者执行任务。
