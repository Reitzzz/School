# 第8章 人工神经网络及其应用（导论5）

## 1. 人工神经元模型 (M-P模型)
人工神经网络(ANN)的基础是神经元。一个M-P神经元接收多个输入信号 $x_i$，与其对应的权重 $w_i$ 进行线性加权求和，然后通过一个非线性的激活函数 $f$ 输出：
$$y = f\left(\sum_{i=1}^{n} w_i x_i - \theta \right)$$
其中 $\theta$ 是神经元的阈值（偏置）。

## 2. 激活函数 (Activation Functions)
激活函数为神经网络引入了非线性能力，使其能够拟合复杂的非线性映射。
- **Sigmoid函数**：将输出映射到 $(0,1)$，容易发生梯度消失：
  $$\sigma(x) = \frac{1}{1 + e^{-x}}$$
- **Tanh函数**：将输出映射到 $(-1,1)$，零点中心对称。
- **ReLU函数**：目前最常用的激活函数，有效缓解梯度消失问题：
  $$f(x) = \max(0, x)$$

## 3. 前馈神经网络与 BP 算法
多层前馈神经网络解决了单层感知机无法处理非线性可分（如XOR逻辑）的问题。
- **BP算法 (误差反向传播算法)**：用于训练多层网络的经典核心算法。其原理是使用梯度下降法寻找使得损失函数最小的权重。
- **损失函数 (均方误差)**：
  $$E = \frac{1}{2} \sum_{k} (y_k - \hat{y}_k)^2$$
- **权重更新规则**：根据链式求导法则，把误差从输出层逐层向输入层反向传播。
  $$w_{ij} \leftarrow w_{ij} - \eta \frac{\partial E}{\partial w_{ij}}$$
  其中 $\eta$ 为学习率 (Learning Rate)。

## 4. 深度学习简介 (Deep Learning)
随着计算算力的提升，含有很多隐层的深度神经网络得到广泛应用。
- **卷积神经网络 (CNN)**：专为处理图像等网格状数据设计。核心操作包括局部感受野的**卷积层**（提取空间特征）和**池化层/下采样层**（降低特征维度，防止过拟合）。网络中还存在**权值共享**机制，大幅减少了参数量。
- **循环神经网络 (RNN)**：含有闭环结构，隐层状态不仅依赖当前输入，还依赖上一时刻的隐层状态，专门用于处理语音、文本等序列数据。
