### 核心知识点剖析与解题思路 (逐题讲解)

人工智能导论的期中作业和考试，大部分题型都属于“把自然语言翻译成形式语言，然后按固定流程机械推导”。这类题不是背答案，而是背操作顺序。下面保留之前笔记里的“解题套路”，同时配上作业里的具体题目，方便直接照着做。

---

## 一、谓词逻辑表示 (对应作业第1大题)

### 题目长什么样
作业里常见的是把中文句子翻成谓词公式，比如：
1. 有的旅行者喜欢登山，有的旅行者喜欢海边，有的旅行者既喜欢登山又喜欢海边。
2. 小红每天傍晚都练习绘画。
3. 所有上班族都有休息时间。
4. 喜欢骑行的人一定喜欢徒步。
5. 想要获得奖学金，必须成绩合格。

推理类题也会直接给一句话，比如：
1. 如果城市 X 比城市 Y 人口多，那么城市 Y 比城市 X 人口少。
2. 小刘和小陈是同事，那么小陈和小刘也是同事。
3. 遵守规则的人不会受处罚；小陈受处罚了，所以小陈不遵守规则。

### 解题套路
1. 先找主语和宾语，确定哪些是对象，哪些是属性。
2. 把“是、喜欢、遵守、受处罚”这类动词或状态写成谓词。
3. 遇到“所有、都、一定、必须”时，优先考虑全称量词 ∀。
4. 遇到“有的、有些、存在”时，优先考虑存在量词 ∃。
5. 如果题目是“某类人一定满足某条件”，通常结构是 ∀x(P(x) → Q(x))。
6. 如果题目是“存在某个对象同时满足几个条件”，通常结构是 ∃x(P(x) ∧ Q(x))。

### 直接对应到作业解答
* “有的旅行者喜欢登山” 写成 （∃x）（Traveler(x) ∧ Climb(x)）
* “小红每天傍晚都练习绘画” 写成 （∀x）（Evening(x) → Practice(a, x)）
* “所有上班族都有休息时间” 写成 （∀x）（Worker(x) → Rest(x)）
* “喜欢骑行的人一定喜欢徒步” 写成 （∀x）（Ride(x) → Hike(x)）
* “想要获得奖学金，必须成绩合格” 写成 （∀x）（Scholarship(x) → Pass(x)）

### 避坑指南
不要把“所有”直接写成 ∀x(P(x) ∧ Q(x))。这样会把“如果满足前件就满足后件”的条件关系，误写成“所有对象都同时满足两个性质”。

## 二、谓词公式化为子句集 (对应作业第2大题)

### 题目长什么样
作业里一般直接给公式，让你化成子句集，例如：
1. （∀x）（∀y）（R(x, y) → S(x, y)）
2. （∀x）（∃y）（R(x, y) ∨ S(x, y) → T(x, y)）
3. （∀x）（∀y）Q(x, y) ∨ （∀y）（W(x, y) → Z(x, y)）

### 解题套路
1. 先消去蕴含，统一换成 ¬P ∨ Q。
2. 再把否定往里推，利用德·摩根定律。
3. 如果不同量词用了同名变量，先重命名，避免混淆。
4. 再做 Skolem 化，把存在量词消掉。
   - Skolem 化（具体操作）：
     1) 处理“依赖型”存在变量 — Skolem 函数
        - 字面意思：如果一个存在量词 $\exists y$ 出现在一个或多个全称量词（如 $\forall x_1,\forall x_2$）的作用域内，说明 $y$ 的具体对象依赖于这些全称变量的取值。
        - 操作：引入一个新的带参数函数 $f(x_1,\dots,x_n)$，用它替换 $y$，并移除该 $\exists y$。
        - 示例：$\forall x\;\exists y\;P(x,y)$ 替换为 $\forall x\;P(x,f(x))$（$f$ 为新函数符号）。

     2) 处理“独立型”存在变量 — Skolem 常量
        - 字面意思：如果 $\exists y$ 前面没有任何全称量词，表示存在某个固定的、与其他变量无关的对象作为 $y$ 的实例。
        - 操作：引入一个新的常量 $a$（或 $c$），用它替换 $y$，并移除该 $\exists y$。
        - 示例：$\exists y\;\forall x\;R(x,y)$ 替换为 $\forall x\;R(x,a)$（$a$ 为新常量）。

     3) 移除存在量词并重复
        - 字面意思：每做一次替换，就把相应的存在量词从公式中删掉，直到公式中不再出现任何存在量词为止。
        - 操作：对公式中所有的 $\exists$ 按出现顺序或从内到外依次进行替换和删除。
        - 示例：从 $\forall x\;\exists y\;P(x,y)$ 得到 $\forall x\;P(x,f(x))$ 后，原来的 $\exists y$ 已被移除。

     4) 命名必须唯一（避免命名冲突）
        - 字面意思：新引入的函数名或常量名不能与公式中已有的符号冲突，且函数的参数必须严格对应其依赖的全称变量。
        - 操作：为每个被 Skolem 化的存在量词创造唯一的新符号（如 $f_1,f_2,a_1$ 等），并确保参数顺序与依赖关系一致。
        - 示例：若公式已包含函数 $g$，不要用 $g$ 作为 Skolem 名称，改用 $f$ 或 $f_1$；若 $y$ 依赖于 $x$ 与 $z$，则用 $f(x,z)$。

5. 去掉所有全称量词，默认保留的变量都是全称的。
6. 用分配律把式子整理成合取范式。
7. 把每个合取项拆出来，就是一个子句。
   - **子句的定义**：若干原子公式（或其否定）用 ∨（或）连接起来的式子。
   - **快速判断**：最外层是 ∨ → ✅ 是子句；最外层是 ∧ → ❌ 不是子句（需要分开）；单个原子公式或其否定 → ✅ 是子句。

### 直接对应到作业解答
* 题 1：（∀x）（∀y）（R(x, y) → S(x, y)）
  * 先消去蕴含，得到 （∀x）（∀y）（¬R(x, y) ∨ S(x, y)）
  * 所以子句集就是 {¬R(x, y) ∨ S(x, y)}

* 题 2：（∀x）（∃y）（R(x, y) ∨ S(x, y) → T(x, y)）
  * 先变成 （∀x）（∃y）（¬(R(x, y) ∨ S(x, y)) ∨ T(x, y)）
  * 用德·摩根后得到 （∀x）（∃y）((¬R(x, y) ∧ ¬S(x, y)) ∨ T(x, y)）
  * 再分配成 （∀x）（∃y）((¬R(x, y) ∨ T(x, y)) ∧ (¬S(x, y) ∨ T(x, y)))
  * 因为 y 受前面的 ∀x 约束，所以必须换成函数 f(x)
  * 最终子句集是 {¬R(x, f(x)) ∨ T(x, f(x)), ¬S(x, f(x)) ∨ T(x, f(x))}

* 题 3：（∀x）（∀y）Q(x, y) ∨ （∀y）（W(x, y) → Z(x, y)）
  * 先把后面的 y 改名成 z
  * 再消去蕴含，合并量词，最后得到一个子句：(Q(x, y) ∨ ¬W(x, z) ∨ Z(x, z))

### 最容易错的点
Skolem 化时，判断“存在变量前面有没有全称变量”非常关键。没有前置全称变量时用常量，有前置全称变量时用函数。

## 三、子句集可满足性判断 (对应作业第3大题)

### 题目长什么样
作业会直接给一个子句集，让你判断是否可满足，例如：
1. S = {¬R ∨ S, ¬S, R, ¬R}
2. S = {R ∨ S, R ∨ ¬S, ¬R ∨ S, ¬R ∨ ¬S}
3. S = {R(y) ∨ S(y), ¬R(g(x)) ∨ T(b)}
4. S = {¬R(x) ∨ S(x), ¬R(y) ∨ T(y), R(m), U(m), ¬U(z) ∨ ¬T(z)}

### 解题套路
1. 先找互补对，也就是一个子句里有 P，另一个里有 ¬P。
2. 如果变量不一致，先做置换，让两个子句能匹配。
3. 把能抵消的部分删掉，剩下的部分组成新子句。
4. 重复进行，直到推出空子句 □，或者再也推不出新东西。

### 直接对应到作业解答
* 题 1 中，R 和 ¬R 直接互补，所以能归结出空子句，结论是不可满足。
* 题 2 中，先由 (1) 和 (2) 归结出 R，再由 (3) 和 (4) 归结出 ¬R，最后得到空子句，所以不可满足。
* 题 3 中，把 y 置换成 g(x) 后，可以得到 S(g(x)) ∨ T(b)，但推不出空子句，所以可满足。
* 题 4 中，先由 (2) 和 (3) 得到 T(m)，再由 (4) 和 (5) 得到 ¬T(m)，最终推出 □，所以不可满足。

### 书写建议
每一步都写清楚“由哪两个子句归结”“用的是什么置换”。这比只写结论更容易拿满过程分。

## 四、归结原理证明 (对应作业第4大题)

### 题目长什么样
作业中的证明题是：
* 已知 Law(x) → Edu(x)。
* 已知 Monkey(x) → ¬Edu(x)。
* 已知 ∃z(Monkey(z) ∧ Tool(z))。
* 证明 ∃x(Tool(x) ∧ ¬Law(x))。

### 解题套路
1. 把所有前提先化成子句集。
2. 把要证明的结论取反，也化成子句加入集合。
3. 对所有子句做归结。
4. 如果最后推出空子句，就证明成功。

### 直接对应到作业解答
* Law(x) → Edu(x) 变成 ¬Law(x) ∨ Edu(x)
* Monkey(x) → ¬Edu(x) 变成 ¬Monkey(x) ∨ ¬Edu(x)
* ∃z(Monkey(z) ∧ Tool(z)) 通过 Skolem 化引入常量 a，得到 Monkey(a) 和 Tool(a)
* 结论 ∃x(Tool(x) ∧ ¬Law(x)) 取反后得到 ∀x(¬Tool(x) ∨ Law(x))

归结时可以按下面的链条写：
1. 由 Tool(a) 和 ¬Tool(w) ∨ Law(w) 归结，得到 Law(a)。
2. 由 Law(a) 和 ¬Law(x) ∨ Edu(x) 归结，得到 Edu(a)。
3. 由 Edu(a) 和 ¬Monkey(y) ∨ ¬Edu(y) 归结，得到 ¬Monkey(a)。
4. 由 ¬Monkey(a) 和 Monkey(a) 归结，得到 □。

### 核心理解
这类题的本质是反证法：你不是直接证明结论，而是证明“结论的否定”会导致矛盾。

## 五、归结推理求解 (对应作业第5大题)

### 题目长什么样
作业里的典型问法是：
* 谁是俱乐部成员，且为骑行爱好者、不是跑步爱好者？

### 解题套路
1. 先把所有前提化成子句。
2. 再把目标问题写成谓词形式，比如 Mem(x) ∧ Ride(x) ∧ ¬Run(x)。
3. 把目标取反，并附加答案谓词 Ans(x)。
4. 开始归结，目标不是空子句，而是推出 Ans(某个常量)。

### 直接对应到作业解答
题目中已经给了这些前提：
* 成员要么骑行要么跑步
* 成员不能同时骑行和跑步
* 晴天、阴天和喜欢关系之间有若干规则
* Mem(h) 和 Mem(u)

具体推导时可以按作业里的链条写：
1. 由 ¬Like(h, sunny) 和 Like(x, sunny) ∨ Run(x) 归结，得到 Run(h)。
2. 由 Like(h, cloudy) 和 ¬Like(h, y) ∨ ¬Like(u, y) 归结，得到 ¬Like(u, cloudy)。
3. 由上一步和 Like(x, cloudy) ∨ ¬Run(x) 归结，得到 ¬Run(u)。
4. 由 Mem(u) 和 ¬Mem(x) ∨ Ride(x) ∨ Run(x) 归结，得到 Ride(u) ∨ Run(u)。
5. 再和 ¬Run(u) 归结，得到 Ride(u)。
6. 把目标子句实例化到 u，继续归结，最终得到 Ans(u).

### 结果怎么读
一旦推出 Ans(u)，就说明小宇满足题目要求。

## 六、可信度 (CF) 推理 (对应作业第6大题)

### 题目长什么样
这类题会给你规则和初始证据，直接让你算某个结论的可信度。例如：
* r1: IF E1 THEN E2 (0.7)
* r2: IF E2 AND E3 THEN E4 (0.8)
* r3: IF E4 THEN H (0.6)
* r4: IF E5 THEN H (0.9)
* 已知 CF(E1)=0.5，CF(E3)=0.6，CF(E5)=0.7

### 解题套路
1. 先算证据合成，AND 取小，OR 取大。
2. 再把证据值乘上规则的可信度。
3. 如果同一个结论来自多条规则，再做最终合成。
4. 如果证据值不大于 0，这条规则的贡献直接按 0 处理。

### 直接对应到作业解答
* 由 r1 得到 CF(E2)=0.5 × 0.7 = 0.35
* 再由 r2 得到 CF(E4)=min(0.35, 0.6) × 0.8 = 0.28
* 由 r3 得到 CF1(H)=0.28 × 0.6 = 0.168
* 由 r4 得到 CF2(H)=0.7 × 0.9 = 0.63
* 最后合成得到 CF(H)=0.168 + 0.63 - 0.168 × 0.63 = 0.69216

### 书写建议
这类题最重要的是把每一步写成“先算证据，再乘规则，再合成结论”，不要直接跳到最终数值。

## 七、证据理论正交和 (对应作业第7大题)

### 题目长什么样
作业里给的是识别框架 D={a,b,c}，以及两个基本概率分配：
* M1({a,b})=0.5，M1({a,b,c})=0.5
* M2({b,c})=0.8，M2({a,b,c})=0.2

### 解题套路
1. 先列交叉表，把第一个分配放在行，第二个分配放在列。
2. 每个格子都求集合交集，并把概率相乘。
3. 空交集对应的乘积加起来，就是冲突系数 K。
4. 非空集合的结果要除以 1-K。

### 直接对应到作业解答
* {a,b} ∩ {b,c} = {b}，乘积是 0.5 × 0.8 = 0.4
* {a,b} ∩ {a,b,c} = {a,b}，乘积是 0.5 × 0.2 = 0.1
* {a,b,c} ∩ {b,c} = {b,c}，乘积是 0.5 × 0.8 = 0.4
* {a,b,c} ∩ {a,b,c} = {a,b,c}，乘积是 0.5 × 0.2 = 0.1

因为没有空集交集，所以 K=0。最终结果就是：
* M({b})=0.4
* M({a,b})=0.1
* M({b,c})=0.4
* M({a,b,c})=0.1

### 记忆方法
先找交集，再乘概率；先算冲突，再统一归一化。

## 八、模糊关系合成 (对应作业第8大题)

### 题目长什么样
作业给的是两个模糊矩阵：
```text
R1 = [0.4  0.7]
     [0.6  0.3]

R2 = [0.5  0.2]
     [0.1  0.8]
```

要求用 Max-Min 合成法求 R1 ∘ R2。

### 解题套路
1. 先把它当成矩阵乘法来理解，左边按行，右边按列。
2. 把“乘法”换成取小 min。
3. 把“加法”换成取大 max。
4. 每个元素都按“先取小，再取大”的方式计算。

### 直接对应到作业解答
* 第一行第一列：max(min(0.4, 0.5), min(0.7, 0.1)) = 0.4
* 第一行第二列：max(min(0.4, 0.2), min(0.7, 0.8)) = 0.7
* 第二行第一列：max(min(0.6, 0.5), min(0.3, 0.1)) = 0.5
* 第二行第二列：max(min(0.6, 0.2), min(0.3, 0.8)) = 0.3

所以最后结果是：
```text
R1 ∘ R2 = [0.4  0.7]
          [0.5  0.3]
```

### 操作提醒
算这类题时，最容易把行列看反。建议按“左边取一行，右边取一列”的顺序一格一格算。
