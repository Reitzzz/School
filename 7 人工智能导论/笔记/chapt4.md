# 第4章 不确定性推理方法

## 1. 不确定性推理概述
* **概念**：建立在非经典逻辑基础上，基于不确定性的知识和证据，通过特定算法推导出带有不确定性结论的推理过程。
* **基本问题**：不确定性的表示（如何量化）、不确定性的匹配（如何判断条件满足）、不确定性的传播与计算（组合与更新）。

## 2. 可信度方法（CF 模型）
* **知识不确定性的表示**：
    规则通常表示为：`IF E THEN H (CF(H, E))`
    其中，$CF(H, E)$ 是规则的可信度因子（Certainty Factor），范围为 $[-1, 1]$。
    * $CF > 0$ 表示证据 $E$ 的出现增加了结论 $H$ 为真的可信度。
    * $CF < 0$ 表示证据 $E$ 的出现减少了结论 $H$ 为真的可信度。
    * $CF = 0$ 表示证据 $E$ 与结论 $H$ 无关。
* **证据不确定性的表示**：
    观测到的证据 $E$ 也带有可信度，记为 $CF(E)$，取值范围同为 $[-1, 1]$。
* **组合证据不确定性的计算**：
    当规则前提是由多个单一证据复合而成时：
    * 合取（逻辑与 AND）：
        $$CF(E_1 \wedge E_2 \wedge ... \wedge E_n) = \min(CF(E_1), CF(E_2), ..., CF(E_n))$$
    * 析取（逻辑或 OR）：
        $$CF(E_1 \vee E_2 \vee ... \vee E_n) = \max(CF(E_1), CF(E_2), ..., CF(E_n))$$
* **结论不确定性的更新计算**：
    给定前提 $E$ 的可信度 $CF(E)$ 和规则可信度 $CF(H, E)$，结论 $H$ 的最终可信度计算公式为：
    $$CF(H) = CF(H, E) \times \max(0, CF(E))$$
* **多条独立规则的结论合成**：
    若有多条规则独立推导出了同一个结论 $H$，设其计算出的可信度分别为 $CF_1$ 和 $CF_2$，则综合可信度 $CF_{1,2}$ 按照以下规则合成：
    $$CF_{1,2} = \begin{cases} CF_1 + CF_2 - CF_1 \times CF_2, & CF_1 \ge 0, CF_2 \ge 0 \\ CF_1 + CF_2 + CF_1 \times CF_2, & CF_1 < 0, CF_2 < 0 \\ \frac{CF_1 + CF_2}{1 - \min(|CF_1|, |CF_2|)}, & \text{一正一负且符号相异} \end{cases}$$

## 3. 概率推理初步与贝叶斯网络
* **贝叶斯定理**：基于先验概率推导后验概率的核心公式。
    $$P(H|E) = \frac{P(E|H)P(H)}{P(E)}$$
* **贝叶斯网络**：一种有向无环图（DAG），利用节点表示随机变量，有向边表示变量间的因果或条件依赖关系。通过条件概率表（CPT）量化不确定性，大大降低了联合概率分布的计算维度。

## 4. 模糊推理机制
* **模糊集合（Fuzzy Sets）**：
    与经典集合（非黑即白）不同，模糊集合中的元素属于该集合的程度由**隶属度函数** $\mu_A(x)$ 决定。
    $$\mu_A(x) \in [0, 1]$$
    值越接近 $1$ 表示隶属程度越高。
* **模糊逻辑运算**：
    * 模糊交集（AND）：$\mu_{A \cap B}(x) = \min(\mu_A(x), \mu_B(x))$
    * 模糊并集（OR）：$\mu_{A \cup B}(x) = \max(\mu_A(x), \mu_B(x))$
    * 模糊补集（NOT）：$\mu_{\neg A}(x) = 1 - \mu_A(x)$
* **模糊推理过程**：
    主要包含四个基本步骤：
    1.  **模糊化（Fuzzification）**：将确定的输入数据转化为对应的模糊集及隶属度。
    2.  **规则匹配（Rule Evaluation）**：根据模糊规则库，对模糊输入进行逻辑运算。
    3.  **规则聚合（Aggregation）**：将不同规则推导出的模糊结论集合进行合并。
    4.  **解模糊化（Defuzzification）**：将聚合后的模糊结果转换为确定的输出值，常用方法包括最大隶属度法、重心法（Centroid Method）等。
