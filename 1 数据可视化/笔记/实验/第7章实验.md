### 2. ECharts 和 Pyecharts 是什么
* **ECharts（闭卷重点）**：基于 JavaScript 的数据可视化图表库，特点是直观、生动、可交互、可定制。
* **pyecharts（闭卷重点）**：把 Python 和 ECharts 结合起来的可视化工具，可以用 Python 代码生成 ECharts 图表。
* **实验环境**：
  * 操作系统：Windows 10。
  * 工具：Anaconda Jupyter。
* **pyecharts 基本流程**：
  * 读取数据，例如用 `pandas.read_csv()` 读取 CSV 文件。
  * 准备 x 轴、y 轴或分类统计数据。
  * 创建图表对象，如 `Line()`、`Boxplot()`、`Pie()`、`Calendar()`。
  * 添加数据。
  * 设置全局配置，如标题、图例、视觉映射等。
  * 使用 `render()` 生成 HTML 交互页面。
* **易考点**：
  * 问“pyecharts 最终常生成什么格式？”答：HTML 交互图表页面。
  * 问“pyecharts 和 ECharts 的关系？”答：pyecharts 是 Python 与 ECharts 的结合。

### 3. 折线图：AQI 全年变化趋势
* **折线图（闭卷重点）**：用点和线连接连续数据，适合观察数据随时间变化的趋势。
* **实验数据**：
  * 数据源是 `beijing_AQI_2018.csv`。
  * 主要使用 `Date` 列和 `AQI` 列。
* **主要步骤**：
  * 读取 CSV 数据。
  * 提取日期作为 x 轴。
  * 提取 AQI 值作为 y 轴。
  * 使用 `Line()` 绘制全年 AQI 变化趋势。
* **图表增强元素**：
  * `markline_opts`：添加平均值线，用于观察整体平均水平。
  * `markpoint_opts`：标出最大值和最小值。
  * `areastyle_opts`：给折线下方添加面积样式，增强视觉效果。
* **主要能看什么**：
  * AQI 随日期的波动趋势。
  * 哪些时间空气质量较差或较好。
  * AQI 的最高值、最低值和平均水平。

![AQI 全年折线图](https://bsyimg.luoca.net/imgtc/20260611/54ace4d06386d79f31141b5229c3a42f.webp)

* **易考点**：
  * 问“观察连续时间变化趋势用什么图？”答：折线图。
  * 问“标出最大值、最小值用什么配置？”答：`MarkPointOpts`。
  * 问“显示平均水平用什么配置？”答：`MarkLineOpts`。

### 4. 箱形图：季度 AQI 分布比较
* **箱形图（闭卷重点）**：用中位数、四分位数、上下须和异常值展示一组数值数据的分布。
* **实验任务**：
  * 从日期中提取月份。
  * 按月份把 AQI 分成四个季度。
  * 使用 `Boxplot()` 比较四个季度的 AQI 分布。
* **箱形图主要能看什么**：
  * 每个季度 AQI 的中位水平。
  * 每个季度 AQI 的离散程度。
  * 是否存在异常高值或异常低值。
  * 哪个季度空气质量波动更明显。
* **实验中的关键函数**：
  * `boxplot.prepare_data(y_axis)`：把原始列表转换成箱形图需要的数据结构。
* **适用场景**：
  * 比较多个组别的数值分布。
  * 比较季度、月份、类别之间的数据差异。
* **易考点**：
  * 问“比较四个季度 AQI 分布用什么图？”答：箱形图。
  * 问“箱形图重点看什么？”答：中位数、四分位数、离散程度和异常值。

### 5. 环形图：空气质量等级占比
* **环形图（闭卷重点）**：饼图的一种变体，用圆环扇区展示不同类别在整体中的占比。
* **实验任务**：
  * 按 `Quality_grade` 对空气质量等级进行分组统计。
  * 计算每个等级出现的天数。
  * 使用 `Pie()` 并设置内外半径生成环形图。
* **核心视觉编码**：
  * 整个圆环表示全年空气质量总天数。
  * 每个扇区表示一种空气质量等级。
  * 扇区越大，说明该等级出现次数越多、占比越高。
* **关键参数**：
  * `radius=["40%", "75%"]`：设置内半径和外半径，使饼图变成环形图。
  * `legend_opts`：设置图例位置和方向。
  * `label_opts`：控制标签是否显示。
* **适用场景**：
  * 展示优、良、轻度污染等类别在全年中的比例。
  * 展示类别数量较少的部分与整体关系。

![空气质量等级环形图](https://bsyimg.luoca.net/imgtc/20260611/aa473be451bbe9ffab9fbda0d9a45c70.webp)

* **易考点**：
  * 问“环形图适合展示什么关系？”答：类别占整体的比例关系。
  * 问“pyecharts 中环形图本质上用哪个图表类？”答：`Pie()`。

### 6. 日历热力图：PM2.5 时间分布
* **日历热力图（闭卷重点）**：把每天的数据映射到日历格子中，用颜色深浅表示数值大小。
* **实验任务**：
  * 将 `Date` 列转换为日期格式。
  * 将日期和 PM2.5 值组合成二维列表。
  * 使用 `Calendar()` 绘制 2018 年 PM2.5 日历图。
* **核心视觉编码**：
  * 每个日历格子表示一天。
  * 颜色深浅表示 PM2.5 数值大小。
  * 颜色越明显，通常表示污染值越高。
* **关键参数**：
  * `range_="2018"`：指定日历范围为 2018 年。
  * `visualmap_opts`：设置颜色映射范围和显示方式。
  * `max_`、`min_`：控制视觉映射的最大值和最小值。
* **主要能看什么**：
  * PM2.5 在全年中的时间分布。
  * 哪些日期或季节污染更严重。
  * 是否存在连续污染或季节性变化。

![PM2.5 日历热力图](https://bsyimg.luoca.net/imgtc/20260611/bf6f8a35de5bbddb565bec8839d61b2e.webp)

* **易考点**：
  * 问“按日期查看全年 PM2.5 分布用什么图？”答：日历热力图。
  * 问“日历热力图中颜色表示什么？”答：对应日期的数值大小。

### 7. 多视图组合
* **多视图组合（闭卷重点）**：把多个图表放到同一个页面中，从不同角度观察同一批或相关数据。
* **实验中使用的图表**：
  * 柱状图 `Bar()`。
  * 折线图 `Line()`。
  * 饼图或玫瑰图 `Pie()`。
  * 页面布局 `Page()`。
* **主要用途**：
  * 同时展示趋势、比较、比例等不同信息。
  * 方便用户进行多角度对比分析。
  * 通过拖拽布局调整图表位置。
* **关键操作**：
  * `Page(layout=Page.DraggablePageLayout)`：生成可拖拽布局页面。
  * `render("page_draggable_layout.html")`：先生成可拖拽页面。
  * 点击页面中的 `save config` 保存布局配置。
  * `save_resize_html()`：根据配置文件生成重新布局后的 HTML。
* **与单个图表的区别**：
  * 单个图表只表达一种主要关系。
  * 多视图组合可以同时表达多种关系，适合复杂数据分析。

![多视图组合 Dashboard](https://bsyimg.luoca.net/imgtc/20260611/bf3678e97d080e389fdf1da5aa23f764.webp)

* **易考点**：
  * 问“多个图表放在同一页面中分析叫什么？”答：多视图组合或组合视图。
  * 问“pyecharts 中可拖拽组合页面用什么？”答：`Page.DraggablePageLayout`。

### 8. 本实验小结
* pyecharts 可以用 Python 代码生成基于 ECharts 的交互式 HTML 图表。
* 折线图适合观察 AQI 随时间变化的趋势。
* 箱形图适合比较不同季度 AQI 的分布差异。
* 环形图适合展示空气质量等级占全年天数的比例。
* 日历热力图适合观察 PM2.5 在全年日期上的分布。
* 多视图组合适合把多种图表集中在一个页面中进行综合分析。
* 做题时先判断分析目标：趋势、分布、占比、时间日历分布或综合对比，再选择对应图形。
