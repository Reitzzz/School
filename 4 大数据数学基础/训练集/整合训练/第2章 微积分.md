## 三、易错点总结

1. **复合函数与对数求导法**：对数求导时不要忘记 $\ln z$ 求导为 $\frac{1}{z}z'$，最后必须乘以 $z$ 还原。
2. **全微分的形式**：结果必须写成 $dz=f_xdx+f_ydy$，不要漏掉 $dx$ 和 $dy$。
3. **一元极值判断**：驻点不一定是极值点，必须看导数变号或二阶导数。
4. **二元函数极值判别式**：用 $D=AC-B^2$。$D>0$ 时再看 $A$ 的正负，$D<0$ 不是极值，$D=0$ 不能确定。
5. **定积分与不定积分**：不定积分结果带 $+C$；定积分结果是数值，不带 $+C$。

### 2.1 函数与极限 答案

**2.1.1 基础题 1**
> **解答**：集合 $B=\{2,3\}$。$A\cup B=\{1,2,3,4,5\}$；$A\cap B=\{2,3\}$；$A\setminus B=\{1,4,5\}$。

**2.1.1 加强训练 1**
> **解答**：集合 $A=\{x \mid (x-1)(x-2) \le 0\} = \{x \mid 1 \le x \le 2\}$。集合 $B$ 要求 $x-0.5 > 0$ 且 $\ln(x-0.5) < 0 \implies 0 < x-0.5 < 1 \implies 0.5 < x < 1.5$。
> 并集 $A \cup B = \{x \mid 0.5 < x \le 2\}$；
> 交集 $A \cap B = \{x \mid 1 \le x < 1.5\}$；
> 差集 $A \setminus B = \{x \mid 1.5 \le x \le 2\}$。

**2.1.4 典型题 1**
> **解答**：因为 $\lim_{x\to 0}\frac{e^x-1}{x}=1=f(0)$，所以连续。再用定义求导数：$f'(0)=\lim_{x\to 0}\frac{e^x-1-x}{x^2}=\frac{1}{2}$，所以函数连续且可导。

**2.1.4 加强训练 1**
> **解答**：因为 $\lim_{x \to 0} \frac{\ln(1+x^2)}{x} = \lim_{x \to 0} \frac{x^2}{x} = 0 = f(0)$，所以函数在 $x=0$ 处连续。
> 再由导数定义：$f'(0) = \lim_{x \to 0} \frac{\frac{\ln(1+x^2)}{x} - 0}{x} = \lim_{x \to 0} \frac{\ln(1+x^2)}{x^2} = 1$。
> 所以函数在 $x=0$ 处连续且可导。

### 2.2 导数与微分 答案

**2.2.1 基础题 1**
> **解答**：$f'(x)=\lim_{\Delta x\to0}\frac{\frac{1}{x+\Delta x}-\frac{1}{x}}{\Delta x}=\lim_{\Delta x\to0}\frac{-1}{x(x+\Delta x)}=-\frac{1}{x^2}$。

**2.2.1 加强训练 1**
> **解答**：$f'(x) = \lim_{\Delta x \to 0} \frac{\sqrt{x+\Delta x+1} - \sqrt{x+1}}{\Delta x} = \lim_{\Delta x \to 0} \frac{(x+\Delta x+1) - (x+1)}{\Delta x(\sqrt{x+\Delta x+1} + \sqrt{x+1})} = \lim_{\Delta x \to 0} \frac{1}{\sqrt{x+\Delta x+1} + \sqrt{x+1}} = \frac{1}{2\sqrt{x+1}}$。

**2.2.2 基础题 1**
> **解答**：
> (1) $y'=\frac{\cos x}{\sqrt{1-\sin^2x}}=\operatorname{sgn}(\cos x)$（当 $\cos x\ne0$ 时）。
> (2) $y'=\frac{e^x}{\sqrt{1+e^{2x}}}$。
> (3) $y'=\frac{1}{(1-x^2)^{3/2}}$。

**2.2.2 加强训练 1**
> **解答**：
> (1) $y' = -\frac{1}{\sqrt{1-(\cos^2 x)^2}} \cdot (2\cos x) \cdot (-\sin x) = \frac{2\cos x \sin x}{\sqrt{1-\cos^4 x}} = \frac{\sin 2x}{\sqrt{1-\cos^4 x}}$。
> (2) $y' = \frac{1}{x+\sqrt{x^2-1}} \cdot \left(1 + \frac{x}{\sqrt{x^2-1}}\right) = \frac{1}{\sqrt{x^2-1}}$。
> (3) $y' = \frac{(e^x+e^{-x})(e^x+e^{-x}) - (e^x-e^{-x})(e^x-e^{-x})}{(e^x+e^{-x})^2} = \frac{4}{(e^x+e^{-x})^2}$。

**2.2.2 典型题 1**
> **解答**：两边取对数 $\ln y=x\ln x$，两边求导得 $\frac{y'}{y}=\ln x+1$，所以 $y'=x^x(\ln x+1)$。

**2.2.2 加强训练 2**
> **解答**：两边取对数 $\ln y = x \ln(\sin x)$，两边求导得 $\frac{y'}{y} = \ln(\sin x) + x \frac{\cos x}{\sin x}$，所以 $y' = (\sin x)^x (\ln(\sin x) + x \cot x)$。

**2.2.2 典型题 2**
> **解答**：对两边取对数 $\ln z=y\ln(1+xy)$。
> 对 $x$ 求偏导：$\frac{\partial z}{\partial x}=y^2(1+xy)^{y-1}$。
> 对 $y$ 求偏导：$\frac{\partial z}{\partial y}=(1+xy)^y\left[\ln(1+xy)+\frac{xy}{1+xy}\right]$。

**2.2.2 加强训练 3**
> **解答**：取对数 $\ln z = \ln y \ln x$。
> 对 $x$ 求偏导：$\frac{1}{z} \frac{\partial z}{\partial x} = \frac{\ln y}{x} \implies \frac{\partial z}{\partial x} = x^{\ln y-1} \ln y$。
> 对 $y$ 求偏导：$\frac{1}{z} \frac{\partial z}{\partial y} = \frac{\ln x}{y} \implies \frac{\partial z}{\partial y} = x^{\ln y} \frac{\ln x}{y}$。

**2.2.2 综合题 1**
> **解答**：
> $\frac{\partial z}{\partial x}=2xy+y^2+ye^{xy}\ln(1+x)+\frac{e^{xy}}{1+x}$
> $\frac{\partial z}{\partial y}=x^2+2xy+xe^{xy}\ln(1+x)$
> 代入 $(1,0)$，得 $\left.\frac{\partial z}{\partial y}\right|_{(1,0)}=1+\ln2$。

**2.2.2 加强训练 4**
> **解答**：
> $\frac{\partial z}{\partial x} = y^2 e^{xy^2} \cos(x+y) - e^{xy^2} \sin(x+y)$
> $\frac{\partial z}{\partial y} = 2xy e^{xy^2} \cos(x+y) - e^{xy^2} \sin(x+y)$
> 代入 $(0,\pi)$，得到 $\left.\frac{\partial z}{\partial x}\right|_{(0,\pi)} = \pi^2 e^0 \cos(\pi) - e^0 \sin(\pi) = -\pi^2$。

**2.2.3 基础题 1**
> **解答**：
> (1) $dy=\left(-\frac{1}{x^2}+\frac{1}{\sqrt{x}}\right)dx$。
> (2) $dy=2xe^{2x}(1+x)dx$。

**2.2.3 加强训练 1**
> **解答**：
> (1) $dy = (3x^2 \ln x + x^2) dx = x^2(3\ln x + 1) dx$。
> (2) $dy = \frac{x \cos x - \sin x}{x^2} dx$。

**2.2.3 典型题 1**
> **解答**：设 $V=\pi r^2h$，则 $\Delta V\approx dV=2\pi rh\,\Delta r+\pi r^2\,\Delta h$。代入得 $dV\approx-200\pi\text{cm}^3$。

**2.2.3 加强训练 2**
> **解答**：长方体体积 $V = abc$。
> 体积的微分 $dV = bc\,da + ac\,db + ab\,dc$。
> 代入数值 $\Delta V \approx bc \Delta a + ac \Delta b + ab \Delta c = 5 \times 2 \times 0.01 + 10 \times 2 \times (-0.02) + 10 \times 5 \times 0.05 = 0.1 - 0.4 + 2.5 = 2.2\,\text{m}^3$。

### 2.3 微分中值定理与导数的应用 答案

**2.3.1 典型题 1**
> **解答**：令 $f(t)=\ln(1+t)$，在 $[0,x]$ 上使用拉格朗日中值定理，有 $\ln(1+x)=\frac{x}{1+\xi}$，其中 $0<\xi<x$。因为 $1<1+\xi<1+x$，所以 $\frac{1}{1+x}<\frac{1}{1+\xi}<1$，从而 $\frac{x}{1+x}<\ln(1+x)<x$。

**2.3.1 加强训练 1**
> **解答**：令 $f(x) = \ln x$，在 $[b, a]$ 上使用拉格朗日中值定理。
> $f(a) - f(b) = \frac{1}{\xi}(a-b)$，其中 $b < \xi < a$。
> 因为 $\frac{1}{a} < \frac{1}{\xi} < \frac{1}{b}$，且 $a-b > 0$，所以 $\frac{a-b}{a} < \frac{a-b}{\xi} < \frac{a-b}{b}$，即 $\frac{a-b}{a} < \ln\frac{a}{b} < \frac{a-b}{b}$。

**2.3.3 典型题 1**
> **解答**：$f'(x)=3(x+1)(x-3)$，驻点为 $x=-1,3$。在 $x=-1$ 处取极大值 $10$，在 $x=3$ 处取极小值 $-22$。

**2.3.3 加强训练 1**
> **解答**：$f'(x) = 6x^2-18x+12 = 6(x-1)(x-2)$，驻点为 $x=1, 2$。
> 当 $x<1$ 时 $f'(x)>0$，当 $1<x<2$ 时 $f'(x)<0$，当 $x>2$ 时 $f'(x)>0$。
> 所以在 $x=1$ 处取极大值 $f(1)=2-9+12-3=2$，在 $x=2$ 处取极小值 $f(2)=16-36+24-3=1$。

**2.3.3 综合题 1**
> **解答**：$f'(x)=3[x^2-2ax+(a-1)]$，驻点 $x_{1,2}=a\pm\sqrt{a^2-a+1}$。$f''(x)=6(x-a)$。在 $x_1=a-\sqrt{a^2-a+1}$ 处 $f''<0$，取得极大值；在 $x_2=a+\sqrt{a^2-a+1}$ 处 $f''>0$，取得极小值。

**2.3.3 加强训练 2**
> **解答**：$f'(x) = 3x^2-6x+3k$。若函数有极大值和极小值，则 $f'(x)=0$ 有两个不相等的实数根，即判别式 $\Delta = 36 - 36k > 0 \implies k < 1$。
> 此时驻点 $x_{1,2} = \frac{6 \pm \sqrt{36-36k}}{6} = 1 \pm \sqrt{1-k}$。
> $f''(x) = 6x-6$。在 $x_1 = 1-\sqrt{1-k}$ 处，$f''(x_1) = -6\sqrt{1-k} < 0$，取得极大值；
> 在 $x_2 = 1+\sqrt{1-k}$ 处，$f''(x_2) = 6\sqrt{1-k} > 0$，取得极小值。

**2.3.3 综合题 2**
> **解答**：求一阶偏导数得到驻点 $(0,0)$ 和 $(2,2)$。用 $D=AC-B^2$ 判别：点 $(0,0)$ 处取极大值 $1$；点 $(2,2)$ 处不存在极值。

**2.3.3 加强训练 3**
> **解答**：求一阶偏导数，得到方程组：$f_x = 4x^3-4y = 0 \implies y=x^3$；$f_y = 4y^3-4x = 0 \implies x=y^3$。解得驻点 $(0,0), (1,1), (-1,-1)$。
> 二阶偏导数：$A=f_{xx}=12x^2, B=f_{xy}=-4, C=f_{yy}=12y^2$。
> 在 $(0,0)$ 处 $AC-B^2 = -16 < 0$，不是极值点。
> 在 $(1,1)$ 和 $(-1,-1)$ 处，$AC-B^2 = 144-16 = 128 > 0$，且 $A=12>0$，所以 $(1,1)$ 和 $(-1,-1)$ 是极小值点，极小值为 $f(1,1)=f(-1,-1) = -1$。

### 2.4 不定积分与定积分 答案

**2.4.1 基础题 1**
> **解答**：原式 $=\frac{1}{2}x^2+x+C$。

**2.4.1 加强训练 1**
> **解答**：原式 $= \frac{1}{3}x^3 - x^2 + \ln|x| + C$。

**2.4.2 典型题 1**
> **解答**：令 $t=\frac{1}{x}$，积分变为 $\int_0^1\frac{a}{2+at}\,dt=\ln(a+2)-\ln2=\ln\frac{a+2}{2}$。由题意，$\frac{a+2}{2}=2$，所以 $a=2$。

**2.4.2 加强训练 1**
> **解答**：原式 $= \lim_{b \to +\infty} \int_0^b \frac{1}{x^2+4} \,dx = \lim_{b \to +\infty} \left. \frac{1}{2} \arctan \frac{x}{2} \right|_0^b = \lim_{b \to +\infty} \frac{1}{2} \arctan \frac{b}{2} = \frac{1}{2} \cdot \frac{\pi}{2} = \frac{\pi}{4}$。

**2.4.3 基础题 1**
> **解答**：$|\sin x|$ 的周期为 $\pi$，且 $\int_0^\pi|\sin x|dx=2$，所以 $I=2k$，与 $a$ 无关。

**2.4.3 加强训练 1**
> **解答**：证明：$\int_a^{a+T} f(x) dx = \int_a^0 f(x) dx + \int_0^T f(x) dx + \int_T^{a+T} f(x) dx$。
> 对最后一部分积分令 $t=x-T$，则 $\int_T^{a+T} f(x) dx = \int_0^a f(t+T) dt = \int_0^a f(t) dt$。
> 由于 $\int_a^0 f(x) dx = -\int_0^a f(x) dx$，两者抵消，得证 $\int_a^{a+T} f(x) dx = \int_0^T f(x) dx$。
> 计算：$|\cos x|$ 的周期为 $\pi$，所以 $\int_0^{2\pi} |\cos x| dx = 2\int_0^\pi |\cos x| dx = 2 \left( \int_0^{\pi/2} \cos x dx - \int_{\pi/2}^\pi \cos x dx \right) = 2(1 - (-1)) = 4$。
