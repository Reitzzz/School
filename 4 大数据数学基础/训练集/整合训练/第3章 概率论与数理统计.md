## 三、易错点总结

1. **方差的分母**：计算样本方差时分母是 $n-1$ 而不是 $n$。
2. **事件相互独立与两两独立**：两两独立不能推出相互独立。
3. **贝叶斯公式**：分母一定是全概率公式的结果。
4. **边缘分布求法**：离散型求和，连续型求积分（注意积分边界可能带有变量）。
5. **期望和方差性质**：$D(aX+b) = a^2D(X)$；当 $X,Y$ 独立时 $D(X\pm Y) = D(X) + D(Y)$，注意不是减！
6. **似然函数的构造**：如果是离散型则为概率质量函数的乘积，如果是连续型则为密度函数的乘积。

<span id="ans-3-2-古典概型与超几何分布-基础题-1"></span>**古典概型与超几何分布 基础题 1**
> **解答**：
> 设抽到的次品数为 $X$，则 $X$ 服从超几何分布。
> 恰好 90 个次品：$P(X=90)= \frac{C_{600}^{90}C_{1200}^{110}}{C_{1800}^{200}}$。

<span id="ans-3-2-条件概率与全概率-典型题-1"></span>**条件概率、全概率与贝叶斯公式 典型题 1**

### 3.3 参数估计与假设检验 答案

<span id="ans-3-3-极大似然估计-典型题-1"></span>**极大似然估计 典型题 1**
> **解答**：
> 对数似然函数 $\ln L(\lambda)=-n\ln\lambda-\frac{1}{\lambda}\sum x_i$。求导令为 0 得 $\hat{\lambda}=\bar x$。$\hat{\lambda}=\frac{11470}{10}=1147$。

<span id="ans-3-3-极大似然估计-加强训练-1"></span>**极大似然估计 加强训练 1**
> **解答**：
> 似然函数 $L(\theta) = \prod_{i=1}^n \theta e^{-\theta x_i} = \theta^n e^{-\theta \sum_{i=1}^n x_i}$。
> 对数似然函数 $\ln L(\theta) = n \ln \theta - \theta \sum_{i=1}^n x_i$。
> 对 $\theta$ 求导并令为零：$\frac{n}{\theta} - \sum_{i=1}^n x_i = 0$。
> 得到表达式 $\hat{\theta} = \frac{n}{\sum_{i=1}^n x_i} = \frac{1}{\bar{x}}$。
> 代入样本数据 $n=5$，样本总和 $\sum x_i = 2+4+3+5+6 = 20$。
> $\hat{\theta} = \frac{5}{20} = 0.25$。
> 因为极大似然估计值为 $0.25$，所以给出的 $\theta=0.2$ 不是该样本下的极大似然估计。

<span id="ans-3-3-极大似然估计-课件例题-1"></span>**极大似然估计 课件例题 1**
> **解答**：
> 对数似然函数 $\ln L(\lambda)=n\ln\lambda-\lambda\sum x_i$。求导令为 0 得表达式 $\hat{\lambda}=\frac{n}{\sum x_i}=\frac{1}{\bar x}$。
> 代入样本数据 $n=8$，样本总和 $\sum x_i = 1.2+0.8+2.5+1.5+0.5+2.0+1.0+2.5 = 12.0$。
> $\hat{\lambda} = \frac{8}{12} = \frac{2}{3} \approx 0.667$。

<span id="ans-3-3-极大似然估计-加强训练-2"></span>**极大似然估计 加强训练 2**
> **解答**：
> 密度函数 $f(x) = \frac{1}{\theta}$ 当 $0 \le x \le \theta$，否则为 0。
> 似然函数 $L(\theta) = \begin{cases} \frac{1}{\theta^n}, & 0 \le x_1, x_2, \dots, x_n \le \theta \\ 0, & \text{其他} \end{cases}$。
> 要使 $L(\theta)$ 取得最大值，$\theta$ 应该尽可能小，但又必须满足 $x_i \le \theta$ 对所有 $i=1,\dots,n$ 成立。即 $\theta \ge \max(x_1, \dots, x_n)$。
> 因此，$\theta$ 的极大似然估计量表达式为 $\hat{\theta} = \max(x_1, x_2, \dots, x_n)$。
> 代入样本数据：$\max(3.2, 1.5, 4.8, 2.7, 5.1, 4.0) = 5.1$。
> 故 $\hat{\theta} = 5.1$。
