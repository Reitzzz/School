**2. 简答题答案**

设抽取的次品数量为随机变量 $X$，此问题服从超几何分布。总体 $N=1800$，次品 $M=600$，正品 $N-M=1200$，样本容量 $n=200$。

1. 恰好有90个次品的概率：

   $$P(X=90) = \frac{\binom{600}{90} \binom{1200}{110}}{\binom{1800}{200}}$$

2. 至少有2个次品的概率（利用对立事件求解）：

   $$P(X \ge 2) = 1 - P(X=0) - P(X=1) = 1 - \frac{\binom{600}{0} \binom{1200}{200}}{\binom{1800}{200}} - \frac{\binom{600}{1} \binom{1200}{199}}{\binom{1800}{200}}$$

**3. 简答题答案**

设 $A$ 表示选出的产品由甲厂生产，$B$ 表示由乙厂生产，$D$ 表示选出的是次品。
已知：$P(A) = \frac{1800}{3000} = 0.6$，$P(B) = \frac{1200}{3000} = 0.4$；$P(D|A) = 0.01$，$P(D|B) = 0.02$。

1. 选出的产品是次品的概率（全概率公式）：

   $$P(D) = P(A)P(D|A) + P(B)P(D|B) = 0.6 \times 0.01 + 0.4 \times 0.02 = 0.006 + 0.008 = 0.014$$

2. 已知是次品，由甲厂生产的概率（贝叶斯公式）：

   $$P(A|D) = \frac{P(A)P(D|A)}{P(D)} = \frac{0.006}{0.014} = \frac{3}{7}$$

3. 已知是次品，由乙厂生产的概率（贝叶斯公式）：

   $$P(B|D) = \frac{P(B)P(D|B)}{P(D)} = \frac{0.008}{0.014} = \frac{4}{7}$$

**4. 简答题答案**

单台仪器能出厂的概率 $p = 0.7 + 0.3 \times 0.8 = 0.94$，不能出厂的概率 $q = 1 - 0.94 = 0.06$。

1. 能出厂的仪器数量 $X$ 服从二项分布 $X \sim B(n, 0.94)$，其分布律为：

   $$P(X = k) = \binom{n}{k} (0.94)^k (0.06)^{n-k}, \quad k = 0, 1, 2, \dots, n$$

2. $n$ 台全部能出厂的概率：

   $$P(X = n) = (0.94)^n$$

3. 设不能出厂的仪器数量为 $Y = n - X$，则 $Y \sim B(n, 0.06)$。至少有两台不能出厂的概率：

   $$P(Y \ge 2) = 1 - P(Y=0) - P(Y=1) = 1 - (0.94)^n - n(0.06)(0.94)^{n-1}$$

4. 不能出厂仪器数量 $Y$ 的数学期望与方差：
   数学期望 $E(Y) = nq = 0.06n$
   方差 $D(Y) = npq = n \times 0.06 \times 0.94 = 0.0564n$

**5. 简答题答案**

1. 根据概率密度函数性质 $\int_{-\infty}^{+\infty} f(x) dx = 1$：

   $$\int_{-1}^{1} \frac{a}{\sqrt{1-x^2}} dx = a \left[ \arcsin x \right]_{-1}^{1} = a \left( \frac{\pi}{2} - \left(-\frac{\pi}{2}\right) \right) = a\pi = 1$$

   得系数 $a = \frac{1}{\pi}$。

2. 概率 $P(|x| < \frac{1}{3})$：

   $$P\left(|x| < \frac{1}{3}\right) = \int_{-1/3}^{1/3} \frac{1}{\pi\sqrt{1-x^2}} dx = \frac{1}{\pi} \left[ \arcsin x \right]_{-1/3}^{1/3} = \frac{2}{\pi} \arcsin\left(\frac{1}{3}\right)$$

3. 分布函数 $F(x) = \int_{-\infty}^{x} f(t) dt$：
   当 $x \le -1$ 时，$F(x) = 0$；
   当 $-1 < x < 1$ 时，$F(x) = \int_{-1}^{x} \frac{1}{\pi\sqrt{1-t^2}} dt = \frac{1}{\pi} \arcsin x + \frac{1}{2}$；
   当 $x \ge 1$ 时，$F(x) = 1$。

**6. 简答题答案**

收益率 $X$ 的期望与方差：

$$E(X) = 0.01\times0.1 + 0.02\times0.1 + 0.03\times0.2 + 0.04\times0.3 + 0.05\times0.2 + 0.06\times0.1 = 0.037 \text{ (即 3.7\%) }$$

$$E(X^2) = 0.01^2\times0.1 + \dots + 0.06^2\times0.1 = 0.00157$$

$$D(X) = E(X^2) - [E(X)]^2 = 0.00157 - 0.037^2 = 0.000201$$

设收入为 $Y = 100000X$：
预期收入 $E(Y) = 100000 \times E(X) = 100000 \times 0.037 = 3700$ (元)
收入的方差 $D(Y) = (100000)^2 \times D(X) = 10^{10} \times 0.000201 = 2010000$

**8. 简答题答案**

先求边缘分布：<br>
$P(Y=-1) = \frac{3}{8}, P(Y=0) = \frac{2}{8}, P(Y=1) = \frac{3}{8}$ <br> 
$E(X) = -1 \times \frac{3}{8} + 0 \times \frac{2}{8} + 1 \times \frac{3}{8} = 0$，同理 $E(Y) = 0$。<br>
$E(XY) = (-1)(-1)\frac{1}{8} + (-1)(1)\frac{1}{8} + (1)(-1)\frac{1}{8} + (1)(1)\frac{1}{8} = 0$ <br>
协方差 $Cov(X,Y) = E(XY) - E(X)E(Y) = 0$。因此相关系数 $\rho = 0$。<br>
独立性判断：
因为 $P(X=0, Y=0) = 0$，而 $P(X=0)P(Y=0) = \frac{2}{8} \times \frac{2}{8} = \frac{1}{16} \neq 0$。
由于联合概率不等于边缘概率的乘积，所以 $X, Y$ **不相互独立**。

**9. 简答题答案**

指数分布的似然函数：

$$L(\lambda) = \prod_{i=1}^{n} \frac{1}{\lambda} e^{-\frac{x_i}{\lambda}} = \lambda^{-n} e^{-\frac{1}{\lambda} \sum x_i}$$

对数似然函数：

$$\ln L(\lambda) = -n \ln \lambda - \frac{1}{\lambda} \sum_{i=1}^{n} x_i$$

对 $\lambda$ 求导并令为0：

$$\frac{d \ln L(\lambda)}{d\lambda} = -\frac{n}{\lambda} + \frac{1}{\lambda^2} \sum_{i=1}^{n} x_i = 0 \implies \hat{\lambda} = \frac{1}{n} \sum_{i=1}^{n} x_i = \bar{x}$$

由所给数据，$n=10$，样本总和为 $1050+1100+1080+1120+1200+1250+1040+1130+1300+1200 = 11470$。
极大概然估计值 $\hat{\lambda} = \frac{11470}{10} = 1147$。
