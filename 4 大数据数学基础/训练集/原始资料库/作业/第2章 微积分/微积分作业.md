# 微积分作业

### 习题

1. 根据导数的定义，求函数 $f(x)=\frac{1}{x}$ 的导数。 [<font color="blue">查看答案</font>](#calc-ans-1)

2. 求下列函数的导数： [<font color="blue">查看答案</font>](#calc-ans-2)

(1) $y=\arcsin(\sin x)$ ;

(2) $y=\ln(e^x+\sqrt{1+e^{2x}})$ ;

(3) $y=x^x(x>0)$ ;

(4) $y=\frac{x}{\sqrt{1-x^2}}$ 。

3. 求下列函数的微分： [<font color="blue">查看答案</font>](#calc-ans-3)

(1) $y=\frac{1}{x}+2\sqrt{x}$ ;

(2) $y=\ln^2(1-x)$ ;

(3) $y=x^2e^{2x}$ ;

(4) $y=\tan^2(1+2x^2)$ 。

4. 利用函数的微分知识求 $\sqrt[3]{1.02}$ 的近似值。 [<font color="blue">查看答案</font>](#calc-ans-4)

5. 求下列函数的偏导数： [<font color="blue">查看答案</font>](#calc-ans-5)

(1) $z=x^3y-y^3x$ ;

(2) $z=\frac{x^2+y^2}{xy}$ ;

(3) $z=\ln\tan\frac{x}{y}$ ;

(4) $z=(1+xy)^y$ 。

6. 当 $x=1, y=2$ 时，求函数 $z=\ln(1+x^2+y^2)$ 的全微分。 [<font color="blue">查看答案</font>](#calc-ans-6)

7. 当 $x=1, y=1, \Delta x=0.15, \Delta y=0.1$ 时，求函数 $z=e^{xy}$ 的全微分。 [<font color="blue">查看答案</font>](#calc-ans-7)

# 答案区

<a id="calc-ans-1"></a>

**1.**

$f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x} = \lim_{\Delta x \to 0} \frac{\frac{1}{x+\Delta x} - \frac{1}{x}}{\Delta x} = \lim_{\Delta x \to 0} \frac{-1}{x(x+\Delta x)} = -\frac{1}{x^2}$。

<a id="calc-ans-2"></a>

**2.**

(1) $y' = (\arcsin u)' \cdot u' = \frac{1}{\sqrt{1-\sin^2 x}} \cdot \cos x = \text{sgn}(\cos x)$ （当 $\cos x \neq 0$ 时）。

(2) $y' = \frac{1}{e^x+\sqrt{1+e^{2x}}} \cdot (e^x + \frac{1}{2\sqrt{1+e^{2x}}} \cdot 2e^{2x}) = \frac{e^x}{\sqrt{1+e^{2x}}}$。

(3) 两边取对数 $\ln y = x \ln x$，两边求导得 $\frac{y'}{y} = \ln x + 1 \Rightarrow y' = x^x(\ln x + 1)$。

(4) $y' = \frac{1 \cdot \sqrt{1-x^2} - x \cdot \frac{-x}{\sqrt{1-x^2}}}{1-x^2} = \frac{1}{(1-x^2)^{\frac{3}{2}}}$。

<a id="calc-ans-3"></a>

**3.**

(1) $dy = (-\frac{1}{x^2} + \frac{1}{\sqrt{x}}) dx$。

(2) $dy = 2\ln(1-x) \cdot \frac{-1}{1-x} dx = -\frac{2\ln(1-x)}{1-x} dx$。

(3) $dy = (2x e^{2x} + 2x^2 e^{2x}) dx = 2xe^{2x}(1+x) dx$。

(4) $dy = 2\tan(1+2x^2) \cdot \sec^2(1+2x^2) \cdot 4x dx = 8x \tan(1+2x^2) \sec^2(1+2x^2) dx$。

<a id="calc-ans-4"></a>

**4.**

设 $f(x) = \sqrt[3]{x}$，取 $x_0=1, \Delta x=0.02$。
$f'(x) = \frac{1}{3}x^{-2/3}$，故 $f'(1) = \frac{1}{3}$。
利用近似公式 $f(x_0+\Delta x) \approx f(x_0) + f'(x_0)\Delta x$，
$\sqrt[3]{1.02} \approx 1 + \frac{1}{3} \times 0.02 \approx 1.00667$。

<a id="calc-ans-5"></a>

**5.**

(1) $\frac{\partial z}{\partial x} = 3x^2y - y^3$；$\frac{\partial z}{\partial y} = x^3 - 3y^2x$。

(2) $z = \frac{x}{y} + \frac{y}{x}$。$\frac{\partial z}{\partial x} = \frac{1}{y} - \frac{y}{x^2}$；$\frac{\partial z}{\partial y} = -\frac{x}{y^2} + \frac{1}{x}$。

(3) $\frac{\partial z}{\partial x} = \frac{1}{\tan(x/y)} \cdot \sec^2(x/y) \cdot \frac{1}{y} = \frac{2}{y\sin(2x/y)}$；$\frac{\partial z}{\partial y} = \frac{2}{y\sin(2x/y)} \cdot (-\frac{x}{y}) = -\frac{2x}{y^2\sin(2x/y)}$。

(4) 对两边取对数 $\ln z = y \ln(1+xy)$，分别求偏导得：
- 对 $x$ 求偏导（将 $y$ 视为常数）：
  $\frac{1}{z} \frac{\partial z}{\partial x} = \frac{y^2}{1+xy} \implies \frac{\partial z}{\partial x} = y^2(1+xy)^{y-1}$
- 对 $y$ 求偏导（使用乘积求导法则）：
  $\frac{1}{z} \frac{\partial z}{\partial y} = \ln(1+xy) + \frac{xy}{1+xy} \implies \frac{\partial z}{\partial y} = (1+xy)^y \left[ \ln(1+xy) + \frac{xy}{1+xy} \right]$

<a id="calc-ans-6"></a>

**6.**

全微分 $dz = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy = \frac{2x}{1+x^2+y^2}dx + \frac{2y}{1+x^2+y^2}dy$。
将 $x=1, y=2$ 代入得 $dz = \frac{2}{6}dx + \frac{4}{6}dy = \frac{1}{3}dx + \frac{2}{3}dy$。

<a id="calc-ans-7"></a>

**7.**

全微分 $dz = y e^{xy} dx + x e^{xy} dy$。
代入 $x=1, y=1$，得 $dz = e \cdot dx + e \cdot dy$。
再代入 $\Delta x=0.15, \Delta y=0.1$，全微分近似增量为 $dz = e(0.15) + e(0.1) = 0.25e$。
