## 三、简答题

1. 实体完整性和参照完整性：
   - 实体完整性：主键属性不能为空，保证每个元组可以被唯一标识。
   - 参照完整性：外键值必须为空，或等于被引用关系中已经存在的主键/候选键值。

2. 视图和基本表：
   - 基本表实际存储数据。
   - 视图是由一个或多个基本表导出的虚拟表，通常只保存查询定义。
   - 视图作用：简化查询、隐藏敏感数据、提供不同用户视角、提高逻辑独立性。

## 四、概念结构设计与逻辑结构设计

实体及属性：

```text
Hotel(hotelNo, hotelName, city)
Room(roomNo, type, price)
Guest(guestNo, guestName, guestAddress, phone)
Booking(bookID, dateFrom, dateTo)
```

联系：

```text
Hotel 与 Room 是 1:N。
Guest 与 Room 通过 Booking 发生预订联系。
Booking 记录某位 Guest 在某时间段预订某 Hotel 的某 Room。
```

关系模式：

```text
Hotel(hotelNo, hotelName, city)
Room(roomNo, hotelNo, type, price)
Guest(guestNo, guestName, guestAddress, phone)
Booking(bookID, hotelNo, roomNo, guestNo, dateFrom, dateTo)
```

主键和外键：

```text
Hotel: 主键 hotelNo
Room: 主键 (roomNo, hotelNo)，外键 hotelNo -> Hotel(hotelNo)
Guest: 主键 guestNo
Booking: 主键 bookID
         外键 guestNo -> Guest(guestNo)
         外键 hotelNo -> Hotel(hotelNo)
         外键 (roomNo, hotelNo) -> Room(roomNo, hotelNo)
```

## 五、规范化题

1. 候选键：

```text
(FilmID, ActorID)
```

2. 范式判断：

```text
主键为 (FilmID, ActorID)。
FilmID -> Title, Year, DirectorID，ActorID -> ActorName。
这些属性只依赖组合主键的一部分，存在部分依赖，不满足 2NF。
因此最高只满足 1NF。
```

还存在传递依赖：

```text
FilmID -> DirectorID
DirectorID -> DirectorName
```

所以也不满足 3NF。

3. 分解到 BCNF：

```text
Film(FilmID, Title, Year, DirectorID)       主键 FilmID
Director(DirectorID, DirectorName)          主键 DirectorID
Actor(ActorID, ActorName)                   主键 ActorID
Role(FilmID, ActorID, Character)            主键 (FilmID, ActorID)
```

## 六、Programming 数据操纵题

### （一）关系代数和 SQL

1. 查询 London 城市所有酒店的酒店号和酒店名。

关系代数：

```text
πhotelNo,hotelName(σcity='London'(Hotel))
```

SQL：

```sql
SELECT hotelNo, hotelName
FROM Hotel
WHERE city = 'London';
```

2. 查询 `Grosvenor Hotel` 中价格低于 100 的房间号和房间类型。

关系代数：

```text
πroomNo,type(σHotel.hotelNo=Room.hotelNo AND hotelName='Grosvenor Hotel' AND price<100
            (Hotel ⋈ Room))
```

SQL：

```sql
SELECT r.roomNo, r.type
FROM Hotel h
JOIN Room r ON h.hotelNo = r.hotelNo
WHERE h.hotelName = 'Grosvenor Hotel'
  AND r.price < 100;
```

3. 查询没有任何预订记录的客人号和客人姓名。

关系代数：

```text
πguestNo,guestName(Guest) - πguestNo,guestName(σGuest.guestNo=Booking.guestNo(Guest ⋈ Booking))
```

SQL：

```sql
SELECT g.guestNo, g.guestName
FROM Guest g
WHERE NOT EXISTS (
    SELECT *
    FROM Booking b
    WHERE b.guestNo = g.guestNo
);
```

4. 查询预订过 London 所有酒店的客人号和客人姓名。

关系代数：

```text
πguestNo,guestName(σQ.guestNo=Guest.guestNo
                  (ρQ(πguestNo,hotelNo(Booking) ÷ πhotelNo(σcity='London'(Hotel))) ⋈ Guest))
```

SQL：

```sql
SELECT g.guestNo, g.guestName
FROM Guest g
WHERE NOT EXISTS (
    SELECT *
    FROM Hotel h
    WHERE h.city = 'London'
      AND NOT EXISTS (
          SELECT *
          FROM Booking b
          WHERE b.guestNo = g.guestNo
            AND b.hotelNo = h.hotelNo
      )
);
```

### （三）建表题

```sql
CREATE TABLE Booking (
    bookID CHAR(10) PRIMARY KEY,
    hotelNo CHAR(10) NOT NULL,
    roomNo CHAR(10) NOT NULL,
    guestNo CHAR(10) NOT NULL,
    dateFrom DATE NOT NULL,
    dateTo DATE NOT NULL,
    FOREIGN KEY (hotelNo) REFERENCES Hotel(hotelNo),
    FOREIGN KEY (roomNo, hotelNo) REFERENCES Room(roomNo, hotelNo),
    FOREIGN KEY (guestNo) REFERENCES Guest(guestNo),
    CHECK (dateTo > dateFrom)
);
```
