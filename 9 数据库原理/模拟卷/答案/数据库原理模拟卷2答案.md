## 三、简答题

1. 实体完整性和参照完整性：
   - 实体完整性：主键属性不能为空，且主键值能唯一标识元组。
   - 参照完整性：外键值必须为空，或等于被引用关系中已存在的主键/候选键值。
   - 复合外键要求一组外键属性整体对应被引用关系的一组主键/候选键属性，例如 `(roomNo, hotelNo)` 必须整体匹配 `Room(roomNo, hotelNo)` 中存在的一行。

2. 视图和基本表：
   - 基本表实际存储数据。
   - 视图通常只保存查询定义，是从一个或多个基本表导出的虚拟表。
   - 含聚合、分组、去重、集合运算或多表复杂连接的视图通常不可直接更新。例如 `GROUP BY hotelNo` 后得到平均房价的视图，无法唯一对应到底层某一行。

## 四、概念结构设计与逻辑结构设计

实体及属性：

```text
Hotel(hotelNo, hotelName, city)
Room(roomNo, type, price)
Guest(guestNo, guestName, guestAddress, phone)
Booking(bookID, dateFrom, dateTo, status)
Payment(payID, amount, payTime, method)
```

联系：

```text
Hotel 与 Room 是 1:N。Room 可视为依赖 Hotel 标识的弱实体，完整标识为 (hotelNo, roomNo)。
Guest 与 Room 通过 Booking 发生预订联系；Booking 记录某位 Guest 在某时间段预订某 Hotel 的某 Room。
Booking 与 Payment 是 1:N，一次预订可以对应多笔支付。
```

关系模式：

```text
Hotel(hotelNo, hotelName, city)
Room(roomNo, hotelNo, type, price)
Guest(guestNo, guestName, guestAddress, phone)
Booking(bookID, hotelNo, roomNo, guestNo, dateFrom, dateTo, status)
Payment(payID, bookID, amount, payTime, method)
```

主键、外键和约束：

```text
Hotel: 主键 hotelNo；UNIQUE(city, hotelName)
Room: 主键 (roomNo, hotelNo)；外键 hotelNo -> Hotel(hotelNo)
Guest: 主键 guestNo
Booking: 主键 bookID
         外键 guestNo -> Guest(guestNo)
         外键 hotelNo -> Hotel(hotelNo)
         外键 (roomNo, hotelNo) -> Room(roomNo, hotelNo)
         CHECK(dateTo > dateFrom)
Payment: 主键 payID；外键 bookID -> Booking(bookID)
```

同一房间已确认预订的时间段不能冲突，通常不能仅靠普通主键/外键表达，需要断言、触发器、排他约束或应用层事务控制配合实现。

## 五、规范化题

1. 候选键：

```text
(FilmID, ActorID)
```

理由：

```text
FilmID -> Title, Year, DirectorID -> DirectorName
ActorID -> ActorName
(FilmID, ActorID) -> Character
Character -> Award
```

因此 `(FilmID, ActorID)+` 能推出全部属性，且 `FilmID` 与 `ActorID` 均不可省略。

2. 范式判断：

```text
主键为 (FilmID, ActorID)。
FilmID -> Title, Year, DirectorID，ActorID -> ActorName。
这些非主属性只依赖组合主键的一部分，存在部分依赖，不满足 2NF。
因此最高只满足 1NF。
```

还存在传递依赖：

```text
FilmID -> DirectorID
DirectorID -> DirectorName
(FilmID, ActorID) -> Character
Character -> Award
```

所以也不满足 3NF。

3. 分解到 BCNF：

```text
Film(FilmID, Title, Year, DirectorID)       主键 FilmID
Director(DirectorID, DirectorName)          主键 DirectorID
Actor(ActorID, ActorName)                   主键 ActorID
Role(FilmID, ActorID, Character)            主键 (FilmID, ActorID)
CharacterAward(Character, Award)            主键 Character
```

该分解可保持题中列出的函数依赖，因为每个依赖均完整出现在某个分解后的关系中。

## 六、Programming 数据操纵题

### （一）关系代数和 SQL

1. 查询 London 城市中平均房价低于 200 的酒店号和酒店名。

关系代数：

```text
先按 hotelNo, hotelName 分组求 AVG(price)，再选择 city='London' 且 AVG(price)<200。
扩展关系代数可写为：
πhotelNo,hotelName(σcity='London' AND AvgPrice<200(
  γhotelNo,hotelName,city; AVG(price)->AvgPrice(Hotel ⋈ Room)
))
```

SQL：

```sql
SELECT h.hotelNo, h.hotelName
FROM Hotel h
JOIN Room r ON h.hotelNo = r.hotelNo
WHERE h.city = 'London'
GROUP BY h.hotelNo, h.hotelName
HAVING AVG(r.price) < 200;
```

2. 查询 `Grosvenor Hotel` 中在 `2026-07-01` 到 `2026-07-03` 期间没有已确认预订冲突的房间号和房间类型。

关系代数：

```text
πroomNo,type(σhotelName='Grosvenor Hotel'(Hotel ⋈ Room))
-
πroomNo,type(
  σhotelName='Grosvenor Hotel' AND status='Confirmed'
   AND dateFrom < '2026-07-03' AND dateTo > '2026-07-01'
  (Hotel ⋈ Room ⋈ Booking)
)
```

SQL：

```sql
SELECT r.roomNo, r.type
FROM Hotel h
JOIN Room r ON h.hotelNo = r.hotelNo
WHERE h.hotelName = 'Grosvenor Hotel'
  AND NOT EXISTS (
      SELECT *
      FROM Booking b
      WHERE b.hotelNo = r.hotelNo
        AND b.roomNo = r.roomNo
        AND b.status = 'Confirmed'
        AND b.dateFrom < DATE '2026-07-03'
        AND b.dateTo > DATE '2026-07-01'
  );
```

3. 查询没有任何预订记录的客人号和客人姓名。

关系代数：

```text
πguestNo,guestName(Guest) - πguestNo,guestName(Guest ⋈ Booking)
```

SQL：

```sql
SELECT g.guestNo, g.guestName
FROM Guest g
WHERE NOT EXISTS (
    SELECT *
    FROM Booking b
    WHERE b.guestNo = g.guestNo
);
```

4. 查询预订过 London 所有酒店且至少有一笔支付记录的客人号和客人姓名。

关系代数：

```text
πguestNo,guestName(
  Guest ⋈
  ρQ(πguestNo,hotelNo(Booking) ÷ πhotelNo(σcity='London'(Hotel)))
  ⋈ πguestNo(Booking ⋈ Payment)
)
```

SQL：

```sql
SELECT g.guestNo, g.guestName
FROM Guest g
WHERE EXISTS (
    SELECT *
    FROM Booking b
    JOIN Payment p ON b.bookID = p.bookID
    WHERE b.guestNo = g.guestNo
)
AND NOT EXISTS (
    SELECT *
    FROM Hotel h
    WHERE h.city = 'London'
      AND NOT EXISTS (
          SELECT *
          FROM Booking b
          WHERE b.guestNo = g.guestNo
            AND b.hotelNo = h.hotelNo
      )
);
```

### （二）SQL 操作题

### （三）建表题

```sql
CREATE TABLE Booking (
    bookID CHAR(10) PRIMARY KEY,
    hotelNo CHAR(10) NOT NULL,
    roomNo CHAR(10) NOT NULL,
    guestNo CHAR(10) NOT NULL,
    dateFrom DATE NOT NULL,
    dateTo DATE NOT NULL,
    status VARCHAR(20) NOT NULL,
    FOREIGN KEY (hotelNo) REFERENCES Hotel(hotelNo),
    FOREIGN KEY (roomNo, hotelNo) REFERENCES Room(roomNo, hotelNo),
    FOREIGN KEY (guestNo) REFERENCES Guest(guestNo),
    CHECK (dateTo > dateFrom),
    CHECK (status IN ('Pending', 'Confirmed', 'Cancelled'))
);
```
