## 三、简答题

1. `NOT EXISTS`：
   - 表达“没有”：不存在一条与当前对象相关的记录。
   - 表达“所有”：使用双层 `NOT EXISTS`，即“不存在一个目标对象，使得当前对象没有完成它”。
   - 逻辑形式：要证明读者 R 借过集合 T 中所有书，可写成“不存在一本 Tom 借过的书，使得 R 没借过这本书”。

示例：

```sql
-- 没有借书的读者
WHERE NOT EXISTS (
    SELECT *
    FROM BookLoans bl
    WHERE bl.CardNo = br.CardNo
)

-- 借过 Tom 借过的所有书的读者
WHERE NOT EXISTS (
    SELECT *
    FROM TomBooks tb
    WHERE NOT EXISTS (
        SELECT *
        FROM BookLoans bl
        WHERE bl.CardNo = br.CardNo
          AND bl.BookID = tb.BookID
    )
)
```

2. 范式快速判断：

```text
1NF：每个属性值必须原子，一个格子一个值。
2NF：非主属性不能只依赖组合候选键的一部分。
3NF：非主属性不能传递依赖于候选键；等价地，对 X -> A，X 是超键或 A 是主属性。
BCNF：每个非平凡函数依赖 X -> Y 的左部 X 都必须是超键。
```

3NF 比 BCNF 略宽松：若依赖右部是主属性，3NF 可能允许该依赖，但 BCNF 仍要求左部必须是超键。

## 四、概念结构设计与逻辑结构设计

实体及属性：

```text
Book(BookID, Title, Year)
Publisher(PubID, PubName, Address)
Author(AuthorID, AuthorName)
Branch(BranchID, BranchName, Address)
Borrower(CardNo, Name, Phone, ReaderType)
```

联系：

```text
Publisher 与 Book 是 1:N，一本 Book 属于一个 Publisher。
Book 与 Author 是 M:N，联系 BookAuthor，属性 AuthorOrder。
Book 与 Branch 是 M:N，联系 BookCopies，属性 TotalCopies, AvailableCopies。
Borrower 与 Book 是 M:N，借阅联系 BookLoans，属性 DateOut, DueDate, DateReturn，并关联借阅分馆 Branch。
```

关系模式：

```text
Publisher(PubID, PubName, Address)
Book(BookID, Title, Year, PubID)
Author(AuthorID, AuthorName)
BookAuthor(BookID, AuthorID, AuthorOrder)
Branch(BranchID, BranchName, Address)
BookCopies(BookID, BranchID, TotalCopies, AvailableCopies)
Borrower(CardNo, Name, Phone, ReaderType)
BookLoans(LoanID, BookID, CardNo, BranchID, DateOut, DueDate, DateReturn)
```

主键、外键和唯一约束：

```text
Publisher: 主键 PubID
Book: 主键 BookID；外键 PubID -> Publisher(PubID)
Author: 主键 AuthorID
BookAuthor: 主键 (BookID, AuthorID)；
            外键 BookID -> Book(BookID)，AuthorID -> Author(AuthorID)；
            UNIQUE(BookID, AuthorOrder)，保证同一本书作者顺序不重复
Branch: 主键 BranchID
BookCopies: 主键 (BookID, BranchID)；
            外键 BookID -> Book(BookID)，BranchID -> Branch(BranchID)
Borrower: 主键 CardNo
BookLoans: 主键 LoanID；
           外键 BookID -> Book(BookID)，CardNo -> Borrower(CardNo)，BranchID -> Branch(BranchID)
```

“同一本实体书同一时间不能被多个读者借出”若没有实体册条码，仅靠上述模式较难精确表达；实际设计可增加 Copy(CopyID, BookID, BranchID, Status)，再让 BookLoans 引用 CopyID，并用业务规则或约束防止同一 CopyID 同期重复借出。

## 五、规范化题

1. 候选键：

```text
(CardNo, BookID, BranchID, DateOut)
```

理由：

```text
CardNo -> ReaderName, ReaderType -> MaxLoan
BookID -> Title, PubID -> PubName
BranchID -> BranchName
(CardNo, BookID, BranchID, DateOut) -> DueDate
```

因此该属性组能推出全部属性，且 `CardNo`、`BookID`、`BranchID`、`DateOut` 均不能由其他属性推出，不能省略。

2. 最高满足 1NF。

原因：

```text
主键是组合键 (CardNo, BookID, BranchID, DateOut)。
CardNo -> ReaderName, ReaderType
BookID -> Title, PubID
BranchID -> BranchName
```

这些非主属性只依赖组合主键的一部分，存在部分依赖，不满足 2NF。

同时存在传递依赖：

```text
CardNo -> ReaderType
ReaderType -> MaxLoan
BookID -> PubID
PubID -> PubName
```

因此也不满足 3NF。

3. 分解到 BCNF：

```text
Borrower(CardNo, ReaderName, ReaderType)             主键 CardNo
ReaderTypeLimit(ReaderType, MaxLoan)                 主键 ReaderType
Book(BookID, Title, PubID)                           主键 BookID
Publisher(PubID, PubName)                            主键 PubID
Branch(BranchID, BranchName)                         主键 BranchID
Borrow(CardNo, BookID, BranchID, DateOut, DueDate)   主键 (CardNo, BookID, BranchID, DateOut)
```

该分解保持题中函数依赖：每个给定依赖都完整落在某个分解后的关系中。

## 六、Programming 数据操纵题

### （一）关系代数和 SQL

1. 查询出版社名为 `Pearson` 且 2020 年以后出版的图书编号和书名。

关系代数：

```text
πBookID,Title(
  σBook.PubID=Publisher.PubID AND PubName='Pearson' AND Year>2020
  (Book ⋈ Publisher)
)
```

SQL：

```sql
SELECT b.BookID, b.Title
FROM Book b
JOIN Publisher p ON b.PubID = p.PubID
WHERE p.PubName = 'Pearson'
  AND b.Year > 2020;
```

2. 查询当前没有归还且已经逾期的借阅记录中的读者姓名、图书名和应还日期。

关系代数：

```text
πName,Title,DueDate(
  σBorrower.CardNo=BookLoans.CardNo AND Book.BookID=BookLoans.BookID
   AND DateReturn IS NULL AND DueDate<CURRENT_DATE
  (Borrower ⋈ BookLoans ⋈ Book)
)
```

SQL：

```sql
SELECT br.Name, b.Title, bl.DueDate
FROM Borrower br
JOIN BookLoans bl ON br.CardNo = bl.CardNo
JOIN Book b ON bl.BookID = b.BookID
WHERE bl.DateReturn IS NULL
  AND bl.DueDate < CURRENT_DATE;
```

3. 查询从未借过任何书，但所在系统中有馆藏记录可借的读者借书证号和姓名。

关系代数：

```text
πCardNo,Name(Borrower) - πCardNo,Name(Borrower ⋈ BookLoans)
```

若要求系统中确实存在可借馆藏，可额外与 `σAvailableCopies>0(BookCopies)` 的非空条件配合判断。

SQL：

```sql
SELECT br.CardNo, br.Name
FROM Borrower br
WHERE EXISTS (
    SELECT *
    FROM BookCopies bc
    WHERE bc.AvailableCopies > 0
)
AND NOT EXISTS (
    SELECT *
    FROM BookLoans bl
    WHERE bl.CardNo = br.CardNo
);
```

4. 查询借过 `Tom` 借过的所有图书的读者借书证号和姓名，并排除 Tom 本人。

关系代数：

```text
TomBooks = πBookID(σName='Tom' AND Borrower.CardNo=BookLoans.CardNo(Borrower ⋈ BookLoans))

πCardNo,Name(
  σName<>'Tom'(Borrower) ⋈
  ρQ(πCardNo,BookID(BookLoans) ÷ TomBooks)
)
```

SQL：

```sql
SELECT br.CardNo, br.Name
FROM Borrower br
WHERE br.Name <> 'Tom'
  AND NOT EXISTS (
      SELECT *
      FROM Borrower tom
      JOIN BookLoans tbl ON tom.CardNo = tbl.CardNo
      WHERE tom.Name = 'Tom'
        AND NOT EXISTS (
            SELECT *
            FROM BookLoans bl
            WHERE bl.CardNo = br.CardNo
              AND bl.BookID = tbl.BookID
        )
  );
```

### （二）SQL 操作题

```sql
SELECT br.CardNo,
       br.Name,
       COUNT(bl.LoanID) AS LoanCount,
       SUM(CASE WHEN bl.DateReturn IS NULL THEN 1 ELSE 0 END) AS UnreturnedCount

LEFT JOIN BookLoans bl ON br.CardNo = bl.CardNo
GROUP BY br.CardNo, br.Name;
```

```sql
CREATE VIEW overdue_view AS
SELECT br.CardNo, br.Name, b.BookID, b.Title, bl.DueDate, bh.BranchName
FROM Borrower br
JOIN BookLoans bl ON br.CardNo = bl.CardNo
JOIN Book b ON bl.BookID = b.BookID

  AND bl.DueDate < CURRENT_DATE;
```

### （三）建表题

```sql
CREATE TABLE BookLoans (
    LoanID CHAR(10) PRIMARY KEY,
    BookID CHAR(10) NOT NULL,
    CardNo CHAR(10) NOT NULL,
    BranchID CHAR(10) NOT NULL,
    DateOut DATE NOT NULL,
    DueDate DATE NOT NULL,
    DateReturn DATE,
    FOREIGN KEY (BookID) REFERENCES Book(BookID),
    FOREIGN KEY (CardNo) REFERENCES Borrower(CardNo),
    FOREIGN KEY (BranchID) REFERENCES Branch(BranchID),
    CHECK (DueDate > DateOut),
    CHECK (DateReturn IS NULL OR DateReturn >= DateOut)
);
```
