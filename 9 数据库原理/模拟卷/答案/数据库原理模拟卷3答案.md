## 三、简答题

1. `NOT EXISTS`：
   - 表达“没有”：不存在一条与当前对象相关的记录。
   - 表达“所有”：双层 `NOT EXISTS`，即“不存在一个目标，使得当前对象没有完成它”。

示例：

```sql
-- 没有选课的学生
WHERE NOT EXISTS (
    SELECT *
    FROM enrol e
    WHERE e.Sno = s.Sno
)

-- 选修了所有课程的学生
WHERE NOT EXISTS (
    SELECT *
    FROM course c
    WHERE NOT EXISTS (
        SELECT *
        FROM enrol e
        WHERE e.Sno = s.Sno
          AND e.Cno = c.Cno
    )
)
```

2. 范式快速判断：

```text
1NF：每个属性值必须原子，一个格子一个值。
2NF：非主属性不能只依赖组合主键的一部分。
3NF：非主属性不能传递依赖于主键。
BCNF：每个函数依赖左边都必须是候选键。
```

## 四、概念结构设计与逻辑结构设计

实体及属性：

```text
Book(BookID, Title, Publisher)
Author(AuthorID, AuthorName)
Branch(BranchID, BranchName, Address)
Borrower(CardNo, Name, Phone)
```

联系：

```text
Book 与 Author 是 M:N，联系 BookAuthor，属性 AuthorOrder。
Book 与 Branch 是 M:N，联系 BookCopies，属性 NCopies。
Borrower 与 Book 是 M:N，联系 BookLoans，属性 DateOut, DueDate, DateReturn。
```

关系模式：

```text
Book(BookID, Title, Publisher)
Author(AuthorID, AuthorName)
BookAuthor(BookID, AuthorID, AuthorOrder)
Branch(BranchID, BranchName, Address)
BookCopies(BookID, BranchID, NCopies)
Borrower(CardNo, Name, Phone)
BookLoans(BookID, CardNo, DateOut, DueDate, DateReturn)
```

主键和外键：

```text
Book: 主键 BookID
Author: 主键 AuthorID
BookAuthor: 主键 (BookID, AuthorID)，外键 BookID -> Book，AuthorID -> Author
Branch: 主键 BranchID
BookCopies: 主键 (BookID, BranchID)，外键 BookID -> Book，BranchID -> Branch
Borrower: 主键 CardNo
BookLoans: 主键 (BookID, CardNo, DateOut)，外键 BookID -> Book，CardNo -> Borrower
```

## 五、规范化题

1. 候选键：

```text
(CardNo, BookID, DateOut)
```

2. 最高满足 1NF。

原因：

```text
主键是组合键 (CardNo, BookID, DateOut)。
CardNo -> ReaderName, ReaderPhone，BookID -> Title, PubID。
这些非主属性只依赖组合主键的一部分，存在部分依赖，不满足 2NF。
```

同时存在传递依赖：

```text
BookID -> PubID
PubID -> PubName
```

3. 分解到 BCNF：

```text
Borrower(CardNo, ReaderName, ReaderPhone)       主键 CardNo
Book(BookID, Title, PubID)                      主键 BookID
Publisher(PubID, PubName)                       主键 PubID
BookLoan(CardNo, BookID, DateOut, DueDate)      主键 (CardNo, BookID, DateOut)
```

## 六、Programming 数据操纵题

### （一）关系代数和 SQL

1. 查询出版社名为 `Pearson` 的图书编号和书名。

关系代数：

```text
πBookID,Title(σBook.PubID=Publisher.PubID AND PubName='Pearson'(Book ⋈ Publisher))
```

SQL：

```sql
SELECT b.BookID, b.Title
FROM Book b
JOIN Publisher p ON b.PubID = p.PubID
WHERE p.PubName = 'Pearson';
```

2. 查询当前没有归还的借阅记录中的读者姓名和图书名。

关系代数：

```text
πName,Title(σBorrower.CardNo=BookLoans.CardNo AND Book.BookID=BookLoans.BookID AND DateReturn IS NULL
           (Borrower ⋈ BookLoans ⋈ Book))
```

SQL：

```sql
SELECT br.Name, b.Title
FROM Borrower br
JOIN BookLoans bl ON br.CardNo = bl.CardNo
JOIN Book b ON bl.BookID = b.BookID
WHERE bl.DateReturn IS NULL;
```

3. 查询没有借过任何书的读者借书证号和姓名。

关系代数：

```text
πCardNo,Name(Borrower) - πCardNo,Name(σBorrower.CardNo=BookLoans.CardNo(Borrower ⋈ BookLoans))
```

SQL：

```sql
SELECT br.CardNo, br.Name
FROM Borrower br
WHERE NOT EXISTS (
    SELECT *
    FROM BookLoans bl
    WHERE bl.CardNo = br.CardNo
);
```

4. 查询借过 `Tom` 借过的所有图书的读者借书证号和姓名。

关系代数：

```text
πCardNo,Name(σQ.CardNo=Borrower.CardNo
            (ρQ(πCardNo,BookID(BookLoans) ÷
                πBookID(σName='Tom' AND Borrower.CardNo=BookLoans.CardNo(Borrower ⋈ BookLoans))) ⋈ Borrower))
```

SQL：

```sql
SELECT br.CardNo, br.Name
FROM Borrower br
WHERE NOT EXISTS (
    SELECT *
    FROM Borrower tom
    JOIN BookLoans tbl ON tom.CardNo = tbl.CardNo
    WHERE tom.Name = 'Tom'
      AND NOT EXISTS (
          SELECT *
          FROM BookLoans bl
          WHERE bl.CardNo = br.CardNo
            AND bl.BookID = tbl.BookID
      )
);
```

### （二）SQL 操作题

1.

```sql
SELECT br.CardNo, br.Name, COUNT(*) AS LoanCount
FROM Borrower br
JOIN BookLoans bl ON br.CardNo = bl.CardNo
GROUP BY br.CardNo, br.Name;
```

如果要包含从未借书的读者，可写：

```sql
SELECT br.CardNo, br.Name, COUNT(bl.BookID) AS LoanCount
FROM Borrower br
LEFT JOIN BookLoans bl ON br.CardNo = bl.CardNo
GROUP BY br.CardNo, br.Name;
```

JOIN Book b ON bl.BookID = b.BookID

### （三）建表题

```sql
CREATE TABLE BookLoans (
    BookID CHAR(10) NOT NULL,
    CardNo CHAR(10) NOT NULL,
    DateOut DATE NOT NULL,
    DueDate DATE NOT NULL,
    DateReturn DATE,
    PRIMARY KEY (BookID, CardNo, DateOut),
    FOREIGN KEY (BookID) REFERENCES Book(BookID),
    FOREIGN KEY (CardNo) REFERENCES Borrower(CardNo),
    CHECK (DueDate > DateOut)
);
```
