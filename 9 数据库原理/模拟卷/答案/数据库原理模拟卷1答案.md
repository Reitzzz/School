## 三、简答题

1. 候选键、主键、外键：
   - 候选键：能唯一标识元组且没有多余属性的最小属性集。
   - 主键：从候选键中选出的主要标识，一个关系通常指定一个主键。
   - 外键：本关系中的属性或属性组，用来引用另一个关系或本关系中的主键/候选键。
   - 外键不一定只能引用主键，也可以引用被引用关系中具有唯一性的候选键或唯一约束属性组。

2. `WHERE` 和 `HAVING`：
   - `WHERE` 在分组前筛选行，不能直接使用聚合函数作为筛选条件。
   - `HAVING` 在分组后筛选分组结果，常用于 `AVG`、`COUNT` 等聚合条件。
   - “平均成绩大于 80 且选课人数不少于 3”应写在 `HAVING` 中：`HAVING AVG(Mark)>80 AND COUNT(*)>=3`。

## 四、概念结构设计与逻辑结构设计

实体及属性：

```text
Department(DeptNo, DeptName, Office)
Student(Sno, Sname, Gender)
Course(Cno, Cname, Credit)
Lecturer(Tno, Tname, Title)
```

联系及约束：

```text
Department 与 Student 是 1:N，Student 全参与。
Department 与 Course 是 1:N，Course 由某院系开设。
Department 与 Lecturer 是 1:N，Lecturer 属于某院系。
Student 与 Course 是 M:N，联系 Enrol，属性 Mark, Semester。
Lecturer 与 Course 是 M:N，联系 Contact，属性 Hours, Semester。
同一院系内课程名不能重复。
同一学生同一学期不能重复选同一门课。
```

关系模式：

```text
Department(DeptNo, DeptName, Office)
Student(Sno, Sname, Gender, DeptNo)
Course(Cno, Cname, Credit, DeptNo)
Lecturer(Tno, Tname, Title, DeptNo)
Enrol(Sno, Cno, Semester, Mark)
Contact(Tno, Cno, Semester, Hours)
```

主键、外键和唯一约束：

```text
Department: 主键 DeptNo；候选键 DeptName（若题设认为院系名唯一）
Student: 主键 Sno；外键 DeptNo -> Department(DeptNo)
Course: 主键 Cno；外键 DeptNo -> Department(DeptNo)；UNIQUE(DeptNo, Cname)
Lecturer: 主键 Tno；外键 DeptNo -> Department(DeptNo)
Enrol: 主键 (Sno, Cno, Semester)；外键 Sno -> Student(Sno)，Cno -> Course(Cno)
Contact: 主键 (Tno, Cno, Semester)；外键 Tno -> Lecturer(Tno)，Cno -> Course(Cno)
```

## 五、规范化题

1. 候选键：

```text
(Sno, Cno, Semester)
```

属性闭包：

```text
(Sno, Cno, Semester)+
= Sno, Cno, Semester
  + Sname, Sdept          由 Sno -> Sname, Sdept
  + Dean                  由 Sdept -> Dean
  + Cname, Credit         由 Cno -> Cname, Credit
  + Mark                  由 (Sno, Cno, Semester) -> Mark
= 全部属性
```

`Sno`、`Cno`、`Semester` 均不能从其他依赖推出，故三者都不可省略。

2. 最高满足 1NF。

原因：

```text
主键是组合键 (Sno, Cno, Semester)。
Sno -> Sname, Sdept，Cno -> Cname, Credit。
这些非主属性只依赖组合主键的一部分，存在部分依赖，不满足 2NF。
```

同时存在传递依赖：

```text
Sno -> Sdept
Sdept -> Dean
```

因此也不满足 3NF。

3. 分解到 BCNF：

```text
Student(Sno, Sname, Sdept)                  主键 Sno
Department(Sdept, Dean)                     主键 Sdept
Course(Cno, Cname, Credit)                  主键 Cno
Enrol(Sno, Cno, Semester, Mark)             主键 (Sno, Cno, Semester)
```

该分解保持给定函数依赖：每个给定依赖都完整落在某个分解后的关系中。

## 六、Programming 数据操纵题

### （一）关系代数和 SQL

1. 查询 CS 系女生的学号和姓名，且该学生至少选修过一门本系开设的课程。

关系代数：

```text
πSno,Sname(
  σstudent.Sno=enrol.Sno AND enrol.Cno=course.Cno
   AND student.Sdept='CS' AND Gender='Female' AND course.Dept='CS'
  (student ⋈ enrol ⋈ course)
)
```

SQL：

```sql
SELECT DISTINCT s.Sno, s.Sname
FROM student s
JOIN enrol e ON s.Sno = e.Sno
JOIN course c ON e.Cno = c.Cno
WHERE s.Sdept = 'CS'
  AND s.Gender = 'Female'
  AND c.Dept = 'CS';
```

2. 查询选修 `Database` 且最近一次该课程成绩不低于 85 分的学生学号、姓名和成绩。

关系代数：

```text
Latest(Sno, Cno, Semester) =
πSno,Cno,Semester(enrol) - πe1.Sno,e1.Cno,e1.Semester(
  σe1.Sno=e2.Sno AND e1.Cno=e2.Cno AND e1.Semester<e2.Semester
  (ρe1(enrol) × ρe2(enrol))
)

πSno,Sname,Mark(
  σstudent.Sno=enrol.Sno AND enrol.Cno=course.Cno
   AND enrol.Sno=Latest.Sno AND enrol.Cno=Latest.Cno AND enrol.Semester=Latest.Semester
   AND Cname='Database' AND Mark>=85
  (student ⋈ enrol ⋈ course ⋈ Latest)
)
```

SQL：

```sql
SELECT s.Sno, s.Sname, e.Mark
FROM student s
JOIN enrol e ON s.Sno = e.Sno
JOIN course c ON e.Cno = c.Cno
WHERE c.Cname = 'Database'
  AND e.Semester = (
      SELECT MAX(e2.Semester)
      FROM enrol e2
      WHERE e2.Sno = e.Sno
        AND e2.Cno = e.Cno
  )
  AND e.Mark >= 85;
```

3. 查询从未被任何学生选修过，但至少有教师讲授安排的课程号、课程名。

关系代数：

```text
πCno,Cname(course ⋈ contact) - πCno,Cname(course ⋈ enrol)
```

SQL：

```sql
SELECT DISTINCT c.Cno, c.Cname
FROM course c
WHERE EXISTS (
    SELECT *
    FROM contact ct
    WHERE ct.Cno = c.Cno
)
AND NOT EXISTS (
    SELECT *
    FROM enrol e
    WHERE e.Cno = c.Cno
);
```

4. 查询在 `2025-Fall` 学期选修了所有 3 学分课程的学生学号、姓名。

关系代数：

```text
πSno,Sname(
  student ⋈
  ρQ(πSno,Cno(σSemester='2025-Fall'(enrol)) ÷ πCno(σCredit=3(course)))
)
```

SQL：

```sql
SELECT s.Sno, s.Sname
FROM student s
WHERE NOT EXISTS (
    SELECT *
    FROM course c
    WHERE c.Credit = 3
      AND NOT EXISTS (
          SELECT *
          FROM enrol e
          WHERE e.Sno = s.Sno
            AND e.Cno = c.Cno
            AND e.Semester = '2025-Fall'
      )
);
```

### （二）SQL 操作题

1.

```sql
SELECT c.Cno, c.Cname, AVG(e.Mark) AS AvgMark, COUNT(*) AS EnrolCount
FROM course c
JOIN enrol e ON c.Cno = e.Cno
GROUP BY c.Cno, c.Cname
HAVING COUNT(*) >= 3
   AND AVG(e.Mark) > 80;
```

2.

```sql
INSERT INTO student(Sno, Sname, Sdept, Gender)
VALUES ('S09', 'Wang Lin', 'CS', 'Female');
```

若 `S09` 已存在，数据库应通过 `student` 表主键约束拒绝插入。

3.

```sql
UPDATE enrol
SET Mark = CASE
             WHEN Mark + 5 > 100 THEN 100
             ELSE Mark + 5
           END
WHERE Semester = '2025-Fall'
  AND Mark < 95
  AND Cno IN (
      SELECT Cno
      FROM course
      WHERE Cname = 'Database'
  );
```

4.

```sql
CREATE VIEW cs_student_summary AS
SELECT s.Sno,
       s.Sname,
       COUNT(e.Cno) AS CourseCount,
       AVG(e.Mark) AS AvgMark
FROM student s
LEFT JOIN enrol e ON s.Sno = e.Sno
WHERE s.Sdept = 'CS'
GROUP BY s.Sno, s.Sname;
```

### （三）建表题

```sql
CREATE TABLE project (
    Pno CHAR(10) PRIMARY KEY,
    Pname VARCHAR(50) NOT NULL,
    Budget DECIMAL(10, 2) NOT NULL,
    Leader CHAR(10),
    StartDate DATE NOT NULL,
    EndDate DATE,
    CHECK (Budget > 0),
```
