## 三、简答题

1. 候选键、主键、外键：
   - 候选键：能唯一标识元组且没有多余属性的最小属性集。
   - 主键：从候选键中选出的主要标识。
   - 外键：本关系中的属性，引用另一个关系或本关系的主键/候选键，用于维护参照完整性。

2. `WHERE` 和 `HAVING`：
   - `WHERE` 在分组前筛选单行记录，例如 `WHERE Gender='Female'`。
   - `HAVING` 在分组后筛选分组结果，例如 `HAVING AVG(Mark)>80`。

## 四、概念结构设计与逻辑结构设计

实体及属性：

```text
Student(Sno, Sname, Gender, Sdept)
Course(Cno, Cname, Credit)
Lecturer(Tno, Tname, Title)
```

联系：

```text
Student 与 Course 是 M:N，联系 Enrol，属性 Mark。
Lecturer 与 Course 是 M:N，联系 Contact，属性 Hours。
```

关系模式：

```text
Student(Sno, Sname, Gender, Sdept)
Course(Cno, Cname, Credit)
Lecturer(Tno, Tname, Title)
Enrol(Sno, Cno, Mark)
Contact(Tno, Cno, Hours)
```

主键和外键：

```text
Student: 主键 Sno
Course: 主键 Cno
Lecturer: 主键 Tno
Enrol: 主键 (Sno, Cno)，外键 Sno -> Student(Sno)，Cno -> Course(Cno)
Contact: 主键 (Tno, Cno)，外键 Tno -> Lecturer(Tno)，Cno -> Course(Cno)
```

## 五、规范化题

1. 候选键：

```text
(Sno, Cno)
```

因为：

```text
Sno -> Sname, Sdept
Sdept -> Dean
Cno -> Cname, Credit
(Sno, Cno) -> Mark
```

所以 `(Sno, Cno)` 可以推出全部属性。

2. 最高满足 1NF。

原因：

```text
主键是组合键 (Sno, Cno)。
Sno -> Sname, Sdept，Cno -> Cname, Credit。
这些非主属性只依赖组合主键的一部分，存在部分依赖，不满足 2NF。
```

同时还有：

```text
Sno -> Sdept
Sdept -> Dean
```

存在传递依赖。

3. 分解到 BCNF：

```text
Student(Sno, Sname, Sdept)          主键 Sno
Department(Sdept, Dean)             主键 Sdept
Course(Cno, Cname, Credit)          主键 Cno
Enrol(Sno, Cno, Mark)               主键 (Sno, Cno)
```

## 六、Programming 数据操纵题

### （一）关系代数和 SQL

1. 查询 CS 系女生的学号和姓名。

关系代数：

```text
πSno,Sname(σSdept='CS' AND Gender='Female'(student))
```

SQL：

```sql
SELECT Sno, Sname
FROM student
WHERE Sdept = 'CS' AND Gender = 'Female';
```

2. 查询选修 `Database` 且成绩不低于 85 分的学生学号、姓名。

关系代数：

```text
πSno,Sname(σstudent.Sno=enrol.Sno AND enrol.Cno=course.Cno AND Cname='Database' AND Mark>=85
          (student ⋈ enrol ⋈ course))
```

SQL：

```sql
SELECT s.Sno, s.Sname
FROM student s
JOIN enrol e ON s.Sno = e.Sno
JOIN course c ON e.Cno = c.Cno
WHERE c.Cname = 'Database' AND e.Mark >= 85;
```

3. 查询没有任何学生选修的课程号、课程名。

关系代数：

```text
πCno,Cname(course) - πCno,Cname(σcourse.Cno=enrol.Cno(course ⋈ enrol))
```

SQL：

```sql
SELECT c.Cno, c.Cname
FROM course c
WHERE NOT EXISTS (
    SELECT *
    FROM enrol e
    WHERE e.Cno = c.Cno
);
```

4. 查询选修了所有 3 学分课程的学生学号、姓名。

关系代数：

```text
πSno,Sname(σQ.Sno=student.Sno
          (ρQ(πSno,Cno(enrol) ÷ πCno(σCredit=3(course))) ⋈ student))
```

SQL：

```sql
SELECT s.Sno, s.Sname
FROM student s
WHERE NOT EXISTS (
    SELECT *
    FROM course c
    WHERE c.Credit = 3
      AND NOT EXISTS (
          SELECT *
          FROM enrol e
          WHERE e.Sno = s.Sno
            AND e.Cno = c.Cno
      )
);
```

### （二）SQL 操作题

1.

```sql
SELECT c.Cno, c.Cname, AVG(e.Mark) AS AvgMark
FROM course c
JOIN enrol e ON c.Cno = e.Cno
GROUP BY c.Cno, c.Cname
HAVING AVG(e.Mark) > 80;
```

UPDATE enrol
