## 1 第一阶段：准备游乐场与底座（数据定义语言 DDL）

首先，我们需要在数据库中开辟一块场地，并规定好这块底板的格子形状。

### 1.1 积木1：创建表(CREATE TABLE)
搭建一块名为“学生成绩表”的底板，规定学号是主键(PRIMARY KEY)，不能为空(NOT NULL)。

```sql
CREATE TABLE 学生成绩表 (
    学号 CHAR(10) NOT NULL,
    姓名 CHAR(20),
    性别 CHAR(2),
    所在系 CHAR(30),
    成绩 INT,
    PRIMARY KEY (学号)
);
```

### 1.2 积木2：创建索引(CREATE INDEX)
为了以后找特定系别的学生能快一点，我们在“所在系”这个维度上贴个标签（建立索引）。

```sql
CREATE INDEX 院系索引 ON 学生成绩表(所在系);
```

## 2 第二阶段：往底板上放积木（数据操纵语言 DML - 更新）

底板建好了，现在按规则放上具体的积木（数据）。

### 2.1 积木1：插入数据(INSERT)
放上一块张三的积木。

```sql
INSERT INTO 学生成绩表 (学号, 姓名, 性别, 所在系, 成绩)
VALUES ('001', '张三', '男', '计算机科学(CS)', 85);
```

### 2.2 积木2：更新数据(UPDATE)
发现张三的成绩登记错了，我们把他的成绩积木换成90分。

```sql
UPDATE 学生成绩表
SET 成绩 = 90
WHERE 学号 = '001';
```

### 2.3 积木3：删除数据(DELETE)
如果张三退学了，我们需要把他的积木拿走。（为了后续演示，我们假设不执行这句代码，把积木留着）。

```sql
DELETE FROM 学生成绩表
WHERE 学号 = '001';
```

## 3 第三阶段：核心拼装，一层层找积木（数据操纵语言 DML - 查询）

这是最精彩的拼装过程。我们的最终目标是：**“找出所有男生平均成绩大于80分的院系，并按平均成绩从高到低排列展示”**。我们将用同一个语句底子，一层层把子句积木加上去。

### 3.1 基础底板：去哪个底板找？(FROM)
首先，锁定我们要翻找的底板。

```sql
SELECT *
FROM 学生成绩表;
```
*(目前状态：把学生成绩表上所有的积木全拿出来了)*

### 3.2 第一层拼装：按什么条件挑单块积木？(WHERE)
我们只关心男生，把女生的积木过滤掉。

```sql
SELECT *
FROM 学生成绩表
WHERE 性别 = '男';
```
*(目前状态：桌子上只剩男生的积木了)*

### 3.3 第二层拼装：怎么把单块积木合成堆？(GROUP BY)
将挑出来的男生积木，按照他们所在的院系分开，堆成几个小堆。

```sql
SELECT 所在系
FROM 学生成绩表
WHERE 性别 = '男'
GROUP BY 所在系;
```
*(目前状态：男生的积木被分成了“计算机科学(CS)堆”、“信息系统(IS)堆”等)*

### 3.4 第三层拼装：按什么条件挑一堆的积木？(HAVING)
我们不是要所有的院系堆，我们只要那些整体平均分超过80分的堆。不够优秀的堆整体拿走。

```sql
SELECT 所在系
FROM 学生成绩表
WHERE 性别 = '男'
GROUP BY 所在系
HAVING AVG(成绩) > 80;
```
*(目前状态：桌子上只留下了平均分优秀的院系堆)*

### 3.5 第四层拼装：挑出哪些部分展示？(SELECT)
除了展示院系名称，我还要把计算出来的平均分展示出来，并给它起个别名(AS)。

```sql
SELECT 所在系, AVG(成绩) AS 平均分
FROM 学生成绩表
WHERE 性别 = '男'
GROUP BY 所在系
HAVING AVG(成绩) > 80;
```
*(目前状态：积木已经加工成了我们想要的样子，左边是院系，右边是平均分)*

### 3.6 第五层拼装：按什么顺序排好交差？(ORDER BY)
最后，把找出来的这些院系，按照平均分从高到低(DESC)整齐排列。

```sql
SELECT 所在系, AVG(成绩) AS 平均分
FROM 学生成绩表
WHERE 性别 = '男'
GROUP BY 所在系
HAVING AVG(成绩) > 80
ORDER BY 平均分 DESC;
```
*(完美组装：一个包含五种不同功能积木的复杂查询语句完成了！)*

## 4 第四阶段：高级扩展拼装

如果我们需要的信息不在一块底板上，就需要使用高级积木。

### 4.1 积木1：多表连接(JOIN)
假设我们还有一块“奖学金表”，我们想把张三的成绩和他的奖学金信息拼在一起看。

```sql
SELECT 学生成绩表.姓名, 学生成绩表.成绩, 奖学金表.奖金金额
FROM 学生成绩表 JOIN 奖学金表 ON 学生成绩表.学号 = 奖学金表.学号;
```

### 4.2 积木2：子查询(Subquery)
我想找出成绩大于全校平均分的学生。全校平均分需要先算出来作为一个内部积木，再套入外部查询。

```sql
SELECT 姓名, 成绩
FROM 学生成绩表
WHERE 成绩 > (SELECT AVG(成绩) FROM 学生成绩表);
```

## 5 第五阶段：保存图纸与控制游乐场

### 5.1 积木1：创建视图(CREATE VIEW)
刚才第三阶段拼出的那个复杂的“优秀男生平均分”语句太长了，我们把它拍张照，保存成一张名为“优秀男系别视图”的快捷图纸。

```sql
CREATE VIEW 优秀男系别视图
AS SELECT 所在系, AVG(成绩) AS 平均分
   FROM 学生成绩表
   WHERE 性别 = '男'
   GROUP BY 所在系
   HAVING AVG(成绩) > 80;
```
*(以后想看这个结果，只需简单地写：`SELECT * FROM 优秀男系别视图;`)*

### 5.2 积木2：授予权限(GRANT)
作为系统管理员，我把查看这张“优秀男系别视图”图纸的权限(SELECT)，交给“教务处老师”这个用户。

```sql
GRANT SELECT
ON 优秀男系别视图
TO 教务处老师;
```
