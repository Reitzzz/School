# 数据库原理期末试卷结构及复习提纲

总分：100分

## 1. 单选题 (10题 * 1分 = 10分)
* **考查范围**：Module 1, 2, 3, 5 (ER), 8, 9, 10 (Normalization) 的主要知识点。

## 2. 计算题 Calculation of relational algebra (5题 * 2分 = 10分)
* **考查内容**：关系代数计算。
* **具体要求**：根据选择(σ)、投影(π)、连接(⋈)、除(÷)、并(∪)、交(∩)、差(-)组成的表达式，计算结果并用**表格显示**。

## 3. 简答题 (2题 * 4分 = 8分)
* **考查范围**：Module 1, 2, 3 的主要知识点。

## 4. 概念结构设计与逻辑结构设计 Conceptual and logical database design (20分)
* **考查范围**：Module 5, 8, 9 的知识点。
* **具体要求**：
  * 画出 E-R 图 (Draw an E-R diagram)。
  * 将 E-R 图映射为关系模式 (Map the ER diagram into relation schemas)，并标出所有的主键 (primary keys)、候选键 (alternative keys, 如果有) 和外键 (foreign keys, 如果有)。

## 5. 规范化 (12分)
* **考查范围**：Module 10 的主要知识点。
* **具体要求**：
  * 给定一个关系（一张大表），识别出主键、所有的函数依赖以及它所属的范式 (Identify the primary key, all the functional dependencies, and normal form)。
  * 进行规范化，直到所有关系都达到 **BCNF**，列出所有最终的关系，并标出每个关系的主键。

## 6. Programming 数据操纵 (40分)
* **背景**：给出属于同一个数据库的几张表 (Given tables form part of a database)。
* **具体题型**：
  1. **Relation Algebra and SQL (4题 * 6分 = 24分)**
     * 涉及 Module 2, 3 的主要知识点。
     * 包括集合运算 (Set Operations), 选择 (σ), 投影 (π), 连接 (join), 除法 (Division) 等关系代数操作及其 SQL 表达式。
  2. **SQL 数据操纵 (4题 * 3分 = 12分)**
     * 涉及 Module 3 的主要知识点。
     * 主要考查：`SELECT`, `INSERT`, `DELETE`, `UPDATE`, `CREATE VIEW`。
  3. **SQL 数据定义 (4分)**
     * 考查建表：`CREATE TABLE`。
     * 需要包含约束规则，如主键 (`PRIMARY KEY`)、检查约束 (`CHECK`) 等。
