**三、 简答题（每题 5 分，答出核心要点即给分）**
1. CISC 指令系统复杂、指令长短不一、寻址方式多；RISC 指令系统简单、只保留常用指令、指令长度固定、执行效率高。（5分）
2. R13是堆栈指针(SP)，用于指向栈顶；R14是链接寄存器(LR)，用于存放子程序的返回地址；R15是程序计数器(PC)，指向当前正在取指的指令地址。（5分，漏一项扣2分）
3. 接口是位于主机与外设之间的硬件电路（及固件），用于协调二者的数据传送（2分）；端口是接口电路中可被CPU直接访问的寄存器，用于存放数据、控制命令或状态信息（2分）。端口是接口的一部分（1分）。
4. 中断处理的 5 个阶段：中断请求、中断判优（排队）、中断响应、中断服务处理、中断返回。（5分，每点1分）
5. 三大组成部分：(1) 时基单元：负责产生基本定时时钟并计数；(2) 输入捕获单元：负责测量外部输入信号的频率或脉宽；(3) 输出比较单元：负责控制输出波形（如 PWM 信号）。（5分）
6. 量化是将连续的模拟电压范围划分成离散的电平阶梯，并将其归入对应的阶梯值中（3分）；编码是将量化后的电平阶梯数值用二进制（或其他数字编码）表示出来（2分）。
7. 数据传输方式包括：无条件传送、查询传送、中断传送、DMA传送（4分）。DMA方式不需要 CPU 的运算资源介入（1分）。

**四、 计算题（每题 5 分）**

// (1) 初始化配置程序 (15分)
void EXTI0_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    EXTI_InitTypeDef EXTI_InitStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    // 1. 开启时钟：GPIOA, GPIOB, 以及 AFIO 时钟 (3分)
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOB | RCC_APB2Periph_AFIO, ENABLE);

    // 2. 配置 PB5 为推挽输出 (3分)
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    // 3. 配置 PA0 为上拉/下拉或浮空输入 (3分)
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU; // 假设上拉输入
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // 4. 配置 EXTI 线路映射及初始化 (3分)
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0);
    EXTI_InitStructure.EXTI_Line = EXTI_Line0;
    EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling; // 下降沿触发
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_Init(&EXTI_InitStructure);

    // 5. 配置 NVIC (3分)
    NVIC_InitStructure.NVIC_IRQChannel = EXTI0_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0x00;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0x00;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

// (2) 中断服务程序 (10分)
void EXTI0_IRQHandler(void)
{
    // 1. 判断是否产生 EXTI0 中断 (3分)
    if(EXTI_GetITStatus(EXTI_Line0) != RESET) 
    {
        // 2. 核心逻辑：翻转 PB5 (4分，使用库函数或ODR寄存器异或均可)
        GPIOB->ODR ^= GPIO_Pin_5; 
        
        // 3. 清除中断标志位，防止死循环 (3分)
        EXTI_ClearITPendingBit(EXTI_Line0);
    }
}

**三、 简答题（每题 5 分）**
1. 指令执行的基本过程包括三个阶段：取指（Fetch）、译码（Decode）、执行（Execute）。（5分）
2. 4 个主动驱动单元包括：(1) Cortex-M3 内核的 DCode 总线；(2) System 总线；(3) DMA1 总线；(4) DMA2 总线。（5分，答出 4 个即可满分）
3. 推挽输出可以输出强高电平和强低电平，驱动能力强（2分）；开漏输出只能输出低电平，输出高电平时呈高阻态，必须依靠外部上拉电阻才能输出高电平，支持线与连接（3分）。
4. 中断嵌套指 CPU 在响应某中断并处理期间，又响应了优先级更高的中断请求，转去执行高优先级中断，执行完后再返回执行原来的中断（3分）。排队原则：抢占优先级高的先执行；抢占优先级相同，子优先级高的先执行；两者均相同，查硬件中断向量表排位（2分）。
5. 定时原理：$CK\_INT$ 经过 $PSC$ 预分频后，得到一个较低的计数时钟给 $CNT$ 计数器（2分）。$CNT$ 每来一个脉冲加 1，当 $CNT$ 的值累加到与 $ARR$ 寄存器设置的溢出值相等时，产生定时更新事件并清零重计，从而实现周期性定时（3分）。
6. 分辨率：指 D/A 转换器能够区分的最小模拟电压变化量，通常用二进制位数表示（2.5分）。转换误差：指实际输出模拟电压与理论输出电压之间的偏差（2.5分）。
7. Cortex-M3 使用的是“向下生长的满栈”结构（2分）。因此执行 PUSH（入栈）操作时，堆栈指针 SP 的值会减小，向低地址方向移动（3分）。

**四、 计算题（每题 5 分）**
1.
**公式**：$PWM频率 = \frac{CK\_INT}{(PSC + 1) \times (ARR + 1)}$，占空比 $= \frac{CCR}{ARR + 1}$ （2分）
**代入过程**：$1000 = \frac{72000000}{(71 + 1) \times (ARR + 1)} \implies ARR + 1 = 1000$ （1分）
占空比 $30\% = \frac{CCR}{1000}$ （1分）
**结果**：$ARR = 999$，$CCR = 300$ （1分）
2.
**公式**：$D = \frac{V_{in}}{V_{ref}} \times 2^n$ （2分）
**代入过程**：$D = \frac{1.65}{3.3} \times 2^{10} = 0.5 \times 1024$ （2分）
**结果**：$D = 512$ （1分）

**三、 简答题（每题 5 分）**
1. 由 CPU（中央处理器）、存储器（RAM/ROM）、I/O 接口、外围设备以及系统总线组成（3分）。核心部件是 CPU（2分）。
2. AHB 高速总线主要用于连接 CPU 极高频率进行交互的模块，如总线矩阵、DMA、SRAM 等（2.5分）；APB 低速总线则挂载普通外设，如串口 UART、通用定时器 TIM、I2C 接口等（2.5分）。
3. 作用是将不确定的信号（悬空状态）通过一个电阻钳位在高电平（上拉）或低电平（下拉）（3分），从而提高引脚的抗干扰能力并提供默认状态电平（2分）。
4. 中断源是指引起微处理器产生中断请求的事件或设备（2分）。常见中断源包括：外部硬件中断（如按键触发）、定时器溢出中断、串口接收中断、ADC转换完成中断等（答出3种得3分）。
5. 三种基本方法：(1) 软件循环延时（空循环操作）；(2) 硬件定时器定时（利用 MCU 内部定时器）；(3) 操作系统提供的系统节拍延时阻塞（5分）。
6. 基本原理：将定时器捕获通道配置为上升沿捕获，记录连续两次上升沿计数值的时间差即可算出周期（频率）；同周期内配置另一通道为下降沿捕获，记录上升沿到下降沿的计数值差，即可得到高电平脉宽。高电平时间除以总周期即为占空比。（5分，言之有理即可满分）
7. 作用：将 MCU 处理后的离散数字量转换为连续变化的模拟电压/电流信号输出，以便控制需要模拟量的外部设备（3分）。应用场景：音频播放、电机调速、模拟波形发生器等（2分）。

**四、 计算题（每题 5 分）**
1.
周期计数值：$T_{cnt} = 20000$，每个时钟 $1\mu s$，周期 $T = 20000\mu s = 0.02s$。
**频率**：$f = \frac{1}{T} = \frac{1}{0.02} = 50Hz$ （2分）
高电平计数值：$T_{high} = 4000$。
**占空比**：$\frac{T_{high}}{T_{cnt}} = \frac{4000}{20000} = 20\%$ （3分）
2.
**公式**：$D = \frac{V_{out}}{V_{ref}} \times 2^n$ （2分）
**代入过程**：$D = \frac{2.5}{5.0} \times 2^8 = 0.5 \times 256$ （2分）
**结果**：$D = 128$ （1分）
