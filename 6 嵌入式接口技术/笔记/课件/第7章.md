# 第7章 DA与AD转换技术 复习笔记

## 一、 ADC、DAC的概念
- **ADC（A/D转换器，模数转换器）**：把连续的模拟电压/电流转换成离散的数字量，便于计算机采集、存储和处理。
- **DAC（D/A转换器，数模转换器）**：把数字量转换成模拟电压/电流，便于驱动执行机构、产生波形或输出控制量。
- **模拟量到数字量流程**：传感器输出模拟信号，经调理、采样保持、ADC转换后进入微处理器。
- **数字量到模拟量流程**：微处理器输出数字量，经DAC转换、功率放大后驱动执行机构。

## 二、 DA转换器的主要性能指标
- **分辨率**：输入数字量最低有效位LSB变化1时，输出模拟量变化的最小值。n位DAC有`2^n`个离散等级。
- **转换精度**：实际输出值与理论输出值之间的最大偏差。
- **建立时间/转换时间**：输入数字量变化后，输出模拟量稳定到规定误差范围内所需时间。
- **温度系数**：环境温度变化导致输出特性变化的程度。
- **非线性误差**：实际转换曲线偏离理想直线的最大误差。

## 三、 DAC量程、分辨率与数字量到模拟电压计算
设DAC参考电压或量程为`Vref`，分辨率为n位，输入数字量为`D`。

常用理论计算：
```text
Vout = D / (2^n - 1) * Vref
```

有些教材按量化单位近似为：
```text
q = Vref / 2^n
Vout ≈ D * q
```

考试时优先按题目给定公式；若未说明，常用满量程对应最大数字量`2^n - 1`。

例：12位DAC，量程0-3.3V，输入数字量2048：
```text
Vout = 2048 / 4095 * 3.3V ≈ 1.65V
```

## 四、 例题7.3/实验7：中断方式产生正弦模拟信号的控制程序
基本思想：定时器周期性产生中断，在中断服务程序中依次取正弦表数据写入DAC，DAC输出阶梯近似正弦波。

程序结构：
1. 配置GPIO模拟引脚，如PA4对应`DAC_OUT1`。
2. 开启DAC、TIM、GPIO时钟。
3. 配置DAC通道、数据格式、触发方式和输出缓存。
4. 配置TIM定时中断，确定采样间隔。
5. 在TIM中断服务程序中清除更新中断标志，写入下一点DAC数据。

```c
const uint16_t sin_tab[100] = {
    /* 0-4095范围内的100点正弦表 */
};
static uint8_t index = 0;

void DAC_Sin_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    DAC_InitTypeDef DAC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_DAC, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AIN;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    DAC_InitStructure.DAC_Trigger = DAC_Trigger_None;
    DAC_InitStructure.DAC_WaveGeneration = DAC_WaveGeneration_None;
    DAC_InitStructure.DAC_OutputBuffer = DAC_OutputBuffer_Enable;
    DAC_Init(DAC_Channel_1, &DAC_InitStructure);

    DAC_Cmd(DAC_Channel_1, ENABLE);
}

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
        DAC_SetChannel1Data(DAC_Align_12b_R, sin_tab[index]);
        index++;
        if (index >= 100) {
            index = 0;
        }
    }
}
```

若100点表每`2ms`更新一次，则一个周期时间为`100 * 2ms = 200ms`，正弦频率为`5Hz`。

## 五、 AD转换的四个步骤：采样、保持、量化、编码
1. **采样**：按一定时间间隔取得模拟信号瞬时值，使时间连续信号变为时间离散信号。
2. **保持**：在转换期间保持采样值不变，保证转换精度。
3. **量化**：把连续幅值映射到有限个离散等级，引入量化误差。
4. **编码**：把量化后的等级用二进制码、BCD码等数字形式表示。

## 六、 AD转换器的主要性能指标
- **分辨率**：ADC能分辨的最小输入变化，n位ADC有`2^n`个输出等级。
- **转换速率**：每秒完成转换的次数，等于转换时间的倒数。
- **量化误差**：有限位数导致的阶梯误差，位数越高，量化单位越小，误差越小。
- **转换精度**：实际转换结果与理论值之间的误差，包含量化误差和器件误差。
- **采样时间**：STM32 ADC总转换时间通常为`采样时间 + 12.5个ADC_CLK周期`。

## 七、 ADC量程、分辨率与模拟电压到数字量计算
设ADC量程为`0-Vref`，分辨率为n位，输入模拟电压为`Vin`。

常用理论计算：
```text
D = Vin / Vref * (2^n - 1)
```

结果通常取整数，题目若要求四舍五入则四舍五入，否则可取最接近整数。

例：12位ADC，量程0-3.3V，输入1.65V：
```text
D = 1.65 / 3.3 * 4095 ≈ 2048
```

## 八、 例题7.5：查询方式获得ADC转换的数字量的控制程序
基本流程：配置ADC输入引脚为模拟输入，设置ADC独立模式、单次/连续模式、规则通道，校准后启动转换，查询EOC标志，读取数据寄存器。

```c
void ADC1_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    ADC_InitTypeDef ADC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_ADC1, ENABLE);
    RCC_ADCCLKConfig(RCC_PCLK2_Div6);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AIN;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    ADC_InitStructure.ADC_Mode = ADC_Mode_Independent;
    ADC_InitStructure.ADC_ScanConvMode = DISABLE;
    ADC_InitStructure.ADC_ContinuousConvMode = DISABLE;
    ADC_InitStructure.ADC_ExternalTrigConv = ADC_ExternalTrigConv_None;
    ADC_InitStructure.ADC_DataAlign = ADC_DataAlign_Right;
    ADC_InitStructure.ADC_NbrOfChannel = 1;
    ADC_Init(ADC1, &ADC_InitStructure);

    ADC_RegularChannelConfig(ADC1, ADC_Channel_1, 1, ADC_SampleTime_55Cycles5);

    ADC_Cmd(ADC1, ENABLE);
    ADC_ResetCalibration(ADC1);
    while (ADC_GetResetCalibrationStatus(ADC1));
    ADC_StartCalibration(ADC1);
    while (ADC_GetCalibrationStatus(ADC1));
}

uint16_t ADC1_Read(void)
{
    ADC_SoftwareStartConvCmd(ADC1, ENABLE);
    while (ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC) == RESET);
    return ADC_GetConversionValue(ADC1);
}
```

## 九、 根据习题7补充的考点

习题7除了考 ADC/DAC 概念、计算题和程序题，还重点考 STM32 片内 DAC、ADC 的具体配置。下面按作业题整理成可直接背诵的版本。

### 1. STM32 DAC基本特性

- **位数**：STM32 的 DAC 是 **12 位** DAC。
- **输出类型**：属于 **电压输出型** D/A 转换器。
- **常用输出引脚**：DAC 通道 1 常用 `PA4/DAC_OUT1`，DAC 通道 2 常用 `PA5/DAC_OUT2`。
- **输出模式**：
  - 正常输出模式；
  - 噪声波生成模式；
  - 三角波生成模式。
- **数据对齐格式**：
  - `DAC_Align_8b_R`：8 位右对齐；
  - `DAC_Align_12b_R`：12 位右对齐；
  - `DAC_Align_12b_L`：12 位左对齐。

### 2. DAC计算题

DAC 数字量到模拟电压常用公式：

```text
Vout = D / (2^n - 1) * Vref
```

反过来，已知输出电压求数字量：

```text
D = Vout / Vref * (2^n - 1)
```

例：STM32 DAC 为 12 位，`VREF+ = 3.3V`，若要输出 `2V`：

```text
D = 2 / 3.3 * 4095 ≈ 2482 = 0x09B2
```

例：12 位 DAC，满量程电压 5V，最小分辨电压约为：

```text
q = 5V / 4096 ≈ 1.22mV
```

### 3. DAC_InitTypeDef结构体

```c
typedef struct
{
    uint32_t DAC_Trigger;
    uint32_t DAC_WaveGeneration;
    uint32_t DAC_LFSRUnmask_TriangleAmplitude;
    uint32_t DAC_OutputBuffer;
} DAC_InitTypeDef;
```

各成员作用：

| 成员 | 作用 |
|---|---|
| `DAC_Trigger` | 设置 DAC 的触发方式，如不触发、定时器触发、外部中断触发等。 |
| `DAC_WaveGeneration` | 设置是否启用波形发生器，可选择无波形、噪声波、三角波。 |
| `DAC_LFSRUnmask_TriangleAmplitude` | 当生成噪声波时设置 LFSR 掩码；当生成三角波时设置三角波幅值。 |
| `DAC_OutputBuffer` | 开启或关闭 DAC 输出缓冲器。 |

### 4. DAC寄存器：DHR与DOR

DAC 输出相关寄存器要分清：

- **DHR（Data Holding Register，数据保持寄存器）**：软件写入数字量的寄存器，如 `DAC_DHR12R1`、`DAC_DHR12L1`、`DAC_DHR8R1`。
- **DOR（Data Output Register，数据输出寄存器）**：真正送到 DAC 转换单元的输出数据寄存器，通常由硬件从 DHR 转移得到，用户一般不直接写 DOR。

标准库中通常不手写寄存器，而用函数写入 DHR：

```c
DAC_SetChannel1Data(DAC_Align_12b_R, data);
```

附件中还列出了软件触发函数：

```c
DAC_SoftwareTriggerCmd(DAC_Channel_1, ENABLE);
```

它的作用是用软件方式触发一次 DAC 转换。若 `DAC_InitStructure.DAC_Trigger` 配置为软件触发，则通常流程是：先用 `DAC_SetChannel1Data()` 写入数字量，再调用 `DAC_SoftwareTriggerCmd()` 让该数字量真正开始转换。若程序采用 `DAC_Trigger_None`，写入数据后通常会直接更新输出，此时不一定需要软件触发。

如果题目问“不能直接写输出寄存器时写哪个寄存器”，答案应写 **DHR 数据保持寄存器**。

### 5. AD采样过程与ADC性能指标

AD 采样/数据采集过程分为四步：

```text
采样 -> 保持 -> 量化 -> 编码
```

ADC 性能指标：

- **分辨率**：n 位 ADC 有 `2^n` 个量化等级。
- **转换速率/采样率**：单位时间内完成转换的次数。
- **量化误差/精度**：量化和器件误差造成的转换偏差。
- **输入电压范围**：ADC 可接受的模拟输入电压范围。
- **采样时间**：STM32 ADC 总转换时间通常为 `采样时间 + 12.5 个 ADC_CLK 周期`。

### 6. STM32 ADC基本特性与通道

- **位数**：STM32 ADC 是 **12 位** ADC。
- **类型**：逐次逼近型 ADC（SAR ADC）。
- **通道数量**：以 STM32F1 为例，ADC 最多可采集 **18 个通道**：
  - 16 个外部通道；
  - 2 个内部通道：内部温度传感器通道、内部参考电压通道。

常见通道写法：

```c
ADC_Channel_0
ADC_Channel_1
ADC_Channel_TempSensor
ADC_Channel_Vrefint
```

### 7. ADC连续转换与扫描模式

- **连续转换模式**：ADC 完成一次转换后，自动开始下一次转换，适合连续采集同一个通道。
- **扫描模式**：用于多通道采集。ADC 按规则通道序列依次转换多个通道。
- **单通道、单次转换**：`ADC_ScanConvMode = DISABLE`，`ADC_ContinuousConvMode = DISABLE`。
- **多通道扫描**：`ADC_ScanConvMode = ENABLE`，并通过 `ADC_NbrOfChannel` 指定规则通道数量。

多通道采集中，结束信号一般在**规则通道序列转换完成**后产生；如果开启每通道 EOC，则也可能每个通道完成后产生一次 EOC，具体看芯片/库配置。

### 8. ADC转换结束获取方式与结果寄存器

获取 ADC 转换结束常用三种方式：

1. **查询方式**：循环查询 `ADC_FLAG_EOC`。
2. **中断方式**：开启 `ADC_IT_EOC`，转换完成后进入 ADC 中断服务函数。
3. **DMA方式**：转换完成后由 DMA 自动搬运数据到内存，适合连续多通道采集。

转换结果存放位置：

- **规则通道结果**：存放在 `ADC_DR`。
- **注入通道结果**：存放在 `ADC_JDR1`、`ADC_JDR2`、`ADC_JDR3`、`ADC_JDR4`。

查询方式读取规则通道结果：

```c
while (ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC) == RESET);
value = ADC_GetConversionValue(ADC1);
```

### 9. ADC计算题

已知数字量求模拟电压：

```text
Vin = D / (2^n - 1) * Vref
```

例：12 位 ADC，采集数字量 `2047`，满量程电压 `3.3V`：

```text
Vin = 2047 / 4095 * 3.3V ≈ 1.65V
```

已知模拟电压求数字量：

```text
D = Vin / Vref * (2^n - 1)
```

### 10. ADC_InitTypeDef结构体

```c
typedef struct
{
    uint32_t ADC_Mode;
    FunctionalState ADC_ScanConvMode;
    FunctionalState ADC_ContinuousConvMode;
    uint32_t ADC_ExternalTrigConv;
    uint32_t ADC_DataAlign;
    uint8_t ADC_NbrOfChannel;
} ADC_InitTypeDef;
```

各成员作用：

| 成员 | 作用 |
|---|---|
| `ADC_Mode` | 设置 ADC 工作模式，如独立模式、双 ADC 模式等。 |
| `ADC_ScanConvMode` | 是否开启扫描模式，多通道采集时通常开启。 |
| `ADC_ContinuousConvMode` | 是否开启连续转换模式。 |
| `ADC_ExternalTrigConv` | 设置外部触发源；软件触发时通常设为 `ADC_ExternalTrigConv_None`。 |
| `ADC_DataAlign` | 设置转换结果对齐方式，常用右对齐 `ADC_DataAlign_Right`。 |
| `ADC_NbrOfChannel` | 设置规则通道组中的通道数量。 |

### 11. 作业速记版

- STM32 DAC：12 位，电压输出型。
- STM32 ADC：12 位，逐次逼近型。
- DAC 输出模式：正常、噪声波、三角波。
- DAC 数据格式：8 位右对齐、12 位右对齐、12 位左对齐。
- DAC 性能指标：分辨率、建立时间、转换精度。
- ADC 性能指标：分辨率、转换速率、量化误差/精度、输入电压范围。
- AD 四步：采样、保持、量化、编码。
- ADC 通道：最多 18 个，16 个外部通道 + 2 个内部通道。
- ADC 结束方式：查询、中断、DMA。
- ADC 结果寄存器：规则通道 `ADC_DR`，注入通道 `ADC_JDRx`。
