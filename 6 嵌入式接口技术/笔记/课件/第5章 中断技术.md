## 一、 中断的概念、中断源的分类
### 1. 中断的概念
中断是CPU执行主程序时，因内部或外部事件请求，暂时停止当前程序，转去执行中断服务程序，处理完后再返回原程序继续执行的过程。

作用：
- 提高CPU利用率，避免长时间轮询等待。
- 提高实时性，及时响应外部事件。
- 处理异常、故障和系统服务请求。

### 2. 中断源的分类
- **外部中断/硬中断**：来自**CPU外部或片上外设**，如按键EXTI、定时器TIM、ADC、USART、DMA等**硬件事件**。
- **内部异常/软中断**：来自**CPU内部执行过程**，如复位、NMI、HardFault、系统调用、调试断点等**软件事件**。
- **可屏蔽中断与不可屏蔽中断**：普通外设中断可通过NVIC屏蔽；NMI等不可屏蔽。

<a id="ch5-2"></a>
## 二、 中断嵌套的概念、中断优先级的排队方法
### 1. 中断嵌套
CPU正在执行低优先级中断服务程序时，如果更高优先级中断到来，系统可暂停当前ISR，先执行高优先级ISR，完成后再回到原ISR，这就是中断嵌套。

### 2. 优先级排队方法
- **软件查询法**：程序**按固定顺序查询中断标志**，先查到的先服务。
- **硬件排队电路**：通过硬件线路或优先级编码器决定响应顺序。
- **专用中断控制器**：如NVIC，由寄存器配置抢占优先级和子优先级，**硬件自动判优**。

<a id="ch5-3"></a>
## 三、 CM3中断源优先级划分、优先级分组
- **固定负优先级异常**：Reset、NMI、HardFault等优先级最高，**普通软件不能随意改变**。
- **可编程优先级中断**：大多数外设中断可由NVIC设置优先级。数值越小，优先级越高。
- **抢占优先级**：决定**能否打断正在执行的中断**，是中断嵌套的依据。
- **子优先级**：当抢占优先级相同时，决定多个挂起中断的响应先后，不能产生嵌套。
- **优先级分组**：`NVIC_PriorityGroupConfig()`把可用优先级位划分给抢占优先级和子优先级。

答题关键句：抢占优先级决定“能不能插队”，子优先级决定“同组谁先排队”。

<a id="ch5-4"></a>
## 四、 中断服务程序、中断向量的概念
- **中断服务程序（ISR）**：处理中断事件的函数，函数名必须与启动文件中的中断向量名一致，如`EXTI2_IRQHandler`、`TIM3_IRQHandler`。
- **中断向量**：中断服务程序的入口地址。
- **中断向量表**：按异常号/中断号顺序存放各ISR入口地址的表。CPU响应中断时根据中断号查表，把入口地址装入PC。

ISR编写原则：
- 尽量短，快进快出。
- 先判断中断标志，再处理事件。
- 处理完必须清除挂起标志，避免重复进入。

<a id="ch5-5"></a>
## 五、 中断处理过程（5个阶段）
1. **中断请求**：外设或异常源**产生请求**，相关挂起标志被置位。
2. **中断判优**：NVIC根据屏蔽状态、抢占优先级、子优先级和中断号**判断是否响应**。
3. **中断响应**：CPU暂停当前程序，硬件自动**压栈保存**R0-R3、R12、LR、PC、xPSR，并**跳转到中断向量**。
4. **执行中断处理**：运行ISR，**完成事件处理**，必要时读写外设寄存器或调用库函数。
5. **中断返回**：清除中断标志后，硬件**从堆栈恢复现场，返回被打断的程序继续执行**。

## 六、 例题5.1/实验3：外部中断控制程序
外部中断程序按“**GPIO输入、AFIO映射、EXTI线路、NVIC通道、ISR清标志**”的顺序写。

```c
#include "stm32f10x_conf.h"
#include "misc.h"

void EXTI_Key_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    EXTI_InitTypeDef EXTI_InitStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOE | RCC_APB2Periph_AFIO, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_Init(GPIOE, &GPIO_InitStructure);

    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource2);

    EXTI_InitStructure.EXTI_Line = EXTI_Line2;
    EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_Init(&EXTI_InitStructure);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitStructure.NVIC_IRQChannel = EXTI2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

void EXTI2_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line2) != RESET) {
        /* 用户控制逻辑：如翻转LED或蜂鸣器 */
        EXTI_ClearITPendingBit(EXTI_Line2);
    }
}
```

## 七、 彩云云库习题5
习题5重点对应中断概念、中断源分类、嵌套和优先级、向量表、五阶段处理过程、EXTI/NVIC程序结构。

### 习题5答题补充
#### 1. 中断请求、中断服务和中断系统
- **中断请求**：中断源发出的触发信号，是原因。
- **中断服务**：CPU响应后执行ISR，是结果。
- **中断系统**：负责接收请求、锁存挂起、判优、响应、返回和支持嵌套的软硬件集合。

#### 2. 外部中断挂起记录与清除
以STM32外部中断为例：
- 外部引脚请求先在**EXTI挂起寄存器EXTI_PR**中记录。
- 请求送入NVIC后，也会在**NVIC挂起寄存器**中记录。
- **EXTI挂起位**：通常在ISR中写1清除，如`EXTI_ClearITPendingBit(EXTI_Line5);`
- **NVIC挂起位**：内核响应进入ISR时通常由硬件自动清除，也可用NVIC相关函数软件清除。

#### 3. 优先级负数
Cortex-M3中Reset、NMI、HardFault等异常极其重要，优先级固定且高于普通外设中断，所以用负数优先级表示，普通程序不能随意改。

#### 4. 中断向量表两种类型
- **静态/Flash向量表**：上电后默认使用，通常位于Flash起始地址。
- **可重定位/RAM向量表**：通过`SCB->VTOR`等寄存器重定位到SRAM，常用于Bootloader、IAP升级、动态修改中断入口。

#### 5. 编写ISR注意事项
- 快进快出，不写长延时和死循环。
- 先判断中断标志，再处理对应事件。
- 退出前必须清除挂起标志。
- 避免调用不可重入函数，如复杂`printf`、`malloc`。
- 主程序和ISR共享变量应加`volatile`。

#### 6. 断点和现场保护
中断会打断原程序，如果不保存PC和寄存器内容，返回后原程序无法继续正确运行。STM32/CM3的特点是：进入中断时硬件自动压栈保存`R0-R3、R12、LR、PC、xPSR`，返回时硬件自动出栈恢复。

#### 7. GPIOA.5上升沿中断计数程序模板
```c
#include "stm32f10x.h"

volatile uint32_t pulse_cnt = 0;

void GPIO_EXTI5_NVIC_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    EXTI_InitTypeDef EXTI_InitStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_AFIO, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource5);

    EXTI_InitStructure.EXTI_Line = EXTI_Line5;
    EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Rising;
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_Init(&EXTI_InitStructure);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_1);
    NVIC_InitStructure.NVIC_IRQChannel = EXTI9_5_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);
}

int main(void)
{
    GPIO_EXTI5_NVIC_Config();
    while (1) {
    }
}

void EXTI9_5_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line5) != RESET) {
        pulse_cnt++;
        EXTI_ClearITPendingBit(EXTI_Line5);
    }
}
```
