# 第4章 接口技术 通俗解释

## 一、 IO接口的概念、IO接口电路的作用、接口和端口、IO端口地址编码
### 1. IO接口的概念
IO接口就像CPU和外设之间的“翻译兼中转站”。CPU很快，外设可能很慢；CPU说数字逻辑，外设可能是按键、电机、传感器。接口负责让两边能听懂、能配合。

### 2. IO接口电路的作用
- **缓冲**：外设数据先放一放，等CPU来取。
- **锁存**：CPU输出的数据保存住，不然CPU一闪而过外设来不及看。
- **格式转换**：比如并行变串行，数字量变控制信号。
- **时序控制**：什么时候读、什么时候写、什么时候有效，都由接口配合。
- **地址译码**：CPU给出地址后，接口判断是不是在叫自己。

### 3. 接口和端口
- **接口**是整套电路。
- **端口**是接口里CPU能直接访问的寄存器。

通俗说：接口是一间办公室，端口是办公室里的窗口。CPU通过不同窗口递交数据、看状态、发命令。

### 4. IO端口地址编码
- **统一编址**：外设寄存器像内存一样拥有地址。STM32就是这样，所以访问GPIO、TIM、ADC本质上都是读写某些地址。
- **独立编址**：I/O有单独地址空间，需要专门I/O指令访问。

## 二、 CPU与外设之间数据传输的方式
### 1. 无条件传送方式
CPU默认外设永远准备好了，直接读写。像你默认门口一直有人接快递。简单，但只适合LED这类简单设备。

### 2. 查询传送方式
CPU反复问外设：“好了吗？”好了才传数据。优点是硬件简单，缺点是CPU一直等，效率低。

### 3. 中断传送方式
CPU先忙别的，外设准备好后主动喊CPU。CPU再暂停当前任务处理外设。适合按键、串口、定时器这类事件驱动任务。

### 4. DMA方式
DMA像搬运工，直接在外设和内存之间搬数据，CPU只负责安排任务和检查结果。适合大量数据，比如ADC连续采样。

## 三、 上拉和下拉输入
输入引脚如果什么都不接，就像一个没有固定意见的人，容易被干扰影响。

- **上拉输入**：默认被拉到高电平，平时读1。
- **下拉输入**：默认被拉到低电平，平时读0。
- **作用**：给输入引脚一个确定默认状态，防止浮空乱跳。

按键常见接法：上拉输入时，没按是1，按下接地变0。

## 四、 OC/OD开漏、推挽输出
- **开漏/开集输出**：只能主动拉低，不能主动拉高，高电平要靠上拉电阻。像只会“往下拽”的开关。
- **推挽输出**：既能主动输出高电平，也能主动输出低电平。像有上下两个开关轮流工作，驱动能力强。

常见场景：
- I2C常用开漏，因为多个设备可以共享一根线。
- LED、普通数字输出常用推挽，因为响应快、驱动强。

## 五、 GPIO主要端口寄存器：ODR、IDR、CRL、CRH、BSRR、BRR
- **CRL/CRH**：决定引脚模式。CRL管0-7号引脚，CRH管8-15号引脚。
- **IDR**：读输入电平。想知道按键有没有按，就看它。
- **ODR**：写输出电平。想控制LED亮灭，可以改它。
- **BSRR**：原子置位/复位。适合在中断场景安全改某一位。
- **BRR**：清零某一位。

通俗记忆：
- `I`是Input，`IDR`读输入。
- `O`是Output，`ODR`管输出。
- `C`是Config，`CRL/CRH`管配置。
- `S/R`是Set/Reset，`BSRR/BRR`管置位和复位。

## 六、 例题4.1/实验2：GPIO控制程序
GPIO程序基本套路：

1. **开时钟**：外设没时钟就像没通电。
2. **配模式**：输入、输出、上拉、推挽等。
3. **读写引脚**：输入用读函数，输出用置位/复位函数。
4. **主循环持续执行**。

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &GPIO_InitStructure);

GPIO_SetBits(GPIOA, GPIO_Pin_0);
```

写程序设计题时，先把题目中的端口、引脚、输入输出模式替换进去，再套这个顺序。
