# 第6章 定时器与计数器 通俗解释

## 一、 定（延）时的基本方法（三种）
### 1. 软件延时
让CPU执行空循环来消耗时间。像让人原地数数等一分钟。简单，但人被占住了，不能干别的。

### 2. 硬件延时电路
用外部电路产生延时。像用沙漏计时，不占CPU，但想改时间不方便。

### 3. 可编程定时器/计数器
用STM32内部定时器计数。像一个可设置闹钟的计数器，时间到了可以产生中断，也可以控制PWM输出。

## 二、 定时器的一般工作原理
定时器就是“数脉冲”。每来一个时钟脉冲，计数器加1。数到设定值，就产生事件。

- `CK_INT`：原始时钟。
- `PSC`：预分频器，先把时钟变慢。
- `CK_CNT`：分频后的计数器时钟。
- `CNT`：正在数的数。
- `ARR`：目标数，数到这里就更新。

核心公式：
```text
f_CK_CNT = f_CK_INT / (PSC + 1)
f_Update = f_CK_INT / ((PSC + 1) * (ARR + 1))
```

## 三、 STM32通用定时器的三大组成部分
- **时基单元**：负责基础计时，核心是PSC、CNT、ARR。
- **输入捕获单元**：负责测外部信号，边沿一来就记录CNT值。
- **输出比较单元**：负责输出波形，比较CNT和CCR，常用来产生PWM。

通俗说：时基单元负责“数时间”，输入捕获负责“测别人”，输出比较负责“控制自己输出”。

## 四、 TIM基本定时：PSC和ARR计算
先确定计数器每秒数多少次：

```text
PSC = f_CK_INT / f_CK_CNT - 1
```

再确定要数多少个计数才到时间：

```text
ARR = T * f_CK_CNT - 1
```

例：72MHz时钟，想让计数器变成10kHz：
```text
PSC = 72000000 / 10000 - 1 = 7199
```

如果要定时1秒：
```text
ARR = 1 * 10000 - 1 = 9999
```

## 五、 例题6.1/实验4：TIM基本定时控制程序
基本定时中断程序套路：

1. 开TIM时钟。
2. 配PSC和ARR。
3. 开更新中断。
4. 配NVIC。
5. 使能定时器。
6. 在中断服务程序里清除`TIM_IT_Update`标志。

```c
TIM_TimeBaseStructure.TIM_Period = arr;
TIM_TimeBaseStructure.TIM_Prescaler = psc;
TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);
TIM_Cmd(TIM3, ENABLE);
```

## 六、 TIM输出比较功能：PWM频率、占空比、ARR、CCR计算
PWM可以理解成“周期固定、开关时间可调”的方波。

- **频率**：一秒重复多少次。
- **占空比**：一个周期内高电平占多少比例。
- **ARR**：决定周期长度。
- **CCR**：决定高电平持续到哪里。

公式：
```text
f_PWM = f_CK_INT / ((PSC + 1) * (ARR + 1))
Duty = CCR / (ARR + 1)
CCR = (ARR + 1) * Duty
```

例：`ARR=999`，占空比25%，则`CCR=250`。

## 七、 例题6.3/实验5：TIM输出比较PWM控制程序
PWM输出程序套路：

1. PWM引脚配置成复用推挽输出。
2. 配置TIM时基单元，确定PWM频率。
3. 配置输出比较通道，选择PWM模式。
4. 设置`TIM_Pulse`，也就是CCR。
5. 使能预装载和定时器。

```c
TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
TIM_OCInitStructure.TIM_Pulse = 250;
TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
TIM_OC1Init(TIM2, &TIM_OCInitStructure);
```

## 八、 TIM输入捕获功能：由CCR1、CCR2计算频率和占空比
输入捕获像“拿秒表测别人信号”。

在PWM输入模式中：
- `CCR1`常保存一个周期的计数值。
- `CCR2`常保存高电平宽度的计数值。

计算：
```text
f_Input = f_CK_CNT / CCR1
Duty = CCR2 / CCR1
```

如果题目说明计数包含0到捕获值，则用：
```text
f_Input = f_CK_CNT / (CCR1 + 1)
Duty = (CCR2 + 1) / (CCR1 + 1)
```

## 九、 例题6.4/实验6：TIM输入捕获控制程序
输入捕获程序套路：

1. 输入引脚配置为浮空输入或按要求配置。
2. 配置TIM时基，通常给足够大的ARR。
3. 配置`TIM_PWMIConfig()`。
4. 选择触发源`TIM_TS_TI1FP1`。
5. 设置从模式为Reset，让每个周期开始时CNT清零。
6. 读取CCR1、CCR2计算频率和占空比。

```c
TIM_PWMIConfig(TIM4, &TIM_ICInitStructure);
TIM_SelectInputTrigger(TIM4, TIM_TS_TI1FP1);
TIM_SelectSlaveMode(TIM4, TIM_SlaveMode_Reset);
TIM_Cmd(TIM4, ENABLE);
```
