# 第7章 DA与AD转换技术 通俗解释

## 一、 ADC、DAC的概念
- **ADC**：把模拟量变成数字量。像把温度、电压这种连续变化的东西，变成计算机能保存的数字。
- **DAC**：把数字量变成模拟量。像把程序里的数字，变成一个真实电压输出。

通俗理解：
- ADC是“现实世界到计算机”。
- DAC是“计算机到现实世界”。

## 二、 DA转换器的主要性能指标
- **分辨率**：输出能分得多细。位数越多，台阶越小。
- **转换精度**：实际输出和理论输出差多少。
- **建立时间**：数字量变化后，模拟输出稳定下来需要多久。
- **温度系数**：温度变化对输出影响多大。
- **非线性误差**：实际台阶曲线偏离理想直线的程度。

## 三、 DAC量程、分辨率与数字量到模拟电压计算
DAC计算就像“把满量程电压分成很多份，数字量占几份就输出多少”。

常用公式：
```text
Vout = D / (2^n - 1) * Vref
```

其中：
- `D`是输入数字量。
- `n`是分辨率位数。
- `Vref`是参考电压或满量程电压。

例：12位DAC、0-3.3V、数字量2048：
```text
Vout ≈ 2048 / 4095 * 3.3V ≈ 1.65V
```

## 四、 例题7.3/实验7：中断方式产生正弦模拟信号的控制程序
思路：先准备一张正弦表，里面放一圈正弦波对应的数字量。定时器每隔固定时间中断一次，中断里把表中下一个数字写进DAC。DAC输出一串台阶电压，看起来就接近正弦波。

程序套路：
1. PA4/PA5等DAC引脚配置为模拟模式。
2. 开DAC和定时器时钟。
3. 初始化DAC通道。
4. 配置TIM定时中断。
5. 在TIM中断里写`DAC_SetChannel1Data()`。

```c
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
        DAC_SetChannel1Data(DAC_Align_12b_R, sin_tab[index]);
        index = (index + 1) % 100;
    }
}
```

频率理解：如果100个点组成一个周期，每2ms输出一个点，那么一个周期是200ms，频率就是5Hz。

## 五、 AD转换的四个步骤：采样、保持、量化、编码
ADC不是一下子“魔法变数字”，它分四步：

1. **采样**：每隔一段时间看一眼模拟电压。
2. **保持**：看的这一眼先固定住，防止转换时变化。
3. **量化**：把连续电压归到某个有限等级。
4. **编码**：把这个等级写成二进制数字。

通俗说：拍照、定格、分档、编号。

## 六、 AD转换器的主要性能指标
- **分辨率**：输入电压变化多小ADC能察觉。
- **转换速率**：一秒能转换多少次。
- **量化误差**：连续值被分档后产生的误差。
- **转换精度**：实际转换结果和理论结果的差。
- **采样时间**：输入信号被采样的时间，STM32总转换时间还要加固定的12.5个ADC时钟周期。

## 七、 ADC量程、分辨率与模拟电压到数字量计算
ADC计算是DAC的反过程：输入电压占满量程多少比例，数字量就占最大数字多少比例。

常用公式：
```text
D = Vin / Vref * (2^n - 1)
```

例：12位ADC、0-3.3V、输入1.65V：
```text
D = 1.65 / 3.3 * 4095 ≈ 2048
```

## 八、 例题7.5：查询方式获得ADC转换的数字量的控制程序
查询方式就是CPU主动等ADC转换完成。

程序套路：
1. ADC输入引脚配置为模拟输入。
2. 开GPIO和ADC时钟。
3. 设置ADC独立模式、单通道、右对齐、软件触发。
4. 配置规则通道和采样时间。
5. 校准ADC。
6. 软件启动转换。
7. 查询EOC标志。
8. 读取转换结果。

```c
ADC_SoftwareStartConvCmd(ADC1, ENABLE);
while (ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC) == RESET);
value = ADC_GetConversionValue(ADC1);
```
