# 第5章 中断技术 通俗解释

## 一、 中断的概念、中断源的分类
### 1. 中断的概念
中断可以理解成“正在做题时有人敲门”。CPU本来在执行主程序，突然有重要事件来了，就先记住当前做到哪，再去处理事件，处理完继续回来。

中断的好处：
- CPU不用一直问外设有没有准备好。
- 重要事件能及时处理。
- 程序结构更像“事件来了再响应”。

### 2. 中断源的分类
- **外部中断/硬件中断**：按键、定时器、ADC、USART等硬件事件。
- **内部异常/软件相关异常**：复位、故障、系统调用、调试断点等。
- **可屏蔽与不可屏蔽**：普通外设中断可开关，NMI这类不能随便屏蔽。

## 二、 中断嵌套的概念、中断优先级的排队方法
### 1. 中断嵌套
低优先级中断正在处理时，如果更紧急的中断来了，CPU可以先去处理高优先级中断，再回来继续处理低优先级中断。这叫嵌套。

### 2. 中断优先级排队方法
- **软件查询**：程序按顺序查，谁先被查到谁先处理。
- **硬件排队**：硬件线路直接决定谁优先。
- **NVIC控制器**：STM32常用方式，通过寄存器设置优先级，由硬件自动判定。

通俗说，NVIC就是“中断调度员”。

## 三、 CM3中断源优先级划分、优先级分组
CM3中断优先级数值越小，优先级越高。

- **抢占优先级**：决定能不能打断别人。它管“插队权”。
- **子优先级**：抢占优先级相同时，决定谁先被响应。它管“排队顺序”。
- **优先级分组**：把有限的优先级位分给抢占优先级和子优先级。

一句话记忆：抢占优先级管嵌套，子优先级管同级排序。

## 四、 中断服务程序、中断向量的概念
- **中断服务程序ISR**：事件来了以后真正执行的处理函数。
- **中断向量**：ISR的入口地址。
- **中断向量表**：所有ISR入口地址排成的一张表。

CPU响应中断时，不是随便找函数，而是根据中断号查向量表，找到对应入口地址，再跳过去执行。

## 五、 中断处理过程（5个阶段）
1. **中断请求**：外设举手说“我有事”。
2. **中断判优**：NVIC看谁更急、谁没被屏蔽。
3. **中断响应**：CPU保存现场，跳到ISR。
4. **执行中断处理**：在ISR里完成控制动作。
5. **中断返回**：清除标志，恢复现场，回主程序。

最容易丢分的点：ISR里处理完后要清除挂起标志，否则会反复进入中断。

## 六、 例题5.1/实验3：外部中断控制程序
外部中断配置可以记成五步：

1. **GPIO输入配置**：按键引脚设成上拉或下拉输入。
2. **AFIO映射**：告诉芯片哪个GPIO口接到哪条EXTI线。
3. **EXTI配置**：设置中断线、触发边沿、是否使能。
4. **NVIC配置**：设置中断通道、抢占优先级、子优先级。
5. **写ISR**：判断标志、执行动作、清除挂起位。

```c
GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource2);

EXTI_InitStructure.EXTI_Line = EXTI_Line2;
EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;
EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
EXTI_InitStructure.EXTI_LineCmd = ENABLE;
EXTI_Init(&EXTI_InitStructure);

NVIC_InitStructure.NVIC_IRQChannel = EXTI2_IRQn;
NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
NVIC_Init(&NVIC_InitStructure);
```

中断服务程序模板：

```c
void EXTI2_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line2) != RESET) {
        /* 用户控制逻辑 */
        EXTI_ClearITPendingBit(EXTI_Line2);
    }
}
```
