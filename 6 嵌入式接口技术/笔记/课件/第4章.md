## 一、 IO接口的概念、IO接口电路的作用、接口和端口、IO端口地址编码
### 1. IO接口的概念
IO接口是CPU与外部设备之间交换信息的硬件逻辑电路和控制部件。它负责让速度、电平、格式、时序都可能不同的CPU和外设能够可靠通信。

### 2. IO接口电路的作用
- **数据缓冲与锁存**：协调CPU和外设**速度差异**。输入常用缓冲器，输出常用锁存器。
- **信号转换**：完成电平、模拟/数字、串并**格式等转换**。
- **时序控制**：产生读、写、片选、握手等控制信号。
- **设备寻址**：根据地址译码**选中**具体外设或寄存器。
- **状态反馈**：向CPU提供忙、就绪、错误等**状态**。

### 3. 接口和端口
- **接口**：包含数据缓冲、控制、状态、译码等**电路的整体**。
- **端口**：接口中可被CPU直接访问的**寄存器**，常见有数据端口、状态端口、控制端口。

### 4. IO端口地址编码
- **统一编址（内存映射IO）**：I/O端口和存储器共用同一地址空间，STM32采用这种方式，可用普通访存指令访问外设寄存器。
- **独立编址**：I/O端口有独立地址空间，如x86常用`IN`、`OUT`指令访问。

<a id="ch4-2"></a>
## 二、 CPU与外设之间数据传输的方式
### 1. 无条件传送方式
CPU默认外设**随时就绪**，直接读写数据端口。硬件和软件简单，适合LED、拨码开关等简单慢速外设。

### 2. 查询传送方式
CPU先读状态端口，判断外设是否就绪；**未就绪就循环查询，已就绪再读写数据端口**。优点是硬件简单，缺点是CPU时间被等待过程占用。

### 3. 中断传送方式
外设准备好后向CPU发中断请求，**CPU响应后执行中断服务程序完成数据传输**。优点是CPU利用率高、实时性好，适合按键、串口、定时器等事件。

### 4. DMA方式
DMA控制器接管总线，**在外设和存储器之间直接搬运数据，CPU只负责初始化和结果处理**。适合大量、高速、连续数据传输。复习要求是了解其思想和适用场景。

<a id="ch4-3"></a>
## 三、 上拉和下拉输入
- **上拉输入**：引脚通过电阻接到高电平，**默认读到1**；外部按下或导通到低电平时读到0。
- **下拉输入**：引脚通过电阻接到低电平，**默认读到0**；外部接高电平时读到1。
- **作用**：给输入引脚提供确定默认电平，避免浮空输入受干扰产生误判。
- **STM32常用模式**：`GPIO_Mode_IPU`为上拉输入，`GPIO_Mode_IPD`为下拉输入。

<a id="ch4-4"></a>
## 四、 OC/OD开漏、推挽输出
- **开漏/开集输出（OD/OC）**：**只能主动拉低，不能主动输出高电平**；高电平依赖上拉电阻。适合I2C、多设备线与、电平转换等场景。
- **推挽输出**：内部上管和下管交替导通，**既能主动输出高电平，也能主动输出低电平**。驱动能力强，适合LED、普通数字输出。
- **复用开漏/复用推挽**：当GPIO引脚交给片内外设使用时，根据外设需求选择复用开漏或复用推挽。

<a id="ch4-5"></a>
## 五、 GPIO主要端口寄存器：ODR、IDR、CRL、CRH、BSRR、BRR
- **CRL**：配置Px0-Px7的输入/输出模式和输出速度。
- **CRH**：配置Px8-Px15的输入/输出模式和输出速度。
- **IDR**：输入数据寄存器，只读，**用于读取引脚实际输入电平**。
- **ODR**：输出数据寄存器，可读写，**用于控制输出引脚电平**。
- **BSRR**：位设置/复位寄存器，写低16位可置位，写高16位可复位，具有原子性。
- **BRR**：位复位寄存器，写1可清除对应ODR位。

**英文全称速记表：**
- **CRL**：Configuration Register Low — 端口配置低寄存器
- **CRH**：Configuration Register High — 端口配置高寄存器
- **IDR**：Input Data Register — 端口输入数据寄存器
- **ODR**：Output Data Register — 端口输出数据寄存器
- **BSRR**：Bit Set/Reset Register — 端口位设置/复位寄存器
- **BRR**：Bit Reset Register — 端口位复位寄存器

常用库函数对应关系：
- `GPIO_ReadInputDataBit()`读IDR。
- `GPIO_SetBits()`通常写BSRR置位。
- `GPIO_ResetBits()`通常写BRR或BSRR高位复位。
- `GPIO_Init()`根据结构体参数配置CRL/CRH。

## 六、 例题4.1/实验2：GPIO控制程序
GPIO控制程序按“开时钟、配GPIO、读输入/写输出、主循环调用”的顺序写。

```c
#include "stm32f10x_conf.h"

void LED_Key_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_Init(GPIOE, &GPIO_InitStructure);
}

int main(void)
{
    LED_Key_Config();
    while (1) {
        if (GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4) == Bit_RESET) {
            GPIO_SetBits(GPIOA, GPIO_Pin_0);
        } else {
            GPIO_ResetBits(GPIOA, GPIO_Pin_0);
        }
    }
}
```

答题时可以把具体端口和引脚替换成题目给定条件。

## 七、 彩云云库习题4
习题4用于巩固接口概念、数据传输方式、上拉/下拉、开漏/推挽、GPIO寄存器和标准库初始化流程。

### 习题4答题补充
- **CPU与外设交换的信息类型**：数据信息、状态信息、控制信息。
- **查询输入方式过程**：读状态端口 → 测试就绪位 → 未就绪继续循环 → 就绪后读数据端口。
- **输入/输出接口硬件**：输入接口常用缓冲器或三态门；输出接口常用锁存器或触发器。
- **GPIO八种工作方式**：模拟输入、浮空输入、上拉输入、下拉输入、开漏输出、推挽输出、复用开漏输出、复用推挽输出。
- **GPIO位操作三法**：读改写ODR；直接写BSRR/BRR；位带别名区操作。
- **PA0置位库函数**：`GPIO_SetBits(GPIOA, GPIO_Pin_0);`
- **GPIO_Init用到的数据结构**：`GPIO_InitTypeDef`，包含`GPIO_Pin`、`GPIO_Mode`、`GPIO_Speed`等成员；底层根据引脚号配置CRL或CRH。
