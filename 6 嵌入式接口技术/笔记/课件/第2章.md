# 第2章 Cortex-M3 基础 复习笔记

## 一、 8位微处理器的功能结构
8位微处理器通常由运算器、控制器、寄存器组和总线接口部件组成。

- **运算器**：核心是ALU，完成算术运算、逻辑运算、移位、比较等操作，并影响状态标志位。
- **控制器**：从存储器取出指令，完成译码，产生控制信号，协调取指、读写、运算和转移。
- **寄存器组**：临时保存数据、地址和中间结果，常见有累加器、通用寄存器、程序计数器PC、堆栈指针SP、状态寄存器等。
- **总线接口**：通过地址总线、数据总线、控制总线与存储器和I/O接口交换信息。

考试答题可按“取指令、译码、执行；用总线访问存储器/I/O；ALU运算并更新标志位”的主线说明。

## 二、 CM3处理器的结构：两种典型的AMBA总线
- **AHB（Advanced High-performance Bus）**：高级高性能总线，面向高速部件，常用于内核、DMA、存储器接口、总线矩阵等模块之间的数据传输。
- **APB（Advanced Peripheral Bus）**：高级外设总线，面向低速、低功耗外设，常连接GPIO、TIM、USART、ADC等外设。
- **AHB/APB桥**：连接高速AHB与低速APB，完成总线协议转换、时钟域适配和访问控制。

## 三、 STM32主系统的4个驱动单元、4个被动单元
- **4个驱动单元**：Cortex-M3内核的**ICode总线、DCode总线、系统总线，以及DMA总线**。
- **4个被动单元**：内部Flash、内部SRAM、FSMC外部存储器接口、AHB/APB桥。它们主要响应驱动单元发起的访问。

记忆方式：驱动单元“主动访问”，被动单元“被访问”。

## 四、 STM32主系统总线相关部件
- **ICode （Instruction Code）总线**：指令总线，<u>主要用于内核从Flash取指令</u>。
- **DCode （Data Code）总线**：数据总线，<u>主要用于内核访问Flash中的常量、查表数据等</u>。
- **系统总线**：连接内核与SRAM、外设、调试部件等，是一般数据访问通道。
- **DMA（Direct Memory Access）总线**：直接内存访问，DMA控制器直接访问存储器或外设，实现数据搬运，减少CPU参与。
- **总线矩阵**：在多个主设备同时访问被动单元时进行仲裁，**协调访问冲突**。
- **AHB/APB桥**：把AHB访问转换成APB外设访问，是高速总线到低速外设总线的桥梁。

## 五、 CM3寄存器组：R13、R14、R15与程序状态寄存器
- **R0-R12**：通用寄存器，保存运算数据、中间结果和函数参数。
- **R13（SP  Stack Pointer）堆栈指针**：指向当前栈顶。CM3有两个堆栈指针：
  - **MSP （Main SP）**：主堆栈指针，复位后默认使用，常用于异常和中断服务。
  - **PSP （Process SP）**：进程堆栈指针，常用于操作系统中的线程或用户任务。
- **R14（LR Link Register）链接寄存器**：保存函数调用或异常返回地址。
- **R15（PC）程序计数器**：保存当前取指位置，通常指向当前指令之后的地址。

程序状态寄存器xPSR中常考标志位：
- **N（Negative）**：运算结果为负时置1。
- **Z（Zero）**：运算结果为0时置1。
- **C（Carry）**：无符号运算产生进位或借位时置1。
- **V（Overflow）**：有符号运算溢出时置1。

## 六、 堆栈的概念，CM3的堆栈指针
- **堆栈**：按后进先出（LIFO）方式管理的一段存储区。
- **入栈**：把数据压入栈中，栈指针随之改变。
- **出栈**：从栈顶取出数据，栈指针恢复。
- **CM3中断现场保护**：进入异常/中断时，硬件会自动把R0-R3、R12、LR、PC、xPSR压入当前堆栈；异常返回时再自动弹出。

堆栈常用于函数调用、局部变量保存、中断现场保护和任务切换。

### 习题2答题补充
#### 1. 基本CPU内部功能部件
基本CPU内部通常包括：
- **算术逻辑运算单元ALU**：执行加减、逻辑、移位、比较等操作。
- **寄存器组**：暂存数据、地址、中间结果和状态。
- **指令处理单元/控制器**：完成取指、译码，发出控制信号。

#### 2. FR标志寄存器
FR也称程序状态字寄存器，用来保存最近一次ALU运算结果的状态。
- **SF**：符号标志，结果最高位为1时通常表示负。
- **ZF**：零标志，结果为0时置1。
- **CF**：进位/借位标志，反映无符号运算最高位进位或借位。
- **OF**：溢出标志，反映有符号运算结果超出表示范围。
- **PF**：奇偶标志，结果低8位中1的个数为偶数时置1。

CM3中常考的是xPSR里的`N/Z/C/V`，可对应理解为`SF/ZF/CF/OF`。

#### 3. 无符号数比较与标志位
汇编中比较`A`和`B`通常执行`A - B`，不保存结果，只看标志位：
- `A == B`：`ZF = 1`
- `A > B`：`CF = 0 且 ZF = 0`
- `A < B`：`CF = 1`
- `A >= B`：`CF = 0`
- `A <= B`：`CF = 1 或 ZF = 1`

注意：这是无符号数比较，主要看`CF`和`ZF`。

#### 4. R14实现跳转和返回
执行子程序调用时，硬件把返回地址保存到`R14/LR`；子程序结束时，把LR中的地址送回`PC/R15`，程序就回到调用点之后继续执行。

#### 5. Cortex-M3操作模式和特权级别
- **Thread模式**：普通程序运行模式，主程序通常在此模式。
- **Handler模式**：异常或中断服务程序运行模式。
- **特权级**：可访问所有外设、系统寄存器和特殊指令。
- **用户级**：权限受限，不能随意访问NVIC、SysTick、调试控制等内核外设。

作用：用权限隔离保护系统，避免普通应用程序破坏内核或关键外设配置。

#### 6. Cortex-M3存储器组织
CM3采用统一的4GB地址空间，常见区域：
- **Code区**：存放程序代码和常量。
- **SRAM区**：存放变量、堆栈、运行时数据。
- **片上外设区**：GPIO、TIM、ADC、USART等外设寄存器。
- **外部RAM/外部设备区**：扩展存储器或外部设备。
- **内核外设区**：NVIC、SysTick、SCB、MPU等内核控制部件。
