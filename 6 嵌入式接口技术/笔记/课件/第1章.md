## 一、 原码、补码的编码
* **负数的编码**：负数无法用无符号码表示。例如 -100 的32位有符号补码形式为 0xFFFFFF9C。
* **正数的编码**：正数的无符号码与有符号补码表示一致。例如 +25 的32位无符号码为 0x00000019，有符号补码同样为 0x00000019。
* **真实值计算实例**：无符号码 0x00000021 的十进制真实值为 +33；补码 0xFFFFFFE2 的十进制真实值为 -30。

## 二、 微型计算机体系结构
微机体系结构主要分为两类，其核心区别在于指令和数据的存储方式及总线设计：
* **冯·诺依曼结构**：
  * **特点**：将指令和数据一律用二进制编码，且存储在同一组存储器中。
  * **工作机制**：计算机顺序执行程序，指令和数据共享同一套总线。
* **哈佛结构**：
  * **特点**：使用两个独立的存储模块，分别存储指令和数据，每个模块都不允许指令和数据并存。
  * **工作机制**：使用独立的两组总线，分别作为CPU与每个存储器模块之间的专用通信路径，互不干扰，支持并行取指和取数。

## 三、 CISC 和 RISC 概念对比
处理器架构在指令系统设计上分为复杂指令系统计算机（CISC）和精简指令系统计算机（RISC）：

| 对比维度 | CISC (如 X86体系结构) | RISC (如 ARM架构) |
| :--- | :--- | :--- |
| **指令功能与寻址** | 指令系统庞大、功能复杂、指令格式和寻址方式多，基本上一个功能对应一条指令。 | 指令功能简单、规整，特殊复杂功能需要一系列简单指令完成。 |
| **执行周期** | 绝大多数指令需要多个机器周期（总线周期）才能完成。 | 大多单周期执行（因CPU结构简单）。 |
| **访存权限** | 各种指令都可以访问存储器。 | 对存储器操作有限制（通常只有Load/Store指令可访问内存），从而简化控制。 |
| **控制方式与硬件** | 采用微程序控制，内部专用寄存器较少。 | CPU包含单元少，面积小，功耗低，结构简单。 |
| **中断响应** | 必须等指令结束才可响应中断。 | 允许在一条指令执行的适当位置被中断。 |

## 四、 微型计算机系统组成
微型计算机系统由硬件系统和软件系统两大部分组成。

### 1. 硬件系统
主要包含以下四个核心部件：
* **微处理器（CPU）**：硬件核心部件，实现运算和控制功能（如 ARM Cortex-M3）。
* **主存储器**：存放需要运行的程序和数据的地方。
* **I/O接口及设备**：I/O接口是CPU与外部设备沟通的桥梁；输入输出设备用于实现人机交互和外部通信。
* **总线**：连接各个功能部件的纽带，是信息交互的公共通道。包含三类：
  * **地址总线**：单向，用于传输CPU发出的地址编码信息，以便访问指定的存储单元或I/O端口。
  * **数据总线**：双向，用于CPU与主存储器或I/O端口之间的数据传输。
  * **控制总线**：双向，用来传输控制信号。
* **总线的优缺点**：
  * **优点**：系统结构清晰、标准化程度高，便于硬件模块的扩展、替换和维护。
  * **缺点**：由于多部件共享同一物理通道，**同一时刻只允许一对设备进行数据传输，数据量大时容易造成通信瓶颈。**

### 2. 软件系统
* **系统软件**：包含语言翻译程序（汇编、解释、编译程序）、操作系统、监控管理程序、调试与诊断程序，以及开发工具（如 KEIL、VS Code 等）。
* **应用软件**：为满足特定需求而编写的程序。

## 五、 微型计算机工作过程
微机执行程序的过程可分为三个核心阶段：
1. **取指令阶段**：程序的起始地址放到程序计数器（PC）中，将地址信息发到地址总线上，经地址译码器找到相应的存储单元，将机器指令代码取出送入指令寄存器（IR）中，随后PC自动增加指向下一条指令。
2. **指令译码阶段**：指令译码器（ID）对IR中的指令代码进行译码，产生各种时序与控制信号，指挥CPU各部件协调工作。
3. **操作阶段**：获取操作数后，算术逻辑单元（ALU）进行运算处理，存放运算结果，并更新状态标志寄存器（FR）。

### 习题1答题补充
- **32位补码负数换算**：负数`-x`的32位补码可用`2^32 - x`计算，再转16进制。例如`-100`：`0x100000000 - 0x64 = 0xFFFFFF9C`。
- **补码求真值**：若最高位为1，说明是负数；真值可用“取反加1得到绝对值，再加负号”，或用`补码值 - 2^32`。
- **总线三类**：地址总线负责寻址，数据总线负责传数据，控制总线负责读写、中断、时钟、片选等控制信号。
- **微机工作过程标准答法**：取指令（PC给地址，取到IR）→ 指令译码（ID产生控制信号）→ 执行操作（ALU运算/访存/I/O，并更新标志位）。
