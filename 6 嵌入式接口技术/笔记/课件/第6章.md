## 一、 定（延）时的基本方法（三种）
1. **软件延时**：用循环语句消耗CPU时间。简单但精度差，CPU不能做其他事。
2. **硬件延时电路**：用RC、555等外部电路产生延时。不占CPU，但参数调整不方便。
3. **可编程定时器/计数器**：通过MCU内部定时器设置PSC、ARR等寄存器定时。精度高、灵活、可产生中断或PWM，是本章重点。

<a id="ch6-2"></a>
## 二、 定时器的一般工作原理
定时器本质是对时钟脉冲计数。

- **时钟源**（Clock Source，时钟源）：提供计数脉冲，如内部时钟`CK_INT`（Clock Input / Internal Clock，定时器输入时钟 / 内部时钟源）。
- **预分频器PSC**（Prescaler，预分频器）：把输入时钟分频得到计数器时钟`CK_CNT`（Counter Clock，计数器时钟）。
- **计数器CNT**（Counter，计数器寄存器）：按`CK_CNT`递增或递减。
- **自动重装载寄存器ARR**（Auto-Reload Register，自动重装载寄存器）：**设定计数上限**。CNT达到ARR后产生更新事件，必要时触发中断。

补充：在常见 STM32 通用定时器中，`PSC` 和 `ARR` **通常都是 16-bit 寄存器，所以它们的合法范围都是 $0 \sim 65535$。** 做题时如果算出来超出这个范围，就要重新选择 `PSC` 或 $f_{CK\_CNT}$，直到 $PSC \le 65535$ 且 $ARR \le 65535$。

基本关系：
$$
T_{Update} = \frac{(PSC + 1)(ARR + 1)}{f_{CK\_INT}}
$$

<a id="ch6-3"></a>
## 三、 STM32通用定时器的三大组成部分
- **时基单元**：由PSC、CNT、ARR等组成，负责基本计数和定时。
- **输入捕获单元**：检测外部输入边沿，把边沿到来时的CNT值锁存到CCR，用于测频率、周期、脉宽、占空比。
- **输出比较单元**：比较CNT和CCR，按比较结果改变输出电平，可产生PWM。

## 四、 计算题汇总：定时周期、PWM占空比、输入捕获
STM32定时器可以理解成一个“数脉冲的计数器”。每来一个计数器时钟脉冲，`CNT`加1；当`CNT`从0数到`ARR`后，就产生一次更新事件，也就是一次定时到达。

**因为`CNT`从0开始数**，所以：
- $PSC = 7199$ 表示实际分频系数是 $7199 + 1 = 7200$。
- $ARR = 9999$ 表示实际计数次数是 $9999 + 1 = 10000$。

因此做第六章计算题时，**一定要记住`PSC`和`ARR`都要加1**。

### 1. 基本定时：PSC、ARR和定时周期
给定内部时钟 $f_{CK\_INT}$ 和需要的计数器时钟 $f_{CK\_CNT}$，要求计算 $PSC$：
$$
PSC = \frac{f_{CK\_INT}}{f_{CK\_CNT}} - 1
$$

给定定时时间 $T$，要求计算 $ARR$：
$$
ARR = T \times f_{CK\_CNT} - 1
$$

补充：在常见 STM32 通用定时器中，`PSC` 和 `ARR` 都是 16-bit 寄存器，所以合法范围都是 $0 \sim 65535$。任何解都必须满足 $PSC \le 65535$ 且 $ARR \le 65535$，否则需要重新选计数器时钟 $f_{CK\_CNT}$ 再算。

例：`f_CK_INT = 72MHz`，希望`f_CK_CNT = 10kHz`，定时1s：
$$
PSC = \frac{72\text{ MHz}}{10\text{ kHz}} - 1 = 7199
$$

$$
ARR = 1\text{ s} \times 10\text{ kHz} - 1 = 9999
$$

### 基本定时题的做题套路
考试中常见题型是给定 $f_{CK\_INT}$ 和目标定时时间 $T$，要求计算 $PSC$ 和 $ARR$。

步骤：
1. 先选一个好算的计数器时钟 $f_{CK\_CNT}$。
2. 计算 $PSC = \dfrac{f_{CK\_INT}}{f_{CK\_CNT}} - 1$。
3. 计算 $ARR = T \times f_{CK\_CNT} - 1$。
4. 代回 $T = \dfrac{(PSC + 1)(ARR + 1)}{f_{CK\_INT}}$ 检查。

例：`f_CK_INT = 72MHz`，要求定时`1ms`。
$$
f_{CK\_CNT} = 1\text{ MHz}
$$

$$
PSC = \frac{72000000}{1000000} - 1 = 71
$$

$$
ARR = 0.001 \times 1000000 - 1 = 999
$$

检查：
$$
T = \frac{(71 + 1)(999 + 1)}{72000000} = 0.001\text{ s} = 1\text{ ms}
$$

### 2. PWM输出：频率、周期、占空比、CCR
PWM（Pulse-Width Modulation，脉冲宽度调制）可以理解为“周期固定、高电平时间可调”的方波。
 
 - **PWM周期**：完整重复一次所用的时间。

 $$
 T_{PWM} = \frac{1}{f_{PWM}} = \frac{1}{\text{PWM频率}}
 $$

 - **PWM频率**：一秒重复多少次。

 $$
f_{PWM} = \frac{f_{CK\_INT}}{(PSC + 1)(ARR + 1)} = \frac{\text{定时器输入时钟频率}}{\text{预分频后的计数频率} \times \text{一个PWM周期的计数次数}}
$$

 - **占空比 Duty**：一个周期内高电平持续时间所占比例。

 $$
 Duty = \frac{\text{高电平时间}}{T_{PWM}} = \frac{\text{高电平持续时间}}{\text{PWM周期}}
 $$

 - **CCR**（Capture/Compare Register，捕获/比较寄存器）：PWM输出时，`CCR`用来决定一个周期内高电平持续到哪个计数值，可以理解为“高电平持续的计数次数”。

 $$
 CCR = (ARR + 1) \times Duty = (ARR + 1) \times \frac{\text{高电平时间}}{\text{PWM周期}}
 $$

 给定目标PWM频率 $f_{PWM}$：


$$
f_{CK\_CNT} = \frac{f_{CK\_INT}}{PSC + 1}
$$

$$
ARR = \frac{f_{CK\_CNT}}{f_{PWM}} - 1
$$


$$
Duty = \frac{CCR}{ARR + 1}
$$



PWM周期和占空比题的做题套路：
1. 先由`PSC`算出`f_CK_CNT`。
2. 再由目标PWM频率算`ARR`。
3. 最后由目标占空比算`CCR`。

例：定时器输入时钟`72MHz`，要求输出`100Hz`的PWM，占空比`30%`。若取`PSC = 719`，求`ARR`和`CCR`。
$$
f_{CK\_CNT} = \frac{72000000}{719 + 1} = 100000\text{ Hz}
$$

$$
ARR = \frac{100000}{100} - 1 = 999
$$

$$
CCR = (999 + 1) \times 30\% = 300
$$

答案：
$$
ARR = 999,\quad CCR = 300
$$

易错点：
- `ARR + 1`才是一个PWM周期内的实际计数次数。
- `CCR`表示高电平持续的计数次数。
 

### 3. PWM输入捕获：由CCR1、CCR2计算频率和占空比
PWM输入模式下，常用通道1捕获周期、通道2捕获高电平宽度。

若 `CCR1` 保存一个周期对应的计数值，`CCR2` 保存有效电平宽度对应的计数值：
$$
f_{Input} = \frac{f_{CK\_CNT}}{CCR1}
$$

$$
Duty = \frac{CCR2}{CCR1}
$$

$$
PulseWidth = \frac{CCR2}{f_{CK\_CNT}}
$$

若教材或程序把计数从0计到捕获值，可能写成：
$$
f_{Input} = \frac{f_{CK\_CNT}}{CCR1 + 1}
$$

$$
Duty = \frac{CCR2 + 1}{CCR1 + 1}
$$

考试计算时以题目给出的 CCR 含义为准。先写 $f_{CK\_CNT} = \dfrac{f_{CK\_INT}}{PSC + 1}$，再代入 $CCR1$、$CCR2$。

## 五、 例题6.1/实验4：TIM（Timer，定时器）基本定时控制程序

说明：`TIM` = Timer（定时器）；`RCC` = Reset and Clock Control（复位与时钟控制）；`NVIC` = Nested Vectored Interrupt Controller（嵌套向量中断控制器）。
```c
void TIM3_Int_Init(u16 arr, u16 psc)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = arr;
    TIM_TimeBaseStructure.TIM_Prescaler = psc;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);

    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 3;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM3, ENABLE);
}

void TIM3_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);
        /* 定时到达后的控制逻辑 */
    }
}
```

## 八、 彩云云库习题6
习题6重点练PSC、ARR、CCR计算，基本定时中断、PWM输出和PWM输入捕获程序结构。

### 习题6答题补充
#### 1. 影子寄存器
影子寄存器是“真正参与硬件工作的寄存器副本”。程序先写预装载寄存器，等更新事件到来时，预装载值再装入影子寄存器生效。

作用：
- 避免定时器运行中途修改ARR、CCR等参数导致当前周期波形突变。
- 让新参数在下一个更新事件统一生效，波形更稳定。

通用定时器中常见具有预装载/影子机制的寄存器：
- **ARR**：自动重装载寄存器，可用`TIM_ARRPreloadConfig(TIMx, ENABLE/DISABLE)`控制预装载。
- **CCR1-CCR4**：捕获/比较寄存器，输出比较模式下可用`TIM_OCxPreloadConfig()`控制预装载。
- **PSC**：预分频器通常也在更新事件后装入生效。

#### 2. 更新事件
更新事件是定时器把新参数装入、计数周期更新或产生更新中断/DMA请求的重要事件。

常见来源：
- 计数器上溢或下溢。
- 软件设置`UG`（Update Generation，生成更新）位产生更新。
- 从模式控制器触发重新初始化。

用途：
- 重新装载PSC、ARR影子寄存器。
- 置位更新中断标志`UIF`（Update Interrupt Flag，更新中断标志）。
- 在允许时产生更新中断或DMA请求。

#### 3. 低功耗与高精度下PSC/ARR取舍
实现同样定时时间时：
- **低功耗要求**：尽量把`PSC`设大，让`CK_CNT`较低，计数器翻转频率低，功耗更低。
- **高时间精度要求**：尽量让`CK_CNT`较高，即`PSC`较小，这样一个计数单位时间更短，定时分辨率更高。

例：5ms定时，`f_CK_INT=72MHz`：
- 低功耗可选`f_CK_CNT=1kHz`，`PSC=71999`，`ARR=4`。
- 高精度可选`f_CK_CNT=1MHz`，`PSC=71`，`ARR=4999`。

#### 4. PC10输出周期500ms方波
周期500ms意味着每250ms翻转一次电平。可用定时中断实现：

说明：`GPIO` = General-Purpose Input/Output（通用输入/输出）；`ODR` = Output Data Register（输出数据寄存器）。
```c
void GPIO_TIM_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_10;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOC, &GPIO_InitStructure);

    TIM_TimeBaseStructure.TIM_Prescaler = 7199;
    TIM_TimeBaseStructure.TIM_Period = 2499;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);

    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM3, ENABLE);
}

void TIM3_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);
        GPIOC->ODR ^= GPIO_Pin_10;
    }
}
```
这里`PSC=7199`时`f_CK_CNT=10kHz`，`ARR=2499`对应250ms翻转一次。

#### 5. 输出比较翻转与定时中断翻转区别
- **输出比较翻转**：硬件在`CNT=CCR`时自动翻转引脚，时间精确，CPU参与少。
- **定时中断翻转**：定时到后进入ISR，由软件翻转GPIO，灵活但有中断响应延迟和软件开销。

#### 6. 输入捕获测脉宽和占空比
输入捕获用于测外部信号的周期、频率、脉宽和占空比。PWM输入模式下通常：
- `CCR1`记录周期。
- `CCR2`记录高电平宽度。

$$
f_{Input} = \frac{f_{CK\_CNT}}{CCR1}
$$

$$
PulseWidth = \frac{CCR2}{f_{CK\_CNT}}
$$

$$
Duty = \frac{CCR2}{CCR1}
$$

若题目说明捕获值包含从0开始的计数，可用`CCR1 + 1`和`CCR2 + 1`。

    high_cnt = TIM_GetCapture2(TIM4);
