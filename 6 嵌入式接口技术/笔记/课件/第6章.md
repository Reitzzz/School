# 第6章 定时器与计数器 复习笔记

## 一、 定（延）时的基本方法（三种）
1. **软件延时**：用循环语句消耗CPU时间。简单但精度差，CPU不能做其他事。
2. **硬件延时电路**：用RC、555等外部电路产生延时。不占CPU，但参数调整不方便。
3. **可编程定时器/计数器**：通过MCU内部定时器设置PSC、ARR等寄存器定时。精度高、灵活、可产生中断或PWM，是本章重点。

## 二、 定时器的一般工作原理
定时器本质是对时钟脉冲计数。

- **时钟源**：提供计数脉冲，如内部时钟`CK_INT`。
- **预分频器PSC**：把输入时钟分频得到计数器时钟`CK_CNT`。
- **计数器CNT**：按`CK_CNT`递增或递减。
- **自动重装载寄存器ARR**：设定计数上限。CNT达到ARR后产生更新事件，必要时触发中断。

基本关系：
```text
f_CK_CNT = f_CK_INT / (PSC + 1)
f_Update = f_CK_INT / ((PSC + 1) * (ARR + 1))
T_Update = (PSC + 1) * (ARR + 1) / f_CK_INT
```

## 三、 STM32通用定时器的三大组成部分
- **时基单元**：由PSC、CNT、ARR等组成，负责基本计数和定时。
- **输入捕获单元**：检测外部输入边沿，把边沿到来时的CNT值锁存到CCR，用于测频率、周期、脉宽、占空比。
- **输出比较单元**：比较CNT和CCR，按比较结果改变输出电平，可产生PWM。

## 四、 TIM基本定时：PSC和ARR计算
给定内部时钟`f_CK_INT`和需要的计数器时钟`f_CK_CNT`：
```text
PSC = f_CK_INT / f_CK_CNT - 1
```

给定定时时间`T`：
```text
ARR = T * f_CK_CNT - 1
```

例：`f_CK_INT = 72MHz`，希望`f_CK_CNT = 10kHz`，定时1s：
```text
PSC = 72MHz / 10kHz - 1 = 7199
ARR = 1s * 10kHz - 1 = 9999
```

## 五、 例题6.1/实验4：TIM基本定时控制程序
```c
void TIM3_Int_Init(u16 arr, u16 psc)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = arr;
    TIM_TimeBaseStructure.TIM_Prescaler = psc;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);

    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 3;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM3, ENABLE);
}

void TIM3_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);
        /* 定时到达后的控制逻辑 */
    }
}
```

## 六、 TIM输出比较功能：PWM频率、占空比、ARR、CCR计算
PWM输出常用输出比较单元实现。

给定目标PWM频率`f_PWM`：
```text
f_PWM = f_CK_INT / ((PSC + 1) * (ARR + 1))
ARR = f_CK_CNT / f_PWM - 1
```

给定占空比`Duty`：
```text
CCR = (ARR + 1) * Duty
Duty = CCR / (ARR + 1)
```

例：`f_CK_INT=72MHz`，取`PSC=719`，则`f_CK_CNT=100kHz`。若输出`100Hz` PWM：
```text
ARR = 100kHz / 100Hz - 1 = 999
占空比25%时 CCR = (999 + 1) * 25% = 250
```

## 七、 例题6.3/实验5：TIM输出比较PWM控制程序
```c
void TIM2_PWM_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    TIM_OCInitTypeDef TIM_OCInitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    TIM_TimeBaseStructure.TIM_Period = 999;
    TIM_TimeBaseStructure.TIM_Prescaler = 719;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);

    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStructure.TIM_Pulse = 250;
    TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OC1Init(TIM2, &TIM_OCInitStructure);

    TIM_OC1PreloadConfig(TIM2, TIM_OCPreload_Enable);
    TIM_ARRPreloadConfig(TIM2, ENABLE);
    TIM_Cmd(TIM2, ENABLE);
}
```

## 八、 TIM输入捕获功能：由CCR1、CCR2计算频率和占空比
PWM输入模式下，常用通道1捕获周期、通道2捕获高电平宽度。

若`CCR1`保存一个周期对应的计数值，`CCR2`保存有效电平宽度对应的计数值：
```text
f_Input = f_CK_CNT / CCR1
Duty = CCR2 / CCR1
```

若教材或程序把计数从0计到捕获值，可能写成：
```text
f_Input = f_CK_CNT / (CCR1 + 1)
Duty = (CCR2 + 1) / (CCR1 + 1)
```

考试计算时以题目给出的CCR含义为准。先写`f_CK_CNT = f_CK_INT / (PSC + 1)`，再代入CCR1、CCR2。

## 九、 例题6.4/实验6：TIM输入捕获控制程序
```c
void TIM4_PWM_Input_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    TIM_ICInitTypeDef TIM_ICInitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM4, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING;
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    TIM_TimeBaseStructure.TIM_Period = 0xFFFF;
    TIM_TimeBaseStructure.TIM_Prescaler = 71;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM4, &TIM_TimeBaseStructure);

    TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
    TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Rising;
    TIM_ICInitStructure.TIM_ICSelection = TIM_ICSelection_DirectTI;
    TIM_ICInitStructure.TIM_ICPrescaler = TIM_ICPSC_DIV1;
    TIM_ICInitStructure.TIM_ICFilter = 0x0;
    TIM_PWMIConfig(TIM4, &TIM_ICInitStructure);

    TIM_SelectInputTrigger(TIM4, TIM_TS_TI1FP1);
    TIM_SelectSlaveMode(TIM4, TIM_SlaveMode_Reset);
    TIM_SelectMasterSlaveMode(TIM4, TIM_MasterSlaveMode_Enable);

    TIM_Cmd(TIM4, ENABLE);
}
```
