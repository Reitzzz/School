# 定时器与计数器核心知识点详解

## 一、定（延）时的基本方法

### 1. 软件延时

#### 专业术语讲解
软件延时是指**通过CPU执行一段无实际数据操作的空循环指令**（如 `for` 或 `while` 循环）来消耗固定的CPU时钟周期，从而达到延时效果。延时时间取决于循环次数、指令周期以及编译优化等级。由于CPU在延时期间被完全占用，无法响应其他中断或执行其他任务，因此属于“阻塞式”延时。

#### 通俗概念讲解
软件延时就像你在办公室里故意绕远路走路去倒水——虽然达到了“耗时间”的目的，但在这段时间里你什么事也干不了，只能一直在走。如果中途有人打电话给你，你也接不了，因为你的大脑全在数步数。这种方法简单，但效率低下，而且受到CPU主频和中断的影响，延时时间不精确。

### 2. 硬件延时电路

#### 专业术语讲解
硬件延时电路**通常由电阻、电容组成的RC充放电路或专用定时芯片（如NE555）构成**。RC电路的时间常数 $\tau = R \times C$ 决定了延时长度，当电容电压达到阈值时触发输出翻转。这种方案不占用CPU资源，<u>但延时参数由物理元件值决定，修改困难，缺乏灵活性</u>。

#### 通俗概念讲解
硬件延时就像用一个沙漏来计时——你不需要盯着它，沙漏自己流沙。**但如果你想改变计时时间，就得换一个不同大小的沙漏（更换电阻或电容）**，非常麻烦。它不占用你的精力，但灵活性很差。

### 3. 可编程定时器/计数器

#### 专业术语讲解
可编程定时器/计数器是微控制器内部集成的一个专用硬件外设，**拥有独立的时钟源和计数逻辑。开发者通过配置预分频器、自动重装载寄存器等参数，可精确设定定时周期**。定时器启动后独立于CPU核心运行，当计数值达到设定阈值时产生更新事件，通过中断请求通知CPU进行处理。这是嵌入式实时系统中实现精确时间控制的首选方法。

#### 通俗概念讲解
可编程定时器就像一个可以设置闹钟的智能厨房计时器。你设定好时间（配置寄存器），按下启动按钮，它就开始倒计时，而你完全可以去做别的事情（比如切菜）。时间到了，它会发出声音（中断）提醒你。你可以随时改变设置，非常灵活精准。这就是嵌入式开发中定时的主流方式。

## 二、定时器的一般工作原理

#### 专业术语讲解
定时器的本质是一个对固定频率时钟脉冲进行累加计数的二进制计数器。内部包含预分频器（Prescaler）、计数器（Counter）和自动重装载寄存器（ARR）。预分频器将高频的内部时钟（如72MHz）降频为计数器的工作时钟 $f_{CK\_CNT}$。计数器在该时钟驱动下从0开始向上（或向下）累加。当计数器的值与ARR中设定的目标值相等时，产生一个更新事件（UEV），可触发中断或DMA请求。同时计数器被清零（或重载）并重新开始计数，形成周期性的定时。

#### 通俗概念讲解
定时器就像一个有刻度的水桶，水龙头以固定速度滴水（时钟脉冲）。水桶里有一个浮标（计数器），每滴一滴水，浮标上升一格。你在桶壁上画一条刻度线（自动重装载值）。当浮标到达那条刻度线时，水桶会“叮”一声（触发中断），然后浮标自动回到底部重新开始。通过调整滴水速度（预分频）和刻度线位置（ARR），就能精确控制“叮”的间隔时间。

## 三、STM32通用定时器的三大组成部分

#### 专业术语讲解
STM32通用定时器（如TIM2~TIM5）由三个主要单元组成：
1. **时基单元**：包含16位预分频器寄存器（PSC）、16位计数器（CNT）、16位自动重装载寄存器（ARR）。负责产生基本的定时周期。
2. **输入捕获单元**：用于测量外部信号的频率和脉宽。当指定输入引脚出现预设的电平跳变（上升沿或下降沿）时，当前计数器的值会被立即锁存到捕获/比较寄存器（CCR）中，并产生捕获中断。
3. **输出比较单元**：用于产生PWM波形或控制输出引脚。它将计数器的值与CCR中的值进行比较，当两者相等时，根据配置的模式自动改变输出引脚的电平状态（置高、置低或翻转）。

#### 通俗概念讲解
STM32的通用定时器就像一个功能强大的智能手表，它有三个主要部件：
- **时基单元** = 手表的心跳发生器，负责产生稳定的秒信号。
- **输入捕获单元** = 手表的秒表功能。你按一下按钮，它立刻记下当前时间，用来测量外部事件持续了多久。
- **输出比较单元** = 手表的闹钟功能。你设定一个时间点，到了那个点手表就会自动输出一个电信号（比如振动或点亮屏幕）。常用于产生方波或PWM信号。

## 四、TIM基本定时参数计算

#### 专业术语讲解
设内部时钟源频率为 $f_{CK\_INT}$（STM32常用72MHz），目标计数器工作频率为 $f_{CK\_CNT}$，则预分频器寄存器值 $PSC$ 的计算公式为：
$$PSC = \frac{f_{CK\_INT}}{f_{CK\_CNT}} - 1$$
若要求定时时间为 $T_{out}$（秒），则自动重装载寄存器值 $ARR$ 的计算公式为：
$$ARR = T_{out} \times f_{CK\_CNT} - 1$$
定时器的更新频率（中断频率）$f_{Update}$ 满足：
$$f_{Update} = \frac{f_{CK\_INT}}{(PSC + 1) \cdot (ARR + 1)}$$

注意：PSC和ARR寄存器实际写入的值需要减去1，因为计数从0开始。

#### 通俗概念讲解
想象你有一个72MHz的水龙头（每秒滴7200万滴水）。你想让水桶每1秒响一次。你可以先装一个调速器（预分频器），把滴水速度降下来。比如调到每秒滴10万滴（$f_{CK\_CNT}=100KHz$），那么调速器的档位需要设为 $72M/100K - 1 = 719$。然后，你要在水桶上画刻度线：每秒滴10万滴，想让水桶1秒响一次，刻度线应该画在第10万滴水的位置，但计数器从0开始，所以 $ARR = 100000 - 1 = 99999$。这样，每滴满10万滴水（1秒），水桶就响一次。

## 五、基本定时控制程序逻辑 (例题6.1)

#### 专业术语讲解
该程序演示了如何配置STM32的TIM3定时器产生1秒的周期性中断。步骤如下：
1. 使能TIM3所在的APB1总线时钟。
2. 配置时基单元：设置ARR和PSC，选择向上计数模式。
3. 使能TIM3的更新中断。
4. 配置NVIC中断优先级，使能TIM3中断通道。
5. 启动定时器。
6. 编写中断服务函数，在函数中检查更新中断标志，清除标志后执行用户任务。

#### 通俗概念讲解
这段代码就像在设置一个每隔1秒响一次的闹钟：
- 第一步：给闹钟通电（使能时钟）。
- 第二步：设定闹钟的计时周期（ARR和PSC）。
- 第三步：允许闹钟到点发出声音（使能中断）。
- 第四步：告诉CPU，这个闹钟的声音优先级是多少（NVIC配置）。
- 第五步：按下启动按钮（使能定时器）。
- 第六步：当闹钟响起时（中断服务函数），先确认是这个闹钟在响（检查标志），然后关闭铃声（清除标志），最后做你真正想做的事（翻转LED）。

```c
void TIM3_Int_Init(u16 arr, u16 psc) {
    TIM_TimeBaseInitTypeDef  TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE); // 1. 使能定时器时钟

    // 2. 配置时基单元
    TIM_TimeBaseStructure.TIM_Period = arr;             // 设置ARR
    TIM_TimeBaseStructure.TIM_Prescaler = psc;          // 设置PSC
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up; // 向上计数
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    // 3. 开启定时器更新中断
    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);

    // 4. NVIC中断优先级配置
    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 3;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM3, ENABLE); // 5. 使能定时器
}

// 6. 编写中断服务函数
void TIM3_IRQHandler(void) {
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET) {
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update); // 必须手动清除标志位
        // 执行用户逻辑，如翻转LED
    }
}
```

## 六、TIM输出比较功能（PWM输出）

#### 专业术语讲解
输出比较单元可以产生脉宽调制（PWM）信号。通过配置定时器为PWM模式，计数器从0向上计数到ARR，并与捕获/比较寄存器（CCR）的值进行比较。当计数器的值小于CCR时，输出有效电平（如高电平）；当大于等于CCR时，输出无效电平（如低电平）。PWM的频率由 $f_{Update} = f_{CK\_INT} / [(PSC+1)(ARR+1)]$ 决定，占空比由 $Duty = (CCR+1)/(ARR+1)$ 决定（具体公式取决于计数模式和极性设置）。

**示例计算**：要求PA0输出频率100Hz，占空比25%的矩形波。
- 取 $PSC = 719$，则 $f_{CK\_CNT} = 72MHz / 720 = 100KHz$。
- 为得到100Hz，$ARR = 100KHz / 100Hz - 1 = 999$。
- 占空比25%，$CCR = (999+1) \times 25\% = 250$。

#### 通俗概念讲解
PWM输出就像是一个可以快速开关的灯光调光器。定时器每秒钟开关很多次，通过控制“亮”的时间占总周期的比例（占空比）来调节平均亮度。频率就是开关的快慢，占空比就是亮的时间比例。例如，要求输出100Hz的波形，即每秒钟开关100次，每次周期10ms。占空比25%意味着每个周期内高电平保持2.5ms，低电平7.5ms。代码就是配置这个调光器的参数。

```c
void TIM2_PWM_Init(void) {
    GPIO_InitTypeDef GPIO_InitStr;
    TIM_TimeBaseInitTypeDef TIM_Base;
    TIM_OCInitTypeDef TIM_OCInitStr;

    // 1. 时钟使能 (GPIO和TIM2)
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    // 2. GPIO配置为复用推挽输出 (AF_PP)
    GPIO_InitStr.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStr.GPIO_Mode = GPIO_Mode_AF_PP; 
    GPIO_InitStr.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStr);

    // 3. 时基单元配置 (f=100Hz)
    TIM_Base.TIM_Period = 999; 
    TIM_Base.TIM_Prescaler = 719;
    TIM_Base.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_Base.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_Base);

    // 4. 输出比较通道配置 (PWM模式1)
    TIM_OCInitStr.TIM_OCMode = TIM_OCMode_PWM1; // 计数值<CCR时为有效电平
    TIM_OCInitStr.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStr.TIM_Pulse = 250;              // CCR = 250 (占空比25%)
    TIM_OCInitStr.TIM_OCPolarity = TIM_OCPolarity_High; // 高电平为有效电平
    TIM_OC1Init(TIM2, &TIM_OCInitStr);

    TIM_OC1PreloadConfig(TIM2, TIM_OCPreload_Enable); // 使能预装载寄存器
    TIM_Cmd(TIM2, ENABLE);
}
```

## 七、TIM输入捕获功能（PWM输入模式）

#### 专业术语讲解
输入捕获单元可以测量外部PWM信号的频率和占空比。配置定时器为PWM输入模式时，一个通道（如CH1）被设置为捕获上升沿，另一个通道（CH2）自动设置为捕获下降沿。同时将从模式控制器设置为“复位模式”，并选择上升沿作为触发源。当上升沿到来时，计数器CNT的值被锁存到CCR1中（记录周期），同时CNT被硬件复位。随后下降沿到来时，CNT的值被锁存到CCR2中（记录高电平宽度）。由此可得：
- 信号周期 $T = (CCR1 + 1) \times T_{CK\_CNT}$，频率 $f = \frac{f_{CK\_CNT}}{CCR1 + 1}$
- 高电平时间 $T_{high} = (CCR2 + 1) \times T_{CK\_CNT}$，占空比 $Duty = \frac{CCR2 + 1}{CCR1 + 1}$

#### 通俗概念讲解
输入捕获就像用秒表测量一个跑步选手的每圈时间和冲刺时间。你设置秒表在选手经过起点（上升沿）时开始计时并记录圈时（CCR1），同时秒表自动归零重新计时；当选手经过终点线（下降沿）时，记录这次冲刺用时（CCR2）。那么一圈的总时间就是CCR1，冲刺时间就是CCR2，占空比就是冲刺时间/总时间。通过这种方式，可以精确测出外部信号的频率和占空比。

```c
void TIM4_Cap_Init(void) {
    GPIO_InitTypeDef GPIO_InitStr;
    TIM_TimeBaseInitTypeDef TIM_Base;
    TIM_ICInitTypeDef TIM_ICInitStr;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM4, ENABLE);

    // 1. GPIO配置为浮空输入 (PB6对应TIM4_CH1)
    GPIO_InitStr.GPIO_Pin = GPIO_Pin_6;
    GPIO_InitStr.GPIO_Mode = GPIO_Mode_IN_FLOATING;
    GPIO_Init(GPIOB, &GPIO_InitStr);

    // 2. 时基配置 (f_CK_CNT=1MHz，即测量精度1us)
    TIM_Base.TIM_Period = 0xFFFF; // 自动重装载设为最大，防止溢出
    TIM_Base.TIM_Prescaler = 71;  // PSC = 71
    TIM_Base.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_Base.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM4, &TIM_Base);

    // 3. 配置PWM输入捕获
    TIM_ICInitStr.TIM_Channel = TIM_Channel_1;
    TIM_ICInitStr.TIM_ICPolarity = TIM_ICPolarity_Rising;   // 上升沿捕获
    TIM_ICInitStr.TIM_ICSelection = TIM_ICSelection_DirectTI;
    TIM_ICInitStr.TIM_ICPrescaler = TIM_ICPSC_DIV1;
    TIM_ICInitStr.TIM_ICFilter = 0x0;
    TIM_PWMIConfig(TIM4, &TIM_ICInitStr); // 自动配置通道2为相反极性以测脉宽

    // 4. 选择输入触发源及从模式 (Reset模式)
    TIM_SelectInputTrigger(TIM4, TIM_TS_TI1FP1); // 触发源为通道1
    TIM_SelectSlaveMode(TIM4, TIM_SlaveMode_Reset); // 触发时复位CNT

    TIM_Cmd(TIM4, ENABLE);
}
```

## 八、重点补充：影子寄存器

#### 专业术语讲解
影子寄存器是STM32定时器中的一种双缓冲机制。每个关键参数寄存器（如PSC、ARR、CCR）实际上对应两个物理寄存器：**预装载寄存器**和**影子寄存器**。程序访问的是预装载寄存器，而影子寄存器才是真正控制定时器运行的寄存器。只有在定时器发生更新事件（UEV）时，预装载寄存器的内容才会被一次性拷贝到影子寄存器中。这样设计可以避免在定时器运行过程中修改参数导致当前计数周期出现异常波形或时序错误。通过 `TIM_ARRPreloadConfig()` 函数可以控制自动重装载寄存器的预装载使能。

#### 通俗概念讲解
影子寄存器就像舞台后台的化妆间和舞台上的演员。你可以提前给后台的替身（预装载寄存器）换好服装（修改参数），但只有等到幕间休息（更新事件发生时），替身才会走上舞台变成实际表演的演员（影子寄存器）。这样观众（硬件逻辑）看到的表演（波形）不会在演出中途突然变装而显得突兀。它保证了参数修改的平滑过渡，尤其是在PWM输出等实时性要求高的场景下，避免产生毛刺或错误的脉冲宽度。

```c
// 使能ARR预装载（推荐开启）
TIM_ARRPreloadConfig(TIMx, ENABLE);
// 禁止ARR预装载（修改立即生效，可能导致波形异常）
TIM_ARRPreloadConfig(TIMx, DISABLE);
```
