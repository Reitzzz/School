### 第4章 接口技术 核心知识点笔记（完整版）

---

#### 一、 IO接口的概念、作用、底层逻辑与地址编码

* **1. IO接口的概念**
    * IO接口（Input/Output Interface）是CPU与外部设备之间进行信息交换的硬件逻辑电路及控制部件，充当**中转站**或**桥梁**。
* **2. IO接口电路的作用（考点扩展）**
    * **数据缓冲与锁存**：协调CPU与外设之间的极大的速度差异。
    * **信号转换**：包括电平转换（数字逻辑电平与模拟/高压信号之间的转换）。
    * **数据格式转换（重要）**：CPU内部采用并行数据总线，部分外设采用串行传输，接口需完成串并转换。
    * **时序控制（重要）**：接口协助CPU提供外设需要的特定时序控制信号。
    * **设备寻址**：识别CPU要访问的具体外设。
* **3. 输入输出硬件底层逻辑电路（常考）**
    * **输入接口**：需要**缓冲器（如三态门）**。外设数据有效时间不可控，缓冲器隔离信号，仅在CPU发出读命令时打开门控允许数据进入总线。
    * **输出接口**：需要**锁存器（如D触发器）**。CPU送出的数据转瞬即逝，锁存器将数据保存下来，直到慢速外设取走。
* **4. 接口和端口的区别**
    * **接口 (Interface)**：指包含具体硬件电路的整体。
    * **端口 (Port)**：指接口电路中可以被CPU直接通过地址寻址访问的**寄存器**。 通常分为：**数据端口**、**状态端口**、**控制端口**。CPU通过访问不同端口实现对外设的控制。
* **5. IO端口地址编码方式**
    * **统一编址（内存映射）**：IO端口地址和内存地址统一分配在同一个地址空间中。**ARM Cortex-M系列（如STM32）采用此方式**。优点是可以使用丰富的内存操作指令来操作IO端口；缺点是占用了部分内存地址空间。
    * **独立编址**：IO端口有独立地址空间，如x86架构，需要使用专用的指令（如 `IN` / `OUT`）进行访问。

#### 二、 CPU与外设之间数据传输的四种方式

这是核心重点，需掌握各方式的工作原理及对CPU资源的占用情况：

* **1. 无条件传送方式**
    * **原理**：硬件和软件最简单，CPU认为外设随时处于就绪状态，直接执行IO指令读写。
    * **特点**：只适用于极慢或总是就绪的简单外设（如LED灯、拨码开关）。
* **2. 查询（轮询）传送方式**
    * **标准执行流程（4步走）**：
        1. CPU首先从I/O接口读取状态端口的状态字。
        2. CPU测试状态标志位，判断外设数据是否就绪。
        3. 若未准备好，CPU循环执行上述读取和测试操作（原地等待）。
        4. 若已准备好，CPU向数据端口发读/写指令，完成数据传输。
    * **特点**：硬件简单；但由于CPU频繁轮询，导致**CPU利用率极低**，系统实时性差。
* **3. 中断传送方式**
    * **原理**：平时CPU执行主程序。当外设准备就绪时主动向CPU发出中断请求，CPU响应后才暂停当前工作进行数据传输。
    * **特点**：大大提高了**CPU的利用率**和系统的实时响应能力。绝大多数外设（如串口接收、定时器）都采用此方式。
* **4. DMA（直接存储器存取）方式**
    * **原理**：数据传输由专门的DMA控制器接管，数据直接在内存与外设之间高速传输，**传输过程无需CPU干预**。
    * **特点**：适合大批量、高速数据的传输（如ADC连续采样、显示屏刷新）。

#### 三、 STM32 GPIO的 8 种工作模式（全解析）

GPIO引脚配置需根据不同外设需求选择以下8种模式之一：

* **【输入模式】**
    * **1. 模拟输入**：引脚直接连接内部ADC，用于模数转换器的模拟信号采集。
    * **2. 浮空输入**：引脚处于悬空状态。用于标准数字量输入（需外部硬件处理抗干扰）或 USART的RX引脚。
    * **3. 下拉输入**：引脚内部接下拉电阻（至GND），用于需要默认低电平的数字信号输入。
    * **4. 上拉输入**：引脚内部接上拉电阻（至VCC），用于需要默认高电平的数字信号输入。
* **【输出模式】**
    * **5. 开漏输出 (Open-Drain)**：
        * **原理**：内部仅有N-MOS管。只能主动拉低输出低电平，无法主动输出高电平，必须依靠外部上拉电阻才能输出高电平。
        * **应用**：用于需要改变输出电平幅度的场合（电平转换）；适用于多设备挂载在同一总线上的“线与”逻辑应用（如I2C总线）。
    * **6. 推挽输出 (Push-Pull)**：
        * **原理**：内部由P-MOS和N-MOS管组成。可以直接主动输出强高电平和低电平。
        * **应用**：驱动能力强，电平切换快。广泛用于直接驱动LED、发送普通数字逻辑信号。
* **【复用模式】**（将引脚控制权交给片内外设）
    * **7. 复用开漏输出**：用于片内硬件外设（如硬件I2C）的开漏输出。
    * **8. 复用推挽输出**：用于片内硬件外设（如SPI的SCK/MOSI、USART的TX）的推挽输出。

> **补充概念：使用上下拉电阻的场景**
> 当引脚处于悬空防止杂波干扰误动作时；为了增强电路驱动能力时；输出引脚为开漏结构时；以及为总线设备设定默认电平时。

#### 四、 掌握GPIO的核心端口寄存器

以STM32F1系列为例，操作GPIO本质上就是读写以下寄存器：

* **1. 配置寄存器：CRL 和 CRH (或 MODER)**
    * **作用**：用于配置各个GPIO引脚的工作模式（输入/输出方式）和输出速度。
    * **CRL**：控制引脚 Px0 到 Px7。
    * **CRH**：控制引脚 Px8 到 Px15。
* **2. 数据寄存器：IDR 和 ODR**
    * **IDR (输入数据寄存器)**：只读，用于读取对应GPIO引脚当前外部的电平状态。
    * **ODR (输出数据寄存器)**：可读写，向该寄存器写入数据可以控制对应GPIO引脚输出高低电平。
* **3. 位控制寄存器：BSRR 和 BRR**
    * **BSRR (端口位设置/清除寄存器)**：用于原子性地对ODR的特定位进行置1（Set）或清0（Reset），且不影响其他位的状态。
    * **BRR (端口位清除寄存器)**：专门用于原子性地将ODR的特定位清0。
* **4. 配置锁定寄存器：LCKR（补充）**
    * **作用**：用于锁定GPIO端口的配置参数，防止意外修改。

#### 五、 GPIO位操作的三种实现方法

在嵌入式编程中，控制单个引脚而不影响其他引脚至关重要，有以下三种方法：

* **1. 读-改-写（操作ODR寄存器）**
    * 先读取输出数据寄存器（ODR），使用按位与（&）掩码清除目标位，或使用按位或（|）掩码设置目标位，最后将结果写回ODR寄存器。
* **2. 直接写寄存器（操作BSRR/BRR寄存器）**
    * 无需读取原状态，直接向BSRR或BRR的特定位写入数据1。硬件会自动屏蔽其他位，直接改变ODR中对应引脚的状态，效率高且在中断中绝对安全。
* **3. 位带操作（Bit-Banding）**
    * 通过访问MCU中专门映射到具体某个寄存器位的“位带别名区地址”，向别名地址写入字数据，由硬件直接映射并完成对该特定位的原子级置位或复位。

#### 六、 控制程序与底层配置逻辑（库函数版）

**典型例题：将PA0配置为输出，并使用库函数对其置位（输出高电平）。**
```c
// 库函数置位单句代码
GPIO_SetBits(GPIOA, GPIO_Pin_0); 
```

**库函数 `GPIO_Init()` 的底层执行逻辑分析：**
* **用到什么数据结构？**
    主要用到了 `GPIO_InitTypeDef` 结构体。它封装了初始化所需的三个核心参数：引脚标号（`GPIO_Pin`）、工作模式（`GPIO_Mode`）和输出速率（`GPIO_Speed`）。
* **底层是如何配置寄存器的？**
    `GPIO_Init()` 函数内部会读取该结构体中的参数。它首先通过条件判断定位到是配置低8位引脚（操作CRL寄存器）还是高8位引脚（操作CRH寄存器）。随后，利用**移位运算和位掩码技术**，计算出代表这些配置的二进制数值。最后，通过指针操作将计算出的数值直接写入到对应的GPIO配置寄存器中，从而改变底层硬件状态。

```c
// 标准初始化模板参考
void GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    // 1. 开时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    // 2. 配模式 (填充结构体)
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP; 
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    // 3. 写入底层配置寄存器
    GPIO_Init(GPIOA, &GPIO_InitStructure); 
}
```
