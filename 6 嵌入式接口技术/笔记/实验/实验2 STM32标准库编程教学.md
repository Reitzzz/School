# STM32标准库编程教学

## 实验目的

本实验的目的是：**用STM32标准外设库实现按键控制LED的功能**。

实验1用寄存器实现了这个功能，实验2要求用标准库重新实现。实验报告中需要截图的代码，就是你自己需要写的部分。

---

## 从问题出发：为什么要这样做？

### 第一步：为什么需要使能时钟？

STM32的所有外设（GPIO、USART、TIM等）默认是关闭的，目的是**降低功耗**。就像家里不用的电器要关掉一样。

所以使用任何外设前，必须先给它"通电"——也就是使能时钟。

```c
// 使能GPIOB和GPIOE的时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);
```

**问题**：为什么是`RCC_APB2`而不是`RCC_APB1`？

**答案**：GPIOB和GPIOE挂载在APB2总线上。不同的外设挂在不同的总线上，这在芯片手册中有说明。对于初学者，记住：GPIO通常在APB2上。

---

### 第二步：为什么需要配置GPIO模式？

一个GPIO引脚可以有多种功能：输入、输出、模拟、复用等。我们必须告诉芯片这个引脚用来干什么。

**对于LED（输出）**：
- 需要**输出高/低电平来控制LED亮灭**
- 所以选择"推挽输出"模式

**对于按键（输入）**：
- **需要读取外部电平是高还是低**
- 所以选择"输入"模式
- **选择"上拉输入"是因为按键按下时接地（低电平），松开时需要稳定的高电平**

```c
// LED配置为推挽输出
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;

// 按键配置为上拉输入
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
```

实验2的目录结构是这样的：

```
USER_APP/           ← 你写主程序的地方
```

## 实验步骤：你需要写什么代码？

### 实验报告截图1：按键驱动（key_driver）

**你需要写的代码**：

`key_driver.h` - 头文件，声明函数和定义按键读取宏：

```c
#include "stm32f10x_conf.h"

// 读取按键状态的宏
// KEY0按下时为低电平，所以读取到0表示按下
#define KEY0  GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4) //为GPIOE上第4个引脚的电平 即按键的开关情况取别名为key0
#define KEY1  GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_3) //为GPIOE上第3个引脚的电平 即按键的开关情况取别名为key1
#define KEY2  GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_2) //为GPIOE上第2个引脚的电平 即按键的开关情况取别名为key2

// 按键GPIO初始化函数声明
void KEY_GPIO_Config(void);
```

`key_driver.c` - 源文件，实现按键初始化：

```c
#include "key_driver.h"

void KEY_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    
    // 问题：为什么这里只初始化输入？
    // 因为按键只需要读取状态，不需要输出
    
    // 1. 使能GPIOE时钟（给GPIOE通电，让它开始工作）
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOE, ENABLE);
    
    // 2. 配置PE2、PE3、PE4为上拉输入
    
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2 | GPIO_Pin_3 | GPIO_Pin_4; //GPIO_Pin_2|GPIO_Pin_3|GPIO_Pin_4：选择这三个引脚
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU; //GPIO_Mode_IPU：上拉输入，松开时为高电平，按下时为低电平
    GPIO_Init(GPIOE, &GPIO_InitStructure); //把上面配置好的参数应用到GPIOE上
}
```

**思考**：为什么用上拉输入而不是下拉输入？

**答案**：看电路图，按键按下时接地（低电平），松开时需要外部或内部上拉到高电平。如果用下拉输入，松开时就是低电平，无法区分按下和松开。

### 实验报告截图2：LED驱动（led_driver）

**你需要写的代码**：

`led_driver.h` - 头文件，声明LED控制函数：

```c
#include "stm32f10x_conf.h"

// 函数声明
void LED_GPIO_Config(void);   // LED GPIO初始化
void LED0_LightUp(void);       // LED0点亮
void LED1_LightUp(void);       // LED1点亮
void LED0_PutOut(void);        // LED0熄灭
void LED1_PutOut(void);        // LED1熄灭
```

`led_driver.c` - 源文件，实现LED初始化和控制：

```c
#include "led_driver.h"

void LED_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    
    // 1. 使能GPIOB和GPIOE时钟（LED接在这两个端口上）
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);
    
    // 2. 配置PB5为推挽输出（LED0）
    
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5; //在配置表上填：要配置哪个引脚
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;  //GPIO_Mode_Out_PP：推挽输出，可以输出高/低电平
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz; //GPIO_Speed_50MHz：输出速度，对于LED控制足够
    GPIO_Init(GPIOB, &GPIO_InitStructure);
    
    // 3. 默认GPIOB的5号引脚输出高电平，关闭LED
    //    - 为什么是高电平熄灭？因为LED阳极接电源，阴极接GPIO
    //    - GPIO输出高电平，两端无电压差，LED不亮
    GPIO_SetBits(GPIOB, GPIO_Pin_5);  
    
    // 4. 配置PE5为推挽输出（LED1）
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5; //在配置表上填：要配置哪个引脚
    GPIO_Init(GPIOE, &GPIO_InitStructure); //把上面配置好的参数应用到GPIOE上
    GPIO_SetBits(GPIOE, GPIO_Pin_5); 
}

// LED0点亮：输出低电平，电流从电源流过LED到GPIO
void LED0_LightUp(void)
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_5);
}

// LED0熄灭：输出高电平，LED两端无电压差
void LED0_PutOut(void)
{
    GPIO_SetBits(GPIOB, GPIO_Pin_5);
}

// LED1点亮
void LED1_LightUp(void)
{
    GPIO_ResetBits(GPIOE, GPIO_Pin_5);
}

// LED1熄灭
void LED1_PutOut(void)
{
    GPIO_SetBits(GPIOE, GPIO_Pin_5);
}
```

**思考**：为什么LED用推挽输出而不是开漏输出？

**答案**：推挽输出可以主动输出高/低电平，驱动能力强。开漏输出只能主动拉低，高电平需要外部上拉，适合I2C等需要线与的场合。LED控制用推挽更直接。

### 实验报告截图3：主程序（main.c）

**你需要写的代码**：

```c
#include "key_driver.h"
#include "led_driver.h"

int main(void)
{
    // 初始化：配置按键和LED的GPIO
    KEY_GPIO_Config();
    LED_GPIO_Config();
    
    // 主循环：不断检测按键状态，控制LED
    while(1)
    {
        // 读取按键状态
        // KEY0、KEY1、KEY2都是读取GPIO输入电平
        // 0表示按下，1表示松开
        
        if((KEY0 == 1) && (KEY1 == 1) && (KEY2 == 1))
        {
            // 没有按键按下：两个LED都熄灭
            LED0_PutOut();
            LED1_PutOut();
        }
        
        if((KEY0 == 1) && (KEY1 == 1) && (KEY2 == 0))
        {
            // KEY2按下：LED0亮，LED1灭
            LED0_LightUp();
            LED1_PutOut();
        }
        
        if((KEY0 == 1) && (KEY1 == 0) && (KEY2 == 1))
        {
            // KEY1按下：LED0灭，LED1亮
            LED0_PutOut();
            LED1_LightUp();
        }
        
        if((KEY0 == 0) && (KEY1 == 1) && (KEY2 == 1))
        {
            // KEY0按下：两个LED都亮
            LED0_LightUp();
            LED1_LightUp();
        }
    }
}
```

**思考**：为什么用if而不用switch？

**答案**：这里每个if条件是独立的，不是互斥的。虽然实际上只有一个按键按下，但用if更直观。如果用switch需要先组合按键状态，代码会更复杂。

## 标准库函数速查

| 你想做什么 | 用什么函数 | 示例 |
|-----------|-----------|------|
| 使能GPIO时钟 | `RCC_APB2PeriphClockCmd()` | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);` |
| 初始化GPIO | `GPIO_Init()` | `GPIO_Init(GPIOB, &GPIO_InitStructure);` |
| 输出高电平 | `GPIO_SetBits()` | `GPIO_SetBits(GPIOB, GPIO_Pin_5);` |
| 输出低电平 | `GPIO_ResetBits()` | `GPIO_ResetBits(GPIOB, GPIO_Pin_5);` |
| 读取输入状态 | `GPIO_ReadInputDataBit()` | `KEY0 = GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4);` |

## 常见错误

1. **忘记使能时钟**
   - 症状：配置了GPIO但不工作
   - 原因：外设时钟没开，等于没通电

2. **模式配错**
   - 症状：输出没反应或输入读不到
   - 原因：输出配成输入，或输入配成输出

3. **引脚号写错**
   - 症状：控制的不是预期的LED
   - 原因：`GPIO_Pin_5`和`GPIO_Pin_4`搞混了
