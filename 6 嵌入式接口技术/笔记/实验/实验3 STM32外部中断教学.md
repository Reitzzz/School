# STM32外部中断教学

## 实验目的

本实验的目的是：**用STM32外部中断（EXTI）实现按键中断控制LED和蜂鸣器**。

实验2用轮询方式（在while循环里不断检测按键）控制LED，实验3改用中断方式——按键按下时自动触发中断，CPU不需要一直"盯着"按键。

---

## 从问题出发：为什么要用中断？

### 轮询 vs 中断

**实验2的轮询方式**：
```c
while(1)
{
    if(KEY0 == 0)  // CPU一直在这里检查按键
    {
        LED0_LightUp();
    }
    // ... 检查其他按键
}
```
- 问题：CPU大部分时间在做无用功（按键没按下时也在反复检查）
- 好处：简单直观

**实验3的中断方式**：
```c
// 初始化时配置好中断，然后main里什么都不用做
// 按键按下时，硬件自动通知CPU，CPU再去处理
```
- 好处：CPU空闲时可以做其他事，响应更及时
- 代价：配置更复杂

**类比**：轮询就像你每隔5秒去看一次门口有没有快递；中断就像快递员到了按门铃，你该干嘛干嘛，门铃响了再去开门。

---

### 实验报告截图1：按键中断配置（key_driver）

**你需要写的代码**：

`key_driver.h` 中已经给出了函数声明，知道主程序后面能调用这个函数即可：

```c
void KEY_GPIO_EXTI_NVIC_Config(void); // 按键中断初始化配置
```

真正需要补全的是 `key_driver.c` 中的中断配置函数：

```c
#include "misc.h"
#include "stm32f10x_conf.h"

void KEY_GPIO_EXTI_NVIC_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    EXTI_InitTypeDef EXTI_InitStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    // ========== 第一步：使能时钟 ==========
    // 需要使能3个时钟：
    // 1. GPIO端口时钟（配置引脚用）
    // 2. AFIO时钟（配置外部中断映射用）
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOE | RCC_APB2Periph_AFIO, ENABLE);

    // ========== 第二步：配置GPIO为输入 ==========
    // KEY0->PE4, KEY1->PE3, KEY2->PE2, KEY3(WK_UP)->PA0
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2 | GPIO_Pin_3 | GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU; // 上拉输入
    GPIO_Init(GPIOE, &GPIO_InitStructure);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPD; // 下拉输入（WK_UP按下为高电平）
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // ========== 第三步：配置GPIO引脚到EXTI中断线的映射 ==========
    // STM32的EXTI线只有16条（EXTI0~EXTI15），但有几十个GPIO引脚
    // 所以需要通过AFIO把具体引脚"连接"到对应的EXTI线
    // PE4 -> EXTI4, PE3 -> EXTI3, PE2 -> EXTI2, PA0 -> EXTI0
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource4); // PE4映射到EXTI4
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource3); // PE3映射到EXTI3
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource2); // PE2映射到EXTI2
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0); // PA0映射到EXTI0

    // ========== 第四步：配置EXTI中断线 ==========
    // EXTI可以配置为：上升沿触发、下降沿触发、双边沿触发
    // KEY0~KEY2按下为低电平，所以用下降沿触发
    // KEY3(WK_UP)按下为高电平，所以用上升沿触发

    EXTI_InitStructure.EXTI_Line = EXTI_Line0 | EXTI_Line2 | EXTI_Line3 | EXTI_Line4;
    EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;      // 中断模式（不是事件模式）
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;  // 下降沿触发
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;                // 使能这些中断线
    EXTI_Init(&EXTI_InitStructure);

    // 单独配置EXTI0为上升沿触发（WK_UP按下为高电平）
    EXTI_InitStructure.EXTI_Line = EXTI_Line0;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Rising;   // 上升沿触发
    EXTI_Init(&EXTI_InitStructure);

    // ========== 第五步：配置NVIC（中断优先级控制器） ==========
    // NVIC决定：多个中断同时发生时，谁先被处理
    // 优先级数值越小，优先级越高

    NVIC_InitStructure.NVIC_IRQChannel = EXTI0_IRQn;         // EXTI0中断通道
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0; // 抢占优先级（数值越小越高）
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;        // 子优先级
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;           // 使能这个中断通道
    NVIC_Init(&NVIC_InitStructure);

    NVIC_InitStructure.NVIC_IRQChannel = EXTI2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_Init(&NVIC_InitStructure);

    NVIC_InitStructure.NVIC_IRQChannel = EXTI3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
    NVIC_Init(&NVIC_InitStructure);

    NVIC_InitStructure.NVIC_IRQChannel = EXTI4_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 3;
    NVIC_Init(&NVIC_InitStructure);
}
```

**重点理解：5个步骤的逻辑链**

```
使能时钟 -> 配置GPIO输入 -> 映射EXTI线 -> 配置EXTI触发方式 -> 配置NVIC优先级
```

**思考**：为什么需要 `GPIO_EXTILineConfig()` 这一步？

**答案**：STM32的引脚和EXTI线不是一对一的。比如EXTI4可以是PE4、PB4、PC4等。所以需要通过AFIO告诉芯片："我要把PE4接到EXTI4上"。

### 实验报告截图1补充：LED驱动配置（led_driver）

**你需要写的代码**：

`led_driver.c` — 补全 `LED_GPIO_Config()`，让LED0和LED1对应的GPIO能正常输出：

```c
void LED_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    // LED0接在PB5，LED1接在PE5，所以要同时使能GPIOB和GPIOE时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);

    // 配置PB5为推挽输出，用来控制LED0
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    // 配置PE5为推挽输出，用来控制LED1
    GPIO_Init(GPIOE, &GPIO_InitStructure);

    // 默认输出低电平，保持和本实验提供的点亮/熄灭函数逻辑一致
    GPIO_ResetBits(GPIOB, GPIO_Pin_5);
    GPIO_ResetBits(GPIOE, GPIO_Pin_5);
}
```

**思考**：为什么实验3还要写 `LED_GPIO_Config()`？

**答案**：中断服务函数里会调用 `LED0_Flash()`、`LED1_Flash()` 和 `LED01_Flash()`，这些函数只是改变PB5、PE5的输出电平。如果没有先把PB5、PE5配置成输出模式，后面的闪烁函数就没有可靠的硬件基础。

### 实验报告截图2：中断服务函数（it.c）

**你需要写的代码**：

```c
#include "key_driver.h"
#include "led_driver.h"
#include "beep_driver.h"
#include "sw_delay.h"

// EXTI0中断服务函数（WK_UP按下触发）
void EXTI0_IRQHandler(void)
{
    if(EXTI_GetITStatus(EXTI_Line0) != RESET) // 检查是不是EXTI0触发的中断
    {
        BEEP_Sound();      // KEY3(WK_UP)按下：蜂鸣器响一声
        EXTI_ClearITPendingBit(EXTI_Line0); // 清除中断标志位（非常重要！）
    }
}

// EXTI2中断服务函数（KEY2按下触发）
void EXTI2_IRQHandler(void)
{
    if(EXTI_GetITStatus(EXTI_Line2) != RESET)
    {
        LED01_Flash();     // KEY2按下：LED0和LED1同时闪烁4次
        EXTI_ClearITPendingBit(EXTI_Line2);
    }
}

// EXTI3中断服务函数（KEY1按下触发）
void EXTI3_IRQHandler(void)
{
    if(EXTI_GetITStatus(EXTI_Line3) != RESET)
    {
        LED1_Flash();      // KEY1按下：LED1闪烁4次
        EXTI_ClearITPendingBit(EXTI_Line3);
    }
}

// EXTI4中断服务函数（KEY0按下触发）
void EXTI4_IRQHandler(void)
{
    if(EXTI_GetITStatus(EXTI_Line4) != RESET)
    {
        LED0_Flash();      // KEY0按下：LED0闪烁4次
        EXTI_ClearITPendingBit(EXTI_Line4);
    }
}
```

**关键点**：
1. 函数名必须是 `EXTI0_IRQHandler`、`EXTI2_IRQHandler` 等，不能改名
2. 必须先检查中断标志位 `EXTI_GetITStatus()`，确认是这个中断触发的
3. **必须清除中断标志位** `EXTI_ClearITPendingBit()`，否则会反复进入中断

### 实验报告截图3：主程序（main.c）

**你需要写的代码**：

```c
#include "key_driver.h"
#include "led_driver.h"
#include "beep_driver.h"

int main(void)
{
    // 初始化LED和蜂鸣器
    LED_GPIO_Config();
    BEEP_GPIO_Config();

    // 初始化按键中断配置
    KEY_GPIO_EXTI_NVIC_Config();

    // 主循环：什么都不用做！
    // 按键按下时，硬件会自动跳转到对应的中断服务函数
    while(1)
    {
        // CPU可以在这里做其他事情，比如低功耗等待
    }
}
```

**思考**：main.c里几乎没有代码，那LED是怎么亮的？

**答案**：按键按下时，硬件自动触发中断，CPU暂停main程序，跳转到 `EXTI2_IRQHandler` 等函数执行，执行完再回来。这就是中断的核心思想。

## 标准库函数速查

| 你想做什么 | 用什么函数 | 示例 |
|-----------|-----------|------|
| 使能AFIO时钟 | `RCC_APB2PeriphClockCmd()` | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);` |
| 映射EXTI线 | `GPIO_EXTILineConfig()` | `GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource4);` |
| 初始化EXTI | `EXTI_Init()` | `EXTI_Init(&EXTI_InitStructure);` |
| 初始化NVIC | `NVIC_Init()` | `NVIC_Init(&NVIC_InitStructure);` |
| 检查中断标志 | `EXTI_GetITStatus()` | `EXTI_GetITStatus(EXTI_Line0) != RESET` |
| 清除中断标志 | `EXTI_ClearITPendingBit()` | `EXTI_ClearITPendingBit(EXTI_Line0);` |

## 常见错误

1. **忘记使能AFIO时钟**
   - 症状：GPIO_EXTILineConfig不生效，中断不触发
   - 原因：EXTI线映射需要AFIO模块，它也需要时钟

2. **忘记清除中断标志位**
   - 症状：程序反复进入同一个中断，卡死
   - 原因：不清除标志位，硬件认为中断还没处理完，会一直触发

3. **中断服务函数名写错**
   - 症状：中断触发了但函数不执行
   - 原因：启动文件中的中断向量表要求函数名严格匹配

4. **EXTI触发方式配错**
   - 症状：按键按下没反应，松开才有反应（或反过来）
   - 原因：上升沿/下降沿选反了
