# STM32定时器中断教学

## 实验目的

本实验的目的是：**用STM32定时器TIM3中断实现LED定时闪烁**。

实验3用外部中断控制LED（外部事件触发），实验4用定时器中断——芯片内部的"闹钟"，每隔固定时间自动触发中断，让LED闪烁。

---

## 从问题出发：为什么需要定时器？

### 软件延时 vs 定时器中断

**实验2/3的延时方式**：
```c
void SoftwareDelay(uint32_t time)
{
    while(time > 0) { time--; }
}
```
- 问题1：CPU在空转，浪费资源
- 问题2：延时不精确（被中断打断后时间会变长）
- 问题3：延时期间不能做其他事

**定时器中断方式**：
- 定时器是一个独立的硬件计数器，不占用CPU
- 设好"闹钟"后，时间到了自动通知CPU
- CPU在等待期间可以做其他事

**类比**：软件延时就像你盯着手表数秒；定时器中断就像设了个闹钟，闹钟响了再去做事。

### 实验报告截图1：定时器和LED配置（led_driver）

**你需要写的代码**：

`led_driver.c` — 你需要补全的部分（填充到已有函数中）：

```c
void LED_GPIO_TIM3_NVIC_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    // ========== 第一步：配置LED的GPIO ==========
    // LED0->PB5, LED1->PE5，和实验2一样
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;   // 推挽输出
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);             // PB5 -> LED0
    GPIO_Init(GPIOE, &GPIO_InitStructure);             // PE5 -> LED1

    GPIO_SetBits(GPIOB, GPIO_Pin_5);  // 默认熄灭
    GPIO_SetBits(GPIOE, GPIO_Pin_5);

    // ========== 第二步：配置TIM3定时器 ==========
    // 定时器的核心公式：
    // 定时时间 = (PSC+1) × (ARR+1) / CK_INT
    // 其中 CK_INT = 72MHz（STM32的内部时钟频率）

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE); // 使能TIM3时钟

    // 预分频器PSC：把72MHz分频到10kHz
    TIM_TimeBaseStructure.TIM_Prescaler = 7199;

    // 自动重装载值ARR：决定计数周期
    TIM_TimeBaseStructure.TIM_Period = 10000 - 1;  // ARR = 9999

    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    // ========== 第三步：使能TIM3更新中断 ==========
    // 注意补充TIM3参数，否则编译报错
    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);

    // ========== 第四步：配置NVIC ==========
    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    // ========== 第五步：启动定时器 ==========
    TIM_Cmd(TIM3, ENABLE);
}

void LED01_Flash(void) //LED1,LED1闪烁1次
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_5);
    GPIO_ResetBits(GPIOE, GPIO_Pin_5);
    SoftwareDelay(2000000);              
    GPIO_SetBits(GPIOB, GPIO_Pin_5);    
    GPIO_SetBits(GPIOE, GPIO_Pin_5);    
}
```

**定时器配置的核心公式**：

```
定时时间 = (PSC + 1) × (ARR + 1) / 72MHz

例：PSC=7199, ARR=9999
定时时间 = (7199+1) × (9999+1) / 72MHz
         = 7200 × 10000 / 72000000
         = 1秒
```

**思考**：为什么TIM3的时钟是APB1而不是APB2？

**答案**：STM32的定时器挂在不同的总线上。TIM1、TIM8是高级定时器在APB2上；TIM2~TIM7是通用定时器在APB1上。APB1总线时钟默认是36MHz，但定时器的时钟会被倍频到72MHz。

### 实验报告截图2：中断服务函数（it.c）

**你需要写的代码**：

`it.c` — 你需要补齐的中断函数代码：

```c
void TIM3_IRQHandler(void)   //TIM3中断
{
    if(TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET) // 检查是否是TIM3更新中断
    {
        LED01_Flash();  // LED1,LED1闪烁1次
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);   // 清除中断标志位
    }
}
```

**关键点**：
1. 函数名必须是 `TIM3_IRQHandler`，对应TIM3中断
2. 必须检查 `TIM_GetITStatus()` 确认是TIM3的更新中断
3. **必须清除中断标志位** `TIM_ClearITPendingBit()`，否则会反复进入中断

### 实验报告截图3：主程序（main.c）

**你需要写的代码**：

`main.c` — 你需要补完的主程序代码：

```c
 int main(void)
 {
    // 初始化LED GPIO和TIM3定时器中断
    LED_GPIO_TIM3_NVIC_Config();

    // 主循环：什么都不用做
    // 每隔1秒，TIM3自动触发中断，LED闪烁一次
    while(1)
    {
        // CPU空闲，可以做其他事
    }
 }
```

**运行效果**：LED0和LED1每1秒同时闪烁一次。

## 常见错误

1. **忘记使能TIM3时钟**
   - 症状：定时器不工作
   - 原因：TIM3在APB1上，需要 `RCC_APB1PeriphClockCmd()`

2. **PSC和ARR计算错误**
   - 症状：LED闪烁太快或太慢
   - 原因：公式用错，或把72MHz当成72kHz

3. **忘记使能更新中断**
   - 症状：定时器在计数但中断不触发
   - 原因：需要 `TIM_ITConfig(TIM_IT_Update, ENABLE)`

4. **中断服务函数名写错**
   - 症状：中断触发了但函数不执行
   - 原因：必须是 `TIM3_IRQHandler`
