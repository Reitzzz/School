# 嵌入式开发总体步骤

很多人看代码能看懂，但自己写就没思路。按照下面5个步骤，就能有方向：

---

## 第1步：明确目的

先问自己：**我要实现什么功能？**

比如：按键控制LED
- 按KEY0 → LED0亮
- 按KEY1 → LED1亮
- 不按键 → LED都灭

---

## 第2步：拆解成硬件操作

把功能翻译成硬件操作：

| 功能 | 需要操作什么 |
|------|-------------|
| 读取按键 | 读取GPIO输入引脚的电平 |
| 控制LED | 设置GPIO输出引脚的高/低电平 |

---

## 第3步：回忆标准库三板斧

任何GPIO操作，都是这三步：

```
1. 使能时钟（给外设通电）
2. 配置GPIO（设置引脚模式）
3. 使用GPIO（读取/输出）
```

---

## 第4步：套用模板

**模板1：初始化GPIO（写在xxx_Config函数里）**
```c
void XXX_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    // 1. 使能时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOx, ENABLE);

    // 2. 配置GPIO
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_X;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_XX;  // 输入还是输出？
    GPIO_Init(GPIOx, &GPIO_InitStructure);
}
```

**模板2：控制GPIO（写在功能函数里）**
```c
// 输出
GPIO_SetBits(GPIOx, GPIO_Pin_X);    // 置1
GPIO_ResetBits(GPIOx, GPIO_Pin_X);  // 置0

// 输入
GPIO_ReadInputDataBit(GPIOx, GPIO_Pin_X);  // 读取电平
```

---

## 第5步：组合

把上面的组合起来：

```c
// 按键驱动
void KEY_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOE, ENABLE);
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2 | GPIO_Pin_3 | GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;  // 输入，上拉
    GPIO_Init(GPIOE, &GPIO_InitStructure);
}

// 读取按键
#define KEY0 GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4)
```

---

## 总结

```
1. 我要做什么？ → 明确功能
2. 需要操作什么硬件？ → GPIO输入/输出
3. 三板斧是什么？ → 使能时钟、配置、使用
4. 套用模板 → 填空
```
