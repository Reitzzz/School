# 六类程序设计顺序

说明：这份只记“写程序时先写什么、后写什么”。按程序设计题范围整理为 `GPIO、EXTI、NVIC、TIM、ADC、DAC` 六类；PWM 不再作为独立大类，若题目要求 PWM，可归到 TIM 的输出比较内容里理解。

## 1. GPIO 程序顺序

适用：LED 输出、按键输入、普通数字量输入输出、模拟输入引脚初始化。

| 顺序 | 要做什么 | 常用写法 |
| --- | --- | --- |
| 1 | 打开 GPIO 外设时钟 | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOx, ENABLE);` |
| 2 | 定义 GPIO 初始化结构体变量 | `GPIO_InitTypeDef GPIO_InitStructure;` |
| 3 | 选择 GPIO 引脚 | `GPIO_InitStructure.GPIO_Pin = GPIO_Pin_x;` |
| 4 | 设置 GPIO 工作模式 | 输出：`GPIO_Mode_Out_PP`<br>上拉输入：`GPIO_Mode_IPU`<br>下拉输入：`GPIO_Mode_IPD`<br>模拟输入：`GPIO_Mode_AIN`<br>复用推挽：`GPIO_Mode_AF_PP` |
| 5 | 如果是输出或复用输出，设置输出速度 | `GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;` |
| 6 | 调用初始化函数，真正写入硬件 | `GPIO_Init(GPIOx, &GPIO_InitStructure);` |
| 7 | 如果需要，读输入或写输出 | 写高：`GPIO_SetBits()`<br>写低：`GPIO_ResetBits()`<br>读输入：`GPIO_ReadInputDataBit()` |

记忆版：

```text
开 GPIO 时钟 -> 定义 GPIO 结构体 -> 选引脚 -> 选模式
-> 必要时设速度 -> GPIO_Init -> 读/写引脚
```

## 2. EXTI 程序顺序

适用：按键外部中断、外部脉冲中断输入。EXTI 只负责“哪条外部线、什么边沿触发、是否产生中断”。

| 顺序 | 要做什么 | 常用写法 |
| --- | --- | --- |
| 1 | 打开 GPIO 和 AFIO 时钟 | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOx \| RCC_APB2Periph_AFIO, ENABLE);` |
| 2 | 配置 GPIO 为输入模式 | 常用 `GPIO_Mode_IPU`、`GPIO_Mode_IPD` 或 `GPIO_Mode_IN_FLOATING` |
| 3 | 调用 `GPIO_Init()` 初始化输入引脚 | `GPIO_Init(GPIOx, &GPIO_InitStructure);` |
| 4 | 把 GPIO 引脚映射到 EXTI 线 | `GPIO_EXTILineConfig(GPIO_PortSourceGPIOx, GPIO_PinSourcex);` |
| 5 | 定义 EXTI 初始化结构体 | `EXTI_InitTypeDef EXTI_InitStructure;` |
| 6 | 选择 EXTI 线 | `EXTI_InitStructure.EXTI_Line = EXTI_Linex;` |
| 7 | 设置为中断模式 | `EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;` |
| 8 | 设置触发边沿 | 上升沿：`EXTI_Trigger_Rising`<br>下降沿：`EXTI_Trigger_Falling` |
| 9 | 使能 EXTI 线 | `EXTI_InitStructure.EXTI_LineCmd = ENABLE;` |
| 10 | 初始化 EXTI | `EXTI_Init(&EXTI_InitStructure);` |
| 11 | 在中断服务函数中判断并清除 EXTI 标志 | `EXTI_GetITStatus()` 判断<br>`EXTI_ClearITPendingBit()` 清标志 |

记忆版：

```text
开 GPIO/AFIO 时钟 -> GPIO 输入初始化 -> GPIO 映射到 EXTI 线
-> 配 EXTI 线/中断模式/触发边沿 -> EXTI_Init
-> IRQHandler 中判断 EXTI 标志 -> 清 EXTI 标志
```

## 3. NVIC 程序顺序

适用：所有需要中断的程序，包括 EXTI 中断、TIM 中断、ADC 中断。NVIC 只负责“CPU 是否接收这个中断、优先级是多少”。

| 顺序 | 要做什么 | 常用写法 |
| --- | --- | --- |
| 1 | 如果题目要求，配置优先级分组 | `NVIC_PriorityGroupConfig(NVIC_PriorityGroup_x);` |
| 2 | 定义 NVIC 初始化结构体 | `NVIC_InitTypeDef NVIC_InitStructure;` |
| 3 | 选择中断通道 | EXTI：`EXTI0_IRQn`、`EXTI9_5_IRQn`<br>TIM：`TIM3_IRQn`<br>ADC：`ADC1_2_IRQn` |
| 4 | 设置抢占优先级 | `NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;` |
| 5 | 设置子优先级 | `NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;` |
| 6 | 使能该中断通道 | `NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;` |
| 7 | 初始化 NVIC | `NVIC_Init(&NVIC_InitStructure);` |
| 8 | 写对应中断服务函数 | EXTI：`EXTIx_IRQHandler()`<br>TIM：`TIMx_IRQHandler()`<br>ADC：`ADC1_2_IRQHandler()` |

记忆版：

```text
优先级分组 -> 定义 NVIC 结构体 -> 选 IRQChannel
-> 配抢占优先级/子优先级 -> 使能通道 -> NVIC_Init
-> 写对应 IRQHandler
```

## 4. TIM 程序顺序

适用：基本定时、中断定时、周期翻转 LED。若题目要求 PWM，可在时基配置后加入输出比较配置，但不作为独立大类背。

| 顺序 | 要做什么 | 常用写法 |
| --- | --- | --- |
| 1 | 打开 TIM 时钟 | `RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIMx, ENABLE);` |
| 2 | 定义 TIM 时基结构体 | `TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;` |
| 3 | 计算并填写 PSC | `TIM_TimeBaseStructure.TIM_Prescaler = PSC;` |
| 4 | 计算并填写 ARR | `TIM_TimeBaseStructure.TIM_Period = ARR;` |
| 5 | 设置计数方向 | `TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;` |
| 6 | 设置时钟分频 | `TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;` |
| 7 | 初始化 TIM 时基单元 | `TIM_TimeBaseInit(TIMx, &TIM_TimeBaseStructure);` |
| 8 | 如果要定时中断，使能更新中断 | `TIM_ITConfig(TIMx, TIM_IT_Update, ENABLE);` |
| 9 | 如果要中断，配置 NVIC | `NVIC_Init(&NVIC_InitStructure);` |
| 10 | 启动定时器 | `TIM_Cmd(TIMx, ENABLE);` |
| 11 | 在中断服务函数中判断并清除 TIM 标志 | `TIM_GetITStatus()` 判断<br>`TIM_ClearITPendingBit()` 清标志 |

记忆版：

```text
开 TIM 时钟 -> 定义时基结构体 -> 填 PSC/ARR/计数模式/时钟分频
-> TIM_TimeBaseInit -> 需要中断则 TIM_ITConfig + NVIC_Init
-> TIM_Cmd -> IRQHandler 中判断标志、清标志
```

计算版：

```text
CK_CNT = CK_INT / (PSC + 1)
定时时间 = (ARR + 1) / CK_CNT
```

PWM 若题目临时要求：

```text
GPIO 配复用推挽输出 -> TIM 时基配置 PSC/ARR
-> 输出比较结构体配置 PWM 模式/通道/CCR/极性
-> TIM_OCInit 或 TIM_OCxInit -> TIM_Cmd
```

## 5. ADC 程序顺序

适用：查询方式获得 ADC 转换数字量，或 ADC 中断方式读取转换结果。

| 顺序 | 要做什么 | 常用写法 |
| --- | --- | --- |
| 1 | 打开 GPIO 和 ADC 时钟 | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOx \| RCC_APB2Periph_ADC1, ENABLE);` |
| 2 | 配置 ADC 时钟分频 | `RCC_ADCCLKConfig(RCC_PCLK2_Div6);` |
| 3 | 配置模拟输入引脚 | `GPIO_Mode_AIN` |
| 4 | 调用 `GPIO_Init()` 初始化模拟输入引脚 | `GPIO_Init(GPIOx, &GPIO_InitStructure);` |
| 5 | 定义 ADC 初始化结构体 | `ADC_InitTypeDef ADC_InitStructure;` |
| 6 | 配置 ADC 工作模式 | `ADC_Mode_Independent` |
| 7 | 配置扫描模式、连续转换、外部触发、数据对齐、通道数量 | 按题目要求填写 |
| 8 | 初始化 ADC | `ADC_Init(ADC1, &ADC_InitStructure);` |
| 9 | 配置规则通道 | `ADC_RegularChannelConfig(ADC1, ADC_Channel_x, 1, ADC_SampleTime_x);` |
| 10 | 如果用 ADC 中断，使能 ADC 中断并配置 NVIC | `ADC_ITConfig()` + `NVIC_Init()` |
| 11 | 使能 ADC | `ADC_Cmd(ADC1, ENABLE);` |
| 12 | 查询方式：等待转换完成后读取转换值 | `ADC_GetConversionValue(ADC1);` |
| 13 | 中断方式：在中断服务函数中判断、读取、清标志 | `ADC_GetITStatus()` -> `ADC_GetConversionValue()` -> `ADC_ClearITPendingBit()` |

记忆版：

```text
开 GPIO/ADC 时钟 -> ADC 时钟分频 -> GPIO 模拟输入
-> ADC 结构体配置 -> ADC_Init -> ADC_RegularChannelConfig
-> 需要中断则 ADC_ITConfig + NVIC_Init
-> ADC_Cmd -> 查询或中断中读取 ADC_GetConversionValue
```

## 6. DAC 程序顺序

适用：输出模拟电压、按表输出正弦波。

| 顺序 | 要做什么 | 常用写法 |
| --- | --- | --- |
| 1 | 打开 GPIO 和 DAC 时钟 | GPIO 用于 DAC 输出引脚，DAC 本身也要开时钟 |
| 2 | 配置 DAC 输出引脚为模拟模式 | 例：`PA4` 对应 `DAC_OUT1`，模式用 `GPIO_Mode_AIN` |
| 3 | 调用 `GPIO_Init()` 初始化 DAC 输出引脚 | `GPIO_Init(GPIOA, &GPIO_InitStructure);` |
| 4 | 定义 DAC 初始化结构体 | `DAC_InitTypeDef DAC_InitStructure;` |
| 5 | 配置 DAC 触发方式 | 软件触发：`DAC_Trigger_Software` |
| 6 | 配置是否使用波形发生器 | 通常：`DAC_WaveGeneration_None` |
| 7 | 配置噪声/三角波参数 | 不用波形发生器时按附件给定默认项填写 |
| 8 | 配置输出缓冲 | `DAC_OutputBuffer_Enable` 或 `DAC_OutputBuffer_Disable` |
| 9 | 初始化 DAC 通道 | `DAC_Init(DAC_Channel_1, &DAC_InitStructure);` |
| 10 | 使能 DAC 通道 | `DAC_Cmd(DAC_Channel_1, ENABLE);` |
| 11 | 写入 DAC 数字量 | `DAC_SetChannel1Data(DAC_Align_12b_R, data);` |
| 12 | 如果使用软件触发，执行软件触发 | `DAC_SoftwareTriggerCmd(DAC_Channel_1, ENABLE);` |

记忆版：

```text
开 GPIO/DAC 时钟 -> GPIO 模拟模式 -> DAC 结构体配置
-> DAC_Init -> DAC_Cmd -> DAC_SetChannel1Data
-> 必要时 DAC_SoftwareTriggerCmd
```

正弦波输出：

```text
准备正弦表 -> 配 DAC -> 配 TIM 定时中断
-> 每次 TIM 中断取表中一个数字量
-> DAC_SetChannel1Data 写入 DAC
-> 下标循环递增
```
