# sy4 从 0 开始写代码

## 1. 这次实验要做什么

`1904300101张三@实验报告4.doc` 要求用 **TIM3 基本定时功能** 实现周期为 1 秒的定时中断：

- 创建工程并加入 GPIO、RCC、TIM、NVIC 标准库。
- TIM3 每隔 1 秒产生一次更新中断。
- 在 `TIM3_IRQHandler()` 中让 LED0、LED1 同时闪烁一次。

一句话：sy4 是“定时器中断点灯”。

## 2. 先认识硬件和时间关系

| 对象 | 连接/参数 | 作用 |
| --- | --- | --- |
| LED0 | PB5 | 输出，低电平点亮 |
| LED1 | PE5 | 输出，低电平点亮 |
| TIM3 | APB1 总线 | 每 1 秒产生一次更新中断 |
| TIM3 中断 | `TIM3_IRQn` | 进入 `TIM3_IRQHandler()` |

定时器最重要的公式：

```text
定时时间 = (PSC + 1) * (ARR + 1) / TIMx_CLK
```

本实验按 TIM3 时钟 72MHz 计算：

```text
PSC = 7199
ARR = 9999
定时时间 = 7200 * 10000 / 72000000 = 1 秒
```

## 3. 本实验需要用到的库函数（考试会给）

| 你想做什么 | 库函数 |
| --- | --- |
| 打开 GPIO 时钟 | `RCC_APB2PeriphClockCmd()` |
| 打开 TIM3 时钟 | `RCC_APB1PeriphClockCmd()` |
| 初始化 GPIO | `GPIO_Init()` |
| 初始化定时器基本计数 | `TIM_TimeBaseInit()` |
| 使能 TIM 更新中断 | `TIM_ITConfig()` |
| 配置 NVIC | `NVIC_Init()` |
| 启动定时器 | `TIM_Cmd()` |
| 判断中断标志 | `TIM_GetITStatus()` |
| 清除中断标志 | `TIM_ClearITPendingBit()` |

常用结构体：

| 名称 | 作用 |
| --- | --- |
| `TIM_TimeBaseInitTypeDef` | 填 PSC、ARR、计数方向等 |
| `NVIC_InitTypeDef` | 填中断通道、抢占优先级、子优先级 |
| `GPIO_InitTypeDef` | 配 LED 引脚输出 |

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/led_driver.c/.h`：配置 LED GPIO、TIM3、NVIC，提供 LED 闪烁函数。
- `USER_APP/it.c`：写 `TIM3_IRQHandler()`。
- `USER_APP/main.c`：调用初始化函数，然后空循环。

驱动层负责把“1 秒闹钟”设置好；`it.c` 负责闹钟响了以后做什么。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求“每隔 1 秒”，所以要配置 TIM3 的 PSC 和 ARR。

第二步，实验要求“通过更新中断方式点灯”，所以要打开 `TIM_IT_Update` 和 `TIM3_IRQn`。

第三步，实验要求“LED0、LED1 闪烁一次”，所以中断服务函数中调用 `LED01_Flash()`。

### 5.2 完整伪代码

```text
开始

初始化 LED 和 TIM3
    打开 GPIOB、GPIOE 时钟
    PB5、PE5 配置为推挽输出
    默认熄灭 LED0、LED1
    打开 TIM3 时钟
    设置 PSC = 7199
    设置 ARR = 9999
    使能 TIM3 更新中断
    在 NVIC 中打开 TIM3_IRQn
    启动 TIM3

主循环
    什么都不用做，等待 TIM3 中断

如果进入 TIM3_IRQHandler
    检查是不是 TIM3 更新中断
    LED0、LED1 同时闪烁一次
    清除 TIM3 更新中断标志
```

## 6. LED、TIM3、NVIC 驱动怎么写

```c
#include "stm32f10x_conf.h"
#include "sw_delay.h"
#include "misc.h"

void LED_GPIO_TIM3_NVIC_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);
    GPIO_Init(GPIOE, &GPIO_InitStructure);

    GPIO_SetBits(GPIOB, GPIO_Pin_5);
    GPIO_SetBits(GPIOE, GPIO_Pin_5);

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = 10000 - 1;
    TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);

    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM3, ENABLE);
}

void LED01_Flash(void)
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_5);
    GPIO_ResetBits(GPIOE, GPIO_Pin_5);
    SoftwareDelay(2000000);
    GPIO_SetBits(GPIOB, GPIO_Pin_5);
    GPIO_SetBits(GPIOE, GPIO_Pin_5);
}
```

## 7. 中断服务函数怎么写

```c
#include "led_driver.h"
#include "stm32f10x_conf.h"

void TIM3_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET)
    {
        LED01_Flash();
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);
    }
}
```

## 8. 主函数怎么写

```c
#include "led_driver.h"

int main(void)
{
    LED_GPIO_TIM3_NVIC_Config();

    while (1)
    {
    }
}
```

## 10. 最容易错的地方

- `TIM_ITConfig()` 少写第一个参数 `TIM3`，正确写法是 `TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);`。
- TIM3 在 APB1 上，要用 `RCC_APB1PeriphClockCmd()`。
- PSC 和 ARR 要代入 `(PSC + 1) * (ARR + 1) / 72MHz`。
- 忘记 `TIM_Cmd(TIM3, ENABLE)`：定时器不会开始计数。
- 忘记清除 `TIM_IT_Update` 标志：会反复进入中断。
