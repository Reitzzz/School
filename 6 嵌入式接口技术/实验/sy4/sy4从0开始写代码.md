## 1. 这次实验要做什么

`1904300101张三@实验报告4.doc` 要求用 **TIM3 基本定时功能** 实现周期为 1 秒的定时中断：

- 创建工程并加入 GPIO、RCC、TIM、NVIC 标准库。
- TIM3 每隔 1 秒产生一次更新中断。
- 在 `TIM3_IRQHandler()` 中让 LED0、LED1 同时闪烁一次。

一句话：sy4 是“定时器中断点灯”。

## 2. 先认识硬件和时间关系

| 对象 | 连接/参数 | 作用 |
| --- | --- | --- |
| LED0 | PB5 | 输出，低电平点亮 |
| LED1 | PE5 | 输出，低电平点亮 |
| TIM3 | APB1 总线 | 每 1 秒产生一次更新中断 |
| TIM3 中断 | `TIM3_IRQn` | 进入 `TIM3_IRQHandler()` |

定时器最重要的公式：

```text
定时时间 = (PSC + 1) * (ARR + 1) / TIMx_CLK
```

本实验按 TIM3 时钟 72MHz 计算：

```text
PSC = 7199
ARR = 9999
定时时间 = 7200 * 10000 / 72000000 = 1 秒
```

## 3. 本实验需要用到的库函数（考试会给）


### 3.1 GPIO 相关库函数

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `RCC_APB2PeriphClockCmd()` | 打开 GPIO 时钟，可近似理解为给 GPIO “通电”，让它开始工作 | 外设时钟名，开关状态<br>`RCC_APB2Periph_GPIOB`、`ENABLE` | 不适用<br>这是函数调用 |
| `GPIO_InitTypeDef` | GPIO 初始化结构体类型，用它定义 GPIO 配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`GPIO_InitTypeDef GPIO_InitStructure;` |
| `GPIO_InitStructure.GPIO_Pin` | 配置要初始化的 GPIO 引脚，可以单个引脚，也可以用 `\|` 同时选择多个引脚 | 不适用<br>这是赋值写法 | GPIO 引脚<br>`GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;` |
| `GPIO_InitStructure.GPIO_Mode` | 配置 GPIO 工作模式，决定这个引脚是输入、输出，还是复用功能 | 不适用<br>这是赋值写法 | GPIO 工作模式<br>`GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;` |
| `GPIO_InitStructure.GPIO_Speed` | 配置 GPIO 输出速度；**只有输出或复用输出时需要重点设置** | 不适用<br>这是赋值写法 | GPIO 输出速度<br>`GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;` |
| `GPIO_Init()` | 初始化 GPIO，真正把 GPIO 结构体配置写进硬件 | GPIO 端口，GPIO 初始化结构体地址<br>`GPIOB`、`&GPIO_InitStructure` | 不适用<br>这是函数调用 |

### 3.2 TIM 相关库函数

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `RCC_APB1PeriphClockCmd()` | 打开 TIM3 时钟，可近似理解为给 TIM3 “通电”，让它开始工作 | 外设时钟名，开关状态<br>`RCC_APB1Periph_TIM3`、`ENABLE` | 不适用<br>这是函数调用 |
| `TIM_TimeBaseInitTypeDef` | TIM 基本计数结构体类型，用它定义定时器配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;` |
| `TIM_TimeBaseStructInit()` | 给 TIM 基本计数结构体填入标准默认值，避免某些成员没有赋值就被拿去初始化 | TIM 基本计数结构体地址<br>`&TIM_TimeBaseStructure` | 不适用<br>这是函数调用 |
| `TIM_TimeBaseStructure.TIM_Period` | 设置自动重装载值 ARR。计数器从 0 数到这个值后产生更新事件 | 不适用<br>这是结构体成员赋值 | 自动重装载值<br>`TIM_TimeBaseStructure.TIM_Period = 10000 - 1;` |
| `TIM_TimeBaseStructure.TIM_Prescaler` | 设置预分频器 PSC，把 72MHz 定时器时钟先分频 | 不适用<br>这是结构体成员赋值 | 预分频器值<br>`TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1;` |
| `TIM_TimeBaseStructure.TIM_ClockDivision` | 设置时钟分频，本实验使用不分频 | 不适用<br>这是结构体成员赋值 | 时钟分频<br>`TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;` |
| `TIM_TimeBaseStructure.TIM_CounterMode` | 设置计数方向，本实验使用向上计数 | 不适用<br>这是结构体成员赋值 | 计数模式<br>`TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;` |
| `TIM_TimeBaseInit()` | 初始化定时器基本计数，**真正把 TIM 结构体配置写进硬件** | TIM 外设，TIM 基本计数结构体地址<br>`TIM3`、`&TIM_TimeBaseStructure` | 不适用<br>这是函数调用 |
| `TIM_ITConfig()` | 使能 TIM 更新中断 | TIM 外设，中断类型，开关状态<br>`TIM3`、`TIM_IT_Update`、`ENABLE` | 不适用<br>这是函数调用 |
| `TIM_Cmd()` | 所有配置完成后启动定时器 | TIM 外设，开关状态<br>`TIM3`、`ENABLE` | 不适用<br>这是函数调用 |
| `TIM_GetITStatus()` | 中断发生后，判断中断标志 | TIM 外设，中断类型<br>`TIM3`、`TIM_IT_Update` | 不适用<br>这是函数调用 |
| `TIM_ClearITPendingBit()` | 中断处理结束前，清除中断标志 | TIM 外设，中断类型<br>`TIM3`、`TIM_IT_Update` | 不适用<br>这是函数调用 |

### 3.3 NVIC 相关库函数

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `NVIC_InitTypeDef` | NVIC 初始化结构体类型，用它定义 NVIC 配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`NVIC_InitTypeDef NVIC_InitStructure;` |

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/led_driver.c/.h`：配置 LED GPIO、TIM3、NVIC，提供 LED 闪烁函数。
- `USER_APP/it.c`：写 `TIM3_IRQHandler()`。
- `USER_APP/main.c`：调用初始化函数，然后空循环。

驱动层负责把“1 秒闹钟”设置好；`it.c` 负责闹钟响了以后做什么。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求“每隔 1 秒”，所以要配置 TIM3 的 PSC 和 ARR。

第二步，实验要求“通过更新中断方式点灯”，所以要打开 `TIM_IT_Update` 和 `TIM3_IRQn`。

第三步，实验要求“LED0、LED1 闪烁一次”，所以中断服务函数中调用 `LED01_Flash()`。

### 5.2 完整伪代码

```text
开始

初始化 LED 和 TIM3
    打开 GPIOB、GPIOE 时钟
    PB5、PE5 配置为推挽输出
    默认熄灭 LED0、LED1
    打开 TIM3 时钟
    设置 PSC = 7199
    设置 ARR = 9999
    使能 TIM3 更新中断
    在 NVIC 中打开 TIM3_IRQn
    启动 TIM3

主循环
    什么都不用做，等待 TIM3 中断

如果进入 TIM3_IRQHandler
    检查是不是 TIM3 更新中断
    LED0、LED1 同时闪烁一次
    清除 TIM3 更新中断标志
```

## 6. LED、TIM3、NVIC 驱动怎么写

```c
#include "stm32f10x_conf.h"
#include "sw_delay.h"
#include "misc.h"

void LED_GPIO_TIM3_NVIC_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;                    // 定义配置结构体变量
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;          // 定义配置结构体变量
    NVIC_InitTypeDef NVIC_InitStructure;                    // 定义配置结构体变量

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE); // 打开外设时钟
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;               // 配置引脚
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;        // 配置工作模式
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;       // 配置输出速度
    GPIO_Init(GPIOB, &GPIO_InitStructure);                  // 真正初始化 GPIO
    GPIO_Init(GPIOE, &GPIO_InitStructure);                  // 真正初始化 GPIO
    GPIO_SetBits(GPIOB, GPIO_Pin_5);                        // 输出高电平
    GPIO_SetBits(GPIOE, GPIO_Pin_5);                        // 输出高电平

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);    // 打开外设时钟
    TIM_TimeBaseStructure.TIM_Period = 10000 - 1;           // 设置自动重装载值 (ARR)
    TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1;         // 设置预分频器值 (PSC)
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1; // 设置时钟分频
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up; // 设置计数模式
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);         // 真正初始化定时器基本计数
    TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);              // 使能外设中断

    NVIC_InitStructure.NVIC_IRQChannel = TIM3_IRQn;         // 选择 NVIC 中断通道
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0; // 配置抢占优先级
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);                         // 真正初始化 NVIC

    TIM_Cmd(TIM3, ENABLE);                                  // 启动外设
}

void LED01_Flash(void)
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_5);                      // 输出低电平
    GPIO_ResetBits(GPIOE, GPIO_Pin_5);                      // 输出低电平
    SoftwareDelay(2000000);                                 // 软件延时
    GPIO_SetBits(GPIOB, GPIO_Pin_5);                        // 输出高电平
    GPIO_SetBits(GPIOE, GPIO_Pin_5);                        // 输出高电平
}
```

## 7. 中断服务函数怎么写

```c
#include "led_driver.h"
#include "stm32f10x_conf.h"

void TIM3_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM3, TIM_IT_Update) != RESET)      // 检查中断标志位是否被置位
    {
        LED01_Flash();                                      // 执行相关动作
        TIM_ClearITPendingBit(TIM3, TIM_IT_Update);         // 清除中断标志位，防止死循环
    }
}
```

## 10. 最容易错的地方

- `TIM_ITConfig()` 少写第一个参数 `TIM3`，正确写法是 `TIM_ITConfig(TIM3, TIM_IT_Update, ENABLE);`。
- TIM3 在 APB1 上，要用 `RCC_APB1PeriphClockCmd()`。
- PSC 和 ARR 要代入 `(PSC + 1) * (ARR + 1) / 72MHz`。
- 忘记 `TIM_Cmd(TIM3, ENABLE)`：定时器不会开始计数。
- 忘记清除 `TIM_IT_Update` 标志：会反复进入中断。
