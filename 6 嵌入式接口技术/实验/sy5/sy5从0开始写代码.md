## 1. 这次实验要做什么

`1904300101张三@实验报告5.doc` 要求用 **TIM3 输出比较 PWM 功能**：

- 使用 TIM3_CH2 输出 PWM。
- 将 TIM3_CH2 部分重映射到 PB5。
- 在 PB5 上产生 100Hz、25% 占空比的 PWM 信号。
- 用这个 PWM 信号驱动 LED0。

一句话：sy5 是“定时器 PWM 输出控制 LED 亮度”。

## 2. 先认识硬件和 PWM 参数

| 对象 | 参数 | 作用 |
| --- | --- | --- |
| LED0 | PB5 | 接收 TIM3_CH2 重映射后的 PWM |
| TIM3_CH2 | PB5 | 输出比较通道 2 |
| PWM 频率 | 100Hz | 每秒 100 个周期 |
| 占空比 | 25% | 高电平时间占整个周期的 1/4 |

本实验中报告调试窗口要求看到：

```text
TIM3_PSC = 71
TIM3_ARR = 9999
TIM3_CCR2 = 2500
```

计算过程：

```text
TIM3_CLK = 72MHz
计数频率 = 72MHz / (71 + 1) = 1MHz
PWM 频率 = 1MHz / (9999 + 1) = 100Hz
占空比 = 2500 / (9999 + 1) = 25%
```

## 3. 本实验需要用到的库函数（考试会给）


### 3.1 GPIO 相关库函数

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `RCC_APB2PeriphClockCmd()` | 打开 GPIOB/AFIO 时钟，可近似理解为给这些外设“通电”，让它们开始工作 | 外设时钟名，开关状态<br>`RCC_APB2Periph_GPIOB \| RCC_APB2Periph_AFIO`、`ENABLE` | 不适用<br>这是函数调用 |
| `GPIO_InitTypeDef` | GPIO 初始化结构体类型，用它定义 GPIO 配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`GPIO_InitTypeDef GPIO_InitStructure;` |
| `GPIO_InitStructure.GPIO_Pin` | 配置要初始化的 GPIO 引脚，可以单个引脚，也可以用 `\|` 同时选择多个引脚 | 不适用<br>这是赋值写法 | GPIO 引脚<br>`GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;` |
| `GPIO_InitStructure.GPIO_Mode` | 配置 GPIO 工作模式，决定这个引脚是输入、输出，还是复用功能 | 不适用<br>这是赋值写法 | GPIO 工作模式<br>`GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;` |
| `GPIO_InitStructure.GPIO_Speed` | 配置 GPIO 输出速度；只有输出或复用输出时需要重点设置 | 不适用<br>这是赋值写法 | GPIO 输出速度<br>`GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;` |
| `GPIO_PinRemapConfig()` | TIM3 部分重映射 | 重映射类型，开关状态<br>`GPIO_PartialRemap_TIM3`、`ENABLE` | 不适用<br>这是函数调用 |
| `GPIO_Init()` | 初始化 GPIO，真正把 GPIO 结构体配置写进硬件 | GPIO 端口，GPIO 初始化结构体地址<br>`GPIOB`、`&GPIO_InitStructure` | 不适用<br>这是函数调用 |

### 3.2 TIM 相关库函数

#### 3.2.1 基本计数器

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `RCC_APB1PeriphClockCmd()` | 打开 TIM3 时钟，可近似理解为给 TIM3 “通电”，让它开始工作 | 外设时钟名，开关状态<br>`RCC_APB1Periph_TIM3`、`ENABLE` | 不适用<br>这是函数调用 |
| `TIM_TimeBaseInitTypeDef` | TIM 基本计数结构体类型，用它定义定时器配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;` |
| `TIM_TimeBaseStructure.TIM_Period` | 设置自动重装载值 ARR，决定 PWM 一个周期需要计多少个数 | 不适用<br>这是结构体成员赋值 | 自动重装载值<br>`TIM_TimeBaseStructure.TIM_Period = ARRValue;` |
| `TIM_TimeBaseStructure.TIM_Prescaler` | 设置预分频器 PSC，把 72MHz 定时器时钟分成需要的计数频率 | 不适用<br>这是结构体成员赋值 | 预分频器值<br>`TIM_TimeBaseStructure.TIM_Prescaler = PrescalerValue;` |
| `TIM_TimeBaseStructure.TIM_ClockDivision` | 设置定时器时钟分频，本实验使用不分频 | 不适用<br>这是结构体成员赋值 | 时钟分频<br>`TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;` |
| `TIM_TimeBaseStructure.TIM_CounterMode` | 设置计数方向，本实验使用向上计数 | 不适用<br>这是结构体成员赋值 | 计数模式<br>`TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;` |
| `TIM_TimeBaseInit()` | 初始化定时器基本计数，真正把 TIM 结构体配置写进硬件 | TIM 外设，TIM 基本计数结构体地址<br>`TIM3`、`&TIM_TimeBaseStructure` | 不适用<br>这是函数调用 |
| `TIM_Cmd()` | 所有配置完成后启动定时器 | TIM 外设，开关状态<br>`TIM3`、`ENABLE` | 不适用<br>这是函数调用 |

#### 3.2.2 PWM

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `TIM_OCInitTypeDef` | TIM 输出比较结构体类型，用它定义 PWM 通道配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`TIM_OCInitTypeDef TIM_OCInitStructure;` |
| `TIM_OCInitStructure.TIM_OCMode` | 设置输出比较模式，本实验用 PWM1 模式产生 PWM 波形 | 不适用<br>这是结构体成员赋值 | PWM 模式<br>`TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;` |
| `TIM_OCInitStructure.TIM_OutputState` | 使能该通道的输出，否则通道配置了也不会从引脚输出波形 | 不适用<br>这是结构体成员赋值 | 输出开关<br>`TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;` |
| `TIM_OCInitStructure.TIM_OCPolarity` | 设置输出有效电平极性，**本实验高电平为有效电平** | 不适用<br>这是结构体成员赋值 | 输出极性<br>`TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;` |
| `TIM_OCInitStructure.TIM_Pulse` | 设置比较值 CCR2，决定占空比；`CCR2 / (ARR + 1)` 就是占空比 | 不适用<br>这是结构体成员赋值 | 比较值<br>`TIM_OCInitStructure.TIM_Pulse = CCRValue;` |
| `TIM_OC2Init()` | 初始化输出比较通道 2，**真正把 PWM 通道配置写进硬件** | TIM 外设，输出比较结构体地址<br>`TIM3`、`&TIM_OCInitStructure` | 不适用<br>这是函数调用 |
| `TIM_SetCompare2()` | 运行中修改 CCR2，从而改变占空比 | TIM 外设，比较值<br>`TIM3`、`2500` | 不适用<br>这是函数调用 |

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/led_driver.c/.h`：配置 PB5、TIM3、PWM 输出比较。
- `USER_APP/main.c`：调用 `LED0_GPIO_TIM3_Config()`，然后空循环。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求 PB5 输出 TIM3_CH2，所以 PB5 不能配普通输出，要配 `GPIO_Mode_AF_PP` 复用推挽输出。

第二步，TIM3_CH2 默认不在 PB5，需要打开 AFIO 并执行 TIM3 部分重映射。

第三步，实验要求 100Hz、25%，所以先算 PSC、ARR、CCR2。

第四步，配置 TIM3 基本计数和 OC2 PWM 模式，最后启动 TIM3。

### 5.2 完整伪代码

```text
开始

初始化 TIM3 PWM 输出
    计算 PSC = 71
    计算 ARR = 9999
    计算 CCR2 = 2500
    打开 GPIOB 和 AFIO 时钟
    开启 TIM3 部分重映射，让 TIM3_CH2 输出到 PB5
    PB5 配置为复用推挽输出
    打开 TIM3 时钟
    配置 TIM3 基本计数参数
    配置 TIM3_CH2 为 PWM1 模式
    设置 CCR2 = 2500
    启动 TIM3

主循环
    什么都不用做，PWM 由硬件自动输出
```

## 6. PWM 输出驱动怎么写

```c
#include "stm32f10x_conf.h"

void LED0_GPIO_TIM3_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;                    // 定义配置结构体变量
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;          // 定义配置结构体变量
    TIM_OCInitTypeDef TIM_OCInitStructure;                  // 定义配置结构体变量

    u32 CK_INT_FREQ = 72000000;
    u32 CK_CNT_FREQ = 1000 * 1000;
    u16 Update_FREQ = 100;
    float Duty = 0.25;

    u16 PrescalerValue = (u16)(CK_INT_FREQ / CK_CNT_FREQ) - 1;
    u16 ARRValue = (u16)(CK_CNT_FREQ / Update_FREQ) - 1;
    u16 CCRValue = (u16)(Duty * (ARRValue + 1));

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_AFIO, ENABLE); // 打开外设时钟
    GPIO_PinRemapConfig(GPIO_PartialRemap_TIM3, ENABLE);
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;               // 配置引脚
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;         // 配置工作模式
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;       // 配置输出速度
    GPIO_Init(GPIOB, &GPIO_InitStructure);                  // 真正初始化 GPIO

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);    // 打开外设时钟
    TIM_TimeBaseStructure.TIM_Period = ARRValue;            // 设置自动重装载值 (ARR)
    TIM_TimeBaseStructure.TIM_Prescaler = PrescalerValue;   // 设置预分频器值 (PSC)
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1; // 设置时钟分频
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up; // 设置计数模式
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);         // 真正初始化定时器基本计数

    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OCInitStructure.TIM_Pulse = CCRValue;
    TIM_OC2Init(TIM3, &TIM_OCInitStructure);                // 真正初始化定时器输出比较通道

    TIM_Cmd(TIM3, ENABLE);                                  // 启动外设
}
```

## 9. 最容易错的地方

- PB5 必须配 `GPIO_Mode_AF_PP`，不是 `GPIO_Mode_Out_PP`。
- 要打开 AFIO 时钟，否则重映射不可靠。
- 要调用 `GPIO_PinRemapConfig(GPIO_PartialRemap_TIM3, ENABLE)`，否则 TIM3_CH2 默认在 PA7。
- CCR2 决定占空比，ARR 决定周期，不要混。
- 忘记 `TIM_Cmd(TIM3, ENABLE)` 会导致没有 PWM 输出。
