# sy5 从 0 开始写代码

## 1. 这次实验要做什么

`1904300101张三@实验报告5.doc` 要求用 **TIM3 输出比较 PWM 功能**：

- 使用 TIM3_CH2 输出 PWM。
- 将 TIM3_CH2 部分重映射到 PB5。
- 在 PB5 上产生 100Hz、25% 占空比的 PWM 信号。
- 用这个 PWM 信号驱动 LED0。

一句话：sy5 是“定时器 PWM 输出控制 LED 亮度”。

## 2. 先认识硬件和 PWM 参数

| 对象 | 参数 | 作用 |
| --- | --- | --- |
| LED0 | PB5 | 接收 TIM3_CH2 重映射后的 PWM |
| TIM3_CH2 | PB5 | 输出比较通道 2 |
| PWM 频率 | 100Hz | 每秒 100 个周期 |
| 占空比 | 25% | 高电平时间占整个周期的 1/4 |

本实验中报告调试窗口要求看到：

```text
TIM3_PSC = 71
TIM3_ARR = 9999
TIM3_CCR2 = 2500
```

计算过程：

```text
TIM3_CLK = 72MHz
计数频率 = 72MHz / (71 + 1) = 1MHz
PWM 频率 = 1MHz / (9999 + 1) = 100Hz
占空比 = 2500 / (9999 + 1) = 25%
```

## 3. 本实验需要用到的库函数（考试会给）

| 你想做什么 | 库函数 |
| --- | --- |
| 打开 GPIOB/AFIO 时钟 | `RCC_APB2PeriphClockCmd()` |
| TIM3 部分重映射 | `GPIO_PinRemapConfig()` |
| 初始化 GPIO | `GPIO_Init()` |
| 打开 TIM3 时钟 | `RCC_APB1PeriphClockCmd()` |
| 初始化定时器 | `TIM_TimeBaseInit()` |
| 初始化输出比较通道 2 | `TIM_OC2Init()` |
| 启动定时器 | `TIM_Cmd()` |
| 修改 CCR2 | `TIM_SetCompare2()` |

常用结构体：

| 名称 | 作用 |
| --- | --- |
| `TIM_TimeBaseInitTypeDef` | 设置 PWM 频率，主要填 PSC 和 ARR |
| `TIM_OCInitTypeDef` | 设置 PWM 模式、输出极性、CCR 值 |
| `GPIO_InitTypeDef` | 设置 PB5 为复用推挽输出 |

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/led_driver.c/.h`：配置 PB5、TIM3、PWM 输出比较。
- `USER_APP/main.c`：调用 `LED0_GPIO_TIM3_Config()`，然后空循环。

PWM 输出由 TIM3 硬件自动完成，所以 `main.c` 不需要反复翻转 PB5。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求 PB5 输出 TIM3_CH2，所以 PB5 不能配普通输出，要配 `GPIO_Mode_AF_PP` 复用推挽输出。

第二步，TIM3_CH2 默认不在 PB5，需要打开 AFIO 并执行 TIM3 部分重映射。

第三步，实验要求 100Hz、25%，所以先算 PSC、ARR、CCR2。

第四步，配置 TIM3 基本计数和 OC2 PWM 模式，最后启动 TIM3。

### 5.2 完整伪代码

```text
开始

初始化 TIM3 PWM 输出
    计算 PSC = 71
    计算 ARR = 9999
    计算 CCR2 = 2500
    打开 GPIOB 和 AFIO 时钟
    开启 TIM3 部分重映射，让 TIM3_CH2 输出到 PB5
    PB5 配置为复用推挽输出
    打开 TIM3 时钟
    配置 TIM3 基本计数参数
    配置 TIM3_CH2 为 PWM1 模式
    设置 CCR2 = 2500
    启动 TIM3

主循环
    什么都不用做，PWM 由硬件自动输出
```

## 6. PWM 输出驱动怎么写

```c
#include "stm32f10x_conf.h"

void LED0_GPIO_TIM3_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    TIM_OCInitTypeDef TIM_OCInitStructure;

    u32 CK_INT_FREQ = 72000000;
    u32 CK_CNT_FREQ = 1000 * 1000;
    u16 Update_FREQ = 100;
    float Duty = 0.25;

    u16 PrescalerValue = (u16)(CK_INT_FREQ / CK_CNT_FREQ) - 1;
    u16 ARRValue = (u16)(CK_CNT_FREQ / Update_FREQ) - 1;
    u16 CCRValue = (u16)(Duty * (ARRValue + 1));

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_AFIO, ENABLE);
    GPIO_PinRemapConfig(GPIO_PartialRemap_TIM3, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = ARRValue;
    TIM_TimeBaseStructure.TIM_Prescaler = PrescalerValue;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OCInitStructure.TIM_Pulse = CCRValue;
    TIM_OC2Init(TIM3, &TIM_OCInitStructure);

    TIM_Cmd(TIM3, ENABLE);
}
```

## 9. 最容易错的地方

- PB5 必须配 `GPIO_Mode_AF_PP`，不是 `GPIO_Mode_Out_PP`。
- 要打开 AFIO 时钟，否则重映射不可靠。
- 要调用 `GPIO_PinRemapConfig(GPIO_PartialRemap_TIM3, ENABLE)`，否则 TIM3_CH2 默认在 PA7。
- CCR2 决定占空比，ARR 决定周期，不要混。
- 忘记 `TIM_Cmd(TIM3, ENABLE)` 会导致没有 PWM 输出。
