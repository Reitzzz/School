## 1. 这次实验要做什么

`1904300101张三@实验报告6.doc` 要求用 **TIM 输入捕获功能** 测量 PWM：

- TIM3_CH2 在 PA7 输出一个 100Hz、23.5% 占空比的 PWM 信号。
- 用杜邦线把 PA7 连接到 PA0。
- TIM2_CH1 在 PA0 输入捕获这个 PWM。
- 通过 PWM 输入模式测量频率和占空比。

一句话：sy6 是“TIM3 产生 PWM，TIM2 测量 PWM”。

## 2. 先认识硬件连接和测量关系

| 对象 | 引脚/通道 | 作用 |
| --- | --- | --- |
| TIM3_CH2 | PA7 | 产生待测 PWM |
| TIM2_CH1 | PA0 | 捕获 PWM 上升沿 |
| TIM2_CH2 | 内部间接通道 | 捕获同一输入信号的下降沿 |
| 杜邦线 | PA7 -> PA0 | 把输出信号接到输入捕获引脚 |

PWM 输入模式的核心：

```text
CCR1 记录周期计数值
CCR2 记录高电平计数值
频率 = 计数器频率 / CCR1
占空比 = CCR2 / CCR1
```

本实验 TIM2 的计数频率：

```text
TIM2_CLK = 72MHz
PSC = 719
计数频率 = 72MHz / (719 + 1) = 100kHz
```

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求“测量未知 PWM”，所以输入端 PA0 要配成输入，不能配输出。

第二步，PWM 有周期和高电平时间两个量，所以 TIM2 要用两个通道：CH1 测周期，CH2 测高电平。

第三步，为了让 CCR1 直接等于一个周期，TIM2 使用从模式 Reset：每次上升沿来时复位计数器。

第四步，在捕获中断里读 CCR1、CCR2，算频率和占空比。

### 5.2 完整伪代码

```text
开始

初始化 TIM3 PWM 发生器
    PA7 输出 100Hz、23.5% 占空比 PWM

初始化 TIM2 PWM 输入捕获
    PA0 配置为浮空输入
    TIM2 计数频率配置为 100kHz
    CH1 直接输入，上升沿捕获，记录周期
    CH2 间接输入，下降沿捕获，记录高电平时间
    选择 TI1FP1 作为触发源
    配置 Reset 从模式，让每次上升沿复位计数器
    打开 CC1 捕获中断
    在 NVIC 中打开 TIM2_IRQn
    启动 TIM2

主循环
    什么都不用做，在 Watch 窗口观察结果

如果进入 TIM2_IRQHandler
    检查 CC1 捕获中断标志
    读取 CCR1 作为周期计数值
    读取 CCR2 作为高电平计数值
    频率 = 100000 / CCR1
    占空比 = CCR2 / CCR1
    清除 CC1 中断标志
```

## 6. PWM 输入捕获驱动怎么写

```c
#include "stm32f10x_conf.h"
#include "misc.h"

void PWMTest_GPIO_TIM2_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;                    // 定义配置结构体变量
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;          // 定义配置结构体变量
    TIM_ICInitTypeDef TIM_ICInitStructure;                  // 定义配置结构体变量
    NVIC_InitTypeDef NVIC_InitStructure;                    // 定义配置结构体变量

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);   // 打开外设时钟

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;               // 配置引脚
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING;   // 配置工作模式
    GPIO_Init(GPIOA, &GPIO_InitStructure);                  // 真正初始化 GPIO

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);    // 打开外设时钟

    TIM_TimeBaseStructure.TIM_Period = 0xFFFF;              // 设置自动重装载值 (ARR)
    TIM_TimeBaseStructure.TIM_Prescaler = 719;              // 设置预分频器值 (PSC)
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1; // 设置时钟分频
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up; // 设置计数模式
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);         // 真正初始化定时器基本计数

    TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
    TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Rising;
    TIM_ICInitStructure.TIM_ICSelection = TIM_ICSelection_DirectTI;
    TIM_ICInitStructure.TIM_ICPrescaler = TIM_ICPSC_DIV1;
    TIM_ICInitStructure.TIM_ICFilter = 0x00;
    TIM_IC1Init(TIM2, &TIM_ICInitStructure);                // 真正初始化定时器输入捕获通道

    TIM_ICInitStructure.TIM_Channel = TIM_Channel_2;
    TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Falling;
    TIM_ICInitStructure.TIM_ICSelection = TIM_ICSelection_IndirectTI;
    TIM_ICInitStructure.TIM_ICPrescaler = TIM_ICPSC_DIV1;
    TIM_ICInitStructure.TIM_ICFilter = 0x00;
    TIM_IC2Init(TIM2, &TIM_ICInitStructure);                // 真正初始化定时器输入捕获通道

    TIM_SelectInputTrigger(TIM2, TIM_TS_TI1FP1);            // 选择输入触发源
    TIM_SelectSlaveMode(TIM2, TIM_SlaveMode_Reset);         // 配置定时器从模式
    TIM_SelectMasterSlaveMode(TIM2, TIM_MasterSlaveMode_Enable);

    TIM_ITConfig(TIM2, TIM_IT_CC1, ENABLE);                 // 使能外设中断

    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;         // 选择 NVIC 中断通道
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0; // 配置抢占优先级
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);                         // 真正初始化 NVIC

    TIM_Cmd(TIM2, ENABLE);                                  // 启动外设
}
```

## 7. 中断服务函数怎么写

```c
#include "stm32f10x_tim.h"
#include "PWM_driver.h"

float PWMDutyResult = 0;
float PWMFreqResult = 0;

void TIM2_IRQHandler(void)
{
    uint16_t PeriodValue;
    uint16_t PulseValue;

    if (TIM_GetITStatus(TIM2, TIM_IT_CC1) != RESET)         // 检查中断标志位是否被置位
    {
        PeriodValue = TIM_GetCapture1(TIM2);
        PulseValue = TIM_GetCapture2(TIM2);

        if (PeriodValue != 0)
        {
            PWMFreqResult = 100000.0 / PeriodValue;
            PWMDutyResult = (float)PulseValue / PeriodValue;
        }

        TIM_ClearITPendingBit(TIM2, TIM_IT_CC1);            // 清除中断标志位，防止死循环
    }
}
```

## 10. 最容易错的地方

- 忘记用杜邦线连接 PA7 和 PA0：TIM2 捕获不到信号。
- PA0 应该是 `GPIO_Mode_IN_FLOATING`。
- CH1 用 `TIM_ICSelection_DirectTI`，CH2 用 `TIM_ICSelection_IndirectTI`。
- CH1 捕获上升沿，CH2 捕获下降沿。
- 忘记配置 `TIM_SlaveMode_Reset`：周期值不好直接读。
- 频率计算要用 100000Hz，因为 TIM2 计数频率是 100kHz。
