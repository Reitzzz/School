# sy2 从 0 开始写代码

## 1. 这次实验要做什么

`sy2工程创建与设置.docx` 主要讲 Keil 工程怎么创建、怎么添加文件、怎么配置芯片型号和头文件路径。

真正需要写代码的部分，可以理解成一个 GPIO 输入输出实验：

- 使用 STM32F103ZE。
- 配置 GPIO 输出，控制两个 LED。
- 配置 GPIO 输入，读取三个按键。
- 在 `while(1)` 死循环里不断读按键。
- 根据按键状态点亮或熄灭 LED。

一句话：**sy2 的目标是用按键控制 LED。**

## 2. 先认识硬件连接

从 `led_driver.c` 和 `key_driver.h` 可以看出：

| 名称 | GPIO | 作用 | 有效电平 |
| --- | --- | --- | --- |
| LED0 | PB5 | 输出控制 DS0 | 低电平点亮 |
| LED1 | PE5 | 输出控制 DS1 | 低电平点亮 |
| KEY0 | PE4 | 输入读取按键 0 | 按下读到 0 |
| KEY1 | PE3 | 输入读取按键 1 | 按下读到 0 |
| KEY2 | PE2 | 输入读取按键 2 | 按下读到 0 |

注意两个很重要的点：

1. LED 是低电平点亮，所以 `GPIO_ResetBits()` 是点亮，`GPIO_SetBits()` 是熄灭。
2. KEY0、KEY1、KEY2 是上拉输入，所以没按下时读到 `1`，按下时读到 `0`。

## 3. 本实验需要用到的库函数（考试会给）

期末程序设计题一般会把可用库函数作为附件给出。sy2 只需要 GPIO 和 RCC 相关函数，重点不是背整段代码，而是知道“什么时候该用哪个函数”。

| 名称 | 作用 | 函数参数 |
| --- | --- | --- |
| `RCC_APB2PeriphClockCmd()` | 打开 GPIO 外设时钟，可近似理解为给 GPIO “通电”，让它开始工作 | 外设时钟名，开关状态<br>`RCC_APB2Periph_GPIOB`、`ENABLE` |
| `GPIO_InitTypeDef` | GPIO 初始化结构体类型，用它定义一个配置表变量。声明本身只是在内存里创建变量，还没有配置硬件 | 变量名<br>`GPIO_InitStructure` |
| `GPIO_InitStructure.GPIO_Pin` | 配置要初始化的 GPIO 引脚，可以单个引脚，也可以用 `\|` 同时选择多个引脚 | GPIO 引脚<br>`GPIO_Pin_5`、`GPIO_Pin_2 \| GPIO_Pin_3 \| GPIO_Pin_4` |
| `GPIO_InitStructure.GPIO_Mode` | 配置 GPIO 工作模式，决定这个引脚是输入、输出，还是复用功能 | GPIO 工作模式<br>`GPIO_Mode_Out_PP`（推挽输出）、`GPIO_Mode_IPU`（上拉输入）、`GPIO_Mode_IPD`（下拉输入） |
| `GPIO_InitStructure.GPIO_Speed` | 配置 GPIO 输出速度；只有输出或复用输出时需要重点设置 | GPIO 输出速度<br>`GPIO_Speed_50MHz` |
| `GPIO_Init()` | 按设置好的配置表初始化 GPIO，真正把结构体里的配置写进 GPIO 硬件 | GPIO 端口，GPIO 初始化结构体地址<br>`GPIOB`、`&GPIO_InitStructure` |
| `GPIO_SetBits()` | 初始化完成后输出高电平 | GPIO 端口，引脚号<br>`GPIOB`、`GPIO_Pin_5` |
| `GPIO_ResetBits()` | 初始化完成后输出低电平 | GPIO 端口，引脚号<br>`GPIOB`、`GPIO_Pin_5` |
| `GPIO_ReadInputDataBit()` | 初始化完成后读取输入引脚电平 | GPIO 端口，引脚号<br>`GPIOE`、`GPIO_Pin_4` |

表格的顺序可以这样理解：

```text
先打开 GPIO 时钟，让 GPIO 外设能工作
再定义 GPIO_InitTypeDef 结构体变量，准备一张配置表
再给配置表的字段赋值
最后调用 GPIO_Init()，把配置真正写入硬件
```

## 4. 驱动和 main.c 怎么分工

可以这样理解：

| 文件 | 主要负责什么 |
| --- | --- |
| `led_driver.c/.h` | 初始化 LED 用到的 GPIO，并提供点亮、熄灭 LED 的函数 |
| `key_driver.c/.h` | 初始化按键用到的 GPIO，并提供读取按键状态的宏或函数 |
| `main.c` | 调用驱动初始化函数，然后根据按键状态决定具体动作 |

所以“驱动”可以近似理解为：**把硬件先配置好，让 LED 和按键能被程序使用。**

`main.c` 更像是写“业务逻辑”的地方：按下哪个键，要让哪个灯亮或灭。

也就是说：

```text
驱动层：负责初始化硬件，封装硬件操作
main.c：负责判断状态，决定具体动作
```

## 5. 先写伪代码

写 C 代码前，先把程序想成“人话流程”。

### 5.1 怎么得出伪代码

伪代码不是凭空背出来的，而是从实验要求一步一步推出来的。

第一步，看实验要完成什么功能：**按键控制 LED**。这句话里已经能分出两个对象：

```text
按键是输入
LED 是输出
```

第二步，看硬件连接表。KEY0、KEY1、KEY2 接在 PE4、PE3、PE2，所以程序必须先把这些引脚配置成输入；LED0、LED1 接在 PB5、PE5，所以程序必须先把这些引脚配置成输出。

```text
PE2、PE3、PE4 是输入
PB5、PE5 是输出
```

第三步，看有效电平。按键按下读到 `0`，松开读到 `1`；LED 输出低电平点亮，输出高电平熄灭。

```text
KEYx == 0 表示按下
LED 点亮 = 输出 0
LED 熄灭 = 输出 1
```

第四步，把“初始化”和“循环判断”分开：

```text
程序开始时，只需要初始化一次
while(1) 里反复读取按键并控制 LED
```

### 5.2 完整伪代码

```text
开始

初始化 LED
    打开 GPIOB、GPIOE 时钟
    准备 GPIO 配置表
    PB5 配置为推挽输出
    PE5 配置为推挽输出
    默认输出高电平，让 LED0、LED1 熄灭

初始化按键
    打开 GPIOE 时钟
    准备 GPIO 配置表
    PE2、PE3、PE4 配置为上拉输入

进入 while(1) 死循环
    如果 KEY0 被按下
        点亮 LED0
    否则
        熄灭 LED0

    如果 KEY1 被按下
        点亮 LED1
    否则
        熄灭 LED1

    如果 KEY2 被按下
        同时点亮 LED0 和 LED1
```

## 6. LED 驱动怎么写

先写初始化函数，把 LED 对应的 GPIO 配置成输出。

```c
void LED_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;

    GPIO_Init(GPIOB, &GPIO_InitStructure);
    GPIO_SetBits(GPIOB, GPIO_Pin_5);

    GPIO_Init(GPIOE, &GPIO_InitStructure);
    GPIO_SetBits(GPIOE, GPIO_Pin_5);
}
```

这里的顺序要理解清楚：

```text
RCC_APB2PeriphClockCmd()：先打开 GPIOB、GPIOE 时钟
GPIO_InitTypeDef GPIO_InitStructure：定义配置表变量
GPIO_InitStructure.xxx = xxx：填写配置表
GPIO_Init()：真正初始化 GPIO
GPIO_SetBits()：默认输出高电平，让 LED 熄灭
```

虽然在 C 代码里，局部变量声明通常会放在函数开头；但从理解硬件流程来说，可以记成：**先开时钟，再准备配置表，再初始化硬件。**

## 7. 按键驱动怎么写

按键是输入，所以要配置为上拉输入。

```c
void KEY_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2 | GPIO_Pin_3 | GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;

    GPIO_Init(GPIOE, &GPIO_InitStructure);
}
```

读取按键时，只需要读对应引脚电平：

```c
GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4);
GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_3);
GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_2);
```

因为按下是低电平，所以判断按下时要写：

```c
if (GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4) == 0)
{
    // KEY0 被按下
}
```

## 8. main.c 怎么写

`main.c` 不负责重新讲一遍 GPIO 怎么配置，它只负责调用初始化函数，然后根据按键状态做动作。

```c
int main(void)
{
    LED_GPIO_Config();
    KEY_GPIO_Config();

    while (1)
    {
        if (GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4) == 0)
        {
            GPIO_ResetBits(GPIOB, GPIO_Pin_5);
        }
        else
        {
            GPIO_SetBits(GPIOB, GPIO_Pin_5);
        }

        if (GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_3) == 0)
        {
            GPIO_ResetBits(GPIOE, GPIO_Pin_5);
        }
        else
        {
            GPIO_SetBits(GPIOE, GPIO_Pin_5);
        }
    }
}
```

考试时如果给了 `LED0_ON()`、`LED0_OFF()`、`KEY0` 这类宏，就优先用宏；如果没给，就直接用 `GPIO_SetBits()`、`GPIO_ResetBits()`、`GPIO_ReadInputDataBit()`。

## 9. 最后怎么检查自己有没有写对

写完后按这个顺序检查：

| 检查点 | 你要确认什么 |
| --- | --- |
| 时钟 | 用到 GPIOB、GPIOE，就要打开 GPIOB、GPIOE 时钟 |
| LED 模式 | LED 引脚要配置成 `GPIO_Mode_Out_PP` |
| 按键模式 | KEY0、KEY1、KEY2 要配置成 `GPIO_Mode_IPU` |
| 有效电平 | LED 低电平点亮，按键按下读到 0 |
| 初始化位置 | 初始化函数只在 `main()` 开始时调用一次 |
| 循环逻辑 | `while(1)` 里反复读按键，反复控制 LED |

最容易错的地方：

- 把 LED 的亮灭电平写反。
- 忘记打开 GPIO 时钟。
- 忘记调用 `GPIO_Init()`。
- 把按键按下判断写成 `== 1`。
- 只定义了 `GPIO_InitTypeDef GPIO_InitStructure;`，但没有给字段赋值，也没有调用 `GPIO_Init()`。
