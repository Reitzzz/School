# sy2 从 0 开始写代码

## 1. 这次实验要做什么

`sy2工程创建与设置.docx` 主要讲 Keil 工程怎么创建、怎么添加文件、怎么配置芯片型号和头文件路径。真正写代码的主题在资源代码里：

- 使用 STM32F103ZE。
- 配置 GPIO 输出控制两个 LED。
- 配置 GPIO 输入读取三个按键。
- 在 `while(1)` 死循环里不断读按键，根据按键状态点亮或熄灭 LED。

一句话：sy2 是 GPIO 输入输出实验，目标是“按键控制 LED”。

## 2. 先认识硬件连接

从 `led_driver.c` 和 `key_driver.h` 可以看出：

| 名称 | GPIO | 作用 | 有效电平 |
| --- | --- | --- | --- |
| LED0 | PB5 | 输出控制 DS0 | 低电平点亮 |
| LED1 | PE5 | 输出控制 DS1 | 低电平点亮 |
| KEY0 | PE4 | 输入读取按键 0 | 按下读 0 |
| KEY1 | PE3 | 输入读取按键 1 | 按下读 0 |
| KEY2 | PE2 | 输入读取按键 2 | 按下读 0 |

注意两个很重要的点：

1. LED 是低电平点亮，所以 `GPIO_ResetBits()` 是点亮，`GPIO_SetBits()` 是熄灭。
2. KEY0、KEY1、KEY2 是上拉输入，所以没按下时读到 `1`，按下时读到 `0`。

## 3. 本实验需要用到的库函数（考试会给）

期末程序设计题一般会把可用库函数作为附件给出。sy2 只需要 GPIO 和 RCC 相关函数，重点是知道“什么时候该用哪个函数”。

| 你想做什么 | 库函数 |
| --- | --- |
| 打开 GPIO 外设时钟 | `RCC_APB2PeriphClockCmd()` |
| 按配置表初始化 GPIO | `GPIO_Init()` |
| 输出高电平 | `GPIO_SetBits()` |
| 输出低电平 | `GPIO_ResetBits()` |
| 读取输入引脚电平 | `GPIO_ReadInputDataBit()` |

还要认识两个结构体和几个常用配置值：

| 名称 | 作用 |
| --- | --- |
| `GPIO_InitTypeDef` | GPIO 初始化结构体，用来填写引脚、模式、速度 |
| `GPIO_Mode_Out_PP` | 推挽输出，用于 LED 这种普通数字输出 |
| `GPIO_Mode_IPU` | 上拉输入，用于 KEY0、KEY1、KEY2 |
| `GPIO_Mode_IPD` | 下拉输入，用于 WK_UP 这类按下为高电平的按键 |
| `GPIO_Speed_50MHz` | GPIO 输出速度，LED 控制用这个即可 |

考试答题时，不要一上来背整段代码。先想清楚：

```text
输出 LED -> 开 GPIO 时钟 -> GPIO_Mode_Out_PP -> GPIO_SetBits / GPIO_ResetBits
输入按键 -> 开 GPIO 时钟 -> GPIO_Mode_IPU -> GPIO_ReadInputDataBit
```

## 4. 写代码前先分层

sy2 已经把代码分成三类：

- `USER_APP/main.c`：主程序，写业务逻辑。
- `USER_DEVICE_DRIVER/led_driver.c/.h`：LED 初始化和控制函数。
- `USER_DEVICE_DRIVER/key_driver.c/.h`：按键初始化和读取宏。
- `USER_APP/sw_delay.c/.h`：软件延时。

写嵌入式代码时，建议先把底层驱动写好，再在 `main.c` 里调用。不要一上来就在 `main.c` 里堆所有寄存器或库函数，不然很快就乱。

## 5. 先写伪代码

写 C 代码前，先把程序想成“人话流程”。先看伪代码是怎么得出来的，再看完整伪代码。

### 5.1 怎么得出伪代码

伪代码不是凭空背出来的，而是从实验要求一步一步推出来的。

第一步，看实验要完成什么功能：**按键控制 LED**。这句话里已经能分出两个对象：按键是输入，LED 是输出。

```text
需要读取按键状态
需要控制 LED 亮灭
```

第二步，看硬件连接表。KEY0、KEY1、KEY2 接在 PE4、PE3、PE2，所以程序必须先配置这几个引脚为输入；LED0、LED1 接在 PB5、PE5，所以程序必须先配置这几个引脚为输出。

```text
PE2、PE3、PE4 是输入
PB5、PE5 是输出
```

第三步，看有效电平。按键按下读到 `0`，松开读到 `1`；LED 输出低电平点亮，输出高电平熄灭。所以判断时不能写反。

```text
KEYx == 0 表示按下
LED 点亮 = 输出 0
LED 熄灭 = 输出 1
```

第四步，把“硬件初始化”和“循环控制”分开。单片机程序通常先初始化外设，再进入 `while(1)` 一直运行。

```text
先初始化按键
再初始化 LED
然后一直循环读取按键并控制 LED
```

第五步，把实验要求中的按键和 LED 对应关系写成条件判断：

| 条件 | 要做什么 |
| --- | --- |
| 都没按 | 两个 LED 都熄灭 |
| KEY2 按下 | LED0 亮，LED1 灭 |
| KEY1 按下 | LED0 灭，LED1 亮 |
| KEY0 按下 | 两个 LED 都亮 |

把上面五步连起来，就得到下面的完整伪代码。

```text
开始

初始化按键 GPIO
    打开 GPIOE 的时钟
    把 PE2、PE3、PE4 配置成上拉输入
    以后读取 PE4 就表示 KEY0
    以后读取 PE3 就表示 KEY1
    以后读取 PE2 就表示 KEY2

初始化 LED GPIO
    打开 GPIOB 和 GPIOE 的时钟
    把 PB5 配置成推挽输出，用来控制 LED0
    把 PE5 配置成推挽输出，用来控制 LED1
    让 PB5 输出高电平，LED0 默认熄灭
    让 PE5 输出高电平，LED1 默认熄灭

一直循环
    如果 KEY0、KEY1、KEY2 都没有按下
        熄灭 LED0
        熄灭 LED1

    如果只有 KEY2 按下
        点亮 LED0
        熄灭 LED1

    如果只有 KEY1 按下
        熄灭 LED0
        点亮 LED1

    如果只有 KEY0 按下
        点亮 LED0
        点亮 LED1
结束
```

把这段伪代码翻译成 C 语言时，只要记住三组对应关系：

| 伪代码动作 | C 代码怎么写 |
| --- | --- |
| 打开 GPIO 时钟 | `RCC_APB2PeriphClockCmd(..., ENABLE);` |
| 配置 GPIO 输入/输出 | 填 `GPIO_InitTypeDef`，再调用 `GPIO_Init()` |
| 读按键、控制 LED | `GPIO_ReadInputDataBit()`、`GPIO_SetBits()`、`GPIO_ResetBits()` |

所以期末遇到 GPIO 程序设计题，可以先在草稿纸上写这种伪代码，再逐句翻译成标准库代码。

## 6. LED 驱动怎么写

LED 驱动分两步：

1. 打开 GPIOB 和 GPIOE 的时钟。
2. 把 PB5、PE5 配成推挽输出。

核心代码：

```c
void LED_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;

    GPIO_Init(GPIOB, &GPIO_InitStructure);
    GPIO_SetBits(GPIOB, GPIO_Pin_5);

    GPIO_Init(GPIOE, &GPIO_InitStructure);
    GPIO_SetBits(GPIOE, GPIO_Pin_5);
}
```

解释：

- `RCC_APB2PeriphClockCmd(...)`：不给 GPIO 开时钟，后面配置不会生效。
- `GPIO_Mode_Out_PP`：推挽输出，适合普通 LED 控制。
- 初始化后 `GPIO_SetBits()`：先输出高电平，让 LED 默认熄灭。

然后封装控制函数：

```c
void LED0_LightUp(void)
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_5);
}

void LED0_PutOut(void)
{
    GPIO_SetBits(GPIOB, GPIO_Pin_5);
}

void LED1_LightUp(void)
{
    GPIO_ResetBits(GPIOE, GPIO_Pin_5);
}

void LED1_PutOut(void)
{
    GPIO_SetBits(GPIOE, GPIO_Pin_5);
}
```

## 7. 按键驱动怎么写

KEY0、KEY1、KEY2 接在 PE4、PE3、PE2，使用上拉输入。

```c
void KEY_GPIO_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOE, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2 | GPIO_Pin_3 | GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_Init(GPIOE, &GPIO_InitStructure);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPD;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
}
```

解释：

- `GPIO_Mode_IPU`：上拉输入，默认读 1，按下读 0。
- `GPIO_Mode_IPD`：下拉输入，给 PA0 的 WK_UP 用，本实验主逻辑暂时没用它。

在头文件里用宏简化读取：

```c
#define KEY0 GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_4)
#define KEY1 GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_3)
#define KEY2 GPIO_ReadInputDataBit(GPIOE, GPIO_Pin_2)
```

以后在 `main.c` 里直接写 `KEY0 == 0` 就表示 KEY0 被按下。

## 8. 主函数怎么写

主函数只做三件事：

1. 初始化按键。
2. 初始化 LED。
3. 死循环检测按键状态并控制 LED。

```c
#include "key_driver.h"
#include "led_driver.h"

int main(void)
{
    KEY_GPIO_Config();
    LED_GPIO_Config();

    while (1)
    {
        if ((KEY0 == 1) && (KEY1 == 1) && (KEY2 == 1))
        {
            LED0_PutOut();
            LED1_PutOut();
        }

        if ((KEY0 == 1) && (KEY1 == 1) && (KEY2 == 0))
        {
            LED0_LightUp();
            LED1_PutOut();
        }

        if ((KEY0 == 1) && (KEY1 == 0) && (KEY2 == 1))
        {
            LED0_PutOut();
            LED1_LightUp();
        }

        if ((KEY0 == 0) && (KEY1 == 1) && (KEY2 == 1))
        {
            LED0_LightUp();
            LED1_LightUp();
        }
    }
}
```

逻辑表：

| 按键状态 | LED0 | LED1 |
| --- | --- | --- |
| 都没按 | 熄灭 | 熄灭 |
| KEY2 按下 | 点亮 | 熄灭 |
| KEY1 按下 | 熄灭 | 点亮 |
| KEY0 按下 | 点亮 | 点亮 |

## 9. 从 0 写的时候按这个顺序来

1. 新建 Keil 工程，芯片选 `STM32F103ZE`。
2. 按文档创建代码组：`CMSIS_LIB`、`SYSTEM`、`USER_APP`、`USER_DEVICE_DRIVER`。
3. 添加对应 `.c` 文件。
4. 在 C/C++ 里添加宏和头文件路径。
5. 先写 `led_driver.h` 和 `led_driver.c`。
6. 再写 `key_driver.h` 和 `key_driver.c`。
7. 最后写 `main.c`。
8. 编译，先解决头文件路径和函数声明问题。
9. 下载到开发板，按 KEY0、KEY1、KEY2 验证 LED 反应。

## 10. 最容易错的地方

- 忘记开 GPIO 时钟：LED 或按键完全没反应。
- 把 LED 有效电平搞反：写了点亮函数但实际熄灭。
- 把按键按下判断写成 `KEYx == 1`：上拉按键按下是 `0`。
- 头文件没加进 Keil Include Paths：会报找不到 `stm32f10x_conf.h` 或驱动头文件。
- `.c` 文件没加入工程组：代码写了但链接时报函数未定义。
