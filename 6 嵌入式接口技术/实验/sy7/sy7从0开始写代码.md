## 1. 这次实验要做什么

考试大纲要求完成 **DAC 波形发生器实验**：

- 硬件准备：参照图 12，使用跳线帽短接 P3 的 3、4 脚。
- DAC 配置：通过单片机的 DAC 通道 1 产生正弦波。明确要求 **正常输出、无波形、不开缓冲**。
- 触发方式：由 **TIM2 定时更新**，定时周期为 **2ms**。
- 实验操作：用示波器测量 P3 的 3 脚。要修改代码调整正弦表最大值（如 400、2000、4095）或定时器周期，观察波形变化。

一句话：sy7 是“配置一个 2ms 进一次中断的定时器，在中断里把算好的正弦数据塞给 DAC，让它拼凑出一个完整的正弦波”。

## 2. 先认识外设和波形发生关系

| 对象 | 作用 |
| --- | --- |
| 正弦表数组 | 提前算好的正弦波离散点数字量集合，如 32 个点构成一个正弦周期 |
| DAC 通道 1 | 把数组里的 12 位数字量依次转换成模拟电压（内部对应 PA4 引脚） |
| TIM2 | 每 2ms 产生一次定时中断 |
| TIM2_IRQn | 在定时中断服务函数里，负责把数组里的下一个点写入 DAC |
| P3 的 3、4 脚 | 硬件跳线，将 DAC 模拟输出引到测试端，供示波器观察 |

**DAC 数字量和电压关系**：
```text
DAC 是 12 位：范围 0 ~ 4095
输出电压(V) = (DAC数字量 / 4095) * 3.3V
```

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求输出正弦波，所以得先**算好一个正弦表数组**。
第二步，DAC 走通道 1，引脚是 PA4，要配成**模拟输入模式（AIN）**。
第三步，DAC 要求：**正常输出、无波形发生器、不开缓冲**。因为不依赖定时器的硬件 TRGO 触发，所以选择 `DAC_Trigger_None`。
第四步，要求 **TIM2 定时周期 2ms**，用 $72\text{MHz}$ 算，PSC = 7199 时计数频率是 $10\text{kHz}$（$0.1\text{ms}$），那么 ARR = 19 时，周期刚好是 $20 \times 0.1\text{ms} = 2\text{ms}$。
第五步，因为是定时器中断里写数据，要打开 TIM2 的中断并在 NVIC 开通通道。
第六步，在 `TIM2_IRQHandler` 中，把正弦表的数值一个一个写入 DAC 的寄存器，写到数组末尾再重头开始。

### 5.2 完整伪代码

```text
开始

准备正弦波数组

初始化 TIM2、DAC1、NVIC
    打开 GPIOA 时钟
    打开 DAC 时钟
    打开 TIM2 时钟
    配置 PA4 为模拟输入
    初始化 DAC：无触发，无硬件波形，关闭输出缓冲
    开启 DAC 通道 1
    
    配置 NVIC 打开 TIM2_IRQn
    
    TIM2 设置为每 2ms 更新一次 (ARR=19, PSC=7199)
    打开 TIM2 更新中断
    启动 TIM2

主循环
    什么都不用做，正弦波数据由定时器中断每 2ms 写入一次

如果进入 TIM2_IRQHandler
    判断是不是 TIM2 更新中断
    DAC_SetChannel1Data 写入正弦表当前点的数据
    索引+1
    如果索引越界，索引清零
    清除 TIM2 中断标志
```

## 6. 外设驱动怎么写

可以在 `dac_driver.c` 中实现：

```c
#include "stm32f10x_conf.h"

// 生成一个32个点的正弦表，最大值4095
// 考试要求：“调整正弦表大小（例如调整最大值为400、2000、4095）”，只需在此按比例缩放即可
const uint16_t sin_tab[32] = {
    2048, 2447, 2831, 3185, 3495, 3750, 3939, 4056,
    4095, 4056, 3939, 3750, 3495, 3185, 2831, 2447,
    2048, 1649, 1265,  911,  601,  346,  157,   40,
       0,   40,  157,  346,  601,  911, 1265, 1649
};

void DAC_TIM2_NVIC_CONFIG(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    DAC_InitTypeDef DAC_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    // 1. 开时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_DAC, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    // 2. GPIO 配置：PA4 (DAC_OUT1)
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AIN; // DAC输出必须是模拟输入
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // 3. DAC 配置
    DAC_InitStructure.DAC_Trigger = DAC_Trigger_None; // 中断中软件写入，不需外设触发
    DAC_InitStructure.DAC_WaveGeneration = DAC_WaveGeneration_None; // 无波形
    DAC_InitStructure.DAC_LFSRUnmask_TriangleAmplitude = DAC_LFSRUnmask_Bit0;
    DAC_InitStructure.DAC_OutputBuffer = DAC_OutputBuffer_Disable; // 不开缓冲
    DAC_Init(DAC_Channel_1, &DAC_InitStructure);
    DAC_Cmd(DAC_Channel_1, ENABLE);

    // 4. NVIC 配置
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    // 5. TIM2 配置：2ms 周期
    // 72MHz / 7200 = 10kHz (0.1ms/tick), 0.1ms * 20 = 2ms
    TIM_TimeBaseStructure.TIM_Period = 20 - 1;
    TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);

    TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);
    TIM_Cmd(TIM2, ENABLE);
}
```

## 7. 定时器中断服务函数怎么写

在 `it.c` 中写中断服务函数：

```c
#include "stm32f10x_conf.h"

extern const uint16_t sin_tab[32]; // 引用驱动里的正弦表
static uint8_t sin_index = 0;      // 正弦表游标

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET)
    {
        // 往 DAC 写当前点的数据
        DAC_SetChannel1Data(DAC_Align_12b_R, sin_tab[sin_index]);
        
        // 游标递增，越界清零
        sin_index++;
        if (sin_index >= 32)
        {
            sin_index = 0;
        }

        // 必须清除中断标志，否则会卡死在中断中
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update); 
    }
}
```

## 8. 主函数怎么写

主函数只需要初始化外设即可。在 `main.c` 中：

```c
// 假设头文件名为 dac_driver.h，需先声明刚才的配置函数
extern void DAC_TIM2_NVIC_CONFIG(void);

int main(void)
{
    // 调用 DAC 与定时器初始化函数
    DAC_TIM2_NVIC_CONFIG();

    while (1)
    {
        // 什么都不做，每隔 2ms 定时器自动进中断更新一次波形
    }
}
```
