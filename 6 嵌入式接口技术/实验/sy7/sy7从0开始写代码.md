# sy7 从 0 开始写代码

## 1. 这次实验要做什么

`1904300101张三@实验报告7.doc` 要求完成 **ADC 中断方式实验**：

- 模拟信号源使用 STM32 内部温度传感器。
- TIM3 每隔 1 秒触发一次 ADC1 转换。
- ADC 转换完成后进入 `ADC1_2_IRQHandler()`。
- 在中断服务函数中读取 ADC 数字量，计算电压和温度，并显示到 LCD。

一句话：sy7 是“TIM3 定时触发 ADC，ADC 中断读取结果并显示”。

## 2. 先认识信号和外设关系

| 对象 | 作用 |
| --- | --- |
| 内部温度传感器 | 模拟信号源，对应 ADC 通道 16 |
| ADC1 | 把模拟电压转换成 12 位数字量 |
| TIM3 | 每 1 秒输出一次 TRGO 触发信号 |
| ADC1_2_IRQn | ADC1/ADC2 共用中断通道 |
| LCD | 显示 ADC 值、电压、温度 |

ADC 数字量和电压关系：

```text
ADC 是 12 位：0 ~ 4095
电压(mV) = ADC值 * 3300 / 4096
```

内部温度传感器常用公式：

```text
T = 25 + (1.43V - Vsense) / 4.3mV
```

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/sensor_driver.c/.h`：配置 TIM3、ADC1、NVIC。
- `USER_APP/it.c`：写 `ADC1_2_IRQHandler()`，读取并计算结果。
- `USER_APP/main.c`：初始化 LCD，调用传感器配置函数，显示固定标题。
- `USER_DEVICE_DRIVER/lcd_driver.c/.h`：实验资源已提供，负责 LCD 显示。

驱动层负责“让 TIM3 和 ADC1 按要求工作”；中断服务函数负责“数据来了怎么处理”。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，实验要求“每隔 1 秒触发一次”，所以需要 TIM3 配成 1 秒更新。

第二步，实验要求“TIM3 触发 ADC”，所以 TIM3 更新事件要作为 TRGO，ADC 外部触发源选 `ADC_ExternalTrigConv_T3_TRGO`。

第三步，实验要求“中断方式获取结果”，所以 ADC 要开启 EOC 中断，NVIC 要打开 `ADC1_2_IRQn`。

第四步，实验要求“内部温度传感器”，所以 ADC 通道选择 `ADC_Channel_TempSensor`，并开启 `ADC_TempSensorVrefintCmd(ENABLE)`。

### 5.2 完整伪代码

```text
开始

初始化 LCD
初始化 TIM3、ADC1、NVIC
    打开 ADC1 时钟
    打开 TIM3 时钟
    ADC 时钟设置为 PCLK2 / 6
    NVIC 打开 ADC1_2_IRQn
    TIM3 设置为每 1 秒更新一次
    TIM3 更新事件作为 TRGO 输出
    ADC1 设置为独立模式、单通道、非连续转换
    ADC1 外部触发源选择 TIM3_TRGO
    打开内部温度传感器
    ADC1 规则通道选择温度传感器通道
    打开 ADC 转换完成中断
    打开 ADC 外部触发
    使能 ADC1
    校准 ADC1
    启动 TIM3

主循环
    什么都不用做，LCD 数据由 ADC 中断刷新

如果进入 ADC1_2_IRQHandler
    判断是不是 ADC1 转换完成中断
    读取 ADC 数字量
    数字量换算成 mV
    mV 换算成温度
    刷新 LCD
    清除 ADC 中断标志
```

## 6. 传感器驱动怎么写

```c
#include "stm32f10x_conf.h"

void SNESOR_TIM_ADC_NVIC_CONFIG(void)
{
    ADC_InitTypeDef ADC_InitStructure;
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);
    RCC_ADCCLKConfig(RCC_PCLK2_Div6);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitStructure.NVIC_IRQChannel = ADC1_2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    TIM_TimeBaseStructure.TIM_Period = 10000 - 1;
    TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1;
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);
    TIM_SelectOutputTrigger(TIM3, TIM_TRGOSource_Update);

    ADC_DeInit(ADC1);
    ADC_InitStructure.ADC_Mode = ADC_Mode_Independent;
    ADC_InitStructure.ADC_ScanConvMode = DISABLE;
    ADC_InitStructure.ADC_ContinuousConvMode = DISABLE;
    ADC_InitStructure.ADC_ExternalTrigConv = ADC_ExternalTrigConv_T3_TRGO;
    ADC_InitStructure.ADC_DataAlign = ADC_DataAlign_Right;
    ADC_InitStructure.ADC_NbrOfChannel = 1;
    ADC_Init(ADC1, &ADC_InitStructure);

    ADC_TempSensorVrefintCmd(ENABLE);
    ADC_RegularChannelConfig(ADC1, ADC_Channel_TempSensor, 1, ADC_SampleTime_239Cycles5);
    ADC_ITConfig(ADC1, ADC_IT_EOC, ENABLE);
    ADC_ExternalTrigConvCmd(ADC1, ENABLE);
    ADC_Cmd(ADC1, ENABLE);

    ADC_ResetCalibration(ADC1);
    while (ADC_GetResetCalibrationStatus(ADC1));
    ADC_StartCalibration(ADC1);
    while (ADC_GetCalibrationStatus(ADC1));

    TIM_Cmd(TIM3, ENABLE);
}
```

## 7. ADC 中断服务函数怎么写

```c
#include "lcd_driver.h"
#include "stm32f10x_conf.h"

static void LCD_ShowFixed3(u16 x, u16 y, u32 value)
{
    LCD_ShowNum(x, y, value / 1000, 1, 16);
    LCD_ShowChar(x + 8, y, '.', 16, 0);
    LCD_ShowxNum(x + 16, y, value % 1000, 3, 16, 0X80);
}

static void LCD_ShowTemperature(u16 x, u16 y, int temp_mc)
{
    u32 abs_temp;

    if (temp_mc < 0)
    {
        LCD_ShowChar(x, y, '-', 16, 0);
        abs_temp = (u32)(-temp_mc);
    }
    else
    {
        LCD_ShowChar(x, y, ' ', 16, 0);
        abs_temp = (u32)temp_mc;
    }

    LCD_ShowNum(x + 8, y, abs_temp / 1000, 2, 16);
    LCD_ShowChar(x + 24, y, '.', 16, 0);
    LCD_ShowxNum(x + 32, y, abs_temp % 1000, 3, 16, 0X80);
}

void ADC1_2_IRQHandler(void)
{
    u16 adc_value;
    u32 adc_mv;
    int temp_mc;

    if (ADC_GetITStatus(ADC1, ADC_IT_EOC) != RESET)
    {
        adc_value = ADC_GetConversionValue(ADC1);
        adc_mv = (u32)adc_value * 3300 / 4096;
        temp_mc = 25000 + ((1430 - (int)adc_mv) * 10000) / 43;

        POINT_COLOR = BLUE;
        LCD_ShowNum(180, 130, adc_value, 4, 16);
        LCD_ShowFixed3(180, 150, adc_mv);
        LCD_ShowTemperature(156, 170, temp_mc);

        ADC_ClearITPendingBit(ADC1, ADC_IT_EOC);
    }
}
```

## 10. 最容易错的地方

- 忘记 `RCC_ADCCLKConfig(RCC_PCLK2_Div6)`：ADC 时钟不合适。
- 忘记 `TIM_SelectOutputTrigger(TIM3, TIM_TRGOSource_Update)`：TIM3 不会给 ADC 触发信号。
- 忘记 `ADC_ExternalTrigConvCmd(ADC1, ENABLE)`：ADC 不响应外部触发。
- 忘记 `ADC_TempSensorVrefintCmd(ENABLE)`：内部温度传感器没有打开。
- ADC1/ADC2 的中断入口叫 `ADC1_2_IRQHandler()`，NVIC 通道是 `ADC1_2_IRQn`。
- 忘记 ADC 校准：采样值可能不稳定。
- 忘记清除 `ADC_IT_EOC`：会反复进入 ADC 中断。
