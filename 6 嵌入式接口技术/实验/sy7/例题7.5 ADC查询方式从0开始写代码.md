# 例题 7.5 ADC 查询方式从 0 开始写代码

## 1. 这道应用题要做什么

例题 7.5 考的是 **查询方式获得 ADC 转换后的数字量**。

一句话：把某个模拟输入引脚配置给 ADC，用软件启动一次转换，然后一直查询转换结束标志 `ADC_FLAG_EOC`，标志置位后读取 ADC 转换结果。

典型流程：

```text
配置 GPIO 模拟输入
配置 ADC1
配置 ADC 规则通道
使能并校准 ADC

需要读取时：
    软件启动 ADC 转换
    查询 EOC 标志
    读取 ADC 转换数字量
```

## 2. 先认识外设关系

| 对象 | 作用 |
| --- | --- |
| 模拟输入引脚 | 接收外部模拟电压，例如 `PA1` |
| ADC1 | 把模拟电压转换成 12 位数字量 |
| 规则通道 | 指定 ADC 本次转换哪个输入通道，例如 `ADC_Channel_1` |
| 查询方式 | 程序循环判断 `ADC_FLAG_EOC`，等转换结束后再读取结果 |

ADC 数字量范围：

```text
12 位 ADC：0 ~ 4095
```

如果量程为 `0 ~ 3.3V`：

```text
ADC数字量 = 输入电压 / 3.3 * 4095
输入电压 = ADC数字量 / 4095 * 3.3
```

## 3. 本题需要用到的库函数

### 3.1 GPIO 和 RCC 相关

| 名称 | 作用 | 典型写法 |
| --- | --- | --- |
| `RCC_APB2PeriphClockCmd()` | 打开 GPIOA、ADC1 时钟 | `RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA \| RCC_APB2Periph_ADC1, ENABLE);` |
| `RCC_ADCCLKConfig()` | 配置 ADC 时钟分频 | `RCC_ADCCLKConfig(RCC_PCLK2_Div6);` |
| `GPIO_InitTypeDef` | 定义 GPIO 配置结构体 | `GPIO_InitTypeDef GPIO_InitStructure;` |
| `GPIO_InitStructure.GPIO_Mode` | ADC 输入引脚要配置成模拟输入 | `GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AIN;` |
| `GPIO_Init()` | 初始化 GPIO | `GPIO_Init(GPIOA, &GPIO_InitStructure);` |

### 3.2 ADC 相关

| 名称 | 作用 | 典型写法 |
| --- | --- | --- |
| `ADC_InitTypeDef` | 定义 ADC 配置结构体 | `ADC_InitTypeDef ADC_InitStructure;` |
| `ADC_Init()` | 初始化 ADC | `ADC_Init(ADC1, &ADC_InitStructure);` |
| `ADC_RegularChannelConfig()` | 配置规则通道、顺序、采样时间 | `ADC_RegularChannelConfig(ADC1, ADC_Channel_1, 1, ADC_SampleTime_55Cycles5);` |
| `ADC_Cmd()` | 使能 ADC | `ADC_Cmd(ADC1, ENABLE);` |
| `ADC_ResetCalibration()` | 复位 ADC 校准 | `ADC_ResetCalibration(ADC1);` |
| `ADC_GetResetCalibrationStatus()` | 查询复位校准是否完成 | `while (ADC_GetResetCalibrationStatus(ADC1));` |
| `ADC_StartCalibration()` | 开始 ADC 校准 | `ADC_StartCalibration(ADC1);` |
| `ADC_GetCalibrationStatus()` | 查询校准是否完成 | `while (ADC_GetCalibrationStatus(ADC1));` |
| `ADC_SoftwareStartConvCmd()` | 软件启动一次 ADC 转换 | `ADC_SoftwareStartConvCmd(ADC1, ENABLE);` |
| `ADC_GetFlagStatus()` | 查询转换结束标志 | `ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC)` |
| `ADC_GetConversionValue()` | 读取 ADC 转换结果 | `ADC_GetConversionValue(ADC1);` |

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/adc_driver.c/.h`：配置 GPIO、ADC1、规则通道、ADC 校准。
- `USER_APP/main.c`：调用 ADC 初始化函数，需要数据时调用 ADC 读取函数。
- 查询方式不需要写 `ADC_IRQHandler()`，也不需要配置 NVIC。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，ADC 输入引脚必须配置成模拟输入，例如 `PA1` 对应 `ADC_Channel_1`。

第二步，打开 `GPIOA` 和 `ADC1` 的时钟。ADC1 在 APB2 总线上，所以用 `RCC_APB2PeriphClockCmd()`。

第三步，设置 ADC 时钟。常见写法是 `RCC_ADCCLKConfig(RCC_PCLK2_Div6)`。

第四步，配置 ADC 为独立模式、单通道、单次转换、软件触发、右对齐。

第五步，配置规则通道，指定 ADC 采哪个通道。

第六步，使能 ADC 并完成校准。

第七步，需要读数时，软件启动转换，查询 `ADC_FLAG_EOC`，转换完成后读取结果。

### 5.2 完整伪代码

```text
开始

初始化 ADC1
    打开 GPIOA 和 ADC1 时钟
    配置 ADC 时钟分频
    配置 PA1 为模拟输入
    配置 ADC1：
        独立模式
        不扫描
        不连续转换
        软件触发
        右对齐
        规则通道数为 1
    配置规则通道 ADC_Channel_1
    使能 ADC1
    复位校准并等待完成
    开始校准并等待完成

读取 ADC 数字量
    软件启动一次转换
    等待 EOC 标志置位
    读取 ADC 转换值
    返回数字量

主循环
    调用读取函数得到 ADC 数字量
```

## 6. ADC 驱动怎么写

可以在 `adc_driver.c` 中实现：

```c
#include "stm32f10x_conf.h"

void ADC1_QUERY_CONFIG(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;
    ADC_InitTypeDef ADC_InitStructure;

    // 1. 打开 GPIOA 和 ADC1 时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_ADC1, ENABLE);

    // 2. 配置 ADC 时钟，72MHz / 6 = 12MHz
    RCC_ADCCLKConfig(RCC_PCLK2_Div6);

    // 3. 配置 PA1 为模拟输入，对应 ADC_Channel_1
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_1;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AIN;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // 4. 配置 ADC1
    ADC_InitStructure.ADC_Mode = ADC_Mode_Independent;
    ADC_InitStructure.ADC_ScanConvMode = DISABLE;
    ADC_InitStructure.ADC_ContinuousConvMode = DISABLE;
    ADC_InitStructure.ADC_ExternalTrigConv = ADC_ExternalTrigConv_None;
    ADC_InitStructure.ADC_DataAlign = ADC_DataAlign_Right;
    ADC_InitStructure.ADC_NbrOfChannel = 1;
    ADC_Init(ADC1, &ADC_InitStructure);

    // 5. 配置规则通道：ADC1 的通道 1，转换顺序为第 1 个
    ADC_RegularChannelConfig(ADC1, ADC_Channel_1, 1, ADC_SampleTime_55Cycles5);

    // 6. 使能 ADC1
    ADC_Cmd(ADC1, ENABLE);

    // 7. ADC 校准
    ADC_ResetCalibration(ADC1);
    while (ADC_GetResetCalibrationStatus(ADC1));

    ADC_StartCalibration(ADC1);
    while (ADC_GetCalibrationStatus(ADC1));
}

uint16_t ADC1_QUERY_READ(void)
{
    uint16_t adc_value;

    // 1. 软件启动一次 ADC 转换
    ADC_SoftwareStartConvCmd(ADC1, ENABLE);

    // 2. 查询转换结束标志 EOC
    while (ADC_GetFlagStatus(ADC1, ADC_FLAG_EOC) == RESET);

    // 3. 读取转换结果
    adc_value = ADC_GetConversionValue(ADC1);

    return adc_value;
}
```

## 7. 主函数怎么写

```c
#include "stm32f10x_conf.h"

extern void ADC1_QUERY_CONFIG(void);
extern uint16_t ADC1_QUERY_READ(void);

int main(void)
{
    uint16_t adc_value;

    ADC1_QUERY_CONFIG();

    while (1)
    {
        adc_value = ADC1_QUERY_READ();

        // 如果题目要求显示，可以把 adc_value 显示到 LCD
        // 如果题目只要求获得数字量，到这里已经完成
    }
}
```

## 8. 如果题目要求换算电压

若 ADC 量程是 `0 ~ 3.3V`，12 位 ADC：

```c
uint16_t adc_value;
float voltage;

adc_value = ADC1_QUERY_READ();
voltage = (float)adc_value / 4095.0f * 3.3f;
```

不用浮点数也可以用毫伏：

```c
uint16_t adc_value;
uint32_t voltage_mv;

adc_value = ADC1_QUERY_READ();
voltage_mv = (uint32_t)adc_value * 3300 / 4095;
```

## 9. 考试答题模板

写程序时按这个顺序：

1. 开时钟：`GPIOA`、`ADC1`。
2. 配 ADC 时钟：`RCC_ADCCLKConfig(RCC_PCLK2_Div6)`。
3. 配 GPIO：ADC 输入引脚配置为 `GPIO_Mode_AIN`。
4. 配 ADC：独立模式、单通道、单次转换、软件触发、右对齐。
5. 配规则通道：`ADC_RegularChannelConfig()`。
6. 使能并校准 ADC。
7. 读取函数中：软件启动转换、查询 `ADC_FLAG_EOC`、读取 `ADC_GetConversionValue()`。

## 10. 最容易错的地方

| 易错点 | 正确理解 |
| --- | --- |
| 查询方式还写 ADC 中断 | 查询方式不需要 `ADC_IRQHandler()`，也不需要 `NVIC_Init()` |
| 忘记配置 GPIO 模拟输入 | ADC 输入引脚必须配置成 `GPIO_Mode_AIN` |
| 忘记配置规则通道 | 不写 `ADC_RegularChannelConfig()`，ADC 不知道采哪个通道 |
| 忘记软件启动转换 | 查询方式通常要调用 `ADC_SoftwareStartConvCmd()` |
| 查询错标志 | 查询转换结束标志用 `ADC_FLAG_EOC` |
| 忘记读取结果 | 转换结果用 `ADC_GetConversionValue(ADC1)` 读取 |
| 连续转换和单次转换混淆 | 例题 7.5 查询方式常按单次转换写，读一次启动一次 |
