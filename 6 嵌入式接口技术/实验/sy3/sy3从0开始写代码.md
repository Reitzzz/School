## 1. 这次实验要做什么

`1904300101张三@实验报告3.doc` 要求用 STM32 标准库完成 **EXTI 外部中断实验**：

- 用 KEY0、KEY1、KEY2、KEY_UP 触发外部中断。
- KEY0 触发后 LED0 闪烁 4 次。
- KEY1 触发后 LED1 闪烁 4 次。
- KEY2 触发后 LED0、LED1 同时闪烁 4 次。
- KEY_UP 触发后蜂鸣器响一次。

一句话：sy3 是“按键外部中断控制 LED 和蜂鸣器”。

代码范围：


1. `key_driver.c` 中 `KEY_GPIO_EXTI_NVIC_Config()`。
2. `led_driver.c` 中 `LED_GPIO_Config()` 和闪烁函数。
3. `it.c` 中四个中断服务函数。
4. `main.c`。

## 2. 先认识硬件连接

| 名称 | GPIO | EXTI 线 | 中断通道 | 触发方式 | 现象 |
| --- | --- | --- | --- | --- | --- |
| KEY0 | PE4 | EXTI4 | `EXTI4_IRQn` | 下降沿 | LED0 闪烁 |
| KEY1 | PE3 | EXTI3 | `EXTI3_IRQn` | 下降沿 | LED1 闪烁 |
| KEY2 | PE2 | EXTI2 | `EXTI2_IRQn` | 下降沿 | LED0、LED1 同时闪烁 |
| KEY_UP | PA0 | EXTI0 | `EXTI0_IRQn` | 上升沿 | 蜂鸣器响一次 |
| LED0 | PB5 | - | - | 低电平点亮 | 输出 |
| LED1 | PE5 | - | - | 低电平点亮 | 输出 |
| BEEP | PB8 | - | - | 高电平发声 | 输出 |

KEY0、KEY1、KEY2 是上拉输入，按下时从 `1` 变成 `0`，所以用下降沿触发。KEY_UP 是下拉输入，按下时从 `0` 变成 `1`，所以用上升沿触发。

> [!NOTE]
> **关于 EXTI 和中断通道的通俗理解：**
> 整个按键触发中断的过程，就像是一个“报警系统”。
>
> 1. **EXTI 线 (外部中断线) —— “门口的传感器”**
>    - **作用**：专门负责“盯”着 GPIO 引脚上的电压变化。当你按下按键产生电平变化（比如下降沿）时，EXTI 监测到后就会产生一个报警信号。
>    - **对应关系**：STM32 规定所有尾号相同的引脚共享同一根 EXTI 线。例如 `KEY0` 接在 `PE4` 上，尾号是 4，所以它连接到 `EXTI4` 线。
> 2. **中断通道 (IRQn) —— “报警传输专线”**
>    - **作用**：EXTI 产生报警信号后，需要把信号送到 NVIC（中断大管家）。**中断通道**就是连接 EXTI 和 NVIC 之间的专线。
>    - **对应关系**：在 STM32 中，0~4 号 EXTI 线都有独立的专线通道，例如 `EXTI4` 的信号只走 `EXTI4_IRQn` 这条通道。
>
> **完整流程（以 KEY0 为例）**：
> 按下 `KEY0` $\rightarrow$ `PE4` 引脚电压变低（产生**下降沿**） $\rightarrow$ `EXTI4` 捕捉到下降沿，产生中断信号 $\rightarrow$ 信号顺着 `EXTI4_IRQn` 通道送到 NVIC $\rightarrow$ NVIC 暂停 CPU 当前工作 $\rightarrow$ CPU 去执行对应的中断服务函数（使得 LED0 闪烁）。

## 3. 本实验需要用到的库函数（考试会给）

### 3.1 GPIO 相关库函数

| 名称 | 作用 | 函数参数 | 赋值写法 |
| --- | --- | --- | --- |
| `RCC_APB2PeriphClockCmd()` | 打开 GPIO/AFIO 时钟，可近似理解为给这些外设“通电”，让它们开始工作 | 外设时钟名，开关状态<br>`RCC_APB2Periph_GPIOE \| RCC_APB2Periph_AFIO`、`ENABLE` | 不适用<br>这是函数调用 |
| `GPIO_InitTypeDef` | GPIO 初始化结构体类型，用它定义 GPIO 配置表变量。声明本身只定义变量，还没有配置硬件 | 不适用<br>这是类型声明 | 定义配置表变量<br>`GPIO_InitTypeDef GPIO_InitStructure;` |
| `GPIO_InitStructure.GPIO_Pin` | 配置要初始化的 GPIO 引脚，可以单个引脚，也可以用 `\|` 同时选择多个引脚 | 不适用<br>这是赋值写法 | GPIO 引脚<br>`GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;` |
| `GPIO_InitStructure.GPIO_Mode` | 配置 GPIO 工作模式，决定这个引脚是输入、输出，还是复用功能 | 不适用<br>这是赋值写法 | GPIO 工作模式<br>`GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;` |

## 4. 写代码前先分层

- `USER_DEVICE_DRIVER/key_driver.c/.h`：配置按键 GPIO、EXTI、NVIC。
- `USER_DEVICE_DRIVER/led_driver.c/.h`：配置 LED GPIO，提供闪烁函数。
- `USER_DEVICE_DRIVER/beep_driver.c/.h`：配置蜂鸣器 GPIO，提供响一声函数。
- `USER_APP/it.c`：写外部中断服务函数。
- `USER_APP/main.c`：初始化外设，然后等待中断。

和 sy2 最大的区别是：sy2 的按键判断写在 `while(1)` 里；sy3 的按键响应写在 `EXTI_IRQHandler` 中。

## 5. 先写伪代码

### 5.1 怎么得出伪代码

第一步，看实验要求：按键不是轮询，**而是“按压并释放一次”后触发动作（即人或外界不可控的操作）**，所以要用 EXTI 外部中断。

第二步，看按键接线：PE4、PE3、PE2、PA0 分别对应 EXTI4、EXTI3、EXTI2、EXTI0。

第三步，看触发电平：KEY0~KEY2 按下为低电平，选下降沿；KEY_UP 按下为高电平，选上升沿。

第四步，把响应动作放到中断服务函数中：哪个 EXTI 线触发，就执行对应动作，最后清除中断标志。

### 5.2 完整伪代码

```text
开始

初始化 LED
    打开 GPIOB、GPIOE 时钟
    PB5、PE5 配置为推挽输出
    默认输出高电平，让 LED 熄灭

初始化蜂鸣器
    打开 GPIOB 时钟
    PB8 配置为推挽输出
    默认输出低电平，让蜂鸣器不响

初始化按键外部中断
    打开 GPIOA、GPIOE、AFIO 时钟
    PE2、PE3、PE4 配置为上拉输入
    PA0 配置为下拉输入
    PE4 映射到 EXTI4
    PE3 映射到 EXTI3
    PE2 映射到 EXTI2
    PA0 映射到 EXTI0
    EXTI2、EXTI3、EXTI4 配置为下降沿中断
    EXTI0 配置为上升沿中断
    在 NVIC 中打开 EXTI0、EXTI2、EXTI3、EXTI4 中断通道

主循环
    什么都不用做，等待中断发生

如果进入 EXTI4_IRQHandler
    检查 EXTI4 标志
    LED0 闪烁 4 次
    清除 EXTI4 标志

如果进入 EXTI3_IRQHandler
    检查 EXTI3 标志
    LED1 闪烁 4 次
    清除 EXTI3 标志

如果进入 EXTI2_IRQHandler
    检查 EXTI2 标志
    LED0、LED1 同时闪烁 4 次
    清除 EXTI2 标志

如果进入 EXTI0_IRQHandler
    检查 EXTI0 标志
    蜂鸣器响一次
    清除 EXTI0 标志
```

## 6. LED 和蜂鸣器驱动怎么写

### 6.1 LED

`LED_GPIO_Config()`：**负责配置LED灯**

```c
void LED_GPIO_Config(void)
{
    // 定义 GPIO 配置表变量
    GPIO_InitTypeDef GPIO_InitStructure;

    // 打开 GPIOB、GPIOE 时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_GPIOE, ENABLE);

    // 填写配置表：5 号引脚、推挽输出、50MHz 速度
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;

    // 初始化 GPIOB，默认输出高电平，让 LED0 熄灭
    GPIO_Init(GPIOB, &GPIO_InitStructure);
    GPIO_SetBits(GPIOB, GPIO_Pin_5);

    // 初始化 GPIOE，默认输出高电平，让 LED1 熄灭
    GPIO_Init(GPIOE, &GPIO_InitStructure);
    GPIO_SetBits(GPIOE, GPIO_Pin_5);
}
```

`LED0_Flash(void)` : **负责封装闪烁函数**

```c
void LED0_Flash(void)
{
    uint8_t i;
    for (i = 1; i <= 4; i++)
    {
        GPIO_ResetBits(GPIOB, GPIO_Pin_5);
        SoftwareDelay(2000000);
        GPIO_SetBits(GPIOB, GPIO_Pin_5);
        SoftwareDelay(2000000);
    }
}
```

### 6.2 蜂鸣器

`BEEP_GPIO_Config()` ：**负责配置蜂鸣器**

```c
void BEEP_GPIO_Config(void)
{
    // 定义 GPIO 配置表变量
    GPIO_InitTypeDef GPIO_InitStructure;

    // 打开 GPIOB 时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);

    // 填写配置表：8 号引脚、推挽输出、50MHz 速度
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_8;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    // 初始化 GPIOB
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    // 默认输出低电平，让蜂鸣器不响
    GPIO_ResetBits(GPIOB, GPIO_Pin_8);
}
```
`BEEP_Sound()`：**负责封装蜂鸣器发声函数**
```
void BEEP_Sound(void)
{
    GPIO_SetBits(GPIOB, GPIO_Pin_8);
    SoftwareDelay(2000000);
    GPIO_ResetBits(GPIOB, GPIO_Pin_8);
}
```

## 7. 按键中断驱动怎么写

`key_driver.h`：

```c
#include "stm32f10x_conf.h"

void KEY_GPIO_EXTI_NVIC_Config(void);
```

`key_driver.c`：

```c
#include "misc.h"
#include "stm32f10x_conf.h"

void KEY_GPIO_EXTI_NVIC_Config(void)
{
    GPIO_InitTypeDef GPIO_InitStructure; // 定义配置表变量
    EXTI_InitTypeDef EXTI_InitStructure;
    NVIC_InitTypeDef NVIC_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA |
                           RCC_APB2Periph_GPIOE |
                           RCC_APB2Periph_AFIO, ENABLE); // 打开 GPIOA、GPIOE 和 AFIO 复用功能时钟

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_2 | GPIO_Pin_3 | GPIO_Pin_4; // 配置 PE2, PE3, PE4
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;                       // 配置工作模式为上拉输入
    GPIO_Init(GPIOE, &GPIO_InitStructure);                              // 真正初始化 GPIOE

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;                           // 配置 PA0
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPD;                       // 配置工作模式为下拉输入
    GPIO_Init(GPIOA, &GPIO_InitStructure);                              // 真正初始化 GPIOA

    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource4);         // 将 GPIO 引脚映射到相应的 EXTI 线
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource3);
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOE, GPIO_PinSource2);
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0);

    EXTI_InitStructure.EXTI_Line = EXTI_Line2 | EXTI_Line3 | EXTI_Line4; // 配置 EXTI2, EXTI3, EXTI4 为下降沿触发中断 （听到什么声音需要报警）
    EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt;                  // 配置为中断模式
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;              // 配置触发方式为下降沿触发
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;                            // 使能这些 EXTI 线
    EXTI_Init(&EXTI_InitStructure);                                      // 真正初始化 EXTI

    EXTI_InitStructure.EXTI_Line = EXTI_Line0;                           // 配置 EXTI0 为上升沿触发中断 （听到什么声音需要报警）
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Rising;               // 配置触发方式为上升沿触发
    EXTI_Init(&EXTI_InitStructure);                                      // 真正初始化 EXTI

    NVIC_InitStructure.NVIC_IRQChannel = EXTI0_IRQn;                     // 配置 NVIC，打开 EXTI0 中断通道 （打开报警通道）
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 0;            // 配置抢占优先级（数字越小优先级越高）
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 0;                   // 配置响应优先级（子优先级）
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;                      // 使能中断通道
    NVIC_Init(&NVIC_InitStructure);                                      // 真正初始化 NVIC

    NVIC_InitStructure.NVIC_IRQChannel = EXTI2_IRQn;                     // 打开 EXTI2 中断通道
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;            // 配置抢占优先级（比 EXTI0 低）
    NVIC_Init(&NVIC_InitStructure);                                      // 真正初始化 NVIC

    NVIC_InitStructure.NVIC_IRQChannel = EXTI3_IRQn;                     // 打开 EXTI3 中断通道
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;            // 配置抢占优先级
    NVIC_Init(&NVIC_InitStructure);                                      // 真正初始化 NVIC

    NVIC_InitStructure.NVIC_IRQChannel = EXTI4_IRQn;                     // 打开 EXTI4 中断通道
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 3;            // 配置抢占优先级
    NVIC_Init(&NVIC_InitStructure);                                      // 真正初始化 NVIC
}
```

## 8. 中断服务函数怎么写

```c
#include "key_driver.h"
#include "led_driver.h"
#include "beep_driver.h"
#include "sw_delay.h"

void EXTI0_IRQHandler(void)
{
    // 检查 EXTI0 中断标志位
    if (EXTI_GetITStatus(EXTI_Line0) != RESET)
    {
        BEEP_Sound(); // 执行蜂鸣器发声
        // 清除中断标志位，防止死循环
        EXTI_ClearITPendingBit(EXTI_Line0);
    }
}

void EXTI2_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line2) != RESET)
    {
        LED01_Flash();
        EXTI_ClearITPendingBit(EXTI_Line2);
    }
}

void EXTI3_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line3) != RESET)
    {
        LED1_Flash();
        EXTI_ClearITPendingBit(EXTI_Line3);
    }
}

void EXTI4_IRQHandler(void)
{
    // 检查 EXTI4 中断标志位
    if (EXTI_GetITStatus(EXTI_Line4) != RESET)
    {
        LED0_Flash(); // 执行 LED0 闪烁
        // 清除中断标志位，防止死循环
        EXTI_ClearITPendingBit(EXTI_Line4);
    }
}
```

中断函数有三个固定动作：

```text
检查中断标志 -> 执行动作 -> 清除中断标志
```

## 10. 最容易错的地方

- 忘记打开 `RCC_APB2Periph_AFIO`：GPIO 到 EXTI 的映射不生效。
- `GPIO_EXTILineConfig()` 的端口源和引脚源写错：比如 PE4 必须对应 `GPIO_PortSourceGPIOE` 和 `GPIO_PinSource4`。
- KEY0~KEY2 用错触发边沿：它们按下是下降沿。
- KEY_UP 用错触发边沿：它按下是上升沿。
- 中断服务函数最后忘记 `EXTI_ClearITPendingBit()`：程序会反复进中断。
- 中断服务函数名字写错：名字必须和启动文件里的向量表一致。
