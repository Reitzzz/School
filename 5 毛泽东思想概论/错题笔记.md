# 1. 理解题

**题号：** 02  
**题干：** 科学发展观是中国特色社会主义理论体系在新世纪新阶段的新发展，是中国特色社会主义理论体系的重要组成部分。科学发展观的第一要义是()。  
**选项：**  
A 推动经济社会发展  
B 创新驱动发展  
C 全面深化改革  
D 以人民为中心  
**解析：**  
A 正确：科学发展观的第一要义是推动经济社会发展。发展是解决中国一切问题的“总钥匙”。  
B 错误：创新驱动发展是新时代的发展理念，并非科学发展观的第一要义。  
C 错误：全面深化改革属于“四个全面”战略布局，并非科学发展观的第一要义。  
D 错误：以人为本是科学发展观的“核心立场”，以人民为中心则是新时代坚持和发展中国特色社会主义的基本方略。  
**答案：** A

**题号：** 05  
**题干：** 影响中国社会进步和发展的最大障碍，导致近代中国贫困落后和一切灾难祸害的总根源是()。  
**选项：**  
A 封建主义  
B 帝国主义  
C 资本主义  
D 功利主义  
**解析：**  
A 错误：封建主义是中国落后的国内原因之一，**但它是在帝国主义的支持下才得以苟延残喘的**，不是最根本的障碍。  
B 正确：帝国主义不仅侵略中国，还与中国的封建势力相勾结，阻碍中国资本主义的发展和社会的进步。它是导致近代中国贫困落后和一切灾难祸害的“总根源”，也是最大障碍。  
C 错误：资本主义在近代中国属于相对先进的生产关系，并非阻碍社会进步的最大障碍。  
D 错误：功利主义是一种思想倾向，并非政治经济根源上的阻碍。  
**答案：** B

**题号：** 06  
**题干：** 1992年邓小平的南方谈话，针对人们思想中普遍存在的疑虑，重申了深化改革、加速发展的必要性和重要性，标志着邓小平理论()。  
**选项：**  
A 轮廓的形成  
B 逐步走向成熟  
C 步入新阶段  
D 系统性确立  
**解析：**  
A 错误：十一届三中全会到十二大时期，是邓小平理论初步形成轮廓的时期。  
B 正确：1992年的南方谈话深刻回答了长期困扰和束缚人们思想的许多重大认识问题（如姓“资”姓“社”问题），把改革开放推向新阶段，标志着邓小平理论“逐步走向成熟”。  
C 错误：南方谈话确实推动了改革开放步入新阶段，但就理论自身的发展而言，其标志是“逐步走向成熟”。  
D 错误：中共十五大将邓小平理论确立为党的指导思想，标志着其系统性确立。  
**答案：** B

**题号：** 08  
**题干：** “和平赎买”政策实现了()的统一，从而在世界社会主义运动史上第一次实现了和平赎买的理论设想，回答了在过渡时期中改造资产阶级的问题。  
**选项：**  
A 原则性与批判性  
B 原则性与灵活性  
C 灵活性与科学性  
D 科学性与阶级性  
**解析：**  
A 错误：和平赎买政策体现的是和平改造的意图，并非以批判性为主。  
B 正确：“和平赎买”既体现了消灭资本主义私有制、建立社会主义公有制这一坚定的“原则性”，同时又考虑到民族资产阶级的特殊历史作用，采取了循序渐进、和平购买的“灵活性”手段，是原则性与灵活性的完美结合。  
C、D 错误：未能准确概括该政策在坚持大目标前提下采取变通手段的特征。  
**答案：** B

**题号：** 09  
**题干：** 在我国社会主义改造时期，所谓国家资本主义就是()。  
**选项：**  
A 国家对资本主义经济进行行政干预  
B 资本主义国家之间的经济交往  
C 国家直接控制和支配下的资本主义经济  
D 资本主义国家对市场的引导和调控  
**解析：**  
A 错误：国家资本主义并非简单的行政干预，而是通过各种形式将资本主义经济纳入国家计划轨道。  
B 错误：国家资本主义是指国内特定历史时期的经济形式，并非指国家间的经济交往。  
C 正确：在我国社会主义改造时期，国家资本主义是指“国家直接控制和支配下的资本主义经济”，即无产阶级国家能够加以限制、能够规定其活动范围的资本主义成分。  
D 错误：该表述属于现代西方经济学中的宏观调控概念，与过渡时期中国的国家资本主义无关。  
**答案：** C

**题号：** 10  
**题干：** 毛泽东在《星星之火，可以燎原》中提出的重要思想是()。  
**选项：**  
A 枪杆子里面出政权  
B 以乡村为中心  
C 没有调查，就没有发言权  
D 一切为了群众，一切依靠群众  
**解析：**  
A 错误：“枪杆子里面出政权”是在八七会议上提出的。  
B 正确：《星星之火，可以燎原》进一步阐述了农村包围城市、武装夺取政权的思想，提出了“以乡村为中心”的重要观点，标志着这一理论的初步形成。  
C 错误：“没有调查，就没有发言权”是在《反对本本主义》中提出的。  
D 错误：这是党的群众路线的核心内容，并非这篇文章的标志性思想。  
**答案：** B

**题号：** 22  
**题干：** 国家资本主义企业生产关系已经发生了根本的变化是在()。  
**选项：**  
A 三大改造完成后  
B 委托加工开始后  
C 个别企业公私合营后  
D 全行业公私合营后  
**解析：**  
A 错误：三大改造完成意味着整个私有制改造完成，但具体到企业生产关系发生根本变化的标志性事件并非这一个宽泛的时间点。  
B 错误：委托加工属于初级形式的国家资本主义，企业仍完全由资本家控制。  
C 错误：个别企业公私合营属于高级形式的国家资本主义，企业利润分配实行“四马分肥”，生产关系开始发生重大变化，但全国范围内的根本变化是在全行业合营之后。  
D 正确：全行业公私合营后，资本家不再拥有对企业的控制权，而是领取定息。此时企业基本上属于社会主义性质，其生产关系发生了根本性的变化。  
**答案：** D

**题号：** 23  
**题干：** 在新民主主义社会时期，中国社会经济中存在着五种成分，即社会主义性质的国营经济、半社会主义性质的合作社经济、农民和手工业者的个体经济、私人资本主义经济和国家资本主义经济。其中，处在社会主义和资本主义十字路口的经济成分是()。  
**选项：**  
A 半社会主义的合作社经济  
B 私人资本主义经济  
C 农民和手工业者的个体经济  
D 社会主义性质的国营经济  
**解析：**  
A 错误：半社会主义的合作社经济已经具有一定的公有制因素，属于向社会主义过渡的成分。  
B 错误：私人资本主义经济明确属于资本主义性质。  
D 错误：国营经济明确属于社会主义性质。  
C 正确：农民和手工业者的个体经济，既是私有者又是劳动者。作为私有者，它有自发走向资本主义的倾向；作为劳动者，它可以被引导走上社会主义的合作化道路。因此，它是处在社会主义和资本主义“十字路口”的摇摆经济成分。  
**答案：** C

**题干：** 毛泽东关于思想政治工作和文化工作的理论观点不包括()。  
**选项：**  
A 实行“百花齐放，百家争鸣”的方针  
B 思想政治工作是一切工作的生命线  
C 惩前毖后治病救人  
D 知识分子需要和工农群众相结合

C 正确（不包括项）：“惩前毖后，治病救人”是毛泽东在延安整风时期提出的对待犯错误同志的方针，属于“党内斗争和党的建设”的原则，不属于文化工作和思想政治工作的理论范畴。  
**答案：** C

**题号：** 25  
**题干：** 中国共产党在建立、巩固和发展统一战线的革命进程中，坚持的策略方针是()。  
**选项：**  
A “一切经过统一战线”、“一切服从统一战线”  
B 又联合又斗争，以斗争求团结  
C 发展进步势力，争取中间势力，孤立顽固势力  
D 独立自主，自力更生  
**解析：**  
A 错误：抗战初期王明曾提出“一切经过统一战线”，这是右倾投降主义错误，放弃了党在统一战线中的独立自主权。  
B 错误：“又联合又斗争”是统一战线的基本原则，而不是处理不同势力间关系的特定策略方针。  
C 正确：在抗日民族统一战线中，党坚持了“发展进步势力，争取中间势力，孤立顽固势力”的策略方针，这保证了统一战线能够最大限度地团结一切可以团结的力量。  
D 错误：独立自主是统一战线中的基本立足点和原则，并非策略方针。  
**答案：** C

**题号：** 37  
**题干：** 党在过渡时期总路线最显著的特点是()。  
**选项：**  
A 建设和改造同时并举  
B 公有制和计划经济并存  
C 稳定和改造兼顾  
D 建设、改造、稳定三者协调  
**解析：**  
A 正确：党在过渡时期总路线（“一化三改”）最显著的特点是社会主义建设与社会主义改造同时并举，即发展生产力与变革生产关系同时进行。  
B 错误：公有制和计划经济是改造完成后的经济体制特征，不是过渡时期总路线的特点。  
C、D 错误：总路线并未将“稳定”作为并列的显著特点提出。  
**答案：** A

**题号：** 46  
**题干：** 无产阶级对革命的领导权是()。  
**选项：**  
A 经过工农联盟来实现的  
B 自然而然实现的  
C 通过与资产阶级斗争来实现  
D 经过统一战线来实现的  
**解析：**

D 错误：统一战线是无产阶级实现领导权的一个重要阵地和形式，但如果没有与资产阶级的斗争，就无法在统一战线中掌握领导权。  
**答案：** C

**题号：** 47  
**题干：** 毛泽东把新民主主义革命和社会主义革命比喻为文章的上篇和下篇。“两篇文章，上篇与下篇，只有上篇做好，下篇才能做好。坚决地领导民主革命，是争取社会主义胜利的条件。”但在党内，有人提出“毕其功于一役”的主张，这种观点的错误之处是()。  
**选项：**  
A 混淆了旧民主主义革命和新民主主义革命的界限  
B 割裂了旧民主主义革命和新民主主义革命的联系  
C 混淆了新民主主义革命和社会主义革命的界限  
D 割裂了新民主主义革命和社会主义革命的联系  
**解析：**  
A、B 错误：“毕其功于一役”主要是在讨论新民主主义革命与社会主义革命的关系，而不是旧民主主义与新民主主义的关系。  
C 正确：“毕其功于一役”主张在民主革命阶段同时进行社会主义革命（如没收民族资本），这就混淆了民主革命和社会主义革命这两个不同性质的革命阶段的界限，是“左”倾错误。  
D 错误：右倾错误（如陈独秀“二次革命论”）才是割裂了这两个革命的联系，认为两者之间要横插一个资产阶级专政的资本主义阶段。  
**答案：** C

**题号：** 55  
**题干：** 中共八大和十一届三中全会的相同点是()。  
**选项：**  
A 都肯定了实事求是是马克思思想路线  
B 都作出了实行改革开放的伟大决策  
C 都把发展生产作为党和国家的重点  
D 都结束了长期以来左倾错误  
**解析：**  
A 错误：十一届三中全会重新确立了实事求是的思想路线，但中共八大主要贡献在正确分析主要矛盾，并未把“肯定实事求是思想路线”作为其最突出的历史标志。  
B 错误：改革开放是十一届三中全会作出的决策，中共八大时还没有。  
C 正确：中共八大提出党和国家的主要任务是集中力量发展社会生产力；十一届三中全会作出了把党和国家工作中心转移到经济建设上来、实行改革开放的历史性决策。两者都把发展生产力作为重点。  
D 错误：中共八大召开时，“左”倾错误（如“大跃进”）尚未大规模发生，因此不存在“结束长期以来左倾错误”的说法。十一届三中全会才是结束了“左”倾错误。  
**答案：** C

**题号：** 56  
**题干：** 中国革命红色政权能够存在和发展的根本原因是()。  
**选项：**  
A 政治经济发展不平衡  
B 共产党的正确领导  
C 有相当力量的正式红军的存在  
D 有良好的群众基础  
**解析：**  
A 正确：中国是一个半殖民地半封建的大国，政治经济发展极不平衡（如地方农业经济为主、帝国主义划分势力范围导致军阀割据）。这是红色政权能够存在和发展的根本原因（客观条件）。  
B 错误：共产党的正确领导是主观条件，但不是最根本的客观原因。  
C 错误：相当力量的正式红军存在是红色政权存在和发展的主观条件之一，不是根本原因。  
D 错误：良好的群众基础是客观条件之一，但不如政治经济发展不平衡这一条根本。  
**答案：** A
