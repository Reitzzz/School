### 题目 1
**题目内容**：
(计算题) 设8位有效信息位为01101110，试写出它的海明校验码。给出过程，说明分组检测方法，并给出指错字及其逻辑表达式。如果接收方收到的有效信息变为01101111，说明如何定位错误并纠正错误。

**知识点**：
* 海明码（Hamming Code）的编码规则
* 偶校验分组原理与校验位计算
* 错误定位（Syndrome，指错字）计算与单比特纠错

**解题方法**：
1. **确定校验位个数**：
   根据公式 $2^k \ge n + k + 1$，已知数据位 $n=8$，解得校验位 $k=4$。因此海明码总长为12位。
2. **确定位序与分组检测方法**：
   * 设12位海明码为 $H_1, H_2, \dots, H_{12}$。4个校验位分别放置在 $2^{i-1}$ 的位置，即 $P_1(H_1), P_2(H_2), P_3(H_4), P_4(H_8)$。
   * 8位数据位 $D_1 \dots D_8$ (即0, 1, 1, 0, 1, 1, 1, 0) 依次填入余下位置：$H_3, H_5, H_6, H_7, H_9, H_{10}, H_{11}, H_{12}$。
   * **分组检测方法（偶校验）**：每个校验位负责其位号对应二进制表示中特定位为1的所有海明码位：
     * $P_1$ 负责：$H_1, H_3, H_5, H_7, H_9, H_{11}$
     * $P_2$ 负责：$H_2, H_3, H_6, H_7, H_{10}, H_{11}$
     * $P_3$ 负责：$H_4, H_5, H_6, H_7, H_{12}$
     * $P_4$ 负责：$H_8, H_9, H_{10}, H_{11}, H_{12}$
3. **计算校验码**：
   通过组内异或运算（偶校验）求得：
   * $P_1 = D_1 \oplus D_2 \oplus D_4 \oplus D_5 \oplus D_7 = 0 \oplus 1 \oplus 0 \oplus 1 \oplus 1 = 1$
   * $P_2 = D_1 \oplus D_3 \oplus D_4 \oplus D_6 \oplus D_7 = 0 \oplus 1 \oplus 0 \oplus 1 \oplus 1 = 1$
   * $P_3 = D_2 \oplus D_3 \oplus D_4 \oplus D_8 = 1 \oplus 1 \oplus 0 \oplus 0 = 0$
   * $P_4 = D_5 \oplus D_6 \oplus D_7 \oplus D_8 = 1 \oplus 1 \oplus 1 \oplus 0 = 1$
   由此拼接得到完整的海明校验码为：`110011011110`。
4. **指错字及其逻辑表达式**：
   * $S_1 = P_1 \oplus H_3 \oplus H_5 \oplus H_7 \oplus H_9 \oplus H_{11}$
   * $S_2 = P_2 \oplus H_3 \oplus H_6 \oplus H_7 \oplus H_{10} \oplus H_{11}$
   * $S_3 = P_3 \oplus H_5 \oplus H_6 \oplus H_7 \oplus H_{12}$
   * $S_4 = P_4 \oplus H_9 \oplus H_{10} \oplus H_{11} \oplus H_{12}$
5. **定位错误并纠错**：
   接收方收到的有效信息变为 `01101111`，说明最后一个数据位（即整体第12位）由0错变成了1。此时收到的海明码为 `110011011111`。
   将收到的码字代入指错字逻辑表达式，重新计算：
   * $S_1 = 0$, $S_2 = 0$
   * $S_3 = 1$ (因第12位参与计算且发生翻转)
   * $S_4 = 1$ (因第12位参与计算且发生翻转)
   得出指错字 $S_4 S_3 S_2 S_1 = 1100_{(2)} = 12_{(10)}$。指错字的十进制值直接指出了第12位出错，将第12位的 `1` 纠正（取反）为 `0` 即可。

### 题目 2
**题目内容**：
(计算题) 设要采用CRC码传送数据信息x=1001，当生成多项式为G(x)=1101时，请写出它的循环冗余校验码。若接收方收到的数据为x'=1101，说明如何定位错误并纠正错误。

**知识点**：
* 循环冗余校验码（CRC）的编码原理
* 模2除法与余数（FCS）计算
* 利用接收端余数进行错误定位与纠正

**解题方法**：
1. **计算CRC校验码**：
   * 生成多项式 $G(x) = 1101$，其阶数 $r = 3$（对应4位二进制）。
   * 将数据信息 $x = 1001$ 左移 3 位（即在末尾补3个0），得到被除数：`1001000`。
   * 进行模2除法运算：`1001000 ÷ 1101`。
     (1) `1001` 与 `1101` 异或得 `0100`，拉下1位得 `1000`。
     (2) `1000` 与 `1101` 异或得 `0101`，拉下1位得 `1010`。
     (3) `1010` 与 `1101` 异或得 `0111`，拉下1位得 `1110`。
     (4) `1110` 与 `1101` 异或得 `0011`。
   * 最后的余数（FCS）为 `011`。将其附加在原数据之后，得出实际发送的CRC校验码为 `1001011`。
2. **定位错误并纠正**：
   * 接收方收到的数据变成了 $x' = 1101$，附加上原来的校验位后，实际接收到的完整码字为 `1101011`。
   * 接收端同样对该码字进行模2除以 $G(x)=1101$ 运算：
     (1) 前4位 `1101 ÷ 1101`，无余数（`0000`）。
     (2) 剩下的低三位落下，直接得到最终余数为 `011`。
   * 余数不为 `000`，说明数据传输发生错误。
   * **定位与纠错**：根据CRC纠错原理，当生成多项式为1101时，每一位出错对应的余数是固定映射的。计算单一位置错引发的余数（如左起第2位即 `0100000 ÷ 1101` 的余数为 `011`）。接收到的余数为 `011`，查表/计算可知这指示了**从左往右第2位（即信息位的第2位）出错**。将左起第2位的 `1` 取反纠正为 `0`，即可恢复正确的数据 `1001011`。
