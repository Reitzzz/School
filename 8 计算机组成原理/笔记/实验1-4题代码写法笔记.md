# 计算机组成原理实验 1-4 题代码写法笔记

资料来源：`实验` 文件夹中的题干照片、参考机器码图片/视频，以及 `DICE-CP226实验指导书20140926.pdf` 第 3.3 节模型机指令集、第 4 章模型机综合实验。

## 一、先记住这台模型机怎么写程序

CP226 模型机是 8 位机。实验里写的程序本质上是“汇编助记符 -> 机器码 -> 写入 EM 程序存储器”。

常用寄存器/端口：

| 名称 | 作用 |
| --- | --- |
| A | 累加器，大部分运算都围绕 A 做 |
| IN | 输入端口，拨动开关的输入值从这里读入 |
| OUT | 输出端口，A 的值送到灯/数码管显示 |
| PC | 程序计数器，指向下一条机器码地址 |
| EM | 程序存储器，实验时按地址写机器码 |

常用指令机器码：

| 汇编指令 | 机器码 | 字节数 | 含义 |
| --- | --- | --- | --- |
| `IN` | `C0` | 1 | 从输入端口读入到 A |
| `OUT` | `C4` | 1 | 把 A 输出到 OUT |
| `ADD A,#II` | `1C II` | 2 | A 加立即数 II |
| `SUB A,#II` | `3C II` | 2 | A 减立即数 II |
| `MOV A,#II` | `7C II` | 2 | 立即数 II 送入 A |
| `JZ MM` | `A4 MM` | 2 | 若零标志 Z=1，跳转到 MM |
| `JMP MM` | `AC MM` | 2 | 无条件跳转到 MM |
| `RL A` | `D4` | 1 | A 左移一位 |
| `RR A` | `D0` | 1 | A 右移一位 |
| `CPL A` | `E4` | 1 | A 按位取反 |

写代码时按这个顺序想：

1. 先写清楚“每一轮循环要让 A 变成什么”。
2. 需要显示就写 `OUT`。
3. 需要变化就写 `ADD`、`SUB`、`RL`、`RR`、`CPL`。
4. 需要重复就用 `JMP` 跳回循环开始地址。
5. 需要判断是否到头，就用 `JZ`。`JZ` 判断的是上一条运算/移位后 A 是否为 `00H`。
6. 最后按每条指令字节数重新算地址，跳转地址必须写对。

## 二、第 1 题：输入一个数，输出这个数加 1

题干：拨动输入开关，任意输入一个数，显示输出这个数加 1 的结果。

思路：

1. `IN` 把开关输入读到 A。
2. `ADD A,#01H` 让 A 加 1。
3. `OUT` 输出。
4. `JMP 00H` 回到开头，不断读取新输入。

汇编写法：

```asm
START:
    IN
    ADD A,#01H
    OUT
    JMP 00H
END
```

机器码：

| 地址 | 机器码 | 对应汇编 |
| --- | --- | --- |
| `00` | `C0` | `IN` |
| `01` | `1C` | `ADD A,#01H` |
| `02` | `01` | 立即数 `01H` |
| `03` | `C4` | `OUT` |
| `04` | `AC` | `JMP 00H` |
| `05` | `00` | 跳转地址 `00H` |

顺序输入机器码：

```text
C0 1C 01 C4 AC 00
```

## 三、第 2 题：用灯的亮起顺序表示 1,2,3,4,5,6,7,...,127...

题干：用灯的亮起顺序表征 `1,2,3,4,5,6,7,...,127...`。

思路：

1. 先让 A=`01H`。
2. 输出 A。
3. A 加 1。
4. 跳回输出位置。

这里不是“单个灯移动”，而是把 A 当作普通二进制数字显示：`01H, 02H, 03H, ...`。

汇编写法：

```asm
    MOV A,#01H
LOOP:
    OUT
    ADD A,#01H
    JMP LOOP
END
```

机器码：

| 地址 | 机器码 | 对应汇编 |
| --- | --- | --- |
| `00` | `7C` | `MOV A,#01H` |
| `01` | `01` | 立即数 `01H` |
| `02` | `C4` | `OUT` |
| `03` | `1C` | `ADD A,#01H` |
| `04` | `01` | 立即数 `01H` |
| `05` | `AC` | `JMP 02H` |
| `06` | `02` | 跳转地址 `02H` |

顺序输入机器码：

```text
7C 01 C4 1C 01 AC 02
```

关键点：`JMP` 要跳到 `02H`，因为 `02H` 是 `OUT` 的地址。这样每次加完 1 后都会重新输出。

## 四、第 3 题：单灯来回效果

效果：一个亮灯从低位向高位移动，到头后再从高位往低位回来。

思路：

1. 先令 A=`01H`，输出最低位灯。
2. 循环左移：`01 -> 02 -> 04 -> 08 -> 10 -> 20 -> 40 -> 80`。
3. 当 `80H` 再左移会变成 `00H`，`JZ` 检测到零后切换到右移段。
4. 右移段从 `40H` 开始，避免 `80H` 连续显示两次。
5. 右移到 `01H` 后再右移会变成 `00H`，`JZ 00H` 回到开头。

汇编写法：

```asm
    MOV A,#01H
LEFT:
    OUT
    RL A
    JZ RIGHT_INIT
    JMP LEFT

RIGHT_INIT:
    MOV A,#40H
RIGHT:
    OUT
    RR A
    JZ 00H
    JMP RIGHT
END
```

机器码：

| 地址 | 机器码 | 对应汇编 |
| --- | --- | --- |
| `00` | `7C` | `MOV A,#01H` |
| `01` | `01` | 立即数 `01H` |
| `02` | `C4` | `OUT` |
| `03` | `D4` | `RL A` |
| `04` | `A4` | `JZ 08H` |
| `05` | `08` | 跳转地址 `08H` |
| `06` | `AC` | `JMP 02H` |
| `07` | `02` | 跳转地址 `02H` |
| `08` | `7C` | `MOV A,#40H` |
| `09` | `40` | 立即数 `40H` |
| `0A` | `C4` | `OUT` |
| `0B` | `D0` | `RR A` |
| `0C` | `A4` | `JZ 00H` |
| `0D` | `00` | 跳转地址 `00H` |
| `0E` | `AC` | `JMP 0AH` |
| `0F` | `0A` | 跳转地址 `0AH` |

顺序输入机器码：

```text
7C 01 C4 D4 A4 08 AC 02 7C 40 C4 D0 A4 00 AC 0A
```

地址最容易错的地方：

| 跳转 | 为什么这样跳 |
| --- | --- |
| `JZ 08H` | 左移溢出为 `00H` 后，跳到右移初始化 `MOV A,#40H` |
| `JMP 02H` | 左移还没到头，回到 `OUT` 继续显示 |
| `JZ 00H` | 右移到 `00H` 后，重新从 `01H` 开始 |
| `JMP 0AH` | 右移还没到头，回到右移段的 `OUT` |

## 五、第 4 题：先全亮，再全灭，再循环

参考代码效果：先从 `00H` 开始，逐步变成 `01H, 03H, 07H, 0FH, ... FFH`，表现为灯逐个亮起直到全亮；然后从 `FEH, FCH, F8H, ... 80H, 00H`，表现为灯逐个熄灭直到全灭；最后回到开头循环。

思路拆开看：

第一段，逐个点亮：

1. A 初始为 `00H`，先输出全灭。
2. 每轮先判断 `A+1` 是否变成 `00H`。
3. 如果不是 `00H`，恢复原值，再 `RL A` 左移，最后 `ADD A,#01H` 把最低位补成 1。
4. 所以序列是 `00 -> 01 -> 03 -> 07 -> 0F -> 1F -> 3F -> 7F -> FF`。

第二段，逐个熄灭：

1. 当 `FFH + 01H = 00H` 时，`JZ` 跳到第二段。
2. `CPL A` 把 `00H` 取反成 `FFH`。
3. `RL A` 变成 `FEH`，输出。
4. 继续左移：`FE -> FC -> F8 -> F0 -> E0 -> C0 -> 80 -> 00`。
5. 当输出/移位后检测到 `00H`，跳回开头。

汇编写法：

```asm
    MOV A,#00H
LIGHT_LOOP:
    OUT
    ADD A,#01H
    JZ DARK_INIT
    SUB A,#01H
    RL A
    ADD A,#01H
    JMP LIGHT_LOOP

DARK_INIT:
    CPL A
DARK_LOOP:
    RL A
    OUT
    JZ 00H
    JMP DARK_LOOP
END
```

机器码：

| 地址 | 机器码 | 对应汇编 |
| --- | --- | --- |
| `00` | `7C` | `MOV A,#00H` |
| `01` | `00` | 立即数 `00H` |
| `02` | `C4` | `OUT` |
| `03` | `1C` | `ADD A,#01H` |
| `04` | `01` | 立即数 `01H` |
| `05` | `A4` | `JZ 0EH` |
| `06` | `0E` | 跳转地址 `0EH` |
| `07` | `3C` | `SUB A,#01H` |
| `08` | `01` | 立即数 `01H` |
| `09` | `D4` | `RL A` |
| `0A` | `1C` | `ADD A,#01H` |
| `0B` | `01` | 立即数 `01H` |
| `0C` | `AC` | `JMP 02H` |
| `0D` | `02` | 跳转地址 `02H` |
| `0E` | `E4` | `CPL A` |
| `0F` | `D4` | `RL A` |
| `10` | `C4` | `OUT` |
| `11` | `A4` | `JZ 00H` |
| `12` | `00` | 跳转地址 `00H` |
| `13` | `AC` | `JMP 0FH` |
| `14` | `0F` | 跳转地址 `0FH` |

顺序输入机器码：

```text
7C 00 C4 1C 01 A4 0E 3C 01 D4 1C 01 AC 02 E4 D4 C4 A4 00 AC 0F
```

这题最绕的地方是第一段为什么要 `ADD` 后又 `SUB`：

- `ADD A,#01H` 是为了检测 A 是否已经是 `FFH`。如果 A 是 `FFH`，加 1 后变成 `00H`，零标志置 1，跳到熄灭段。
- 如果还没到 `FFH`，就 `SUB A,#01H` 恢复原来的 A，再用 `RL A` 和 `ADD A,#01H` 生成“低位连续为 1”的灯型。

## 六、上机输入与调试步骤

根据指导书第 4 章和第 8/9 章，综合实验大致这样做：

1. 拔掉手工实验接线，用 8 芯电缆连接 `J1` 和 `J2`，进入非手动/微程序控制方式。
2. 控制方式开关 `KC` 拨到“微程序控制”。
3. 可以在 CP226 软件源程序窗口写汇编，也可以直接在实验仪小键盘里输入机器码。
4. 若用小键盘，按 `TV` 选择 `EM`，再按地址顺序输入机器码。
5. 输入完成后按 `RST` 复位，让 `PC` 回到 `00H`。
6. 用 `STEP` 单微指令执行，或用 `SCAL` 单指令执行，确认 `A`、`OUT`、`PC/uPC` 是否按预期变化。
7. 确认无误后再全速执行。

调试时重点看：

| 现象 | 检查点 |
| --- | --- |
| 完全不循环 | `JMP` 的目标地址是否写错 |
| 少显示一个状态 | `OUT` 放的位置是否太晚或太早 |
| 到头不返回 | `JZ` 前一条指令是否真的会产生 `00H` |
| 灯序反了 | `RL A`/`RR A` 是否用反 |
| 机器码地址对不上 | 是否忘记立即数/跳转地址也占 1 个字节 |

## 七、背题技巧

第 1 题记成：读入、加一、输出、回头。

```text
C0 1C 01 C4 AC 00
```

第 2 题记成：从 1 开始，输出、加一、回到输出。

```text
7C 01 C4 1C 01 AC 02
```

第 3 题记成：左移到零，改从 `40H` 右移；右移到零，回开头。

```text
7C 01 C4 D4 A4 08 AC 02 7C 40 C4 D0 A4 00 AC 0A
```

第 4 题记成：先造 `01/03/07/.../FF`，再造 `FE/FC/.../00`。

```text
7C 00 C4 1C 01 A4 0E 3C 01 D4 1C 01 AC 02 E4 D4 C4 A4 00 AC 0F
```
