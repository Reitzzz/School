## 1.1 计算机的发展历史

#### 核心概念

- 1946 年第一台电子计算机 ENIAC 在美国宾夕法尼亚大学诞生。
- **冯·诺依曼 (John von Neumann)** 被誉为现代电子计算机之父，提出了程序存储和程序控制原理。
- 计算机的四个发展阶段（按使用的核心电子元器件划分）：
  1. 电子管计算机（1946-1958）
  2. 晶体管计算机（1958-1964）
  3. 中小规模集成电路计算机（1964-1971）
  4. 大规模、超大规模集成电路计算机（1971-至今）

## 1.2 计算机系统的组成

完整的计算机系统由**硬件系统**和**软件系统**两大部分构成。**硬件**是系统的物质基础，**软件**是系统的灵魂。

### 1.2.1 冯·诺依曼计算机特点

冯·诺依曼原理的核心是：**基于二进制的程序存储和程序控制**（又称指令驱动原理）。

#### 必背结论

- **组成特点**：计算机由**运算器、控制器、存储器、输入设备、输出设备**五大核心部件组成。
- **存储特点**：指令和数据以同等地位、用**二进制**形式存放于存储器中，并且可以按地址寻访。
- **指令格式**：指令由**操作码**（规定做什么操作）和**地址码**（规定对谁操作）组成。
- **指令执行**：指令在存储器中通常按顺序存放，CPU 一般按顺序执行指令，特定条件下（如条件转移）才改变执行顺序。
- **结构特点**：
  - **经典冯氏结构**：以**运算器**为中心，I/O 设备与存储器之间的数据传送必须通过运算器。
  - **现代计算机结构**：逐渐演变为以**存储器**为中心。

### 1.2.2 硬件系统组成

硬件系统通常被抽象为外设和主机（CPU、存储器、I/O 接口、总线）。

#### 各部件核心功能

| 部件名称 | 核心功能与主要结构 |
| --- | --- |
| 运算器 (ALU) | 对数据信息进行加工和处理（算术/逻辑运算）。包含 ALU、累加器 A、暂存器 TMP、状态寄存器、通用寄存器等。 |
| 控制器 (CU) | 控制全机各部件协调工作。负责**取指、分析译码、发出控制信号**。具有定序、定时和操作控制功能。 |
| 存储器 (MEM) | 存放程序和数据。包含存储体(MM)、地址寄存器(`MAR`)、数据寄存器(`MDR`)。`MAR` 存放要访问的地址，`MDR` 暂存要读写的数据。 |
| 输入/输出设备 | 输入：将外部信息转为二进制送入主机；输出：将处理结果转为人类可识别的形式。 |
| I/O 接口 | 外设与主机之间信息传送时，速度适配与信号适配的转换器。 |
| 总线 (BUS) | 连接各部件并传送信息的公共通路。**总线上的部件必须分时发送信息，但可同时接收信息。** |

#### 存储器与总线易考点

- **存储器基本结构**：`MAR` 保存要访问的地址，`MAD` 完成地址译码，`MM` 是实际存储体，`MDR` 暂存读出或准备写入的数据。
- **读存储器**：地址 $\rightarrow MAR$，发出读命令，$MM \rightarrow MDR$。
- **写存储器**：地址 $\rightarrow MAR$，数据 $\rightarrow MDR$，发出写命令，$MDR \rightarrow MM$。
- **系统总线三类**：地址总线 `AB` 传地址，数据总线 `DB` 传数据，控制总线 `CB` 传读写、时序、控制信号。

### 1.2.3 软件系统组成

软件系统可分为**系统软件**和**应用软件**。

- **系统软件**：管理资源、控制运行，方便用户使用。例如操作系统 (OS)、语言处理程序、数据库管理系统等。
- **应用软件**：用户为解决特定问题而编制的程序。

#### 易混点

机器语言、汇编语言与高级语言的区别：
- **机器语言**：面向机器，纯二进制，执行效率最高，但人类不易掌握。
- **汇编语言**：用助记符表示的机器语言，需经“汇编程序”翻译。
- **高级语言**：面向过程或对象，与机器结构无关，易掌握，但需“编译/解释程序”翻译，执行效率相对较低。

## 1.3 计算机系统的多级层次结构

### 1.3.1 层次结构划分

计算机系统可看作是由低到高的多级抽象层次。底层偏向物理硬件，高层偏向用户逻辑。

#### 表格对比

| 级别 | 名称 | 特点 | 虚实划分 |
| --- | --- | --- | --- |
| M4 | 高级语言级 | 面向高级程序员，由编译/解释程序翻译 | 虚机器 |
| M3 | 汇编语言级 | 提供符号形式语言，由汇编程序翻译 | 虚机器 |
| M2 | 操作系统级 | 由机器指令和广义指令组成，混合级 | 虚机器 |
| M1 | 一般机器级 (机器语言级) | 由微程序解释机器指令，能识别机器指令 | 实机器 |
| M0 | 微程序设计级 | CPU 内部硬件直接执行微指令 | 实机器 |

> **易混点**：第一级（M0）和第二级（M1）属于**实机器**，操作系统级（M2）及以上均属于**虚机器**。机器语言层和操作系统层是虚、实机器的分界面。

### 1.3.2 软硬件的逻辑等效性

#### 核心概念

- **逻辑等效性**：任何由硬件实现的操作，原理上都可用软件实现；反之，任何由软件实现的操作，原理上也都可用硬件实现。
- **硬件的软化**：将原来由硬件实现的功能改用软件程序实现（降低成本，增加灵活性）。
- **软件的硬化**：将原来由软件实现的功能改用硬件电路实现（提高速度）。
- **固件**：将复杂且常用的程序写入只读存储器（ROM），功能上看是软件，形态上看是硬件。

## 1.4 计算机系统的性能评价

### 1.4.1 非时间指标

- **机器字长**：计算机并行处理的二进制数据位数（通常等于 CPU 内部数据总线宽度或通用寄存器位数）。
- **总线宽度**：数据总线能同时传送的二进制位数。
- **主存容量**：存储器中所有存储单元的总数。
- **存储带宽**：单位时间内主存与系统其他部件交换数据的最大数量。

### 1.4.2 时间指标与核心公式

#### 核心概念

- **主频 $f$**：CPU 工作的内部时钟频率。
- **时钟周期 $T$**：计算机中最基本的、最小的时间单位，$T = \frac{1}{f}$。一个时钟周期内 CPU 仅完成一个最基本动作。
- **外频 / 倍频**：主频 = 外频 $\times$ 倍频。

#### 必要公式

- **$CPI$ (Clock cycles Per Instruction)**：执行一条指令（平均）需要的时钟周期数。
  $$CPI = \sum (单类指令\ CPI \times 该类指令在程序中的占比)$$
- **$MIPS$ (Million Instructions Per Second)**：每秒钟执行的百万条指令数，衡量处理速度。
  $$MIPS = \frac{f}{CPI \times 10^6}$$
- **$CPU$ 执行时间**：
  $$T_{CPU} = 指令总数 \times CPI \times T = \frac{指令总数 \times CPI}{f} = \frac{指令总数}{MIPS \times 10^6}$$

### 1.4.3 经典例题：CPI 与 MIPS

#### 例题

假设一台计算机的主频 $f = 1\text{GHz}$，运行一段由 $2 \times 10^5$ 条指令组成的目标代码。程序中各类指令占比及对应 $CPI$ 如下：
- 加法指令：占 $60\%$，$CPI = 1$
- 访存指令：占 $18\%$，$CPI = 2$
- 乘法指令：占 $12\%$，$CPI = 4$
- 其他指令：占 $10\%$，$CPI = 8$

求该程序的 $CPI$、$MIPS$ 及 $CPU$ 执行时间。

#### 解题过程

1. **计算程序平均 $CPI$**：
   $$CPI = 1 \times 60\% + 2 \times 18\% + 4 \times 12\% + 8 \times 10\% = 2.24$$
2. **计算 $MIPS$**：
   $$MIPS = \frac{f}{CPI \times 10^6} = \frac{1 \times 10^9}{2.24 \times 10^6} \approx 446.4$$
3. **计算 $CPU$ 执行时间**：
   $$T_{CPU} = \frac{指令总数 \times CPI}{f} = \frac{2 \times 10^5 \times 2.24}{1 \times 10^9} = 4.48 \times 10^{-4} \text{ 秒}$$
