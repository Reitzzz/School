# 计算机组成原理：容量单位与寻址核心笔记

## 一、 绝对不变的基础单位 (底层物理基石)

这两个单位的定义和换算比例是固定的，与计算机架构无关。

* **位 (bit, 简写为小写 b)**
  * **定义**：计算机中最小的数据单位，即一个二进制位。
  * **存储内容**：只能存放 1 个 `0` 或 `1`。

* **字节 (Byte, 简写为大写 B)**
  * **定义**：计算机中最基本的存储单位和编址单位。
  * **固定换算**：**1 B = 8 b** (即 1 Byte = 8 bit)。
  * **注意**：网络带宽常说的 100Mbps 是指 bit；而下载速度 12.5MB/s 是指 Byte。

---

## 二、 依赖系统架构的动态单位 (随 CPU 变化)

这部分单位的具体大小不固定，取决于当前 CPU 的架构位数。

* **机器字长 (Word Length)**
  * **定义**：CPU 内部的 ALU (算术逻辑单元) 一次能直接处理的二进制数据的位数。
  * **常见分类**：16位、32位、64位。

* **字 (Word)**
  * **定义**：机器字长的实际数据实体。一个字就是机器一次处理的数据总长度。
  * **换算关系 (核心考点)**：
    * **16 位系统**：1 字 = 16 bit = **2 Byte**
    * **32 位系统**：1 字 = 32 bit = **4 Byte** (这也是 32 位系统中，程序计数器 PC 每次顺序执行时需要 +4 的原因)
    * **64 位系统**：1 字 = 64 bit = **8 Byte**

---

## 三、 计组专用的数量级单位 (严格按 2 的次幂)

在计算机体系结构和内存计算中，K、M、G、T 必须按照 2 的次幂进行换算，绝不能按 1000 换算。

| 符号 | 名称 | 准确换算 (2的次幂) | 对应的十进制近似值 |
| :--- | :--- | :--- | :--- |
| **K** (Kilo) | 千 | **2^10** = 1024 | 约 10^3 |
| **M** (Mega) | 兆 | **2^20** = 1024 K | 约 10^6 |
| **G** (Giga) | 吉 | **2^30** = 1024 M | 约 10^9 |
| **T** (Tera) | 太 | **2^40** = 1024 G | 约 10^12 |

> **计算技巧**：遇到次方数拆分计算，例如 2^13 = 2^3 * 2^10 = 8 K。

---

## 四、 核心考点：主存容量计算与寻址方式

做题时，首先明确两个前提：容量的单位是什么，以及按什么粒度寻址。

### 1. 存储器容量表示法
* 题目格式：`地址数 × 存储字长` (例如：64K × 8位)
* **地址数 (64K)**：代表内存中有 64K 个可寻址的单元 (门牌号)。64K = 64 * 1024。
* **存储字长 (8位)**：代表每个地址单元里存放了 8 bit (即 1 Byte) 的数据。
* **总容量计算**：64K * 1B = 64 KB。

### 2. 寻址方式的区别
* **按字节寻址 (最常见)**：
  * 每个内存地址对应 1 个字节 (1B)。
  * 若容量为 64KB，按字节寻址，寻址范围就是 0 ~ 64K-1。
* **按字寻址**：
  * 每个内存地址对应 1 个字。
  * 必须结合机器字长计算。如果是在 32 位机器上 (1字 = 4B)，同样是 64KB 的内存，其寻址范围只有 16K (64KB / 4B = 16K)。
