# 计算机组成原理：数据表示与运算方法（课程内容笔记）

## 一、 数制与编码基础
### 1.1 二进制物理与逻辑特性
- 计算机采用二进制的原因（物理实现、运算规则、逻辑对应、抗干扰能力）。
### 1.2 机器数（原码、反码、补码、移码）
- 各种码制的定义域、数零的表示方法（如原码/反码有+0和-0，补码/移码有唯一零）。
- 移码的特殊性与偏移量（标准移码 2^(n-1) 与 IEEE 754 标准移码的偏置常数）。
### 1.3 计算机内部的数据类型与高级语言映射
- **底层与汇编层面**：寄存器、存储器中的操作数本身**没有数据类型**。对其进行何种操作完全**取决于指令的操作码**。同一个操作数可被任意解释为有/无符号或定/浮点数。
- **高级语言（C语言）整型取值范围**（以 8 位 char 为例）：
  - `unsigned char`：机器码 00000000 ~ 11111111，真值范围是 **0 ~ 255** (即 2^8 - 1)。
  - `char`（有符号补码）：机器码 10000000 ~ 01111111，真值范围是 **-128 ~ 127** (即 -2^7 到 2^7 - 1)。
- **溢出特性**：C语言程序**并不检测**整型数据在加、减、乘等运算中产生的溢出。需由程序员在应用层自行逻辑判断。

## 二、 定点数表示与运算
### 2.1 定点整数与定点小数
- 小数点固定位置的约定规则。
### 2.2 补码加减法运算原理
- 模数（Modulo）选择：定点整数为 2^(n+1)，定点小数为 2。
- 减法转加法公式：[A-B]_补 = [A]_补 + [-B]_补。
### 2.3 溢出检测三方法
- 方法1：操作数与结果符号位比较法（同号相加才可能溢出）。
- 方法2：双进位判定法（最高数值位进位 Cf 与符号位进位 Cs 异或）。
- 方法3：变形补码（双符号位）判定法（00 正，11 负，01 正溢出，10 负溢出）。

## 三、 浮点数表示与规格化
### 3.1 浮点数基本格式
- N = r^E * M（阶码 E 决定范围，尾数 M 决定精度）。
### 3.2 规格化基本概念与规律
- 规格化的目的（表示形式唯一、精度最高）。
- 补码尾数的规格化形式：正数为 00.1××…×，负数为 11.0××…×。
- 左规（尾数左移，阶码减）与右规（尾数右移，阶码加）的处理条件。
### 3.3 极值与表示范围
- 最大正数、最小正数、最大负数、最小负数的边界计算规律。

## 四、 工业标准：IEEE 754 浮点数
### 4.1 单精度（32位）与双精度（64位）结构
- 字段划分：符号位(S)、阶码(E，移码表示)、尾数(M，原码表示)。
### 4.2 特殊编码规则
- 隐藏高位1（1.M形式）的意义与实际24位精度。

- 特殊值判定：阶码全0（非规格化数/±0），阶码全1（±∞/NaN）。

## 六、 C语言中的数据类型转换原理
### 6.1 整型数据之间的转换
- **相同字长转换**（如 char <-> unsigned char）：机器码完全保持不变，仅改变对其最高位的解释方式（符号位还是数值位）。交集外相互转换会导致真值发生差错。
- **小字长转大字长**（如 char -> short）：尽量保持真值不变。
  - **源数据为无符号**：进行 **0扩展**（高位全部补 0）。
  - **源数据为有符号**：进行 **符号扩展**（高位全部补源数据的符号位）。
- **大字长转小字长**（如 int -> short）：编译器直接进行**截短处理**（直接丢弃高位字长，保留低位），大概率导致数据真值改变。
### 6.2 int、float、double 之间的转换
- **float -> double**：**真值完全相同**。因为 double 的阶码和尾数容量均大于 float，无损转换。
- **double -> float**：大数转换可能发生**溢出**（超出 float 表示范围）；高精度数转换会发生**舍入**（丢失 double 尾数的低位精度）。
- **float/double -> int**：小数部分向 0 方向**截断**（直接无条件舍弃小数）；大数转换若超过 int 范围会发生**溢出**。
- **int -> float**：**大整数无法精确表示**。两者虽都是 32 位，但 float 的尾数包含隐藏位在内仅 24 位。当 int 型数据的高 8 位（24~31位）包含非 0 有效值时，无法精确转换，会发生**精度丢失（溢出）**。
- **int -> double**：**真值完全相同**。double 的尾数包含隐藏位有 53 位，足以完美、无损地精确表示所有 32 位的 int 整数。
