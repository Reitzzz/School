# 定点数加减法与溢出检测

## 2.2.1(1) 定点数加减法

### 补码加减法运算公式

经过之前的学习可知，**定点数**（定点整数和定点小数）在**计算机内部采用补码**表示，原因如下：

* 补码的符号位可以与数值位一起参加运算。
* 采用补码可将减法运算转换成加法运算。

> **总结：** 运算规则简单，易于实现。

#### 补码加法和减法运算的公式如下：

$$[A]_{补} + [B]_{补} = [A + B]_{补} \pmod M$$

$$[A]_{补} - [B]_{补} = [A - B]_{补} = [A]_{补} + [-B]_{补} \pmod M$$

其中，模数 $M$ 的取值如下：
* **定点整数：** $M = 2^{n+1}$ （其中，$n$ 为补码数值位的位数）
* **定点小数：** $M = 2^1 = 2$



## 2.2.1（2） 溢出检测

定点数补码加减运算判断溢出的方法主要有以下3种：

### 方法1：根据操作数的符号位与运算结果的符号位是否一致进行判断

**核心原理：** 两个操作数**相加**时，当它们的**符号位相同**（即同正或同负）时，才**可能发生溢出**。

**理论证明：**
假设机器字长为 $n+1$ 位，补码所能表示的真值范围是 $-2^n \le \text{真值} < 2^n$。

1. **当真值 $x$ 和 $y$ 同为负数时：**
   $$ -2^n \le x < 0 $$
   $$ -2^n \le y < 0 $$
   两者相加得：$0 > x + y \ge -2^{n+1}$ （超出表示下限，**可能负溢**）
2. **当真值 $x$ 和 $y$ 同为正数时：**
   $$ 0 < x < 2^n $$
   $$ 0 < y < 2^n $$
   两者相加得：$0 < x + y < 2^{n+1}$ （超出表示上限，**可能正溢**）

**判断规则：**
* **溢出：** 运算结果的符号位与原操作数的符号位不同。
* **未溢出：** 运算结果的符号位与原操作数的符号位相同。

**【例题分析】**（采用4位补码表示）
* **例题1：若 $x = -101, y = -011$，判断 $[x+y]_{补}$ 是否会溢出。**
  $[x]_{补} = 1,011$
  $[y]_{补} = 1,101$
  相加结果 $= 11,000$ （最高位的进位 $1$ 为模数，应舍弃）
  最终结果符号位为 $1$，与原操作数符号位相同 $\rightarrow$ **未溢出**。

* **例题2：若 $x = +101, y = +011$，判断 $[x+y]_{补}$ 是否会溢出。**
  $[x]_{补} = 0,101$
  $[y]_{补} = 0,011$
  相加结果 $= 1,000$ 
  最终结果符号位为 $1$，与原操作数符号位不同 $\rightarrow$ **溢出**。

---

### 方法2：根据运算过程中最高数值位的进位与符号位的进位是否一致进行判断

**判断规则：**
* 两个进位**不同**可判定为产生**溢出**。
* 两个进位**相同**可判定为**没有产生溢出**。

**【举例分析】**（采用4位补码表示）
* **举例1：若 $x = 5, y = 4$，判断 $[x+y]_{补}$ 是否会溢出。**
  $[x]_{补} = 0,101$
  $[y]_{补} = 0,100$
  运算过程：最高数值位进位为 $1$，符号位进位为 $0$。
  $0 \neq 1$，结果得 $1,001 = -7$ $\rightarrow$ **9 正溢**。

* **举例2：若 $x = -5, y = -4$，判断 $[x+y]_{补}$ 是否会溢出。**
  $[x]_{补} = 1,011$
  $[y]_{补} = 1,100$
  运算过程：最高数值位进位为 $0$，符号位进位为 $1$。
  $1 \neq 0$，结果得 $10,111$（最高位1舍弃），实际保留为 $0,111 = 7$ $\rightarrow$ **-9 负溢**。

---

### 方法3：利用变形补码（具有2位符号位的补码）的符号位进行判断

变形补码也称为**双符号补码**，具有2个符号位，其余与补码相同。

**判断规则：**
* 双符号位为 **00** 时，表示 **正数**。
* 双符号位为 **11** 时，表示 **负数**。
* 双符号位为 **01** 时，表示 **正溢出**。
* 双符号位为 **10** 时，表示 **负溢出**。

**特点：** 溢出判断非常直观，适合手工运算时的溢出检测；但其硬件成本高，在计算机中主要采用单符号溢出检测方案。

> **注意：** 负数变形补码转换成原码仍可以使用反码法或扫描法。
