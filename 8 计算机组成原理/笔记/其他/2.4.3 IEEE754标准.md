# 2.4.3 IEEE754标准

### 1. IEEE 754 基本格式

IEEE 754 标准主要包括两种基本的浮点数格式，分别对应高级语言中的不同数据类型：

* **32位单精度浮点数**：对应C语言中的 `float` 型。
    * 结构：1位符号位 + 8位阶码 + 23位尾数。
* **64位双精度浮点数**：对应C语言中的 `double` 型。
    * 结构：1位符号位 + 11位阶码 + 52位尾数。

**各组成部分说明：**
* **符号 (S)**：取值0表示正数；取值1表示负数。
* **阶码 (E)**：定点整数，用**移码**表示。
* **尾数 (M)**：定点小数，用**原码**表示。

---

### 2. 32位单精度浮点数详解

以32位单精度浮点数为例，其格式和相关编码规则如下：

| 符号 S (1位) | 阶码 E (8位) | 尾数 M (23位) |
| :---: | :---: | :---: |
| 第31位 | 第23~30位 | 第0~22位 |
| 0表正，1表负 | 定点整数，移码表示 | 定点小数，原码表示 |

* **阶码偏置常数**：阶码用移码表示，单精度浮点数的偏置常数为 $2^{7} - 1 = 127$。
* **隐含的尾数最高位**：尾数用原码表示。在规格化时，符号位前移到最左侧，相邻左侧**隐藏一个1**，该位表示数值而不表示符号。
* **尾数实际长度**：虽然单精度浮点数分配给尾数的只有23位，但由于隐藏了最高位的1，尾数实际有**24位**。节省的1个比特位可用于提高尾数的精度。完整的尾数形式为 **1.M**。

### 3. IEEE 754 单精度浮点数与真值之间的转换

#### 【例题1】将十进制数转换为IEEE 754单精度浮点数
**题目：** 将十进制数 408.6875 转换成 IEEE 754 单精度浮点数的十六进制机器码。

**解析步骤：**
1.  **转二进制**：将十进制数 408.6875 转换为二进制数为 110011000.1011。
2.  **尾数变成 1.M 形式（规格化）**：将小数点左移8位，得到 $1.100110001011 \times 2^{8}$。
3.  **提取各部分数值**：
    * **符号 S** = 0 （表示正数）。
    * **阶码 E** = 真实指数 + 偏置常数 = 8 + 127 = 135，化为二进制为 10000111。
    * **尾数 M** = 去掉隐含的1后的纯小数部分，即 100110001011，后面补0凑足23位，得到 10011000101100000000000。
4.  **组合机器码**：
    组合 (S + E + M)：`0_10000111_10011000101100000000000`
5.  **转十六进制**：
    将上述32位二进制数每4位一组进行转换：`0100 0011 1100 1100 0101 1000 0000 0000`
    最终结果为：**43CC5800 H**

#### 【例题2】将IEEE 754单精度机器码转换为十进制真值
**题目：** 若 C1830000 是某个 IEEE 754 单精度浮点数的十六进制机器码，求其对应的十进制值。

**解析步骤：**
1.  **转二进制并拆分**：将十六进制数 C1830000 展开为32位二进制：
    `1100 0001 1000 0011 0000 0000 0000 0000`
    * **符号 S** = 1 （第31位）
    * **阶码 E** = 10000011 （第23~30位）
    * **尾数 M** = 00000110000000000000000 （第0~22位）
2.  **计算阶码的真值 x**：
    阶码 E 的二进制 10000011 对应十进制为 131。
    真值 x = 阶码 E - 127 = 131 - 127 = 4。
3.  **还原尾数的 1.M 形式**：
    加上隐藏的 1，得到完整的尾数为 1.0000011。
4.  **计算浮点数的真值**：
    公式：浮点数的真值 = $(-1)^{S} \times 2^{x} \times 1.M$
    代入数据 = $(-1)^{1} \times 2^{4} \times 1.0000011$
    计算移位 = -10000.011 (二进制)
5.  **转换为十进制**：
    二进制 -10000.011 对应的十进制为：-(16 + 0.25 + 0.125) = **-16.375**。
