## 题型 1：简答理论题归纳

### 1.1 经典问题：为什么计算机采用二进制？
- **对应PPT章节**：第2章 2.1 数据信息的表示方法（机器数基础）
- **答题卡点**：物理器件易实现（高低电平、导通/截止）；算术逻辑运算规则简单；适合逻辑运算（0/1 对应假/真）；抗干扰、可靠性高。

### 1.2 经典问题：运算器由哪些基本部件组成？
- **对应PPT章节**：第2章 2.5 定点运算器的组成与结构
- **答题卡点**：ALU（算术逻辑运算单元）、数据缓冲寄存器、累加器、通用寄存器组、状态寄存器（PSW/FR）、多路开关、内部数据总线。

### 1.3 经典问题：单总线、双总线、三总线结构执行一次加法分别需要几个时钟周期？
- **对应PPT章节**：第2章 2.5 定点运算器的基本结构
- **答题卡点**：
  - 单总线：2 个锁存器，**3 个时钟周期**
  - 双总线：1 个锁存器，**2 个时钟周期**
  - 三总线：0 个锁存器，**1 个时钟周期**
  - 总线越多，性能越好。

### 1.4 经典问题：浮点数加减运算为什么要“对阶”？原则是什么？
- **对应PPT章节**：第2章 2.6.1 浮点算术运算
- **答题卡点**：只有阶码相同，小数点位置才对齐，才能直接进行尾数加减；**小阶向大阶看齐**，阶小的尾数右移，阶码加 1，直到两阶码相等。

## 题型 2：补码加减运算与溢出判断

### 2.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.2.1 定点补码加、减法与溢出
1. **写出补码**：正数符号位为 `0`（变形补码为 `00`）；负数按位取反末位加 1（变形补码同样处理）。
2. **减法转加法**：$[x-y]_{补} = [x]_{补} + [-y]_{补}$，其中 $[-y]_{补}$ 是将 $[y]_{补}$ **连同符号位**一起取反末位加 1（称为“变补”）。
3. **执行加法**：连同符号位一起相加，最高位产生的进位自然丢弃（模运算）。
4. **溢出判断**（三种方法）：
   - **双符号位法（变形补码）**：结果符号位为 `01` → 正溢出（上溢）；`10` → 负溢出（下溢）；`00`/`11` → 无溢出。$V = S_{f1} \oplus S_{f2}$。
   - **进位判断法（单符号位）**：$V = C_n \oplus C_{n-1}$，$C_n$ 为符号位进位，$C_{n-1}$ 为最高数值位向符号位的进位。$V=1$ 则有溢出。
   - **符号比较法**：同号数相加，若结果符号与操作数符号不同，则溢出。

### 2.2 例题与详细解答

> **【例 1】补码加法**  
> 已知 $x = +0.1011,\ y = -0.0101$，求 $x+y$。  
> **解**：  
> $[x]_{补} = 0.1011$  
> $[y]_{补} = 1.1011$（负数补码：$10.0000 - 0.0101 = 1.1011$）  
> ```
>   0.1011
> + 1.1011
> --------
>  10.0110
> ```
> 丢掉模 2 的最高位进位，$[x+y]_{补} = 0.0110$，故 $x+y = +0.0110$。

> **【例 2】补码减法**  
> 已知 $x = +0.1101,\ y = +0.0110$，求 $x-y$。  
> **解**：  
> $[x]_{补} = 0.1101$  
> $[y]_{补} = 0.0110$  
> $[-y]_{补} = 1.1010$（将 $[y]_{补}$ 连同符号位取反得 `1.1001`，末位加 1 得 `1.1010`）  
> ```
>   0.1101
> + 1.1010
> --------
>  10.0111
> ```
> 丢掉模 2 进位，$[x-y]_{补} = 0.0111$，故 $x-y = +0.0111$。

> **【例 3】单符号位溢出——两正数相加上溢**  
> 已知 $x = +0.1011,\ y = +0.1001$，求 $x+y$ 并判断溢出。  
> **解**：  
> $[x]_{补} = 0.1011,\ [y]_{补} = 0.1001$  
> ```
>   0.1011
> + 0.1001
> --------
>   1.0100
> ```
> 两个正数相加，结果符号位为 1（负数），**发生上溢（正溢出）**。

> **【例 4】单符号位溢出——两负数相加下溢**  
> 已知 $x = -0.1101,\ y = -0.1011$，求 $x+y$ 并判断溢出。  
> **解**：  
> $[x]_{补} = 1.0011,\ [y]_{补} = 1.0101$  
> ```
>   1.0011
> + 1.0101
> --------
>  10.1000
> ```
> 丢掉模 2 进位后得 `0.1000`，两个负数相加结果为正，**发生下溢（负溢出）**。

> **【例 5】变形补码（双符号位）——正溢出**  
> 已知 $x = +0.1011,\ y = +0.0111$，求 $x+y$。  
> **解**：  
> $[x]_{补} = 00.1011,\ [y]_{补} = 00.0111$  
> ```
>   00.1011
> + 00.0111
> ---------
>   01.0010
> ```
> 双符号位为 `01`，**发生正向溢出（上溢）**。第一符号位 `0` 是结果真正符号位。

> **【例 6】变形补码（双符号位）——负溢出**  
> 已知 $x = -0.1011,\ y = +0.0111$，求 $x-y$。  
> **解**：  
> $[x]_{补} = 11.0101$  
> $[y]_{补} = 00.0111 \Rightarrow [-y]_{补} = 11.1001$（连同符号位取反加 1）  
> ```
>   11.0101
> + 11.1001
> ---------
>  110.1110
> ```
> 丢掉最高位模值后得 `10.1110`，双符号位为 `10`，**发生负向溢出（下溢）**。

> **【例 7】进位判断法**  
> 已知 $[x]_{补} = 1.0101,\ [y]_{补} = 1.1001$，求 $x+y$ 并判断溢出。  
> **解**：  
> ```
>      1.0101
>    + 1.1001
>    --------
>     10.1110
> ```
> 最高数值位向符号位进位 $C_{n-1} = 0$，符号位向更高位进位 $C_n = 1$。  
> $V = C_n \oplus C_{n-1} = 1 \oplus 0 = 1$，**有溢出发生**（两个负数相加结果为正，属于下溢）。

> **【例 8】进位判断法——无溢出**  
> 已知 $[x]_{补} = 1.1101,\ [y]_{补} = 0.1001$，求 $x+y$。  
> **解**：  
> ```
>      1.1101
>    + 0.1001
>    --------
>     10.0110
> ```
> $C_{n-1} = 1,\ C_n = 1$，$V = 1 \oplus 1 = 0$，**无溢出**。丢掉模后 $[x+y]_{补} = 0.0110$，$x+y = +0.0110$。

## 题型 3：原码一位乘法

### 3.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.3.1 原码一位乘法
1. **符号位单独处理**：$P_f = x_f \oplus y_f$（异或）。
2. **数值部分取绝对值**：$|x|$ 用双符号位表示（如 `00.xxxx`），$|y|$ 用单符号位表示（如 `0.xxxx`）。
3. **递推公式**：设部分积 $P_0 = 0$，则  
   $P_1 = 2^{-1}(y_n \cdot |x| + P_0)$  
   $P_2 = 2^{-1}(y_{n-1} \cdot |x| + P_1)$  
   $\vdots$  
   $P_n = 2^{-1}(y_1 \cdot |x| + P_{n-1}) = |x| \cdot |y|$
4. **运算流程**：
   - 看乘数最低位 $y_n$：为 1 则部分积加 $|x|$，为 0 则加 0。
   - **部分积与乘数一起逻辑右移 1 位**（完成 $2^{-1}$，同时乘数次低位移至最低位）。
   - 计数器减 1，重复直到完成 n 次。
5. **拼接结果**：最终 $R_0$（高位）与 $R_1$（低位）拼接成 $2n$ 位乘积，再与符号位 $P_f$ 组合。

### 3.2 例题与详细解答

> **【例】原码一位乘法完整演算**  
> 已知 $x = -0.1101,\ y = -0.1011$，求 $[x \times y]_{原}$。  
> **解**：  
> - 符号位：$P_f = 1 \oplus 1 = 0$  
> - $|x| = 00.1101$（双符号位），$|y| = 0.1011$  
>
> | 步骤 | 部分积 $R_0$ | 乘数 $R_1$ | 操作说明 |
> |------|-------------|-----------|----------|
> | 初值 | `00.0000` | `0.1011` | |
> | 1 | `+ 00.1101` → `00.1101` | | $y_n=1$，加 $\|x\|$ |
> | | 右移 → `00.0110` | `10.101` | 右移 1 位得 $P_1$ |
> | 2 | `+ 00.1101` → `01.0011` | | $y_n=1$，加 $\|x\|$ |
> | | 右移 → `00.1001` | `110.10` | 右移 1 位得 $P_2$ |
> | 3 | `+ 00.0000` → `00.1001` | | $y_n=0$，加 0 |
> | | 右移 → `00.0100` | `1110.1` | 右移 1 位得 $P_3$ |
> | 4 | `+ 00.1101` → `01.0001` | | $y_n=1$，加 $\|x\|$ |
> | | 右移 → `00.1000` | `11110.` | 右移 1 位得 $P_4$ |
>
> - 数值部分乘积：$|P| = 0.10001111$  
> - 最终结果：$[x \times y]_{原} = \mathbf{0.10001111}$

## 题型 4：Booth 补码一位乘法

### 4.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.3.2 补码一位乘法
1. **特点**：符号位参与运算，不需单独计算符号位；采用补码运算；共需 $n+1$ 次加法，$n$ 次移位。
2. **初始化**：部分积 $\Sigma = 0$，$[Y]_{补}$ 置于乘数寄存器，附加位 $Y_{n+1} = 0$。
3. **判断规则**（看乘数最低两位 $Y_n Y_{n+1}$）：

| $Y_n$ | $Y_{n+1}$ | 操作 | 说明 |
|-------|-----------|------|------|
| 0 | 0 | $\Sigma + 0$，右移 1 位 | 字符串末位为 0 |
| 0 | 1 | $\Sigma + [X]_{补}$，右移 1 位 | 字符串末位为 +1 |
| 1 | 0 | $\Sigma + [-X]_{补}$，右移 1 位 | 字符串末位为 -1 |
| 1 | 1 | $\Sigma + 0$，右移 1 位 | 字符串末位为 0 |

4. **移位**：部分积、乘数连同符号位一起**算术右移** 1 位。
5. **最后一步**：第 $n+1$ 次根据 $Y_n Y_{n+1}$ 判断后**只加不移位**。

### 4.2 例题与详细解答
- **对应PPT章节**：第2章 2.3.2 补码一位乘法（Booth 算法流程图）
- **说明**：PPT 中给出 Booth 算法的标准流程与判断规则（如上图表所示）。考试若出现，严格按照“末两位判断 → 加减 → 算术右移”的循环执行 $n$ 次，最后一步只加不移位。数值例题请参照课堂/作业补充的 $X, Y$ 具体值代入上述规则逐步演算。

## 题型 5：原码不恢复余数除法

### 5.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.4.1 原码一位除法
1. **符号位**：$Q_f = x_f \oplus y_f$。
2. **数值部分**：$|Q| = |x| / |y|$，采用**不恢复余数法**（加减交替法）。
3. **递推公式**：
   - 若余数 $T_i \ge 0$：商上 1，$T_{i+1} = 2T_i - |y|$
   - 若余数 $T_i < 0$：商上 0，$T_{i+1} = 2T_i + |y|$
4. **运算流程**：
   - 被除数 $|x| \to R_0$，除数 $|y| \to R_2$，商寄存器 $R_1 = 0$，计数器 $T = n$。
   - **比较/减法测试**：$R_0 - R_2$（即加 $[-|y|]_{补}$）。
     - 余数 $\ge 0$：商末位置 1，余数左移 1 位后减 $|y|$。
     - 余数 $< 0$：商末位置 0，余数左移 1 位后加 $|y|$。
   - $R_0$ 与 $R_1$ 一起**左移** 1 位。
   - $T-1$，重复直到 $T=0$。
   - $R_0$ 存余数，$R_1$ 存商。

### 5.2 例题与详细解答
- **对应PPT章节**：第2章 2.4.1 原码一位除法
- **说明**：PPT 中给出手工除法示例 $X=+0.1011,\ Y=-0.1101$ 及机器算法流程。考试若出现，严格按照“余数左移 → 加减除数 → 上商”循环执行。注意：机器运算中通过加减交替实现不恢复余数，最终余数若为负需恢复（加 $|y|$）才能得到正确正余数。

## 题型 6：浮点数加减运算（对阶、尾数运算、规格化）

### 6.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.6.1 浮点算术运算
1. **对阶**：求阶差 $\Delta E = |E_x - E_y|$，**小阶向大阶看齐**。阶小的尾数算术右移 $\Delta E$ 位，阶码加 $\Delta E$。
2. **尾数加减**：对阶后，两数尾数按定点补码（双符号位）进行加法；减法转为加 $[-y]_{补}$。
3. **结果规格化**：
   - **右规**：若尾数为 `01.××…×` 或 `10.××…×`（双符号位不同），尾数右移 1 位，阶码加 1（只需一次）。
   - **左规**：若尾数为 `00.0××…×` 或 `11.1××…×`，尾数连同符号位一起左移，阶码减 1，直到出现 `00.1` 或 `11.0`。
4. **舍入**：对阶或右规时移出的低位按 **0 舍 1 入** 或 **恒置 1** 处理。
5. **溢出判断**：检查规格化后的阶码双符号位。`01` → 上溢（中断）；`10` → 下溢（置机器零）。

### 6.2 例题与详细解答

> **【例】浮点数加法完整演算**  
> 设浮点数阶码 4 位（含阶符，补码），尾数 6 位（含尾符，补码）。  
> $x = 2^{01} \times 0.1101,\ y = 2^{11} \times (-0.1010)$，求 $x+y$。  
> **解**：  
> - $[x]_{补} = 0001,\ 0.11010$  
> - $[y]_{补} = 0011,\ 1.01100$  
>
> ① **对阶**：  
> $[\Delta E]_{补} = [E_x]_{补} - [E_y]_{补} = 0001 + 1101 = 1110$，真值为 $-2$。  
> $x$ 的阶码比 $y$ 小 2，将 $x$ 的尾数右移 2 位，阶码加 2：  
> $[x]_{补} = 0011,\ 0.00111$（0 舍 1 入）  
>
> ② **尾数相加**（双符号位）：  
> ```
>   00.00111
> + 11.01100
> -----------
>   11.10011
> ```
>
> ③ **结果规格化**：  
> 结果尾数为 `11.1××…×` 的形式，需**左规**。  
> 尾数连同符号位左移 1 位：`11.00110`  
> 阶码减 1：`0010`  
>
> ④ **最终结果**：  
> $[x+y]_{补} = 0010,\ 1.00110$  
> 即 $x+y = 2^{010} \times (-0.11010)$

## 题型 7：浮点数乘除运算

### 7.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.6.1 浮点算术运算

**乘法**：
1. **阶码相加**：$E_z = E_x + E_y$（移码/补码加法，注意判溢）。
2. **尾数相乘**：$M_z = M_x \times M_y$（按定点原码/补码乘法）。
3. **结果规格化**：乘积可能需要左规（如 $0.1 \times 0.1 = 0.01$，需左规 1 位，阶码减 1）。

**除法**：
1. **阶码相减**：$E_z = E_x - E_y$。
2. **尾数相除**：$M_z = M_x \div M_y$（按定点除法）。
3. **结果规格化**：商可能需要右规（如 $0.1 \div 0.1 = 1.0$，需右规 1 位，阶码加 1）。

### 7.2 例题与详细解答
- **对应PPT章节**：第2章 2.6.1 浮点算术运算
- **说明**：PPT 中给出浮点乘除的公式化推导与三步操作流程（阶码加减 → 尾数乘除 → 规格化）。若考试出现具体数值，分别调用“题型 3（乘法）”或“题型 5（除法）”的定点算法处理尾数，同时独立处理阶码的加减即可。

## 题型 8：浮点数表示与 IEEE 754 格式转换

### 8.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.1 数值数据编码的表示方法 → 浮点表示 / IEEE 754

**通用浮点数格式（非 IEEE 754）**：
1. 将真值转为二进制，写成 $M \times 2^E$ 形式。
2. 尾数按规格化要求调整（补码规格化：正数 `0.1××…×`，负数 `1.0××…×`）。
3. 阶码、尾数分别转为补码（或移码），按题目给定字长拼接。

**IEEE 754 单精度（32 位）**：
1. **十转二**：整数除 2 取余，小数乘 2 取整。
2. **规格化**：写成 $(-1)^S \times 1.M \times 2^{E_{真实}}$。
3. **符号位 S**：正 0，负 1。
4. **阶码 E**：$E = E_{真实} + 127$（偏移量），转 8 位二进制。
5. **尾数 M**：取小数点后部分，不足 23 位右侧补 0，超出则舍入。
6. **组合**：`S(1位) + E(8位) + M(23位)`，通常写成十六进制。

**IEEE 754 逆向求真值**：
1. 32 位二进制按 1/8/23 切分。
2. 真实指数 = $E_{十进制} - 127$。
3. 还原尾数：前面加隐藏位 `1.`。
4. 真值 = $(-1)^S \times (1.M)_2 \times 2^{E-127}$。

### 8.2 例题与详细解答

> **【例 1】通用浮点数格式表示**  
> 某机用 16 位表示一个数，阶码 8 位（含 1 位符号），尾数 8 位（含 1 位符号）。  
> 写出 $x_1 = -100,\ x_2 = 127/256$ 的两种浮点格式。  
> **解**：  
> - $x_1 = -100 = -1100100_2 = -0.1100100 \times 2^7$  
>   - 阶码 $+7$：补码 `00000111`，移码 `10000111`  
>   - 尾数 $-0.1100100$：补码规格化 `1.0011100`（负数规格化形式 `1.0××…×`）  
>   - **格式一**（阶符+阶码值，数符+尾数值）：`00000111, 1.0011100`  
>   - **格式二**（数符，阶符+阶码值，尾数值）：`1, 10000111, 0011100`  
>
> - $x_2 = 127/256 = 0.1111111_2 = 0.1111111 \times 2^{-1}$  
>   - 阶码 $-1$：补码 `11111111`，移码 `01111111`  
>   - 尾数 $+0.1111111$：补码 `0.1111111`  
>   - **格式一**：`11111111, 0.1111111`  
>   - **格式二**：`0, 01111111, 1111111`

> **【例 2】IEEE 754 单精度编码**  
> 将 $(0.15625)_{10}$ 写成 IEEE 754 单精度浮点数。  
> **解**：  
> - $0.15625 = (0.00101)_2 = 1.01 \times 2^{-3}$  
> - 符号位 $S = 0$（正数）  
> - 真实指数 $E_{真实} = -3$  
> - 存储阶码 $E = -3 + 127 = 124 = 01111100_2$  
> - 尾数小数部分 $M = 01$（后面补 21 个 0）  
> - 完整 32 位：`0 01111100 01000000000000000000000`  
> - 十六进制：`3E200000H`
