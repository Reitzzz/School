## 题型 2：数制转换与定点数表示范围
### 2.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.0 数制与数制转换；2.1.1 数的定点表示
1. **任意进制 → 十进制**：按权展开，各位系数 $K_i$ 与位权 $R^i$ 相乘后求和。
2. **十进制 → 任意进制**：
   - 整数部分：**除基取余**，先余为低位（最低位）。
   - 小数部分：**乘基取整**，先整为高位（最高位）。
3. **二进制 ↔ 八进制**：整数从最低位起每3位一组，小数从最高位起每3位一组，不足补0。
4. **二进制 ↔ 十六进制**：同理，每4位一组。
5. **定点小数表示范围**（$n$ 位字长，含1位符号位）：
   - 原码：$-(1 - 2^{-(n-1)})$ ~ $+(1 - 2^{-(n-1)})$（正负零各占一个编码）。
   - 补码：$-1$ ~ $+(1 - 2^{-(n-1)})$（零编码唯一，可多表示一个 $-1$）。
6. **定点整数表示范围**（$n$ 位字长，含1位符号位）：
   - 原码：$-(2^{n-1} - 1)$ ~ $+(2^{n-1} - 1)$。
   - 补码：$-2^{n-1}$ ~ $+(2^{n-1} - 1)$。

## 题型 3：原码、反码、补码、移码的表示与转换
### 3.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.1 数值数据编码的表示方法 → 机器数的编码表示（原码、反码、补码、移码）
1. **正数**（符号位为0）：原码 = 反码 = 补码，直接将正号替换为0即可。
2. **负数**（符号位为1）：
   - 原码：符号位为1，数值位为绝对值。
   - 反码：符号位保持1，数值位各位取反（0变1，1变0）。
   - 补码：反码末位加1；或利用模运算 $[x]_{\text{补}} = 2^n + x$（Mod $2^n$）。
3. **移码**：补码的符号位取反，数值位不变；常用于浮点阶码以方便比较大小。
4. **0的特例**：
   - 原码和反码中，+0 与 -0 表示不同。
   - 补码中，0 的表示唯一（$[+0]_{\text{补}} = [-0]_{\text{补}} = 0.000\ldots0$）。
   - 补码特殊值：$1.000\ldots0$ 表示 $-1$（纯小数）或 $-2^{n-1}$（纯整数）。
5. **补码求真值**：
   - 符号位为0：直接去掉符号位即为真值。
   - 符号位为1：对补码数值位再求补（取反加1）得绝对值，真值为负。
6. **模的确定**：$n$ 位机器数（含1位符号位）的模为 $2^n$。

## 题型 4：变形补码加减法与溢出判断
### 4.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.1 数值数据编码的表示方法 → 补码表示法 / 溢出问题
1. 将真值转换为双符号位（变形补码）形式：正数为 $00.$，负数为 $11.$。
2. 若为减法，利用连同符号位在内“各位取反，末位加1”求出 $[-Y]_{\text{补}}$。
3. 执行补码加法，连同双符号位一起相加，最高位进位自然丢弃。
4. 观察结果双符号位：
   - $00$ 或 $11$：无溢出。
   - $01$：正溢出（上溢）。
   - $10$：负溢出（下溢）。

## 题型 5：十进制数转 IEEE 754 单精度浮点数
### 5.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.1 数值数据编码的表示方法 → (6) IEEE 754浮点数表示标准
1. **十转二**：分别处理整数和小数部分（除2取余与乘2取整）。
2. **移动小数点**：将其化为 $1.M \times 2^{E_{\text{真实}}}$ 的标准形式。
3. **确定S**：正数填 $0$，负数填 $1$。
4. **算阶码E**：$E = E_{\text{真实}} + 127$，将结果化为 8 位二进制。
5. **填尾数M**：将小数点后的部分填入 23 位，不足在右侧补 $0$，超出则舍入。
6. **转十六进制**：按 4 位一组拼接为十六进制数（注意加 H 结尾）。

## 题型 6：IEEE 754 单精度浮点数机器码求真值（逆向题）
### 6.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.1 数值数据编码的表示方法 → (6) IEEE 754浮点数表示标准
1. **展开二进制**：将十六进制数展开为 32 位二进制。
2. **切分字段**：提取第31位(S)，第30~23位(E)，第22~0位(M)。
3. **恢复指数**：真实指数 = $E(\text{二进制转十进制}) - 127$。
4. **还原尾数**：在 M 前补上隐藏的 $1.$，即得到 $(1.M)_2$。
5. **公式计算**：真值 = $(-1)^S \times (1.M)_2 \times 2^{E-127}$，最后转为十进制。

## 题型 7：浮点数规格化、对阶运算与加减法
### 7.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.1 数值数据编码的表示方法 → 浮点数规格化 / 溢出问题 / IEEE 754标准
1. **规格化判定**：
   - 单符号位补码尾数：正数为 $0.1\times\times\ldots\times$ 的形式，负数为 $1.0\times\times\ldots\times$ 的形式。
   - 双符号位变形补码运算时：正数为 $00.1\times\times\ldots\times$ 的形式，负数为 $11.0\times\times\ldots\times$ 的形式。
2. **对阶操作**：比较两数阶码，**小阶向大阶看齐**。阶小的尾数算术右移，阶码加 $1$，直到两阶码相等。
3. **尾数加减**：使用双符号位补码进行加法；减法转为加 $[-y]_{\text{补}}$。
4. **结果规格化**：
   - **右规**：若双符号位为 $01$（正溢）或 $10$（负溢），尾数右移1位，阶码加 $1$。
   - **左规**：若结果为 $00.0\ldots$ 或 $11.1\ldots$，尾数连同符号位一起左移，阶码减 $1$，直到出现 $00.1$ 或 $11.0$。
5. **舍入**：对阶或右规时移出的低位按规则（0舍1入或恒置1）处理。
6. **溢出判断**：最终检查规格化后的阶码双符号位。$00/11$ 正常，$01$ 上溢，$10$ 下溢。
7. **IEEE 754 加减**：先分别转32位格式（注意隐含位 $1.$），对阶时尾数连同隐含位一起右移，运算后重新规格化并调整阶码。

## 题型 8：海明校验码的编码与单比特纠错
### 8.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.3 信息的抗干扰编码 → 2.6.2 海明校验码
1. 利用 $2^k \ge n + k + 1$ 算出校验位数 $k$，画出 $1$ 到 $n+k$ 的位序表。
2. 将 $P_1, P_2, P_3\ldots$ 填入 $2^{i-1}$（即 $1, 2, 4, 8\ldots$）的位置，数据位按序填入空位。
3. 将数据位的位号写成二进制（如 $H_3 = 2^1 + 2^0$），判定其归属于哪些校验位负责。
4. 利用偶校验（异或为0）求出各校验位的值。
5. 纠错时：代入收到的码字计算指错字 $S_4S_3S_2S_1$。其二进制对应的十进制数即为出错的位序，取反即可纠正。

## 题型 9：循环冗余校验码（CRC）计算与纠错
### 9.1 解题算法（步骤）
- **对应PPT章节**：第2章 2.1.3 信息的抗干扰编码 → 2.6.3 循环冗余校验码
1. 根据生成多项式 $G(x)$ 确定最高阶数 $r$，在原信息码后补 $r$ 个 $0$。
2. 使用**模2除法**（即每一步只做异或，不产生借位和进位）求出 $r$ 位余数。
3. 把余数替换掉原本补的 $0$，得到 CRC 码。
4. 校验时用收到的码字再模2除以 $G(x)$，若余数为 $0$ 则无错；若不为 $0$，根据余数图谱（循环特性）定位出错位。
