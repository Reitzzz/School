# 计算机数据表示与运算（做题笔记/题型攻略）

## 题型 1：简答理论题归纳
### 1.1 经典问题：为什么计算机采用二进制？
- **答题卡点**：物理器件易实现；算术逻辑运算规则简单；抗干扰、可靠性高。
### 1.2 经典问题：浮点数的范围和精度由什么决定？
- **答题卡点**：范围由**阶码位数**决定；精度由**尾数位数**决定。

## 题型 2：定点补码加减法与溢出判断
### 2.1 解题算法（步骤）
1. 将真值转换为双符号位（变形补码）形式。
2. 若为减法，利用连同符号位在内“各位取反，末位加1”求出 [-Y]_补。
3. 执行补码加法。
4. 观察结果符号位：`01` 报正溢出，`10` 报负溢出，`00/11` 无溢出。

## 题型 3：十进制数转 IEEE 754 单精度浮点数
### 3.1 解题算法（步骤）
1. **十转二**：分别处理整数和小数部分（除2取余与乘2取整）。
2. **移动小数点**：将其化为 1.M * 2^E_真实 的标准形式。
3. **确定S**：正数填 `0`，负数填 `1`。
4. **算阶码E**：E = E_{真实} + 127，将结果化为 8 位二进制。
5. **填尾数M**：将小数点后的部分填入 23 位，不足在右侧补 `0`。
6. **转十六进制**：按 4 位一组拼接为十六进制数（注意加 H 结尾）。
### 3.2 典型例题精选
- *[填入：求与十进制数 408.6875 对应的十六进制机器码过程]*

## 题型 4：IEEE 754 单精度浮点数机器码求真值（逆向题）
### 4.1 解题算法（步骤）
1. **展开二进制**：将十六进制数展开为 32 位二进制。
2. **切分字段**：提取第31位(S)，第30~23位(E)，第22~0位(M)。
3. **恢复指数**：真实指数 = E_{二进制} - 127。
4. **还原尾数**：在 M 前补上隐藏的 `1.`，即得到 (1.M)_2。
5. **公式计算**：真值 = (-1)^S * (1.M)_2 * 2^(E-127)，最后转为十进制。
### 4.2 典型例题精选
- *[填入：求单精度浮点数 43940000H 对应的十进制数过程]*

## 题型 5：海明校验码的编码与单比特纠错
### 5.1 解题算法（步骤）
1. 利用 2^k >= n + k + 1 算出校验位数，画出 1 到 n+k 的位序表。
2. 将 P1, P2, P3... 填入 1, 2, 4, 8... 的位置，数据位按序填入空位。
3. 将数据位的位号写成二进制（如 H3 = 2^1 + 2^0），判定其归属于哪些校验位负责。
4. 利用偶校验（异或为0）求出各校验位的值。
5. 纠错时：代入收到的码字计算指错字 S4S3S2S1。其二进制对应的十进制数即为出错的位序，取反即可纠正。
### 5.2 典型例题精选
- *[填入：8位有效信息 01101110 编码及变异为 01101111 后的纠错定位题]*

## 题型 6：循环冗余校验码（CRC）计算与纠错
### 6.1 解题算法（步骤）
1. 根据生成多项式 G(x) 确定最高阶数 r，在原信息码后补 r 个 `0`。
2. 使用**模2除法**（即每一步只做异或，不产生借位和进位）求出 r 位余数。
3. 把余数替换掉原本补的 `0`，得到 CRC 码。
4. 校验时用收到的码字再模2除以 G(x)，若余数为 `0` 则无错；若不为 `0`，根据余数图谱定位出错位。
### 6.2 典型例题精选
- *[填入：x=1001, G(x)=1101 时计算冗余码及x'=1101时的纠错过程]*

## 题型 7：C语言数据类型转换与真值变化分析
### 7.1 解题算法（判定规则）
1. **纯整型转换（关注字长变化）**：
   - **字长不变**（如 `char` -> `unsigned char`）：直接写出原数的 8 位补码机器码。强制转换后机器码完全不动，直接按无符号数的二进制权值重新计算真值。
   - **短字长转长字长**（如 `short` -> `int`）：
     - 若原数是 `unsigned`：高位一律补 `0`。转换后真值绝对不变。
     - 若原数是有符号数：高位一律补原符号位（正补0，负补1）。转换后真值绝对不变。
   - **长字长转短字长**（如 `int` -> `short`）：直接把高位砍掉，只保留低位对应的短字长位数。再看新类型是有符号还是无符号，重新解析低位真值（极易报错）。
2. **混合类型转换（int/float/double 互转）**：
   - 安全无损判定（满足“小容量”向“大精度容量”看齐）：`int` -> `double`（安全）、`float` -> `double`（安全）。
   - 砍掉小数判定：`float/double` -> `int`，无条件抹去小数点后所有数字，若整数部分超出了 int 范围 [-2^31, 2^31-1]，则直接报错溢出。
   - 精度丢失（大数变异）判定：`int` -> `float`。检查整型变量的值，若真值绝对值大于 2^24（即 16777216），其机器码高8位非0，强制转为 float 时低位会被舍入，导致精度丢失。
### 7.2 典型例题精选
- **例题 1**：若 `char x = -1;` 强制转换为 `unsigned char y;`，求 y 的真值。
  - *解析*：x 的真值为 -1，机器补码为 `11111111`。强制转为无符号后，机器码不变。`11111111` 以无符号解析即为 2^7 + 2^6 + ... + 2^0 = 255。
- **例题 2**：为什么 32 位 int 转 float 会丢失精度，而转 double 不会？
  - *解析*：float 尾数部分总共只有 24 位（含 1 位隐含位），无法精准平移并容纳占满 32 位空间的 int 整数，若 int 超过 24 位有效值则必须舍入。而 double 的尾数空间有 53 位，大于 32 位，可以做到完全无损的精准转换。
