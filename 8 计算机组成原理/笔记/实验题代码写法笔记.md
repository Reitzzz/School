# 计算机组成原理实验 1-5 题代码写法笔记

资料来源：`实验` 文件夹中的题干照片、参考机器码图片/视频，以及 `DICE-CP226实验指导书20140926.pdf` 第 3.3 节模型机指令集、第 4 章模型机综合实验。

## 一、先记住这台模型机怎么写程序

CP226 模型机是 8 位机。实验里写的程序本质上是“汇编助记符 -> 机器码 -> 写入 EM 程序存储器”。

常用寄存器/端口：

| 名称 | 作用 |
| --- | --- |
| A | 累加器，大部分运算都围绕 A 做 |
| IN | 输入端口，拨动开关的输入值从这里读入 |
| OUT | 输出端口，A 的值送到灯/数码管显示 |
| PC | 程序计数器，指向下一条机器码地址 |
| EM | 程序存储器，实验时按地址写机器码 |

常用指令机器码：

| 汇编指令        | 机器码     | 字节数 | 含义              |
| ----------- | ------- | --- | --------------- |
| `IN`        | `C0`    | 1   | 从输入端口读入到 A      |
| `OUT`       | `C4`    | 1   | 把 A 输出到 OUT     |
| `ADD A,#II` | `1C II` | 2   | A 加立即数 II       |
| `SUB A,#II` | `3C II` | 2   | A 减立即数 II       |
| `MOV A,#II` | `7C II` | 2   | 把立即数 II 送入 A    |
| `JZ MM`     | `A4 MM` | 2   | 若零标志 Z=1，跳转到 MM |
| `JMP MM`    | `AC MM` | 2   | 无条件跳转到 MM       |
| `RL A`      | `D4`    | 1   | A 左移一位          |
| `RR A`      | `D0`    | 1   | A 右移一位          |
| `CPL A`     | `E4`    | 1   | A 按位取反          |

写代码时按这个顺序想：

1. 先写清楚“每一轮循环要让 A 变成什么”。
2. 需要显示就写 `OUT`。
3. 需要变化就写 `ADD`、`SUB`、`RL`、`RR`、`CPL`。
4. 需要重复就用 `JMP` 跳回循环开始地址。
5. 需要判断是否到头，就用 `JZ`。`JZ` 判断的是上一条运算/移位后 A 是否为 `00H`。
6. 最后按每条指令字节数重新算地址，跳转地址必须写对。

## 第 1 题：输入一个数，输出这个数加 1

题干：拨动输入开关，任意输入一个数，显示输出这个数加 1 的结果。

思路：

1. `IN` 把开关输入读到 A。
2. `ADD A,#01H` 让 A 加 1。
3. `OUT` 输出。
4. `JMP 00H` 回到开头00对应的操作(即IN)，不断读取新输入。

汇编写法：

```asm
START:
    IN
    ADD A,#01H
    OUT
    JMP 00H
END
```

机器码：

| 地址 | 机器码 | 对应汇编 |
| --- | --- | --- |
| `00` | `C0` | `IN` |
| `01` | `1C` | `ADD A,#01H` |
| `02` | `01` | 立即数 `01H` |
| `03` | `C4` | `OUT` |
| `04` | `AC` | `JMP 00H` |
| `05` | `00` | 跳转地址 `00H` |

顺序输入机器码：

```text
C0 1C 01 C4 AC 00
```

## 第 2 题：用灯的亮起顺序表示 1,2,3,4,5,6,7,...,127...

题干：用灯的亮起顺序表征 `1,2,3,4,5,6,7,...,127...`。

思路：

1. 先让 A=`01H`。
2. 输出 A。
3. A 加 1。
4. 跳回输出位置。

这里不是“单个灯移动”，而是把 A 当作普通二进制数字显示：`01H, 02H, 03H, ...`。

汇编写法：

```asm
    MOV A,#01H
LOOP:
    OUT
    ADD A,#01H
    JMP LOOP
END
```

机器码：

| 地址   | 机器码  | 对应汇编       |
| ---- | ---- | ---------- |
| `00` | `7C` | `MOV A,`   |
| `01` | `01` | 立即数 `01H`  |
| `02` | `C4` | `OUT`      |
| `03` | `1C` | `ADD A,`   |
| `04` | `01` | 立即数 `01H`  |
| `05` | `AC` | `JMP `     |
| `06` | `02` | 跳转地址 `02H` |

顺序输入机器码：

```text
7C 01 C4 1C 01 AC 02
```

关键点：`JMP` 要跳到 `02H`，因为 `02H` 是 `OUT` 的地址。这样每次加完 1 后都会重新输出。

## 第 3 题：单灯来回效果

效果：一个亮灯从低位向高位移动，到头后再从高位往低位回来。

思路：

1. 先令 A=`01H`，输出最低位灯。
2. 循环左移：`01 -> 02 -> 04 -> 08 -> 10 -> 20 -> 40 -> 80`。
3. 当 `80H` 再左移会变成 `00H`，`JZ` 检测到零后切换到右移段。
4. 右移段从 `40H` 开始，避免 `80H` 连续显示两次。
5. 右移到 `01H` 后再右移会变成 `00H`，`JZ 00H` 回到开头。

汇编写法：

```asm
    MOV A,#01H
LEFT:
    OUT
    RL A
    JZ RIGHT_INIT
    JMP LEFT

RIGHT_INIT:
    MOV A,#40H
RIGHT:
    OUT
    RR A
    JZ 00H
    JMP RIGHT
END
```

机器码：

| 地址   | 机器码  | 对应汇编         |
| ---- | ---- | ------------ |
| `00` | `7C` | `MOV A,`     |
| `01` | `01` | 立即数 `01H`    |
| `02` | `C4` | `OUT`        |
| `03` | `D4` | `RL A`       |
| `04` | `A4` | `JZ 08H`     |
| `05` | `08` | 跳转地址 `08H`   |
| `06` | `AC` | `JMP 02H`    |
| `07` | `02` | 跳转地址 `02H`   |
| `08` | `7C` | `MOV A,#40H` |
| `09` | `40` | 立即数 `40H`    |
| `0A` | `C4` | `OUT`        |
| `0B` | `D0` | `RR A`       |
| `0C` | `A4` | `JZ 00H`     |
| `0D` | `00` | 跳转地址 `00H`   |
| `0E` | `AC` | `JMP 0AH`    |
| `0F` | `0A` | 跳转地址 `0AH`   |

顺序输入机器码：

```text
7C 01 C4 D4 A4 08 AC 02 7C 40 C4 D0 A4 00 AC 0A
```

地址最容易错的地方：

| 跳转 | 为什么这样跳 |
| --- | --- |
| `JZ 08H` | 左移溢出为 `00H` 后，跳到右移初始化 `MOV A,#40H` |
| `JMP 02H` | 左移还没到头，回到 `OUT` 继续显示 |
| `JZ 00H` | 右移到 `00H` 后，重新从 `01H` 开始 |
| `JMP 0AH` | 右移还没到头，回到右移段的 `OUT` |

## 第 4 题：先全亮，再全灭，再循环

参考代码效果：先从 `00H` 开始，逐步变成 `01H, 03H, 07H, 0FH, ... FFH`，表现为灯逐个亮起直到全亮；然后从 `FEH, FCH, F8H, ... 80H, 00H`，表现为灯逐个熄灭直到全灭；最后回到开头循环。

思路拆开看：

第一段，逐个点亮：

1. A 初始为 `00H`，先输出全灭。
2. 每轮先判断 `A+1` 是否变成 `00H`。
3. 如果不是 `00H`(FFH+01H=00H)，恢复原值，再 `RL A` 左移，最后 `ADD A,#01H` 把最低位补成 1。
4. 所以序列是 `00 -> 01 -> 03 -> 07 -> 0F -> 1F -> 3F -> 7F -> FF`。

第二段，逐个熄灭：

1. 当 `FFH + 01H = 00H` 时，`JZ` 跳到第二段。
2. 此时`A=00H`，`CPL A` 把 `00H` 取反成 `FFH`。
3. `RL A` 变成 `FEH`，输出。
4. 继续左移：`FE -> FC -> F8 -> F0 -> E0 -> C0 -> 80 -> 00`。
5. 当输出/移位后检测到 `00H`，跳回开头。

汇编写法：

```asm
    MOV A,#00H
LIGHT_LOOP:
    OUT
    ADD A,#01H
    JZ DARK_INIT
    SUB A,#01H
    RL A
    ADD A,#01H
    JMP LIGHT_LOOP

DARK_INIT:
    CPL A
DARK_LOOP:
    RL A
    OUT
    JZ 00H
    JMP DARK_LOOP
END
```

机器码：

| 地址   | 机器码  | 对应汇编       |
| ---- | ---- | ---------- |
| `00` | `7C` | `MOV A,`   |
| `01` | `00` | 立即数 `00H`  |
| `02` | `C4` | `OUT`      |
| `03` | `1C` | `ADD A,`   |
| `04` | `01` | 立即数 `01H`  |
| `05` | `A4` | `JZ `      |
| `06` | `0E` | 跳转地址 `0EH` |
| `07` | `3C` | `SUB A,`   |
| `08` | `01` | 立即数 `01H`  |
| `09` | `D4` | `RL A`     |
| `0A` | `1C` | `ADD A,`   |
| `0B` | `01` | 立即数 `01H`  |
| `0C` | `AC` | `JMP `     |
| `0D` | `02` | 跳转地址 `02H` |
| `0E` | `E4` | `CPL A`    |
| `0F` | `D4` | `RL A`     |
| `10` | `C4` | `OUT`      |
| `11` | `A4` | `JZ `      |
| `12` | `00` | 跳转地址 `00H` |
| `13` | `AC` | `JMP `     |
| `14` | `0F` | 跳转地址 `0FH` |

顺序输入机器码：

```text
7C 00 C4 1C 01 A4 0E 3C 01 D4 1C 01 AC 02 E4 D4 C4 A4 00 AC 0F
```

这题最绕的地方是第一段为什么要 `ADD` 后又 `SUB`：

- `ADD A,#01H` 是为了检测 A 是否已经是 `FFH`。如果 A 是 `FFH`，加 1 后变成 `00H`，零标志置 1，跳到熄灭段。
- 如果还没到 `FFH`，就 `SUB A,#01H` 恢复原来的 A，再用 `RL A` 和 `ADD A,#01H` 生成“低位连续为 1”的灯型。

## 第 5 题：计算 `1+2+3+...+100`

题干：编程计算 `1+2+3+...+100`，并输出结果。

这题先记结果：

```text
1+2+3+...+100 = 5050D = 13BAH
```

因为结果超过 8 位，所以用两个寄存器存结果：

| 寄存器 | 用来干什么 |
| --- | --- |
| `R0` | 当前要加的数，从 `64H` 倒着减到 `00H` |
| `R1` | 结果的低 8 位，最后是 `BAH` |
| `R2` | 结果的高 8 位，最后是 `13H` |

最简单的想法：

1. `R0` 从 `64H` 开始，也就是从 100 开始加。
2. 每轮把 `R0` 加到 `R1` 里。
3. 如果 `R1` 加爆了，就把进位加到 `R2` 里。
4. 每轮最后让 `R0` 减 1。
5. 减到 `00H` 就说明 `100+99+...+1` 已经加完了。

汇编写法：

```asm
    MOV R0,#64H      ; R0 从 100 开始
    MOV R1,#00H      ; R1 存低字节
    MOV R2,#00H      ; R2 存高字节

LOOP:
    MOV A,R1         ; 低字节R1加 R0
    ADD A,R0
    MOV R1,A

    MOV A,R2         ; R1有进位就加到高字节R2
    ADDC A,#00H
    MOV R2,A

    MOV A,R0         ; R0 = R0 - 1
    SUB A,#01H
    MOV R0,A
    JZ RESULT        ; 判断上一条运算的结果，即R0=R0-1的结果是否为0 如果是则跳转RESULT
    JMP LOOP

RESULT:
    MOV A,R2         ; 先输出 13H
    OUT
    MOV A,R1         ; 再输出 BAH
    OUT
    JMP RESULT       ; 告诉程序在这里写完了 保持输出结果
END
```

机器码地址表：

| 地址 | 机器码 | 对应汇编 |
| --- | --- | --- |
| `00` | `8C` | `MOV R0,#64H` |
| `01` | `64` | 立即数 `64H` |
| `02` | `8D` | `MOV R1,#00H` |
| `03` | `00` | 立即数 `00H` |
| `04` | `8E` | `MOV R2,#00H` |
| `05` | `00` | 立即数 `00H` |
| `06` | `71` | `MOV A,R1` |
| `07` | `10` | `ADD A,R0` |
| `08` | `81` | `MOV R1,A` |
| `09` | `72` | `MOV A,R2` |
| `0A` | `2C` | `ADDC A,#00H` |
| `0B` | `00` | 立即数 `00H` |
| `0C` | `82` | `MOV R2,A` |
| `0D` | `70` | `MOV A,R0` |
| `0E` | `3C` | `SUB A,#01H` |
| `0F` | `01` | 立即数 `01H` |
| `10` | `80` | `MOV R0,A` |
| `11` | `A4` | `JZ RESULT` |
| `12` | `15` | 跳转地址 `15H` |
| `13` | `AC` | `JMP LOOP` |
| `14` | `06` | 跳转地址 `06H` |
| `15` | `72` | `MOV A,R2` |
| `16` | `C4` | `OUT`，输出高字节 `13H` |
| `17` | `71` | `MOV A,R1` |
| `18` | `C4` | `OUT`，输出低字节 `BAH` |
| `19` | `AC` | `JMP RESULT` |
| `1A` | `15` | 跳转地址 `15H` |

顺序输入机器码：

```text
8C 64 8D 00 8E 00 71 10 81 72 2C 00 82 70 3C 01 80 A4 15 AC 06 72 C4 71 C4 AC 15
```

只要记住这几个点：

| 问题 | 解释 |
| --- | --- |
| 为什么不用 A 直接加？ | A 只有 8 位，放不下 `13BAH`。 |
| `R1`、`R2` 怎么看？ | `R2:R1 = 13BAH`，高字节在前，低字节在后。 |
| `ADDC A,#00H` 是干什么？ | 把低字节加法产生的进位补到高字节。 |
| 为什么从 `64H` 开始？ | `64H` 就是十进制 100，倒着加可以少写几条代码。 |
| 为什么输出两次？ | `OUT` 一次只能输出 1 个字节，所以先看 `13H`，再看 `BAH`。 |

## 六、背题技巧

第 1 题记成：读入、加一、输出、回头。

```text
C0 1C 01 C4 AC 00
```

第 2 题记成：从 1 开始，输出、加一、回到输出。

```text
7C 01 C4 1C 01 AC 02
```

第 3 题记成：左移到零，改从 `40H` 右移；右移到零，回开头。

```text
7C 01 C4 D4 A4 08 AC 02 7C 40 C4 D0 A4 00 AC 0A
```

第 4 题记成：先造 `01/03/07/.../FF`，再造 `FE/FC/.../00`。

```text
7C 00 C4 1C 01 A4 0E 3C 01 D4 1C 01 AC 02 E4 D4 C4 A4 00 AC 0F
```

第 5 题记成：`R0` 从 `64H` 往下减，`R1` 存低位，`R2` 存高位；低位加爆就用 `ADDC` 补到高位。

```text
8C 64 8D 00 8E 00 71 10 81 72 2C 00 82 70 3C 01 80 A4 15 AC 06 72 C4 71 C4 AC 15
```
