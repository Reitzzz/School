## 四、简答题参考答案

1. 存储层次结构利用局部性原理，把容量小、速度快、价格高的存储器放在上层，把容量大、速度慢、价格低的存储器放在下层。Cache 位于 CPU 与主存之间，主要解决速度不匹配问题；虚拟存储器位于主存与辅存层次，主要解决主存容量不足问题。

2. SRAM 用双稳态触发器保存信息，不需要刷新，速度快、容量小、价格高，常用于 Cache。DRAM 用电容电荷保存信息，需要周期性刷新，速度较慢、容量大、价格低，常用于主存。

3. 直接寻址：EA=D，操作数在主存地址 D 中。间接寻址：EA=(D)，D 中存放的是操作数地址。寄存器寻址：操作数在指令指定的寄存器中，不需访存取数。寄存器间接寻址：EA=(R)，寄存器中存放操作数所在主存地址。

4. 硬布线控制器用门电路、触发器和组合逻辑，根据指令译码、时序和状态直接产生控制信号，速度快但设计和修改困难。微程序控制器把控制信号序列编成微指令并存放在控制存储器中，执行机器指令时读取相应微程序，设计规整、易修改，但速度通常较慢。

5. 一般过程包括：PC 给出指令地址，访问主存取出指令；指令进入 IR；ID 对操作码和地址字段译码；CU 根据译码结果、状态和时序发出控制信号；数据在寄存器、ALU、主存之间传送并完成执行。PC 保存下一条指令地址，IR 保存当前指令，ID 负责译码，CU 负责产生控制信号。

## 五、计算题参考答案

1.  
   （1）512KB = 512 × 1024B = 2^19B，按字节编址，至少需要 19 根地址线。  
   （2）1KB = 1024B，数据总线 16 位 = 2B，一次传 2B，至少需要 1024 / 2 = 512 次。

2.  
   +72 的 8 位补码为 `0100 1000`，+65 的 8 位补码为 `0100 0001`。  
   相加：
   ```text
     0100 1000
   + 0100 0001
   = 1000 1001
   ```
   两个正数相加结果符号位为 1，发生正溢出。真实和为 137，超过 8 位补码最大值 +127。

3.  
   平均访问时间：
   ```text
   T = H × t_c + (1-H) × (t_c + t_m)
     = 0.9 × 10 + 0.1 × (10 + 100)
     = 9 + 11
     = 20ns
   ```
   所以平均访问时间为 20ns。

4.  
   （1）48 条指令需要操作码位数：2^5=32 不够，2^6=64 够，因此 OP 至少 6 位。  
   （2）4 种寻址方式需要 2 位。  
   （3）地址码字段剩余：16 - 6 - 2 = 8 位。  
   （4）直接寻址最多可寻址 2^8 = 256 个单元。

## 六、图题参考答案

1. AB 为地址总线，传送主存地址或 I/O 地址；DB 为数据总线，传送数据或指令内容；CB 为控制总线，传送读/写、片选、时序、允许等控制信号。

2. 取指主要数据流可写为：
   ```text
   PC → AR/MAR → 地址总线 AB → 主存
   主存 → MDR/DR → 数据总线 DB → IR/ID
   ```
   同时 PC 通常更新为下一条指令地址。

3. CU 根据指令译码结果、状态标志和时序信号产生微操作控制信号；TU 产生机器周期、节拍或时钟相关时序，限定控制信号在正确时间有效；ID 对当前指令的操作码和相关字段译码，为 CU 判断要执行的操作提供输入。

4. `ADD R0,[D]` 的大致数据流：
   ```text
   D → MAR/AB → 主存 → MDR/DR/DB → ALU 输入
   R0 → ALU 输入
   ALU 加法结果 → DB/内部总线 → R0
   ```
   控制器在各节拍发出访存读、寄存器输出/输入、ALU 加法、写回等控制信号。
