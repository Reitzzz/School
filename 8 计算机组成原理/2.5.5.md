# 计算机组成原理：计算机内部的数据表示与类型转换

## 一、 计算机中的数据类型

*   **底层存储**：计算机中的数据以二进制的形式存储在寄存器或存储器中。
*   **汇编语言层面**：存储在寄存器、存储器中的操作数本身**没有数据类型**。对其进行何种操作完全**取决于指令的操作码**。同一个操作数，既可以当作有符号数，也可以当作无符号数；既可以是定点数，也可以是浮点数。
*   **高级语言层面（以C语言为例）**：
    *   **整型数据**：
        *   `char` (8位)
        *   `short` (16位)
        *   `int` (32位)
        *   `long` (64位)
        *   *注：默认表示有符号整数，前面加上 `unsigned` 表示无符号数。*
    *   **浮点型数据**：
        *   `float`：对应 IEEE 754 单精度（32位）浮点数标准。
        *   `double`：对应 IEEE 754 双精度（64位）浮点数标准。

## 二、 C语言中整型变量的取值范围

不同类型的整型变量取值范围不同，核心取决于其位数和是否有符号。
以 8位 `char` 型为例：
*   `unsigned char`：机器码从 00000000 到 11111111，真值范围是 **0 ~ 255** (即 2^8 - 1)。
*   `char` (有符号补码)：机器码从 10000000 到 01111111，真值范围是 **-128 ~ 127** (即 -2^7 到 2^7 - 1)。

**重要提醒**：无论是无符号数还是有符号数，C语言程序**并不检测**数据在加、减、乘等运算中产生的**溢出**现象。程序员应尽量避免，并在应用程序中加入对溢出进行判断的功能。

## 三、 C语言中数据类型转换

C语言中不同类型的数据可以互相进行**强制类型转换**。
**基本转换原则**：尽量保持数的真值不变。

### 1. 整型数据之间的转换

整型数据转换时，由于表示范围不一样，可能出现精度缺失，此时只能尽量保持转换前后的机器码相同或部分相同。

*   **相同字长之间的转换** (例如 `char` ↔ `unsigned char`)
    *   **规则**：机器码保持不变，仅改变将其当作有符号位还是无符号位来解释。
    *   **结果**：
        *   两种整型数据交集部分相互转换：无差错（原值不变）。
        *   交集以外相互转换：有差错（例如负数转无符号数会加上 2^n，无符号大数转有符号数会变成负数）。

*   **小字长转大字长** (例如 `char` -> `short`)
    *   **原数据为无符号类型**：进行 **0扩展**（高位全部补0）。
    *   **原数据为有符号类型**：进行 **符号扩展**（高位全部补符号位）。
    *   **结果**：转换后的数据与原数值完全相同，无差错。

*   **大字长转小字长** (例如 `int` -> `short`)
    *   **规则**：编译器会将机器码进行**截短处理**（直接丢弃高位字长）。
    *   **结果**：表示范围缩小，大概率导致转换后的数据与原值不同，很可能出错。

### 2. int、float、double 之间的转换

`int`、`float`、`double` 的机器码并不相同（int 是补码；float/double 的阶码是移码，尾数是原码），表示范围和精度也不相同。因此在转换过程中编译器**只能保证数值尽量相等，大多数情况下只是近似值**。

各类转换情况总结如下：

*   **float → double**
    *   **结果**：**值相同**。
    *   **原因**：由于 double 型数据的阶码和尾数的位数都比 float 型大，精度更高，表示范围更大，因此转换后的 double 型数据与原 float 型数据的值完全相等。
*   **double → float**
    *   **大数转换**：可能发生**溢出**（超出 float 能表示的最大范围）。
    *   **高精度数转换**：发生**舍入**（丢失 double 特有的尾数低位精度）。
*   **float / double → int**
    *   **小数部分**：向 0 方向**截断**（直接舍弃小数部分）。
    *   **大数转换**：可能发生**溢出**。
*   **int → float**
    *   **结果**：**比较大的数无法精确表示**。
    *   **原因**：两种类型虽然都是32位，状态数量相同，但在数轴上表示的数据并不完全重叠。float 型浮点数的尾数包括隐藏位在内共 24 位。当 int 型数据的高 8 位（24~31位）数据为非 0 时，无法精确转换成 24 位浮点数的尾数，此时会发生**精度溢出**。
*   **int → double**
    *   **结果**：**值相同**。
    *   **原因**：double 型数据的尾数包含隐藏位在内有 53 位，可以完全且精确地表示所有 32 位的 int 整数。
